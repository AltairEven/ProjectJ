# Project J

文档版本：1.14.0；创建：2026年10月11日；更新：2026年10月12日。J 的灵感来自家长指定的《安德的游戏》中的 AI 智能体 Jane。

J是家长主导和陪伴的家庭AI学习工作台，以唯一教师Jane串起学习规划、备课、课堂、评价与下一课调整。八个模块各自维护业务对象，应用协调层组织完整用例；课堂核心保持教学状态和动作边界，模型在核实课程范围内理解并调整指导。

## 设计入口

- [架构和模块目录](design/README.md)：八模块、应用协调层及家长/学生/AI流程。
- [共同规范](design/shared/README.md)：规范权威、当前阶段、真实数据权威与新旧设计关系。
- [应用协调层](design/application/README.md)：备课、开课、结束封存、反馈、更正、复盘及失败接续。
- [完整时序与异常案例](design/shared/end-to-end-cases.md)：E2E01逐步对象链和19个未来验收案例。
- [最小可用版本](docs/mvp.md)、[技术选型](docs/technology.md)、[分阶段实现计划](docs/roadmap.md)：已采用的首版范围、实施基线与阶段关卡。
- [产品范围](docs/product.md)、[验收标准](docs/acceptance.md)：质量门槛与进入儿童试教的前提。

目标设计采用课堂结束时封存已取得事实，家长当时或稍后追加反馈；事实保存、评价和计划更新分别显示。规则及失败边界只在[共同执行](design/shared/execution-recovery.md)维护，本次决定见[ADR-0010](decisions/ADR-0010.md)。

## 实施状态

0.1成人实验原型已删除（[ADR-0012](decisions/ADR-0012.md)），历史代码与验证记录只读查阅本地Git标签prototype-0.1。P0已细化业务合同并建立[独立工程检查](project_j/README.md)、项目级Python/Node依赖锁和模拟参考数据，交付[待Opus审查](docs/handoff.md)。目前没有可运行应用，也没有实际API或声音接入通过的证据；阶段1待家长确认。

## 目录

| 目录 | 用途 |
| --- | --- |
| design/ | 按八个大模块保存目标应用设计，含八个业务模块与shared横向合同/执行/案例，当前工作的主要入口 |
| docs/ | 产品说明、最小版本、技术选型、开发路线、验收、开发交接记录和旧项目关系 |
| decisions/ | 应用的重要技术与产品决定 |
| courses/ | 结构化课程与版本绑定材料；不保存学习表现 |
| project_j/ | 全部工程文件（代码、依赖与构建配置、测试、工程脚本），不同语言按需分子目录；阶段0起建立 |

目标应用的数据权威与接入范围见[共同入口](design/shared/README.md)。课程是计划，运行事件是当次事实来源，课后评价是带依据的解释，三者不互相替代。

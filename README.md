# Project J

文档版本：1.19.0；创建：2026年10月11日；更新：2026年10月20日。J 的灵感来自《安德的游戏》中的 AI 智能体 Jane。

J是AI自学助理（[ADR-0018](decisions/ADR-0018.md)）：学生在一个主页面上建档、确认学习目标、上课并认可课后评价，AI教师Jane串起学习规划、备课、课堂、评价与下一课调整。程序只有“学生”一个身份，不预设学生是孩子还是成人。八个模块各自维护业务对象，应用协调层组织完整用例；课堂核心保持教学状态和动作边界，模型在核实课程范围内理解并调整指导。

- [最小可用版本](docs/mvp.md)、[技术选型](docs/technology.md)、[分阶段实现计划](docs/roadmap.md)：已采用的首版范围、实施基线与阶段关卡。
- [产品范围](docs/product.md)、[验收标准](docs/acceptance.md)：产品定位与质量门槛。

课堂结束时封存已取得事实，随后自动评价，学生可补记或提出异议；事实保存、评价和计划更新分别显示。规则及失败边界只在[共同执行](design/shared/execution-recovery.md)维护，本次决定见[ADR-0010](decisions/ADR-0010.md)。

## 实施状态

0.1成人实验原型已删除（[ADR-0012](decisions/ADR-0012.md)），历史代码只读查阅本地Git标签prototype-0.1。[本机应用](project_j/README.md)已有模拟与真实两种提供者：备课、教学资源、课堂、本机发音评分与合成、课后评价、学习规划与复盘均已接真实模型并有隔离检查与成人调试记录（见[交接](docs/handoff.md)）。2026年10月20日定位改为AI自学助理（[ADR-0018](decisions/ADR-0018.md)），按[实施计划](docs/superpowers/plans/2026-10-20-self-study-assistant.md)改为单一主页面（左侧导航、主页只给一件下一步、全屏课堂）、建档与正式学习空间，后台任务由AI自动推进；教学效果与长期使用未验证。GPT与Opus按[共建规则](AGENTS.md#共建协作)分工、自测和交接。

## 目录

| 目录 | 用途 |
| --- | --- |
| design/ | 按八个大模块保存目标应用设计，含八个业务模块与shared横向合同/执行/案例，当前工作的主要入口 |
| docs/ | 产品说明、最小版本、技术选型、开发路线、验收、开发交接记录和旧项目关系 |
| decisions/ | 应用的重要技术与产品决定 |
| courses/ | 结构化课程与版本绑定材料；不保存学习表现 |
| project_j/ | 全部工程文件（代码、依赖与构建配置、测试、工程脚本），不同语言按需分子目录；阶段0起建立 |

目标应用的数据权威与接入范围见[共同入口](design/shared/README.md)。课程是计划，运行事件是当次事实来源，课后评价是带依据的解释，三者不互相替代。

# Project J

文档版本：1.11.0；原型版本：0.1.0；创建：2026年10月11日；更新：2026年10月12日。J 的灵感来自家长指定的《安德的游戏》中的 AI 智能体 Jane。

J是家长主导和陪伴的家庭AI学习工作台，以唯一教师Jane串起学习规划、备课、课堂、评价与下一课调整。八个模块各自维护业务对象，应用协调层组织完整用例；课堂核心保持教学状态和动作边界，模型在核实课程范围内理解并调整指导。

## 现有成人实验原型

以下启动、功能和目录说明专指现有0.1原型，仍使用原先的反馈后保存流程；本轮未修改其代码，也未实现上述新机制。当前阶段和正式入口状态以共同规范及实际验收为准。

## 本地启动

需要 Python 3.9及以上；应用没有第三方运行依赖。

~~~sh
cd /Users/altair/Documents/Altair/课程/J
python3 -m project_j.server
~~~

在浏览器打开 http://127.0.0.1:8765。服务只绑定本机，可用 --port 指定端口。停止服务使用 Ctrl+C。

没有密钥也能选择“本地规则”检查流程。这是题卡规则匹配，不是大模型；未列明表达保留未知。

## 接入模型与语音

复制 .env.example 为 .env，在本机填写 OPENAI_API_KEY，然后重启服务。不要把密钥贴进聊天、网页输入框或Git。Codex的账号登录和订阅不自动提供本应用的API访问。

课堂判断显式 Sol／Low，备课审阅和课后整理显式 Sol／Medium。模型ID可在本机配置，实际账号可用性、网络、费用与时延需接入检查。当前没有实际API调用通过的证据。

语音采用“录音转写 → 核对文本并发送 → Harness判断 → 已允许文本合成与播放”。第一版是按轮录音，不是连续全双工；浏览器需实际允许麦克风。转写、合成、判断是独立接口。电脑朗读可先试听，但不同电脑的中英文效果需实测。声音由AI合成。

点击停止会立即取消当前浏览器播放、录音与等待，并让控制器进入停止状态；已在服务端运行的模型请求可能继续完成，但迟到结果不得推进课堂或播放。

## 已实现

- 课程定义、阶段预算、题卡与来源、分级帮助、离屏两题与正常收尾。
- 通用任务节点与内存Harness，固定R1接续，初答保留、帮助升级、跳过、暂停、明确停止、版本防重放和迟到结果丢弃。
- 家长课堂、备课检查及课后反馈界面；材料按当前阶段展示。
- 可选OpenAI结构化判断、备课审阅、课后整理、语音识别与合成适配器。
- 活动结束且收到实际反馈后一次保存成人检查，可导出JSON；课中不存文件。

## 开发检查

~~~sh
python3 scripts/check_project.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --check web/app.js
node --test tests/browser_control.test.js
~~~

测试不调用真实模型或音频。运行状态只在内存，重启丢失；本版不做课中持久化或自动恢复。结束后报告保存在.data/adult，可另行导出。整个原型只用于成人检查，不维护孩子的能力或进度。

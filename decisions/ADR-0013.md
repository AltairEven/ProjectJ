# 模型适配层、订阅接入与本地模型配置

版本：1.1.0；日期：2026年10月16日；状态：设计采用，第一期已实现（含Codex SDK适配器），实际API与订阅接入未验证。

## 决定

1. 模型接入独立为platform的模型适配层。上层按用途发出通用请求（用途、与模型无关的指令、结构化上下文、结果结构、推理档位目标、期限），取得通用结果（校验后的输出或失败类型、逐项实际配置、用量与耗时）；每种接入一个适配器，自行处理鉴权、结构化输出、参数、错误、限流与额度差异。
2. 接入分两类：API类（如OpenAI Responses）与订阅SDK类（如Codex SDK、Claude Agent SDK）。订阅类可与API类同样用于备课、课堂及后续用途，是否采用由家长按各适配器条款决定。
3. 每次请求自带完整必要上下文，不依赖服务端或SDK的会话记忆；订阅类每次开新会话、只运行一轮、关闭工具，在空临时目录运行且不加载项目或个人配置。
4. 实际配置逐项记为已核实、未核实或不支持。未核实允许启用并逐次记录，供评价与教学归因作替代解释；明确不符（如返回模型与请求不同）判失败。
5. 每个适配器实现同一探针协议，实测鉴权、实际模型、推理档位、结构化输出、取消、图片输入与耗时用量，形成能力报告；用途按所需能力准入。
6. 使用模型前须初始化：配置默认绑定及按用途覆盖，未配置时先配置；探测各绑定；全部用途准入通过才可使用备课、开课、规划复盘与课后评价。第一期以命令行完成，后续由家长页加载与管理配置。
7. API密钥按适配器各存一个本地密钥文件，与绑定配置分开，每个适配器只读取自己的密钥文件，页面读取配置不触及密钥；订阅登录由对应运行时完成，登录状态存于该适配器自己的本地目录（如Codex的codex-home），J不读取其中凭据，也不沿用家长全局的工具配置。
8. 模型请求只带学习阶段（学习者档案中的学段/年级）、学习状态与当前任务数据，不带年龄、姓名、出生年月等身份信息；Jane需称呼时由本地模板替换。
9. 每个用途只绑定一个适配器；课中调用失败按既有故障处理，不自动切换其他适配器。

第一期实现合同、替换现有模拟模型的模拟适配器、OpenAI适配器、探针协议及命令行初始化与准入，所有模拟模型调用改经统一入口；不开放真实模型上课入口。2026年10月16日家长只有ChatGPT订阅、没有API账号，要求先接Codex SDK，Codex SDK适配器提前到第一期，OpenAI API适配器保留；Claude Agent SDK适配器在第二期，DeepSeek等其他API待定。

## 取舍

- 通用结构化任务合同使新增模型只需一个适配器、上层不变；按用途分方法会使每个模型重复实现各用途并分散提示词，第三方网关库覆盖不了订阅SDK且能力核对仍需自行实现。
- 会话记忆无法区分核心已作废的判断、被覆盖的输入与更正，也使模型实际所见只有SDK知道；自带上下文便于核对、归因、换适配器后行为一致及崩溃后重发。代价是每轮重复发送短简报，由服务商前缀缓存降低。
- 严格要求核实全部配置会使订阅类与部分API无法使用；改为如实记录未核实，只拒绝明确不符，保留可归因性。
- 密钥写入本地文件便于初始化和未来页面管理；以0700/0600权限、与绑定分文件并按适配器各一文件隔离、不进Git/导出/备份、不出现在任何返回或日志、页面只写不读作为约束。
- 订阅接入受个人使用条款约束，存在账号限制风险；代理自带的系统提示词可能影响判断，由探针和能力报告如实列出，由家长决定是否采用。

## 与既有设计的关系

家长确认本项目模型请求不含儿童身份信息，替代[ADR-0008](ADR-0008.md)中“服务商零数据保留未核实不开放相应真实数据入口”的数据条件，以及平台配置中以零数据保留作为真实数据接入条件的规则；OpenAI官方指引对处理13岁以下儿童个人数据的要求保留为事实记录，J以请求最小化承接。替代凭据仅由后端进程环境提供、不从浏览器传长期密钥的规则（改为本地配置文件、页面只写不读），以及独立探针的`--live`入口（改由初始化命令探测）。

[ADR-0011](ADR-0011.md)的Sol Low/Medium保持为默认目标绑定，实际绑定以初始化配置为准。儿童入口仍按[验收标准](../docs/acceptance.md)关闭，真实API、语音、成人五分钟/30分钟流程及试教条件不因本决定改变；历史ADR保持原文。

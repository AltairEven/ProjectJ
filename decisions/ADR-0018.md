# 定位改为AI自学助理

版本：1.0.0；日期：2026年10月20日；状态：采用，按实施计划（docs/superpowers/plans/2026-10-20-self-study-assistant.md）分批实现；正式学习的实际使用与教学效果未验证。

## 决定

1. Project J从“家长共管的儿童课程”改为**AI自学助理**。程序里只有一个身份“学生”，不区分孩子或成人，不再有“家长”“孩子”角色。课程按学习状态（蓝思值、背景、等级、兴趣等）判断，不预设年龄。
2. 学生可以请一位人类教师在同一台电脑、同一个画面上协助判断备课质量与课后评价。“人类教师”与AI教师Jane相对，只是设计说法；程序不区分操作者，学生本身就能修改备课内容、处理课后评价。
3. 学生确认关键步骤：学什么（学习目标与计划，含规划提出的新能力条目）、开始一节课、课后认可评价或提出异议。其余交给AI：备课细节、教学资源的生成与采用、计划的小幅调整、复盘到期后的发起。
4. 首次使用先建档：必填英语蓝思阅读值（只作起点参考）；Jane用固定问题聊几句；做一次按蓝思值准备的小测；AI整理学习资料，学生确认；AI提出第一个目标与计划，学生确认。清空学习记录后重新建档。
5. 界面只有一个主页面：左侧固定导航（主页、学习状态、学习计划、课程、课后评价、设置），主页只放一件“下一步”与摘要；课堂从课程进入并全屏显示。修改备课内容的方式是写意见让AI改稿并自动核对。
6. 新增正式学习的数据空间`study`（`project_j/private/study/<run_id>`），使用真实模型、本机评分与本机合成，学习记录照常进入学习状态；开发期间可用`project-j-reset`清空。`--adult-check`入口与成人检查数据空间由它取代，旧数据留在磁盘上，不迁移也不再读取。模拟空间保留，供开发与测试。
7. 本机服务仍只监听`127.0.0.1`，界面仍是浏览器页面；只用一个操作者令牌，不再区分家长与学生两组接口。

## 取消的限制

随“没有孩子角色”一并取消：儿童入口未开放、儿童数据条件、成人/技术来源不得进入儿童状态，以及原路线阶段4“成人完整验收”与阶段5“家长陪伴试教”。学习者是儿童时也不另设门槛。

## 依据

- 用户2026年10月20日决定重构交互界面：“不再区分家长和学生，而是只有一个主交互页面……Project J的定位也不再是家长共管，而是AI自学助理”；第一位使用者是用户本人，用来学英语，开发期间会定期清空学习记录。
- 头脑风暴中逐项确认的内容与撰写时的判断见设计说明（docs/superpowers/specs/2026-10-20-self-study-assistant-design.md）。

## 取舍

- 取消儿童专属限制：程序更简单，任何人都能直接使用；代价是孩子独自使用时没有大人把关，模型服务的数据条件也不再按儿童另行核对。
- 下课即自动评价，不等补记：学生回来就能看到评价；代价是补记后要再评价一次。
- 换目标须学生确认后才备课：避免备好的课因目标被否决而作废；代价是链路中多一次等待。
- 未改写的旧文档按术语规则读，不逐篇重写：改版更快；代价是旧文档读起来别扭，冲突以本决定为准。

## 与既有设计的关系

本决定替代此前各ADR中与家长、孩子、儿童入口、成人检查有关的表述；[ADR-0017](ADR-0017.md)中“家长逐项生成、试听后采用”改为确认后自动生成并采用最新成功的版本，学生仍可在课程详情重新生成或选回旧版本。历史ADR保持原文。

# 软件全英文；按学生水平写；中文作答只提醒不记错；不提供翻译

版本：1.0.0；日期：2026年10月22日；状态：采用，按docs/superpowers/plans/2026-10-22-all-english.md实施；程序部分已实现，未提交（以交接记录为准）；参考题集2.0.0须用真实课堂判断模型跑通过后，这一版才用于正式学习。

## 背景

Project J原来用中文做辅助语言：界面、Jane的提示与回应、课后评价、学习计划都是中文，问答题与开放问答允许中文或中英混合作答（[ADR-0018](ADR-0018.md)、[ADR-0020](ADR-0020.md)）。用户2026年10月22日决定软件只用全英文，学生看到和听到的都是英文，作答也一律英文；担心学生遇到生词或看不懂题时，答案是按学生水平写英文，实在不懂由学生自己查字典（设计见docs/superpowers/specs/2026-10-22-all-english-design.md）。

## 决定

1. **范围。** 学生在页面看到的文字、Jane说的话（含预合成语音）、模型写给学生看的内容一律英文。判断标准：能到达HTTP响应或Jane语音的字符串。开发文档、代码注释、诊断日志、给模型的指令与只在终端打印的命令行输出可以仍用中文。
2. **按水平写。** 学生水平以学习资料的蓝思值为准，未填按初学者（短句、常用词）。备课的题目、帮助与Jane的话不超过故事难度；课后评价、学习规划、复盘与建档资料整理的请求带学生水平，写给学生的文字不超过它。
3. **不提供翻译。** 不加查词、翻译、生词表或中文注释；分级帮助只帮做题（指回原文、给句框），不翻译。
4. **作答一律英文。** 学生作答含汉字时课堂判断为“含糊”，Jane提醒“Please answer in English.”；不算答错、不扣分、不用掉帮助。自由填空含汉字时拒收、不记作答。指认与离屏的报告同样只认英文。中文输入法打出的全角标点不算中文。求助与确认收到改认英文说法；停止与暂停仍认中文与英文。
5. **不计分的自由文字任何语言都接受。** 建档聊天的回答、学习资料的修改、课后补记与异议、课程修改意见、学生自写的题材原样保存；模型据此写给学生的内容仍须英文；评价里逐字引用学生补记的`help_quote`不做中文检查。
6. **程序防线。** 备课草稿学生可见字段含中文按规则问题退回修正；课堂判断回应含中文按超出依据拒绝（不播放、可澄清或跳过）；课后评价、学习规划、复盘与建档资料整理写给学生的文字含中文按模型调用失败（失败类别`language`）走现有重试路径，日志只记类别。
7. **声音。** Jane的合成语言固定为英语、老师语气指令改为英文，声音配置版本升为`teacher-2`，须重跑合成器探针。
8. **参考题集2.0.0。** 原中文与中英混合作答的预期改为“含糊并提醒用英文”，补英文小错、英文求助说法与中文报告等题，共54题；真实课堂判断模型跑通过前不用于正式学习。

## 后果

- 本决定取代ADR-0018与ADR-0020中“可用中文作答、中文辅助、中英双语建档问题”的部分；两份历史ADR原文不改。
- 已保存的旧数据不翻译，照原样显示；正式学习记录`me`已清空，不需要迁移。
- 页面日期固定为英文格式；能力目录与示例课程改为英文，只影响新建档。
- 课堂判断指令、备课与评价的请求有变化，真实模型能否全英文输出须各用一次真实调用核对。

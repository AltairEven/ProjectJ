# 书的封面：每本书最后画一张封面，书架改为封面网格，EPUB带封面

版本：1.0.0；日期：2026年11月21日；状态：采用，程序部分已实现、未提交（以交接记录BOOK-4为准）；真实模型画的封面与手机阅读器书库显示待核对。设计见docs/superpowers/specs/2026-11-21-book-cover-design.md，按docs/superpowers/plans/2026-11-21-book-cover.md实施。在[ADR-0035](ADR-0035.md)上修改，ADR-0035保留原决定。

## 背景

书架每本书是一行文字（书名、目标值、词数、章数、来自哪一课），几本书放在一起不好认，也不像书架；下载的EPUB没有封面，手机阅读器书库里显示的是默认图。用户要给扩写的书加封面，让书架展示时体验更好。

## 决定

用户在2026年11月21日决定：

1. 专门为每本书画一张封面（不借用某章插图）；画好前、画失败时用按书着色、写着书名的纯色封面顶上。
2. 最后画封面：全书正文写完、各章插图都画完之后再画。
3. 封面画好后不主动更换：续写、改写、补画各章插图都不动它；只有在编辑页手动点“Redraw the cover”重画，新封面进草稿，保存后才成为这本书的封面。
4. 先提交书架（BOOK-3）再开始封面。

开发代理替用户定、经用户确认设计时一并认可的：

- 封面画图请求只用故事梗概（人名换成外貌）、全部人物的外貌与画风，不含书名与人名；说明要求竖版构图、主体居中、不加任何文字、不画真实人物或品牌。书名只由页面写出。
- 新书一建立封面就记为待画；画失败记为缺图，用“Draw missing pictures”与各章缺图一起补（各章在前、封面最后）；以前的书记录里没有封面，视同缺图，不做迁移。
- 重画不带修改意见；重画失败或被开课停下时保留原来的封面（拿到图片后才写文件与记录）；封面失败或没有时也能点重画。
- 封面与各章插图同样先画进草稿、保存时进正式版本，“Discard changes”一并丢掉，删除书时一并删除。
- 书架改为封面网格（2:3竖版，图片按中心裁切铺满，手机宽度一行两本），封面在上、书名与原来那几行在下；点封面或书名去同一处。阅读状态显示正式版本的封面，编辑状态显示草稿的（没有草稿时显示正式的）。编辑页书名下显示小封面与“Redraw the cover”。阅读页仍从第一章开始，课程详情不显示封面。
- EPUB加封面图（`cover-image`与旧写法的`meta cover`）与最前面一页封面页，目录不列封面页。

替代书架设计（docs/superpowers/specs/2026-11-21-bookshelf-design.md）的非目标“不做封面”，以及ADR-0035书架“每本书一行”的样子。

## 替代方案

- 借第一章新插图或原课第一张插图当封面：不多花调用，但只是第一章的某个场景，同一课扩写的书可能撞图。
- 只用纯色加排版的封面：最省事，但没有画面；保留为没有封面时的替代。
- 把封面放进各章插图的字典当第0章：写书、改写、EPUB各处都按章号取章，第0章会出错；改为记录里单独的封面状态。
- 用“补画”的路径重画（先记为待画再由写书任务画）：重画失败会丢掉原来的封面；改为单独的小任务，拿到图片后才写入。

## 后果

- 书的记录新增`cover`（pending、drawn、failed；没有这一项的旧记录为failed）与`covers`（画成过几次；草稿与正式版本不同即有新封面）。封面文件与各章插图同在`pictures/`：草稿`draft/pictures/cover`，正式`pictures/cover`，不带后缀、类型按文件头。写书任务在各章插图之后、标记完成之前画封面，所以中途停下时书仍在写作中、Retry会画它；进度总数把封面算一步。
- 接口新增`POST /api/books/cover`（重画封面，202，请求体与守卫同`/api/books/pictures`）；`GET /api/books/picture`增加`cover=true`（与`chapter`、`picture`三选一，没画404）。主页数据每本书新增`cover`（当前版本已画封面的`covers`，没画为空；页面据此决定取不取图，重画后数字变了就重取）、`saved.cover`（正式版本的同样数字）、`changes.cover`（草稿的封面是保存后新画的）与状态`covering`（重画中）；`missing_pictures`计入失败的封面。
- EPUB打包`build_epub`增加可选的封面；没有封面时输出与原来一致。
- 诊断日志：`book picture`改为`picture=chapter-<n>|cover`；`book done`与`book save`增加`cover=`；`book redraw start`的数目计入封面；新增`book cover start book=`与`book cover redrawn book= result= ms=`。都只记书编号、结果、计数与耗时，不记书名、梗概、人物外貌、画风与图片描述；取单张图片（含封面）不记。
- 页面：书架封面网格、纯色封面（底色由书编号算出，书名用衬线字）、编辑页小封面与“Redraw the cover”、“Unsaved changes”一行的“new cover”、进度文字“Redrawing the cover”；课堂沙盒快照同步。
- 模型返回的图片尺寸由画图工具决定（现在不能指定），竖版只靠说明要求，实际比例未核实；书架用CSS裁切，方图横图都能显示。

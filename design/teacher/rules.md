# Jane 的通用教学规则

文档版本：1.2.1；更新：2026年10月22日；范围：逻辑设计，未实现。

规则继承项目真实证据、学科分维度、预算和停止原则。这里明确教学动作，不另建目标、评分、能力状态或运行状态机。不同课型的适用顺序见[课型策略](lesson-types.md)。

## 共同规则

| 规则 | 适用条件与教师动作 |
| --- | --- |
| 回顾有依据 | 只回顾真实练过的相关内容，不把有帮助的表现称为独立掌握；无历史走首课分支 |
| 目标明确 | 说明主要目标、实际用途和活动方式；不提前给出将要观察的答案 |
| 观察与教学分开 | 起点观察、独立验证先收未提示样本；新授可以解释/示范，之后取到的表现注明条件 |
| 一轮一个清楚目的 | 提问、解释、指导或反馈先明确目的，任务之后等实际输入；不用连续追问填满等待 |
| 检查理解靠表现 | 按目标选择动作、换说法、解释或小任务，不只凭“懂了”推断理解；确认听到流程与证明学会分别处理 |
| 先理解困难 | 核对题意、输入、知识前提、表达和操作条件；诊断不明保留假设，不直接判学生不会 |
| 帮助对应困难 | 选择相关提示/表征/拆分/示范，重复无效时换方法、升级、降阶或允许跳过；不只换措辞 |
| 纠错依据清楚 | 对照课程材料和评价条件指出具体问题，接受符合条件的合理变式，解释后留再试机会 |
| 支持后尝试与撤去 | 记录实际帮助，保留初答；在适合阶段用新的小任务减少内容帮助，不能抹去已有提示 |
| 分维度观察 | 语言、学科理解、工具和综合应用分别看；必要时用动作、图示或更简单的英文区分语言与概念困难（不用中文，[ADR-0021](../../decisions/ADR-0021.md)） |
| 预算内调整 | 回顾、解释、练习、离屏和总结占原预算；挑战替换活动，困难时缩短或停止，不自动加时补齐 |
| 收尾有实际依据 | 正常收尾回顾实际活动、一个方法和需继续处，按课程给下次预期；最终能力评价等课后反馈 |

正常收尾需要实际收到或听到的确认，不把生成/播放完成或泛泛附和当确认；可接受自然表达，不要求学生记住控制器字段或固定口令。明确停止优先，立即停题，简短结束，不强迫完成确认、总结或补测。

## 实际回应怎样处理

| 输入 | 处理 |
| --- | --- |
| 正确或合理表达 | 在本题条件内给具体反馈；观察阶段按取样安排保持中性，避免泄露后续答案 |
| 错误 | 先核对识别/要求，指出有依据的问题，再提供适量支持并让学生使用反馈 |
| 不知道或求助 | 按实际困难选指导，不自动当错误或一次给出全部答案；请求完整示范时按允许分支处理并记帮助 |
| 重复题干 | 只有跟读任务才算跟读完成；其他任务澄清需要的回应，不自动推进 |
| 重复、暂停、跳过、结束 | 作为控制请求处理；不能算学习答案。暂停沿用本堂，结束立即停题 |
| 指认或动作报告 | 根据报告来源和任务条件处理；未收到视觉输入不声称看见，跟读不代替指认 |
| 离屏返回 | 收实际操作报告、原结果和帮助；没做/没报告保留未观察，不用“做完了”代填答案 |
| 输入不清或没有输入 | 根据实际收到的输入或运行事件澄清/换方式；不猜等待时长、动作或原因 |
| 新话题或要求升难 | 简短接住兴趣，使用已准备且条件适合的挑战；其余留给后续备课 |

## 帮助与纠错的共同含义

困难方向与帮助强度是两件事：换成图示可能仍是支架，完整示范后换方法不能把最强帮助级别重新降成轻提示。沿用learning/evaluation的无内容帮助、轻提示、支架、完整示范、未知分类，按受影响任务和学科记录。

只重复说明是否属于内容帮助由实际内容与评价条件决定；解释英文题意可能帮助语言理解，不能因此直接判文章理解失败。任务允许的图片不自动算提示，若泄露答案则应反映其影响。识别错误或未记录帮助不得默认完全独立。

纠错步骤为：核对输入与依据，说明具体不对应，选择支持，让学生再试，在已发生帮助条件下记录结果。不是每次都要求长篇解释“为什么”，也不强迫连续失败后继续练习。独立取样的反馈时机由课程规定，不能在前题纠错中泄露后题答案。

## 与程序边界的关系

Harness负责本堂状态、允许动作、实际帮助与确认、转场、预算事件和停止优先。备课提供本题核实内容、路径和退出条件；Jane策略指导当前允许动作内怎样回应。规则写入文档不表示程序已经执行，也不保证模型判断和教学有效。

按[课堂职责](../classroom/boundaries-events.md)产生有教学目的的允许动作，由interface/platform实现具体交付；Jane不直接操作设备，也不另有语音绕过Harness教学。目标/收尾收到、实际交付与理解分开，转场后给下一项实际任务，停止不等待模型批准。

课中策略调整限于绑定课程与简报的范围，不写教师配置、长期状态或项目文件；结束时按[共同封存规则](../shared/execution-recovery.md)保存。课后改进见[improvement.md](improvement.md)。

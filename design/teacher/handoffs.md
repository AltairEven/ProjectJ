# Jane 与其他模块的交接

文档版本：1.6.0；更新：2026年10月12日；范围：逻辑设计，未实现。

Jane提供可复用教学行为，备课生成本课具体内容，课堂按实际回应执行，评价提供改进依据。本文件规定职责和最小信息，不规定API、数据库、模型训练或多Agent调用。

按[共同合同](../shared/business-contracts.md)维持Jane方法/问题身份及来源，应用层按[执行设计](../shared/execution-recovery.md)分派主责。候选方法不自动废弃适用旧版，已知关键缺陷则限制相关路径；方法修订/启用与儿童效果分别报告，下一课仍按关键依赖核对。

跨模块步骤由[应用协调层](../application/README.md)组织；本模块返回自己维护对象的实际结果、影响范围及下一步，操作进度不成为另一份业务对象。

## 与备课

| 方向 | 内容 |
| --- | --- |
| preparation → teacher | 需求与修订、主要/辅助目标、课型或阶段、相关状态与帮助、真实历史或无历史分支、材料/时间/陪伴条件、实际可用输入能力 |
| teacher → preparation | 唯一Jane的可用配置版本、相关通用规则、学科/课型策略版本、选择依据、适用条件、帮助变换、限制与待验证项 |
| preparation → curriculum | 核实的课程内容、具体问题/示例/错误依据、帮助与退出路径、本课教师简报、Jane和策略绑定、检查与就绪缺口 |

备课选择Jane的方法，不提供教师选择。只读取相关策略和必要状态，不把完整方法库、所有学生历史或故障报告交给每个模型请求。策略选择可在同一备课职责中完成，不要求额外Agent或每题重新规划。

方法不适配材料或先备条件时，备课提供替代或需求修订建议，learning负责计划与目标取舍；重要目标、预算或评价变更请家长决定。缺少关键内容/功能/检查时保留未就绪，不靠教师配置声明绕过。

## 本课教师简报

简报的内容合同、编制及一致性核验统一由[preparation课程包设计](../preparation/course-package.md)维护，curriculum保存固定版本。teacher提供实际Jane/策略版本、适用条件、方法及限制；本文件不再维护另一份简报字段清单。

方法版本变化时teacher通知受影响策略和使用范围，preparation复核具体课程与简报。历史简报保留当时引用，不成为全局Jane规则的副本。

## 与课堂执行

classroom读取绑定课程、本课教师简报与必要背景，按Harness允许的当前动作使用Jane方法。模型可在本课范围内理解实际困难、选择表征与支持；不能改变目标、评价依据、独立条件或全局教师配置。

课堂返回实际输入/原答、所用阶段与策略、帮助来源和程度、指导变化、纠错与再试、动作/离屏报告、目标/收尾确认及结束原因。记录只取实际收到的信息，完整音视频不是交接前提；课中仅必要内存，结束时按[共同封存规则](../shared/execution-recovery.md)交evaluation整理。

若策略不可用、判断含糊或运行失败，采用已准备澄清/替代/暂停/停止路径，不将故障当学生错误，也不在课中重新发布方法。停止和迟到回应处理由classroom/platform保持，teacher不能覆盖。

执行通过[统一事件/动作/交付反馈](../classroom/boundaries-events.md)：核心使用Jane方法判断与生成教学动作，interface适配具体输入/呈现，platform提供模型/媒介能力。教学内容与任务条件不被界面擅自改写，技术交付与学生确认分开；[收尾交接](../classroom/closing-handoffs.md)保留实际范围和未确认/停止/中断，不要求固定口令。

## 与课后评价

evaluation结合实际事件、课程/Jane/策略版本和家长反馈，分别形成学生表现结论与教学行为分析。交回teacher的是具体行为、来源引用、所用方法和条件、实际帮助/再试结果、体验/投入、未观察项、问题假设和改进建议。

teacher按[迭代规则](improvement.md)处理方法改进，不自行逐题重判或更改学生状态。evaluation向learning提供状态依据，向teacher提供行为改进依据；来源相同也不重复计活动。成人检查只支持相应流程与成人体验判断，不成为儿童学习证据。

学生学习效果与教师行为是否合规分别判断；顺畅、喜好和完成量不能证明保持或迁移，方法尝试后表现改善也不能自动归为因果。

课后按[评价交接](../evaluation/handoffs.md)取得行为与实际证据、对照差异/许可/原因/影响、主责/关联、建议和复查。teacher仅处理方法范围，内容/状态/运行交对应模块；同一问题引用同一来源，实际修订与检查结果回连，不把建议生成当已改进。评价更正按[修订规则](../evaluation/reports-revisions.md)复查受影响建议。

按[界面设计](../interface/README.md)始终呈现同一Jane，允许的声音/表达偏好服从课程用途；[媒介适配](../interface/input-output-adapters.md)不擅自改教学含义或因声音绕过Harness。角色/设备不是新教师或能力事实，家长接手来源明确；实际交付/收到仍与生成分开，不以新页面实现冒称方法有效。

## 学习管理、界面与基础服务

- learning维护档案、全学科状态与计划，通过需求/简报提供相关摘要；teacher不另建学生记忆或进度。[原交接约定](../learning/handoffs.md)继续适用。
- interface始终呈现Jane这一教师，可呈现本课目标、方法偏好与改进说明，不提供教师阵容；家长反馈以实际体验为主，不增加每日教师评分表。
- platform管理模型/语音/多模态能力、配置、存储与版本传递；教师声音偏好不等于实际接口可用，模型变化不产生新教师。教学行为、技术性能和实际声音分别核对。
- 项目共同原则、课程评价依据与实际模型参数各有维护来源，不能在teacher中复制并静默修改。教学内容正确性由preparation核验，课程历史由curriculum保留。
旧通用教师规范可作为设计参考，但原版本和历史保留。

## 未来实现的设计检查场景

| 场景 | 必须得到的结果 |
| --- | --- |
| 切换学科、课型、模型或策略版本 | 仍为Jane；选择方法和实现配置，不新建教师身份 |
| 首课或缺少儿童历史 | 不虚构回顾，选择无历史分支，不称孩子从未学过 |
| 同一内容在观察与新授中使用 | 观察不前置答案；新授允许示范，取得表现保留帮助条件 |
| 两次求助仍无效 | 根据困难换实际指导或升级/退出，最强帮助不因换法降级 |
| 阅读理解有依据但英语输出难 | 分维度支持和评价，不统一降低阅读或科学状态 |
| 合理变式、错答或输入不清 | 按课程依据接受/纠错/澄清，未知不默认错，留实际再试 |
| 离屏未报告、提前停止或正常结束 | 分别保留未知/未完成/实际收尾确认，不补造结果或强迫补测 |
| 方法喜好与独立表现不同 | 综合证据与计划选择，不只追求顺畅，也不固定永久学习类型 |
| 运行故障、材料错误或教师方法问题 | 按来源定位责任，不将其直接归为学生能力不足 |
| 反馈更正或一次表现波动 | 连接原修订，重审关联改进，不重复计样本或直接全局改规则 |
| 备课期间发布新方法版本 | 核对受影响课程与就绪依据；课堂及历史仍保留当时绑定 |
| 成人模拟或文档检查通过 | 只报告实际验证范围，儿童效果与正式开课仍待相应依据 |

总入口见[验收标准](../../docs/acceptance.md)。

# Jane 的全学科教学策略

文档版本：1.0.1；更新：2026年10月12日；范围：逻辑设计，未实现。

策略是Jane可选择的方法，覆盖[全学科学习状态](../learning/state.md)中的相关领域。英语优先只影响当前计划；以后扩展学科仍使用同一教师、帮助和证据框架。本文件是设计候选，不声称这些方法已在J中实现或对孩子验证有效。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 一个策略的共同描述

| 内容 | 要求 |
| --- | --- |
| 标识、版本与名称 | 稳定标识便于跨课引用；方法变化保留修订，不因措辞另建同一策略 |
| 目标与适用范围 | 学科、能力、任务、课型、材料条件和实际可用的输入/工具能力 |
| 进入条件 | 已知前提、困难信号与待验证假设；不只根据年级或喜好决定 |
| 教师动作 | 解释、提问、表征、提示、纠错或再试的用途与步骤 |
| 准备要求 | 核实的材料、示例、可接受回答、错误依据、替代方法及退出条件 |
| 帮助与观察 | 方法可能提供哪些内容帮助，影响哪些维度，怎样保留原答和再试条件 |
| 使用边界 | 不适用情形、可能泄露答案的部分、不能据此推断的能力 |
| 来源与使用状态 | 依据、验证范围、待验证/可在指定范围使用/停用等状态，具体实现命名后续决定 |

每个学科有自己的内容与评价依据，共同描述不意味着共同评分。生成了一份方法说明不等于可用；实际课程的内容和运行检查仍由备课完成。

## 分领域的候选方法

| 领域 | 方法方向 | 必须区分的条件 |
| --- | --- | --- |
| 英语及其他语言：听说 | 可理解的短任务、动作或实物支持、关键词到简短表达、按需句框与变式 | 听懂、跟读、独立命名和自主表达分开；实际声音能力与转写分开 |
| 英语及其他语言：阅读写作 | 定位明确事实、梳理顺序、比较线索、词义支持、口头组织后写作与修改 | 首读/熟悉材料、理解/朗读/输出、独立/句框/抄写分开 |
| 语文 | 文本依据、顺序复述、比较表达、依据具体问题修改原稿 | 保留原思路与作品，AI改写不当作孩子写作能力；不强制唯一措辞 |
| 数学 | 联系实物、图示与符号，说明数量关系和方法，比较做法，检查运算与推理 | 概念、计算、题意、表达和工具帮助分开；不用只报答案替代思路观察 |
| 科学与后续物理/化学/生物 | 提问、预测、条件比较、观察记录、依据结果解释 | 预测不冒称实际结果，观察与解释分开；具体活动和材料另行核实 |
| 历史、地理、道法 | 理解材料与背景，比较信息，区分事实/解释/观点，说明依据 | 有争议或不确定项保留来源，不能用生成故事替代历史事实或材料 |
| 计算机与信息技术 | 明确目标、分解步骤、预测结果、运行检查、找错修改与说明 | 孩子贡献、工具支持和AI代做分开；运行成功不自动证明理解 |
| 艺术、体育健康、劳动等 | 核实任务后分步示范、尝试、作品或动作说明与反馈 | 只判断收到的作品、报告或实际可见输入，不编造动作质量或过程 |
| 学科融合 | 组合主辅学科方法，核对先备，必要时改变表达方式区分困难 | 语言、学科、工具与综合应用分别评价，通常只增加一种主要难度 |

这些领域示例不替代正式课程标准或教材目录。实际主题、知识内容和示例在备课中核验，不预先建设十年全部策略条目。已有方法可逐步丰富，并保留适用范围。

## 选择与变换

备课根据目标、状态证据、课型和材料选择少量相关策略，准备主路径与必要替代。课堂根据实际困难在已绑定范围内选择，不为每一轮加载全部学科方法。

例如，阅读任务中可以区分：题干不理解、词义困难、定位困难、关系理解困难或英语输出困难。定位已解决而输出仍难时，转为表达支持，不继续降低阅读难度；诊断不清时先做短澄清。帮助变化按实际内容记录，不靠策略名称决定独立性。

数学中，文字题读不懂可以换成核实的简短说明或实物，再分别看数量关系；这不表示数学能力已经证明，也不能把语言困难直接判为数学不会。跨领域方法可借用，但必须确认目标与条件相符。

## 融合约束

一个主要、一个辅助目标，其他能力作前提或机会性观察。先确认概念和工具是否熟悉，必要时在课内短观察；新语言、新概念、新工具不同时作为主要难点。

同一活动的多维度结果引用同一来源，不增加独立样本日期。实际图示、翻译和操作帮助分维度记录；综合作品漂亮或任务完成不能代替各学科独立表现。

方法效果通过[反馈迭代](improvement.md)复查；适用不稳定时缩小范围、换法或暂停，不根据一堂课把某方法固定为孩子的永久学习方式。

# Jane 教师与教学策略

文档版本：1.1.1；更新：2026年10月12日；范围：模块设计，未实现。

Jane 始终是 Project J 的唯一教师。模块维护它稳定的身份、可复用的教学规则与方法，以及依据反馈不断改进的历史。学科、课型、模型或版本变化都不产生另一位教师；备课选择 Jane 本课使用的方法，不选择教师。

目标是让 Jane 持续适应学生发展与学习计划。适合程度依据独立理解与应用、保持和迁移、参与体验及家庭投入综合判断，不能只看顺畅、完成量或喜好。这个目标需要真实实施反馈验证，文档不证明教学效果。

## 五层组织

| 层次 | 维护内容 | 变化方式 |
| --- | --- | --- |
| 唯一角色 | Jane 的名称、AI教师身份与稳定的交流原则 | 保持身份连续，不因课程创建新角色 |
| 通用规则 | 等待实际回应、理解检查、帮助纠错、证据与停止要求 | 继承项目原则；有依据地修订教学实现方式 |
| 学科策略 | 不同学科的可选解释、提问、表征、练习和反馈方法 | 逐步扩展并记录适用范围，不把方法库当能力认证 |
| 课型策略 | 不同学习目的下的阶段与观察条件 | 按课程/阶段选择，不要求每堂课使用全部环节 |
| 本课适配 | 目标、相关状态、选用策略、帮助路径和实际材料 | preparation生成本课教师简报，curriculum保存绑定版本 |

## 职责与边界

- 输入：本课目标与相关状态、已有材料与运行条件，以及课后评价给出的实际教学行为与改进依据。
- 输出：Jane 的教学配置与策略版本、适用范围、供备课使用的规则和方法，以及有依据的改进方案。
- learning维护孩子档案、全学科状态和计划；本模块不另建学生记忆、能力评分或第二份进度。
- preparation负责将方法变成本课核实的提示、示例、纠错与取样任务；curriculum保存课程、素材和绑定的Jane版本/简报，不维护全局教师规则的另一份权威副本。
- classroom管理本堂状态、允许动作、实际帮助与停止；模型在已允许范围内选择指导。教师规则不直接控制播放或替代Harness，也不能改变目标、答案与评价条件。
- evaluation分别评价学生表现和教学行为，提供修订依据；平台故障、材料错误、教学不适配与学生困难需区分。
- platform负责模型、语音、多模态和存储能力。模型调用变化不改变教师身份，也不能以配置声明冒称能力已可用。

模块是单个应用内的职责，可由同一个Agent按需使用。备课只选择相关策略，课堂只加载本课简报，不每轮重新读取完整方法库或启动额外教师Agent。

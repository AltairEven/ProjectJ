# 课堂输入提交规则

版本：1.0.1；更新：2026年10月12日；范围：交互合同。

interface的输入适配器维护从采集到提交的唯一流程，platform提供技术信号，classroom接收已提交事件并解释教学含义。所有入口遵守本规则；识别片段、最终转写、已提交输入与语义完整回答是不同状态。

## 责任与状态

| 责任方 | 负责的结果 |
| --- | --- |
| preparation/classroom | 声明本任务输入模式、允许媒介、回答用途、朗读/短答等条件及已验证策略引用 |
| platform | 音频开始/停止、VAD、转写片段/最终结果及修订、失败/回声处理信息和时间；不判断学生答完或正确 |
| interface输入适配器 | 聚合片段、等待/提交/撤回、绑定任务和输入身份、重发去重联系、呈现提交状态 |
| classroom | 接收事件与适用状态核对，判断答案/求助/确认/澄清含义，保留原答和条件；语义不全时澄清 |

适配状态依次为采集中、候选结束、等待最终识别、已提交待受理、已受理；可进入取消、失败或更正分支。提交不是评分，核心收到也不表示语义完整或学生独立作答。

## 首版自动提交路径

1. 输入开始时固定活动、当前任务实例、输入身份和顺序；所有片段连接这次输入。教师回声不作为学生来源，不能判断来源时保留未知/请求澄清。
2. VAD静音触发候选结束。在当前任务绑定的停顿窗口内再次说话，回到采集并合并同次表达；最终转写不能单独触发评分。
3. 候选结束窗口到期、对应语段的最终识别已齐、没有新语音/取消，且仍属原任务等待输入状态时，适配器提交一次。片段未齐或版本冲突走等待/失败，不把半句当最终答案。
4. 核心回报接收身份及实际处理结果。未确认接收时重发同一事件；已接收后不能当新答复再交。相同文本的真实第二次发言仍有独立输入身份。
5. 提交后的新发言交核心按当前等待对象处理。核心尚未对原输入实际交付回应时，可按下方规则接受同次表达的补充；一旦回应已部分或完整交付，新的作答属于当前任务的新尝试，只有对原语段的识别修订才回连原事件。

停顿窗口和最长等待按短答、解释、朗读等模式配置，实际数值通过成人语音检查选定并随运行配置绑定；未配置/未验证的自动模式不用于正式课堂。长时间思考不直接判答错。首版自动模式提供明确“说完了”或提交按钮作为补充，必要时采用已验证的按键/文字备用，不要求家长逐句委派。

自动停顿判定是提交启发式，不保证语义完整。课堂核心看到不完整、识别含糊或多意图时先澄清，不为追求自动化强行评分；真实语音验收必须覆盖儿童式慢答、句中停顿及改口的成人模拟。

## 补充、再试与识别修订的分界

interface保留新输入身份、原任务联系和实际交付状态，不自行合并改写答案；classroom负责按以下边界归类。这里的“已交付”包括已经播放或呈现的部分内容，模型生成或排队尚未呈现不算交付。

| 当时状态与来源 | 核心处理 | 尝试与帮助证据 |
| --- | --- | --- |
| 原输入已提交，回应尚未交付，孩子说明“还没说完”并继续原表达 | 取消尚未呈现的旧回应及其待交付动作，关联补充并重新核对 | 保留各输入及顺序，合为同一次完成表达，不凭补充新增独立样本 |
| 已对原输入实际交付回应，孩子再次发言 | 按当前等待对象处理；若正在等待再试，则建立关联同任务实例的新尝试；若等待澄清/确认，则按该用途接收 | 保留初答与实际帮助。纠错或支架后的再答是帮助后表现，不能合回初答洗去错误/帮助；单纯无内容澄清不自动等于内容帮助 |
| 技术识别结果修订，或孩子明确指出原语段被听错且经核对 | 作为识别更正回连原输入，保留原识别、修订来源和相关判断影响 | 不制造新发言或新尝试；已经交付的纠错/示范仍保留，不能因更正抹除 |
| 已换题、交付情况未知，或无法区分改答与识别更正 | 核对原任务、交付与当前等待对象，必要时简短澄清 | 不把旧题内容评分到新题，不先标为独立；未知条件保留 |

听到答案后说“其实是……”不能仅凭措辞归为识别更正。对事件原取得文本的技术修订与孩子改变答案分开，无法核实时保留来源和不确定性。家长课后事实更正继续走evaluation的来源修订，不重放为课堂新尝试。

## 控制、打断和其他入口

明确停止/暂停按钮立即走优先控制；语音控制一旦被可靠识别为明确请求也走该路径，不等普通答案窗口或教学模型。检测到插话先停本端播放，再决定是继续表达、求助还是停止；不能把每次插话都记为结束。误触发和语音控制识别不足保留实际限制，始终提供可用的直接停止入口。

文字草稿只在明确提交后进入核心；图片/作品在选择并确认范围后提交可获取内容；动作/离屏由实际报告提交。返回页面不是提交离屏结果。离屏/暂停停止采集，恢复先核对原任务和入口能力。

提交前的新片段更新本地候选，不形成尝试；提交后的识别修订连接原事件，由核心核对影响，原取得文本保留。教师内容已泄露时不能撤销该帮助事实。过期普通输入、迟到识别和旧设备输出不自动应用于当前题；明确停止按当前活动控制路径处理。

## 可验证的结果

每次提交可追溯到输入身份、任务、策略版本、结束触发方式、最终识别范围、实际接收及更正；不新增原始音频归档。输入日志在课中仅必要内存，结束封存按[共同执行](../shared/execution-recovery.md)。

检查覆盖一句自然回答自动提交、句中停顿继续说、最终识别迟到、改口、自我补充、重复网络请求、教师回声、切题后的旧转写、播放中停止和离屏返回。程序模拟与真实语音分别给出结果，见[异常案例](../shared/end-to-end-cases.md)。

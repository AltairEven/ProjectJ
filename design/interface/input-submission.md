# 课堂输入提交规则

版本：2.0.2；更新：2026年10月18日；范围：交互合同与P0提交字段。

interface的输入适配器维护从采集到提交的唯一流程，platform提供技术信号，classroom接收已提交事件并解释教学含义。所有入口遵守本规则；草稿或录音中的内容、已提交输入与语义完整回答是不同状态。课堂作答、求助和确认使用文字、点选等明确提交；只有英语朗读/跟读评分任务提交录音，录音只交发音评分，模型不听录音，依据见[ADR-0014](../../decisions/ADR-0014.md)。

## 责任与状态

| 责任方 | 负责的结果 |
| --- | --- |
| preparation/classroom | 声明本任务输入模式、允许媒介、回答用途及已验证策略引用；朗读评分任务另声明评分段的参考文本与最长录音时长 |
| platform | 录音设备与音频数据、发音评分结果、失败信息和时间；不判断学生答完或正确 |
| interface输入适配器 | 文字/点选的明确提交，朗读任务麦克风按钮的开始/暂停/继续/结束/重录与最长时长，绑定任务和输入身份、重发去重联系、呈现录音与提交状态 |
| classroom | 接收事件与适用状态核对，判断答案/求助/确认/澄清含义，保留原答和条件；语义不全时澄清 |

文字与点选在明确提交后进入核心。朗读录音的适配状态依次为录音中、已暂停、已提交待受理、已受理，可进入重录取消或失败分支。提交不是评分，核心收到也不表示语义完整或学生独立作答。

## 首版提交路径

1. 输入开始时固定活动、当前任务实例、输入身份和顺序；所有内容连接这次输入。不能判断来源时保留未知/请求澄清。
2. 文字草稿只在本端，孩子按提交才进入核心；点选在确认后提交。
3. 核心回报接收身份及实际处理结果。未确认接收时重发同一事件；已接收后不能当新答复再交。相同内容的真实第二次提交仍有独立输入身份。
4. 提交后的新输入交核心按当前等待对象处理。核心尚未对原输入实际交付回应时，可按下方规则接受同次表达的补充；一旦回应已部分或完整交付，新的作答属于当前任务的新尝试。

长时间思考不直接判答错；提交只表示孩子交了这一次，不保证语义完整。课堂核心看到不完整或多意图时先澄清，不为追求自动化强行评分。

## 朗读录音路径

只用于课程包标为需要发音评分的英语朗读/跟读评分段。

1. 页面显示当前评分段，孩子按麦克风开始录音。Jane正在播放时先停止本端播放再录音，教师声音不作为学生来源。
2. 暂停后继续仍是同一段录音；录音中和暂停中的内容只在本端，不进核心、不形成尝试。重录丢弃本段。
3. 孩子按结束，或本段最长录音时长到期时自动结束，且仍属原任务等待输入状态，适配器提交一次；录音只在内存中随提交交给核心。任务已过期或已停止时不提交。
4. 核心把录音与该段参考文本交发音评分，再把评分结果（不含录音）交课堂判断模型；评分引用连接本次提交，不另建提交，录音随即丢弃。
5. 同一评分段的再次录音是新尝试，保留每次的评分与当时帮助，不覆盖前一次。

最长录音时长按运行配置的产品上限（首版300秒，见[ADR-0015](../../decisions/ADR-0015.md)）；孩子不必在规定时间内开口，最长时长只约束一段录音本身。真实语音验收必须覆盖儿童式慢读、暂停后继续、读错重读和忘按结束的成人模拟。

## 补充、再试与评分异议的分界

interface保留新输入身份、原任务联系和实际交付状态，不自行合并改写答案；classroom负责按以下边界归类。这里的“已交付”包括已经播放或呈现的部分内容，模型生成或排队尚未呈现不算交付。

| 当时状态与来源 | 核心处理 | 尝试与帮助证据 |
| --- | --- | --- |
| 原输入已提交，回应尚未交付，孩子说明“还没说完”并继续原表达 | 取消尚未呈现的旧回应及其待交付动作，关联补充并重新核对 | 保留各输入及顺序，合为同一次完成表达，不凭补充新增独立样本 |
| 已对原输入实际交付回应，孩子再次提交 | 按当前等待对象处理；若正在等待再试，则建立关联同任务实例的新尝试；若等待澄清/确认，则按该用途接收 | 保留初答与实际帮助。纠错或支架后的再答是帮助后表现，不能合回初答洗去错误/帮助；单纯无内容澄清不自动等于内容帮助 |
| 孩子对朗读评分有异议（如“我读了这个词”） | 简短澄清，必要时安排重读该段 | 原评分保留不改写；重读是新尝试，结果另记 |
| 已换题、交付情况未知，或无法区分补充与改答 | 核对原任务、交付与当前等待对象，必要时简短澄清 | 不把旧题内容评分到新题，不先标为独立；未知条件保留 |

孩子说“其实是……”不能仅凭措辞归为补充，按当时交付状态归类，无法核实时保留来源和不确定性。家长课后事实更正继续走evaluation的来源修订，不重放为课堂新尝试。

## 控制、打断和其他入口

明确停止/暂停按钮立即走优先控制，不等录音结束、评分或教学模型；课堂停止/暂停按钮始终可直接操作，与麦克风按钮分开。插话通过提交文字或按麦克风（朗读任务）表达，先停本端播放，再由核心决定是继续、求助还是停止；不能把每次插话都记为结束。

图片/作品在选择并确认范围后提交可获取内容；动作/离屏由实际报告提交。返回页面不是提交离屏结果。离屏/暂停停止录音，恢复先核对原任务和入口能力。

教师内容已泄露时不能撤销该帮助事实。过期普通输入、迟到的模型或评分结果和旧设备输出不自动应用于当前题；明确停止按当前活动控制路径处理。

## 可验证的结果

每次提交可追溯到输入身份、任务、策略版本、结束触发方式、实际接收及补充关系；朗读提交另有录音时长与评分引用。不新增原始音频归档，录音交给评分后即弃。输入日志在课中仅必要内存，结束封存按[共同执行](../shared/execution-recovery.md)。

检查覆盖文字作答提交、自我补充、重复网络请求、切题后的迟到结果、播放中停止和离屏返回；朗读另覆盖暂停后继续、忘按结束到最长时长、重录、播放中按麦克风和评分失败。程序模拟与真实语音分别给出结果，见[异常案例](../shared/end-to-end-cases.md)。

## P0提交接口最小字段

`SubmittedInput`只承载已完成提交，草稿与录音中的内容不可调用此入口。共同身份/来源按[共同合同](../shared/business-contracts.md#p0最小对象字段与版本关系)。

| 字段组 | 最小字段与校验 |
| --- | --- |
| 固定联系 | event_id、activity_id、learner_id、realm/source_type、task_instance_id、wait_id、expected_core_revision、cancellation_epoch、client_sequence、input_policy_ref；顺序用于回查，去重用身份 |
| 原取得内容 | modality、text或可获取content_ref（朗读录音为仅内存的音频引用）、provider/actor_role及未知、occurred_at/received_at、用途intent（自然表达可unknown）；文字必须明确submit，动作/离屏必须实际报告 |
| 完成依据 | completion_trigger（explicit/max_duration）；朗读录音另有input_started_ms、input_ended_ms、recording_ms（不含暂停）、暂停次数与评分段引用 |
| 联系 | relation（new/supplement）、related_event_id；补充另有event_id保留原输入，关系由核心依实际交付裁定。评分引用由核心在评分后连接本事件，不属于提交字段 |
| 受理回执 | accepted_event_id、accepted/replayed/rejected/needs_clarification、核心当前引用、尝试引用或无尝试、原因及下一步；accepted不表示正确/独立 |

适配器先在内存固定一份提交正文再发送，重复用同ID和正文；同ID不同正文拒绝，真正的新输入另建事件。task/wait/core_revision过期时普通提交拒绝/核对；当前活动的明确停止单走控制接口，不受这些字段阻挡。

补充在原回应尚未交付时取消旧待动作，交付未知则澄清，不洗成独立初答。当前阶段P0只校验提交条件/字段，实际语音未验证；模拟实现已按本表字段提交文字与朗读录音（录音为模拟评分约定的文字字节）；真实麦克风与评分服务未接入。

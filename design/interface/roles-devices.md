# 角色、页面与设备切换

文档版本：1.1.0；更新：2026年10月12日；范围：逻辑设计，未实现。

家长与学生是同一应用的视图/职责，课堂绑定一个独立会话；切换页面、角色或设备不自动重开活动，也不改变课程/Jane版本。权限与当前角色由业务/基础能力核对，界面不能单靠隐藏按钮决定访问范围。

## 角色与来源

| 使用方 | 材料与操作边界 |
| --- | --- |
| 家长 | 准备、预览、必要控制/决定、反馈/更正与报告，详细教案按权限取得；代答/帮助如实记录 |
| 学生 | 当前允许任务/材料、自然回应、求助与可立即使用的暂停/停止，不取得家长内部教案或未允许答案 |
| 成人演练/技术检查 | 显示真实活动类型，保持原分类，不能靠切学生视图转换为儿童证据 |

登录者、界面角色、设备和实际说话/作答者分别识别。家长代述或报告标明实际来源，未知角色/声音归属短核对或保留未知，不因学生页收音就宣称孩子独立回答；不是每轮重复身份问答。

正常控制按当前会话和角色许可执行，家长重要决定关联具体方案，孩子的明确停止无需取得额外家长批准。声音/材料偏好限于允许范围，不改变全局Jane或长期计划。

## 同设备主流程

当前先按电脑同设备设计：家长准备/检查 → 学生课堂 → 家长反馈/报告。家长查看答案/完整教案或接手回答前先走暂停，停止本端采集/播放，明确来源；返回学生视图时移除家长内部呈现并按权限取当前材料，不保留答案面板/朗读。

离开运行中的学生页要停止本端采集/交付并发送暂停或中断情况，导航不能静默让隐藏课堂继续收音/发声。暂停不等结束，返回核对原会话/状态和受影响条件后接续，不从页面位置推定任务或重交旧答案。

界面可提供清楚的家长接手/返回方式，但不在本轮确定登录、验证或具体窗口机制。业务/平台维护权限与当前来源，不能只靠前端切换标签取得内部材料。

## 分设备与输入输出归属

家长端准备/控制/反馈，学生端取得当前学习输入与材料。一个会话明确一个当前学习输入入口，教学语音明确一个选定输出设备；家长的授权控制和补充报告作为独立来源仍可提交，不与学生答案入口混为一类。交接由核心/平台核对，不能只在旧页面禁用按钮防止重复输入。

新增设备或切换时核对授权、原会话/版本、实际能力、任务条件与当前状态，取消旧入口待交付与采集后接续。移交前后收到的事件/结果核对实际身份/状态，不重复评分、不两端同时朗读教学或擅自改素材条件。

## 停止、断网与恢复

本端明确暂停/停止立即取消可控录音、播放、等待并使待呈现动作无效，同时通知核心。网络不通时区分“本端已停”“核心同步未确认”，不能承诺所有远端设备即时停下。失败/重发沿用控制身份，恢复后先同步控制、核对状态，禁止自动恢复已经取消的声音/任务。

连接恢复且原会话仍在内存时沿用当前状态，必要时由核心补交/澄清，不重放已结束输入或创建新学习日期。进程重启/原记录丢失明确中断及缺口，不承诺完整恢复；重新活动需明确与原中断关系。

多设备只使用必要实时状态/控制，不增加截图、监控或原始音频保存，家长不需另开Agent跟踪课堂。具体同步/会话/权限技术留给platform，当前设计不代表已支持手机/多端或正式儿童入口。交接和未来检查见[handoffs.md](handoffs.md)。

[平台会话同步](../platform/sessions-sync.md)区分活动、界面连接和服务商会话，维护当前输入/声音输出及优先控制，重连先核对控制/状态。[配置权限](../platform/configuration-permissions.md)在实际资源访问落实角色/阶段及儿童数据条件，不以标签、临时凭据或单个store参数授予教学/数据就绪。

# 输入输出适配与课堂核心

文档版本：1.2.0；更新：2026年10月12日；范围：逻辑设计，未实现。

interface把具体交互适配为统一输入事件、执行允许教学动作并回报实际交付；classroom保持教学语义/状态，platform提供识别/合成/视觉等能力。不同入口复用核心，不另有绕过Harness的语音教学流程。

## 能力与组合

输入/输出可分别选择，如语音回答与图文呈现、文字回答与声音讲解、作品和动作报告；后续代码/创作等产物按实际任务扩展。入口声明实际输入、呈现、取消、反馈和可获取材料能力，不以按钮或配置存在当可用。

| 方式 | 适配动作与保留条件 |
| --- | --- |
| 语音输入 | 调用实际识别，标明收音/完成/提交，保留识别限制/更正及提供者；转写不评发音 |
| 文字输入 | 收取原答和明确提交，区分本地草稿与核心收到；不代替未改条件的口语/听辨任务 |
| 图片/作品 | 用户明确选取并预览范围，提交可获取引用/内容和来源，画面不能证明未观察部分 |
| 动作/家长报告 | 提交实际结果/原话、提供者与帮助，报告不冒称直接视觉观察 |
| 文字/声音/图像输出 | 按当前许可呈现、记录真实范围/失败/打断，技术完成不推定收到或理解 |

界面可适配布局、字号、操作入口，教学措辞、知识含义、答案、帮助和接续条件不擅自改写。生成的教学声音与儿童原始录音区分，后者默认不归档。

## 输入事件

按[统一课堂交接](../classroom/boundaries-events.md)保留会话/任务联系、事件身份、实际内容/来源/提供者、接收时间和识别/媒介限制。按钮明确发送控制请求，自然话语由核心结合当前任务理解，interface不必须先给答案分类。

清楚且完成的输入按轮自动提交，不要求家长逐句转交。识别片段不当完整答案，含糊时展示/复述必要部分以澄清，更正连接原事件并保留原答；若核心已换题，核对影响而非静默评分下一题。输入完成、回声/打断和重发按[统一提交规则](input-submission.md)由本模块适配器落实；教师合成声音不当学生发言。

提交与处理反馈按实际来源显示，重发同一事件不重复计尝试，真实两次同句回答不按文本去重。角色声明与实际作答者分别保留，来源未知不能补成儿童独立表现，见[roles-devices.md](roles-devices.md)。

## 教学动作与交付反馈

动作连接会话/任务、身份和适用状态、目的、允许内容/实际素材版本、对象/阶段、下一步等待及失败/取消路径。interface取得当前许可后呈现，教师答案/完整简报不先交学生再隐藏。

反馈连接实际动作/版本、对象与媒介，说明开始、部分/完整交付、失败、取消、打断及范围。核心据此决定继续/补交/备用/暂停；interface不以播放结束独自进下一题，也不自动确认目标/小结已收到。

当前会话变化、暂停/停止后，旧动作和迟到模型/声音/素材不呈现。重复交付和真实再答分别关联，不能重试播放就再评分。技术状态可以本地显示，教学状态与转场以核心实际结果为准。

## 媒介变化与任务条件

字幕、全文文字、朗读、重播、语速或图片支架按任务许可与允许范围处理。听力观察不能全局自动展示全文字幕，未启用提示不提前呈现；改变条件须通知核心并记录实际支持，不能仍称原条件独立样本。对媒介改变的影响不明时保留待核对，不直接允许全部替代。

能力失败或切换入口时按已核实备用、跳过/暂停/停止路径，由核心判断用途是否维持。原条件无法满足且无备用时显示具体缺口，不让界面手动勾选绕过就绪。提交状态和责任按统一规则确定；语音协议及停顿/等待参数经实际入口检查后绑定，未验证的自动模式保留缺口。

[平台实时语音](../platform/realtime-voice.md)明确首版完成输入识别、核心允许、合成及实际播放反馈，interface接续具体设备，不另有直接语音教学路线。[技术交接](../platform/handoffs.md)携带当前动作/版本、期限、取消和真实范围；权限/数据条件核对实际能力，不用语音入口或配置声明代替。

# 课后评价页、补记、认可与更正

文档版本：2.0.2；更新：2026年10月21日；范围：逻辑设计，按[ADR-0018](../../decisions/ADR-0018.md)实施中。

活动结束后，interface先显示事实封存结果，随后应用协调层自动请求评价；评价页呈现evaluation结果并取得学生的补记、异议、认可或更正。原事实、判断和修订由评价维护，状态/计划/Jane/课程分别由对应模块处理。暂停不进入封存，正常结束、未确认、停止和中断分别显示。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 评价的状态

| 状态 | 含义 |
| --- | --- |
| 评价中 | 事实已封存，评价任务在后台运行或失败待重试 |
| 等你认可 | 当前来源版本的评价已保存，学生尚未认可 |
| 有异议 | 学生提出异议后，评价按异议原文重做中 |
| 已认可 | 学生认可了确切的评价版本；之后状态采用与规划自动进行 |

建档小测的评价不单独请学生认可，确认学习资料即视为认可（见[建档](../learning/profile.md#建档)）。

## 补记与异议

认可前，学生可以补记（实际体验、额外帮助、查了什么、离屏结果）或提出异议（认为某题判断不对及理由）。两者都追加为同一活动的来源，不制造新活动或尝试；来源版本变化后评价重新进行，回到“等你认可”。异议原文同时作为更正说明，受影响的任务判断在新评价里先按待复核处理。详细规则见[评价输入](../evaluation/inputs-feedback.md)。

认可绑定确切的评价版本；评价已因补记或异议更新时，认可旧版本被拒绝，并提示查看新版本。认可后要再改，走原有更正流程：提交关联原活动/修订与原因，由evaluation核对、更正及回查依赖；按更正重写的评价再请学生认可，复核期间受影响的课程不列为下一步。评价因补记、异议或更正重写后，详情页列出“与上一版相比”：上一版概括与每道判断改变的题（如“单次独立 → 未知”），没有改变时注明；未认可时说明认可后学习状态才按新版更新。界面呈现旧新解释、实际影响与待处理，不直接改分数或等级，不覆盖原始记录。

## 显示内容

| 默认内容 | 来源与呈现 |
| --- | --- |
| 实际完成/结束、每题原答与帮助 | evaluation的事实/任务判断，保留条件和未知，不显示未经观察的掌握 |
| 结论与依据 | 每题的判断、依据和限制；规则调整单独列出 |
| 状态与计划变化 | 认可后learning实际处理结果及依据，待处理部分仍为建议/未知 |
| 下节预期 | 目标、基本帮助与待观察；换目标时先请学生确认 |

事实保存、评价、状态/计划落实、课程备课分别显示；未收到实际结果不能显示统一绿色完成。保存失败、下游冲突或中断显示已完成/未完成范围，提供针对原修订的接续。历史查阅保留当时版本和更正原因。

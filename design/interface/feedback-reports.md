# 课后反馈、报告与更正

文档版本：1.2.0；更新：2026年10月12日；范围：逻辑设计，未实现。

活动结束后，interface先显示事实封存结果，再接收家长当时或稍后的一次反馈并呈现evaluation结果；原事实、判断和修订由评价维护，状态/计划/Jane/课程分别由对应模块处理。暂停不直接进入最终归档，正常结束、未确认、停止和中断分别显示。

## 一次反馈

默认用一段文字/语音或必要作品补充：孩子实际体验/原话、额外帮助/代答、离屏结果、材料熟悉度、家庭投入与下次条件变化。可明确提交“无额外补充”或“没观察到”，不要求全逐字稿、逐题打分、能力等级或重填档案。

反馈关联原活动、提供者、实际发生日期/报告日期及识别限制。界面角色不能单独证明实际说话者，来源不明保留未知；自动结构化摘要可查但不覆盖原话。需要时预览所选作品和提交范围，不自动上传/扫描整个相册或持续采集。

填写中、已提交/受理、需关键澄清与失败按实际结果显示；失败重试沿用原提交/活动，不创建新样本。只对评价提出的关键冲突短澄清，不将反馈变成第二次课堂。详细规则见[评价输入](../evaluation/inputs-feedback.md)。

按[共同接续](../shared/execution-recovery.md)分别显示“事实已保存，反馈可稍后补充”或“保存失败/尚未确认”。取得封存成功回执后可关闭并从原活动继续；未成功时说明实际缺口。未提交反馈草稿不当反馈，也不隐式落盘。阶段性评价、反馈待补与下一课适用范围分别显示，不因家长未反馈抹去已保存事实。

## 家长报告与处理状态

| 默认内容 | 来源与呈现 |
| --- | --- |
| 实际完成/结束、表现与帮助 | evaluation的事实/任务判断，保留条件和未知，不显示未经观察的掌握 |
| 备课课堂关键对照 | 固定计划 → 实际 → 原因/许可/影响 → 主责关联与建议，不只看完成率 |
| 状态与计划变化 | learning实际处理结果及依据，待处理部分仍为建议/未知 |
| 下节预期 | 目标、基本帮助、挑战/退出和待观察，课程仍需备课与当前检查 |
| 改进与缺口 | 各模块实际修订/检查范围和未完成项，不能把生成建议当已修复 |

默认短报告，原答、材料依据、详细对照和更正历史按需展开。报告生成、记录保存、状态/计划落实、Jane改进、课程修订/备课完成分别显示；未收到实际结果不能显示统一绿色完成。模型/技术细节按实际需要供家长查看，不塞进学生教学操作。

报告可按入口阅读/朗读，保持判断含义与限制，显示/播放不自动表示家长接受重要方案。课中孩子的小结和课后最终报告分别来源，不能将课后新解释记成孩子课上已听到。

评价依据先保存供learning落实，家长汇总报告后取得实际处理结果，采用[共同顺序](../shared/execution-recovery.md)。界面不让报告与状态互等；汇总失败只接续该步骤，原记录和已有效状态保留，关键失败/更正不由绿色显示解除。

## 更正与下节接续

家长可更正原答/帮助/日期等事实，提交关联原活动/修订与原因，由evaluation核对、更正及回查依赖。界面呈现旧新解释、实际影响与待处理，不直接改分数/学生等级，不覆盖原始记录或重放控制器。

收到下节建议后可回工作台准备下一课，learning形成需求，preparation生产核实包；建议生成不自动进入课堂或绕过重大决定。明确决定关联具体方案/版本，常规更新不逐项审批。

保存失败、下游冲突或中断显示已完成/未完成范围，提供针对原修订的接续。历史查阅保留当时版本和更正原因，归档不隐藏已知错误。

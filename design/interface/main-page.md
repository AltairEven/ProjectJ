# 主页面

文档版本：2.11.0；更新：2026年11月20日（扩展阅读，[ADR-0033](../../decisions/ADR-0033.md)）；范围：逻辑设计，按[ADR-0018](../../decisions/ADR-0018.md)实施中。

主页面是学生唯一的交互页面：左侧固定导航，主页只给一件“下一步”。interface呈现各业务模块的权威结果，不另建能力评级、计划、教案或评价副本；“下一步”与后台任务由应用协调层根据已保存对象算出，界面不另作判断。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 栏目与子页面

| 栏目 | 内容 | 学生的操作 |
| --- | --- | --- |
| 主页 | 下一步（只有一件）、最近一课摘要、本周计划摘要、后台进行中的事与失败原因 | 按下一步进入对应页面；失败的后台任务可重试 |
| 学习状态 | 学习资料（蓝思起点、背景、兴趣、可用时间、想加强的方面、可用实物与条件）、各方面情况（每项写依据，没有依据写“未知”）、分数变化（最近5节课按能力的平均分与题数，再逐课按题型与能力；未知不计，整课没有已知分数时写“没有已知分数”，[ADR-0020](../../decisions/ADR-0020.md)）、能力条目 | 修改学习资料；查看依据 |
| 学习计划 | 主/辅目标、各层计划、待决定方案、待确认的新目标与新能力条目、复盘记录 | 同意或不同意方案；确认或不同意新目标；主动发起复盘 |
| 课程 → 课程详情 | 每课一行及状态（备课中、等你确认、待上课、已上、已评价）；详情含说明、故事、题目、预计帮助、教学资源与讨论记录 | 写修改意见让AI改稿；试听、查看、重新生成或选回旧版本资源；确认课程；准备好后开始上课（当前配置的参考题集不是通过时，开课块提示一行、不拦开课）；已上或已评价的课可“Expand this story”：选四档难度之一把课文扩写成分章英文小说（写进全部生词、每章配图），本课的书列出进度、失败原因与重试，完成的书下载EPUB，并可对某一章写修改意见只改写这一章（[ADR-0033](../../decisions/ADR-0033.md)）；课中、有扩写或改写在运行、或参考题集在运行时不能扩写、重试或改写 |
| 课堂 | 从课程进入，全屏；顶部是课堂进度条与控制，下面三栏按1:2:1：左侧Jane说的话，中间课文与图片，右侧作答框与朗读录音，各自滚动，见[学生课堂视图](student-classroom.md#当前任务与操作) | 作答、求助、暂停/继续、重复、离屏返回、停止；跳过与收尾放在“更多”里 |
| 课后评价 → 评价详情 | 每课一份评价及状态（评价中、等你认可、已认可、有异议）；详情含每题原答、帮助、结论与依据；本课标记的词（释义、发音）与本课转为已掌握的词（[ADR-0024](../../decisions/ADR-0024.md)） | 补记、提出异议、认可；认可后改动走更正；听词、重新生成释义 |
| 生词 | 全部标记过的词：“生词”按权重从高到低，“已掌握”按掌握日期从近到远；每词展开显示原形、已标词形、词性、释义、状态、首次与上次标记、累计标记次数、上次见到、退出计数、权重、掌握日期与课程、每次标记所在课程与句子、出现而未标记的课程；数据直接读学习档案的生词记录，权重由服务端算出（[ADR-0024](../../decisions/ADR-0024.md)） | 听发音；重新生成释义；不手动标已掌握、不删词、不改释义 |
| 设置 | 模型、本机评分与合成的状态；各类AI调用的等待时长（七项，保存后下一次调用生效，课中可改）；各用途的模型绑定（含扩写用的“Expanded reading”；适配器与模型下拉选择，模型选项取适配器当前提供的列表，取不到时手填；保存时先探测候选配置，通过才切换，未通过时保留原配置并列出原因；课中不可改；当前配置未通过探测时开课与AI工作被拒绝；[ADR-0025](../../decisions/ADR-0025.md)、[ADR-0032](../../decisions/ADR-0032.md)）；课堂判断参考题集（Classroom judgment check：当前课堂判断配置、题集状态未运行/通过/未通过/需补跑、最近一次整套运行的通过数与耗时、判错题的题号原因与Jane回应、运行进度；课中与模拟数据空间不显示）；备份、导出；封存重试与丢失补报 | 查看；修改等待时长与模型绑定；确认后运行整套题集或补跑调用失败的题（每题一次），运行中不能开课；执行维护操作 |

首次使用（没有学习资料）时直接进入[建档](../learning/profile.md#建档)，完成前左侧栏目不可用。

## 下一步

主页只显示一件学生要做的事，优先级从高到低：建档未完成 → 课堂进行中或中断待处理 → 待决定方案 → 评价等你认可 → 新目标等你确认 → 下一课读什么、练什么 → 课程等你确认 → 课程已确认、等你开始上课 → 资源准备中或失败 → 没有待办。AI正在进行的事（备课、评价、规划、整理资料、复盘、准备资源、课堂判断参考题集、扩写或改写一本书）显示在“后台进行中”；失败时写明原因并提供重试（确认课程、开始上课、参考题集与扩写在各自页面重新发起，主页只显示原因）。扩写进行中开课时，开课先取消扩写再打开课堂。

上一课是学生中途停止（或服务中断）的、评价还等认可时，“评价等你认可”同时提供“重上这节课”（2026年10月21日用户要求）：进入课程详情，从头再上同一版课程，规则见[课程详情与开始](preview-start.md)。

“下一课读什么、练什么”直接在主页的下一步里完成（2026年10月21日用户确认样子）：题材单选，列出Jane想的几个题材并各附理由，每个题材前标出课文形式（如Letter、Talk、Diary，[ADR-0031](../../decisions/ADR-0031.md)），最后一项“我想读别的”配输入框（Jane没列出题材时只有输入框）；知识点按词类、时态、句型分组勾选，Jane建议的项目默认勾上并写理由，最多3项，可以不选，另可写“其他想练的”；题材之后是“Story difficulty”单选（四档，各写目标蓝思值，如“Challenge (650L)”，预选学习资料里的档位；改了随提交存进学习资料，[ADR-0023](../../decisions/ADR-0023.md)）；按钮“交给 Jane，开始备课”，题材没选也没写时不能按。提交后Jane才开始备课（规则见[学习管理](../learning/README.md)）。刚认可的评价（含更正后重写的）还没规划完、或规划失败等重试时，不出现这一步、提交也被拒绝，显示后台进行中；按新评价规划出的下一课需求才请学生选（2026年11月10日修复：曾按将被替换的旧需求先选，选择随重新规划丢失、备课卡住）。建档小测不选；重上停止的课不重新备课，也不选。

状态同时说明对象版本、判断范围、未知与可执行下一步，不能只显示一个绿色就绪标记。

耗时的事显示进度条并写明正在做什么（2026年10月20日用户要求）：后台任务给出项数时（准备资源第n/m项）按比例填充，其余（备课约5分钟、评价与规划一两分钟、讨论改稿等）显示持续移动的进度条；按下的操作在返回前不能再按，避免重复提交（建档时“听 Jane 问”按钮——现为“Hear Jane ask”——曾因没有反应被连点13次、逐次排队合成）。页面不弹出浏览器右键菜单，输入框保留以便粘贴和拼写检查。请求已受理、处理中、成功、失败或仍未知来自实际结果，点击按钮不直接宣布完成。

## 后台推进

学生每次操作之后、页面每次读取主页数据时，应用协调层检查是否有该由AI做的下一步（评价、状态采用与规划、备课、复盘、整理资料），有就启动；同一任务同时只运行一个，课堂进行中不启动任何任务。任务凭原操作身份续接已保存步骤，服务重启后再次打开页面即接续。任务失败保留原因，等学生重试，不自动无限重试。

## 课中

课堂只使用核心已有的必要状态与控制，不新增屏幕监控、课堂快照、原始音频归档或额外Agent检查。离开课堂视图要停止本端采集与播放；暂停不等于结束。课前走[课程详情与开始](preview-start.md)，课后走[课后评价页](feedback-reports.md)。

## 复盘与决定

复盘到期后由AI自动发起，学生也可以主动发起；日期到达不自动标计划完成。重大方案展示明确版本、原安排、拟变化、影响、替代和复查条件，学生的决定连接该版本；依据变化后需复核的方案不能直接应用旧接受。

# 家长与学生界面

版本：1.5.0；更新：2026年10月12日；范围：模块设计，未实现。

提供家长工作台与学生课堂两种视图，呈现学习闭环并控制操作负担。先考虑当前电脑，可扩展同设备切换及家长、学生分设备使用，部署方式待定。

- 输入：计划、课程预览、当前课堂状态与材料、评价和下节预期。
- 输出：家长选择与反馈、孩子输入、实际确认与暂停/停止等操作事件。
- 包含：家长课前预览与材料准备、课中必要控制、课后一段反馈；学生语音、阅读、图像及离屏活动入口。
- 边界：学生视图不提前暴露答案与评分依据；界面不自建评分、进阶或课堂转场规则，业务判断交对应模块。

家长应拿到课前预览、课后评价、下节预期三份简短结果。上课不要求频繁操作，反馈不要求完整逐字稿。等待、含糊识别和故障需有可理解的提示与接手方式。

教师始终呈现Jane，不提供教师阵容或按学科换教师。可在既定范围内表达方法/语速等偏好，家长看到实际版本、必要改进说明与依据；偏好和一次体验不直接变成全局规则。反馈仍以实际体验为主，不要求每日教师评分。职责与版本见[teacher交接](../teacher/handoffs.md)。

按[一页预览](../preparation/parent-preview.md)呈现本课理由、基本预期/帮助、流程时间、材料与家长职责、挑战/退出和缺口。预览已生成、家长实际阅读与必要决定分别记，不把显示页面推定为已了解，也不要求逐题审批或重填档案。

显示[备课完成与当前可开课](../preparation/readiness.md)的实际范围及未知，由对应模块提供判断；本次开始操作可合并必要条件确认，已明确授权不重复询问。学生材料按对象与阶段呈现，不能提前暴露简报、答案或支架。

课程库按[候选与复用](../curriculum/discovery-reuse.md)显示近期候选、待准备、已备好和历史使用，附选择理由、实际版本、条件/缺口及更正限制。固定版本不显示成当前可开课，用过一次也不永久完成，停用历史仍可查原因。

按[资源呈现](../curriculum/presentation-resources.md)只获取当前对象/阶段允许内容，不能先向学生传完整答案再隐藏。真实使用和更正以对应模块来源呈现，不另建成绩、进度或教案副本。

作为[交互适配层](../classroom/boundaries-events.md)，接收实际操作/输入并利用platform识别等能力整理统一事件，按classroom允许教学动作呈现和回报实际交付范围；不必提前判断自然语言教学意图。教师措辞/题意/答案不由界面擅自改写，不以播放完成直接转场或推定收到/理解。

当前会话的明确暂停/停止立即取消本地录音、播放与等待，并同步核心，不等模型批准；迟到动作不显示或发声。入口声明实际能力，切换按[会话接续](../classroom/session-start.md)核对受影响条件，不另开学习样本；目标/收尾确认来自实际输入，离屏提供明确返回方式并停止连续互动。统一交接未实现。

按[一次反馈设计](../evaluation/inputs-feedback.md)收原话、补充/更正及必要决定，家长不逐题评分/评级；按[报告与处理状态](../evaluation/reports-revisions.md)呈现评价、状态/计划实际变化、下节预期和[课堂关键对照](../evaluation/lesson-alignment.md)，证据按需展开。建议、已保存、已落实和课程备好分别显示，界面不另建评分或用显示/朗读替代重要决定。

本目录存页面职责和交互设计，现有web/仍为实验原型。总入口见[模块设计](../README.md)。

# 家长与学生界面

版本：1.8.0；更新：2026年10月16日；范围：模块设计，未实现。

提供家长工作台、学生课堂和交互适配，串起准备、预览、启动、课堂/离屏、反馈/报告与下一课。interface取得实际输入并按许可呈现，classroom维护教学状态/动作，platform提供媒介、会话/权限等能力；不另建评分、能力、计划或转场。

## 输入、输出与边界

- 输入：权威计划/状态/需求、版本预览/素材及缺口、课堂状态/允许动作、报告与实际更新结果、平台能力/技术反馈。
- 输出：实际家长选择/条件/必要决定、孩子回应/作品或报告、统一控制/交付反馈、一次课后原话与更正。
- 边界：家长/学生按职责取内容；页面进入、点击、显示/播放不自动变成已读/接受/收到/理解/任务完成。常规处理不增加审批，重大决定按实际授权。

## 共同规则

家长工作台优先显示下一课、最近结果和必要待处理，状态附范围/缺口/下一步。家长不重填档案、逐科评级或逐题审批；全学科相关状态和未知可查。课程候选、草案、备课完成、本次可开课、使用与报告分别呈现，不能用单个绿色标记代替。

学生专注当前任务与Jane，自然回答、求助、确认自动接续，不要求固定口令或家长每轮委派。技术输入/处理/呈现状态如实说明，界面不独自转场；指认来源清楚，离屏停止收音/连续互动，返回不代填完成。字体、控制与提示适合使用者，不只用颜色表达。

统一输入事件、教学动作、交付反馈按[课堂合同](../classroom/boundaries-events.md)连接实际对象/版本/状态。作答、求助与确认以文字/点选明确提交，含糊/更正保留原来源；只有英语朗读评分任务录音，录音只交发音评分，教师声音不当孩子回答，英语发音以发音评分为据。素材按[对象/阶段](../curriculum/presentation-resources.md)取得，学生不提前拿完整答案/简报或未启用支架；字幕、重播、语速与备用遵守任务条件，不把媒介变化当等价独立样本。

预览来自preparation，当前检查由classroom/platform联合处理，按[两层就绪](../preparation/readiness.md)核对实际依据。角色/页面/设备切换沿用原会话，明确当前学习输入与教学语音输出；角色标签不证明实际提供者。访问限制由业务/平台执行，家长接手先暂停，返回不重交旧答案。

明确暂停/停止本端即时取消并同步核心，不等模型批准；断网区分本端已停与同步未确认，恢复先核对控制/状态，迟到不呈现。重复事件/反馈只处理一次，真实同句回答仍保留实际尝试。进程丢失明确中断和缺口，不假定完整恢复。

按[评价入口](../evaluation/inputs-feedback.md)分别呈现事实封存、反馈追加和评价结果，短报告和对照可展开证据，更正连接原活动。报告生成、记录保存、状态/计划落实、Jane/课程修订和备课完成分别报告，界面不自行改能力/答案或以显示代替重要决定。

课中只必要内存/已有状态，不监控、截屏、写快照、归档原始音频或运行检查；未提交草稿不自动当反馈/保存。[ADR-0007](../../decisions/ADR-0007.md)记录决定，设计文档不证明新版界面、多端、真实声音或教学效果，见[总标准](../../docs/acceptance.md)。

项目阶段、真实数据权威与新旧设计关系统一见[共同入口](../shared/README.md)。

# 验收报告与使用资格

版本：1.0.1；更新：2026年10月12日；范围：组件设计。

应用协调层维护验收报告和由证据推导的使用资格；各业务模块负责其检查结果，platform保存和核对实际运行配置，classroom在开课时消费有效范围。家长决定是否采用课程或开展陪伴试教，不能把未通过的必需检查变为通过。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 验收对象

一份报告连接稳定身份/修订、用途、应用构建与规则版本、课程/素材/Jane/简报、模型与输入提交策略/设备配置、检查案例、执行日期与方式、真实证据引用、通过/失败/未知/未执行、检查责任及适用范围。与本报告无关的配置不强制绑定；影响结论的实际依赖必须可定位。

“可信”表示能核查谁以何种方式对哪个实际版本做了什么、得到什么结果；不是模型自称通过，也不是一段无来源总结。程序测试、内容核验、真实 API/声音、成人流程与儿童效果分列。模拟不能改标为真实执行，历史证据保持原范围。

报告按[学习者归属规则](../learning/profile.md#学习者归属与扩展边界)明确共享范围或指定学习者。模型接口、停止和设备等通用检查在版本/条件匹配时可复用，无需为每个孩子重测同一技术事实；个人课程适配与儿童数据条件、本次需求和开课资格分别核对。另一位孩子通过试教不自动证明当前孩子适配，个人证据也不能混入通用报告后扩大为全体通过。

## 形成与失效

1. 应用层按使用场景确定所需检查项，取[总验收标准](../../docs/acceptance.md)及当前课程声明。
2. 各检查责任模块提交结果和实际证据，缺失保留未执行；应用层核对范围/版本完整性。
3. 保存报告，按必需项形成允许范围、条件或阻断清单；报告未保存或保存未知不作为新的开放依据。
4. 模型/输入策略/构建/课程等相关变化，或已知缺陷，标明受影响范围待复核；无关变化不使全部证据失效。
5. 修复或核实备用后追加新结果和报告修订，保留原失败；开课采用当前有效报告及本次实际条件。

## 使用层次

| 使用范围 | 依据与限制 |
| --- | --- |
| 隔离开发检查 | 明确模拟数据与可重复结果，不接真实儿童来源 |
| 成人真实检查 | 相应接口/声音和实际体验证据；单轮、五分钟、30分钟分别记录 |
| 家长陪伴的儿童试教 | 适用内容、程序、停止/故障、真实媒介、时长、数据与来源接入条件具备，家长明确采用；长期教学效果列待观察 |
| 后续教学效果判断 | 引用真实后续独立表现、保持/迁移、体验和负担；不反向要求试教前先证明长期效果 |

资格是有条件的结果，不是永久全局开关。classroom还要执行[本次开课判定](../classroom/session-start.md)；暂停试用、发现阻断问题或相关配置变化时收缩相应范围，报告保留历史。已有原型检查与新设计验收的实际状态见总验收标准。

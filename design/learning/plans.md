# 长期与短期计划

版本：1.5.0；更新：2026年11月2日；范围：逻辑设计；下节需求参考最近几节课的分数已实现（[ADR-0020](../../decisions/ADR-0020.md)）。

计划表达目标、安排和验证方法，实施记录表达实际发生，评价解释实际表现，[状态](state.md)综合有依据的当前判断。四者分别维护并相互引用。没有实施反馈时，计划不能自动变成完成记录。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 层次与职责

| 层次 | 负责的决定 | 细化程度与复查 |
| --- | --- | --- |
| 长期路线 | 全学科基础、学习方法、自主责任、应用创造的阶段方向 | 约十年的方向与开放路径；每年或重要条件变化时回看，不锁定每日课表、产品、专业或职业 |
| 年度计划 | 少量优先目标、学科投入关系、学校衔接与家庭边界 | 年度重点；阶段复盘后必要时修订，不要求全部学科同步进阶 |
| 阶段计划 | 当前问题、目标、材料候选、验证方法与调整条件 | 初期沿用八周周期，第四周和周期末复盘；周期长度可根据后续需要调整 |
| 周计划 | 近期活动组合、时间安排、复习与观察任务 | 通常只细化下一周，远期保留候选；根据实际反馈滚动修订 |
| 下一课需求 | 本次目标、依据、相关状态、条件与取样要求 | 给备课的交接单，不重复完整教师流程、题卡和素材 |

各层连接上级目标；已有课程和实际记录回连对应需求与目标。下级小调整不自动重写上级方向，但应能解释如何服务当前重点。

## 每个近期目标的共同内容

- 目标与范围：主要学科/能力、涉及概念、辅助学科及上级目标。
- 选择依据：相关状态、证据日期、家庭优先级与当前缺口。
- 可观察任务：希望孩子做什么，在何种材料、场景和帮助条件下做。
- 验证方法：如何区分首次尝试、帮助后完成、延迟保持与新情境应用；不必每次测全部维度。
- 达成与复查条件：哪些证据支持继续、拓展或小步进阶，哪些情况保持未知或需要再观察。
- 活动与预算：基础练习、融合活动、离屏、休息及家长投入，安排是候选还是近期确定计划。
- 调整与退出：疲惫、持续帮助无效、材料不合适、家庭忙碌时怎样缩短、替换、暂停或结束。

完成篇数、课时或作品属于活动量，不能单独作为能力目标。目标的评价条件应适合学科与任务，不用统一分数评所有学科，也不把“两次完成”当所有能力的掌握标准。

## 综合规划与融合选择

英语优先是当前家庭决定，全学科状态用于选择合适的场景和先备条件，不自动平均分配所有学科时间。

规划同时考虑：当前主线、学校必要衔接、相关学科基础、保持/迁移需求、兴趣体验和家庭投入。学校进度作参考，不是家庭难度上限；提前接触后续材料与更深应用分别判断。

融合活动明确一个主要目标和一个辅助目标。其他涉及能力可作为先备条件或机会性观察，不能全部成为必须完成的教学目标。没有证据的先备条件，可在课内用短任务观察，不把全部未知交给家长测评。

选择巩固、拓展或进阶时：帮助依赖多则先改变支持并留独立尝试；当堂会但保持不足则减少新内容并安排复习；熟悉情境会而换材料困难则用相近变式；本课主要目标全部单次独立时增加一种主要难度，平均低于6分时退回上一步，其余由规划判断（[ADR-0030](../../decisions/ADR-0030.md)，替代原“独立与后续保持支持时再增加一种主要难度”；“变难”指题目变难，故事难度仍按学生自选档位）。关键证据不足可短探索，不提前宣布稳定能力。

## 时间与实际进度

时间来自已确认家庭条件，包含回顾、讲解、练习、离屏与收尾。可用预算不表示必须用满；周末余量不全部排课，可选挑战替换等时活动。暂停和忙碌版不自动产生补课债务。

计划状态描述尚待准备、正在实施、暂停、已复盘或被新方案替代等实际情况；具体存储命名后续确定。日期到达不触发完成，课程数完成不证明阶段能力达成。阶段可以在复盘后结束并延续未达目标，保留结论和缺口。

延期只调整未来安排，实际活动日期不改成原计划日期。偏离学校进度需考虑真实前提，但不要求家长逐次批准既定范围内的拓展。

需求与计划的正式修订按[共同合同](../shared/business-contracts.md)取得保存与适用依据，[继续条件](../shared/execution-recovery.md)区分暂定草案、正式备课和本次启动。上一课待反馈/更新失败时不把拟议表现当有效状态；无关旧基线可经明确复核沿用，计划未改也返回沿用的实际版本。

## 下一课需求的最小内容

| 内容 | 说明 |
| --- | --- |
| 目标与路径 | 一个主要、一个辅助目标；巩固/拓展/进阶及选择依据 |
| 相关学习状态 | 各学科及工具前提、帮助条件、材料经历、未观察项与证据引用 |
| 预期与基本目标 | 希望取得的最小实际表现；未知时可明确为观察目标，不预填成绩 |
| 教学与验证要求 | 预计帮助、纠错重点、首次尝试、复习/延迟复查、新材料或离屏取样需求 |
| 家庭条件 | 时间、实际可用材料、陪伴方式及已确认约束 |
| 可选挑战与退出 | 增加哪一种难度、进入依据、退回/跳过/停止条件，不能加时堆任务 |
| 版本与缺口 | 当前档案/状态/计划引用、需求修订、关键材料或先备缺口 |

学习规划与备课的请求附上最近5节课按题型与按能力的平均分（10分制，未知不计）与题数，不带题目、作答或理由（[ADR-0020](../../decisions/ADR-0020.md)）：规划据此决定下节课学什么、往哪方面加强；备课据此选题型与变种，默认用法是某题型平均8分以上升一级变种或少出、5分以下降一级或多练一道、题数少于3只作参考，由AI决定，规则不强制。分数低不等于没学会，结合评价的依据与限制判断。

备课请求另附学习者[生词记录](profile.md#生词记录)里全部状态为生词的词及权重（[ADR-0024](../../decisions/ADR-0024.md)），由备课请求时从记录算出，不写进需求文档；备课AI参考权重自己决定用哪些、用几个，规则不强制。复习课与建档小测不附。

具体交接见[handoffs.md](handoffs.md)。备课可提出更合适的材料与路径，不静默改变主目标或评价标准；学习管理处理需求修订，重要方向变化交家长决定。下一课建议、周计划入口都不是开课许可。

教师始终是[Jane](../teacher/README.md)。计划提供目标、状态和家庭条件，备课按[教师交接](../teacher/handoffs.md)选择Jane方法并绑定实际版本；不增加教师选择或独立的教师学生档案。方法改进不自动改目标或产生能力进度。

## 复盘和需求选择

周、阶段、年度及长期回看按[复盘用例](plan-review.md)执行，由learning维护事项和结论、应用层组织步骤。到期只产生待复盘事项，家长可主动发起，应用正常访问时发现到期并提供入口。

evaluation提出[下一课候选建议](../evaluation/next-lesson.md)，learning综合状态、全学科目标、预算和家庭条件，记录采纳/修改/暂缓/不采纳理由，再保存选定需求。状态中的待巩固/验证项不是第二份需求，建议也不直接成为备课指令。重大变更采用[具体方案合同](../shared/business-contracts.md)，已接受方案还须保存并复核生效。

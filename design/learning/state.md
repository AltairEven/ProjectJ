# 全学科学习状态

版本：1.2.3；更新：2026年11月2日；范围：逻辑设计，未实现。

状态服务综合规划与学科融合，覆盖全部学科，而非只有当前优先学科。英语优先决定近期目标和投入，不限制可记录的知识与能力。框架完整不等于立即逐科测试；尚未观察保持未知。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 领域与能力组织

| 层次 | 维护内容 | 例子与边界 |
| --- | --- | --- |
| 学科知识与能力 | 概念、知识关系、学科方法和具体技能，关联必要的先备条件 | 语言阅读与表达、数学计算与推理、科学观察与解释；不只记教材章节 |
| 跨学科学习能力 | 提问、计划、求助、检查、依据解释、修改、工具使用与AI核验 | 注明实际任务范围；会检查阅读答案不自动表示会检查数学运算 |
| 综合应用表现 | 在实验、调查、编程或创作中结合知识完成任务、解释过程 | 保留各学科表现和综合表现；作品完成不证明每项能力独立掌握 |

领域可包括语文、英语及其他语言、数学、科学及后续物理/化学/生物、历史、地理、道法、计算机与信息技术、艺术、体育健康、劳动等。这里是可扩展领域示例，不替代正式课程标准或教材目录。

使用稳定的学科、能力和概念标识连接状态、目标、任务与证据；同一范围不因Agent措辞变化另建能力。学段变化可细分领域并保留映射，不能把“科学”中的一次表现扩展到全部物理、化学、生物。教材体系和课程标准作为有来源的参考层，实际选用前另行核实；不预先建立十年全部知识节点。

新增领域复用任务、帮助、证据和修订规则，但有自己的内容与评价依据。先备关系来自核实材料或注明为待验证假设，不能只因年级或知识目录邻接而认定已具备。

统一目录维护、候选、别名/合并/细分及历史映射按[capability-catalog.md](capability-catalog.md)，由learning负责，其他模块引用。[共同合同](../shared/business-contracts.md)规定尝试/帮助/证据单位，避免Agent换措辞产生新能力或新样本。

## 当前状态的组成

| 部分 | 保存什么 | 防止的混淆 |
| --- | --- | --- |
| 任务范围内的能力判断 | 能做什么、条件与证据 | 不用一个全科总分或宽泛“英语水平”代替 |
| 学校与家庭材料位置 | 学校报告位置；家庭实际接触、练习、独立应用的位置 | 材料位置不等于掌握，计划材料不等于已接触 |
| 保持与迁移 | 实际学习后间隔再做、相近难度的新材料或新情境应用 | 当堂重复、原题背诵不冒称延迟保持或迁移 |
| 待巩固与待验证项 | 各维度缺口、待观察/复查及有据方向 | 供综合规划选择，不是已选定下一课需求或既有能力事实 |
| 体验与家庭负担 | 孩子原话、当次参与情况、准备和陪伴投入 | 当次疲惫不变成性格、动机或学习障碍标签 |

外部测评、教材进度和平台等级是[档案参考](profile.md)，通过引用服务选材，不直接填充任务能力状态。状态不复制完整实施记录，具体事实与证据由评价模块维护。

## 一条能力判断需要的内容

| 内容 | 说明 |
| --- | --- |
| 学科、能力与任务范围 | 明确行为、材料类型和适用难度；必要时关联概念与先备条件 |
| 实际表现 | 原答或作品引用；当前工作判断与解释另列 |
| 材料与场景 | 课程/材料版本、任务、首次接触或熟悉程度、表达方式等已知条件 |
| 帮助 | AI、家长或其他人的实际帮助；按受影响维度记录。课中帮助程度未知不默认独立；外部帮助只在学生说了时记，没说不阻止独立（[ADR-0030](../../decisions/ADR-0030.md)） |
| 日期与证据 | 实际活动日期、来源记录及其修订，最近观察日期 |
| 保持与迁移 | 有相应样本才填写；未观察保持未知 |
| 不确定项与下一步 | 证据适用范围、可能的替代解释、复查或教学需求 |

语言的听、说、读、写分别维护；学科理解、工具操作和表达负担也可分开。只记录实际证据支持的维度，不为每个计划目标自动生成观察。

## 工作判断与帮助条件

| 工作判断 | 含义 |
| --- | --- |
| 尚未观察/无法判断 | 没有可用样本或关键条件不明，不能转成0分、不会或失败 |
| 需要帮助 | 该任务中需要内容帮助，记录帮助类型和实际结果 |
| 单次独立完成 | 条件清楚的一次独立样本，不称稳定掌握 |
| 不同日期多次独立完成 | 至少两个不同活动日期、范围与独立条件相近的样本；是保守工作约定，不是通用掌握标准 |
| 表现不一致 | 不同条件、样本冲突或波动；解释范围和待核实项 |

这些标签不是统一升级阶梯。多次独立完成不自动证明保持、迁移或更难材料中的表现；不同学科也不共享一个等级。

帮助区分：无内容帮助、轻提示、步骤/句框/翻译等支架、完整示范，以及未知。单纯重复任务说明不必视为内容帮助；任务本身允许的图片是否影响独立性按评价条件判断。首次尝试与帮助后表现分别保留，后来的正确答案不能覆盖初答。换指导方式不降低已经发生的最强帮助程度。

整课含多种帮助时，按任务与维度记录，不标记整堂独立。语音转写不能用于判定发音质量，识别含糊时保留未知。

## 融合任务

备课读取所有相关维度，包括主要和辅助学科、必要知识、工具条件与学习方法。通常只增加语言、学科概念、工具操作中的一种主要难度，挑战替换原活动，不自动加时。

假设未来某实验中，学生能用动作或图示解释两次结果，却需要英语句框表达（课堂全英文，[ADR-0021](../../decisions/ADR-0021.md)）：科学理解与英语表达分别更新；科学结论只能覆盖实际观察范围。若还涉及计数或测量，只有实际取到样本才更新数学状态。

同一个任务可关联多个学科与综合应用表现，并引用同一份证据；不能计为多个日期的独立样本。融合成功不表示所有学科都掌握，融合困难也不能自动归因于某一学科。需要时通过动作、图示或简单独立任务区分语言与学科前提。

## 状态有效性

新难题失败不撤销旧简单任务中的有效表现；旧证据过久或条件改变时标注适用范围并安排轻量复查，不自动计算退步或遗忘。重复使用旧作品不形成新观察，计划到期和日期增长不形成进度。

实际修改遵循[课后更新](updates.md)，向备课只提供相关摘要与证据，见[模块交接](handoffs.md)。本文件没有为当前孩子创建状态或引入真实数据。

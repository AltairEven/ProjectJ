# 学科能力与概念目录

文档版本：1.0.0；更新：2026年10月12日；范围：逻辑设计，目录系统未实现。

learning维护全模块共用的学科、能力与概念身份及范围，curriculum、preparation和evaluation引用同一目录。目录定义“观察什么”，[学习状态](state.md)记录“实际有什么依据”；目录条目不是学生等级或掌握事实。

## 最小条目与维护责任

| 信息 | 要求 |
| --- | --- |
| 身份与类型 | 稳定标识、学科/跨学科/综合应用范围，区分能力、概念及材料参考 |
| 定义与边界 | 可观察行为、所涉及任务/条件、不支持的外推范围 |
| 关系与映射 | 必要上位/细分、别名、跨学科联系、教材/标准来源；先备关系注明核实或假设 |
| 修订与来源 | 定义版本、来源/提出模块、日期、变更范围与引用影响 |
| 使用情况 | 候选、可引用、被替代或待核对；名称变化不自动产生新能力 |

preparation/curriculum可提出新概念或能力，evaluation指出映射缺口，learning核对既有范围、来源和别名后维护。常规有据目录维护不交家长逐项评级或审批；关键范围无法确定保持候选，不靠模型措辞自动生成永久能力。

只建立实际需求涉及的条目，不预先扩展十年全部知识图谱。尚无对应目录时可保留原任务范围及有据观察，映射待核对；不能为填目录损失原事实，也不必阻塞所有其他维度。

## 新增合并与细分

新增先查定义/别名/相关任务，确定新范围才建立身份。相同名字可能不同能力，例如故事事件排序与数的大小排序不能因“排序”合并；不同名称也可能指同一范围，核对后引用已有条目。

定义只是措辞更清楚且范围未变时修订同一身份；范围变化、细分或概念关系改变时保留旧定义和映射。合并保留原身份及来源关系，不删除旧引用、不相加同一证据的样本数。细分后不能把旧宽泛判断自动复制给所有子项。

教材、课程标准和外部量表是有来源的参考映射，实际使用前核实。阅读分值或平台等级不能直接成为所有听说读写能力，年级不能当目录能力层级。

## 边界示例

以下为目录设计示例，未创建真实条目或孩子状态：

| 示例范围 | 可支持的任务 | 不能外推 |
| --- | --- | --- |
| 从短文定位明确事件 | 在规定材料/帮助条件下找到一项直接信息 | 不自动表示推理、口语或所有难度阅读掌握 |
| 用观察结果解释一次比较 | 实际结果/报告与相应概念有据的解释 | 不把模型预设结果或英语句框当独立科学结论 |
| 对给定数进行大小排序 | 明确数域、表达/工具和条件的实际任务 | 不与故事排序合并或推定全部数学推理 |

共享条目不要求各维度统一等级。融合任务可引用多个条目，但样本/帮助仍按[共同合同](../shared/business-contracts.md)分开，来源日期不重复。

## 目录变更与下一课

目录修订通知使用方涉及的身份/定义与范围。learning重审相关状态映射，evaluation回查受影响解释，curriculum连接旧任务引用，preparation复核目标/任务；无影响不废弃旧课程。

历史保留当时定义及原依据，更正不重放课堂事件或生成新表现。正在课堂使用的定义不热换；下一课按[适用性与继续条件](../shared/execution-recovery.md)复核受影响部分。具体数据格式和维护工具后续决定。

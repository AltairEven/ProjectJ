# 学习管理

版本：1.0.0；更新：2026年10月11日；范围：模块设计，未实现。

维护长期方向、阶段与周计划、基础参考及有依据的学习状态，为下一堂课提出需求。家庭进度可以提前、拓展或进阶，年级和学校单元只作参考。

- 输入：家庭目标与时间预算、基础参考、已整理的真实反馈和评价依据。
- 输出：下一课需求、计划调整、注明来源与不确定项的学习状态修订。
- 包含：基础参考推算、分维度能力与材料位置、复习与复查需求、巩固/拓展/进阶选择。
- 边界：不要求家长重复更新年龄或给能力等级；日期增长不生成能力或进度；不直接宣布下一课可开课。

evaluation提供状态更新依据，由本模块维护状态和计划。preparation接收本模块的下一课需求。一般小调整由AI落实并解释；优先级、长期方向、固定时间预算和主要评价方式变化由家长决定。

LearningWithAI目前仍是家庭档案与历史来源。本目录只放设计，不复制真实档案。总入口见[模块设计](../README.md)。

# 学习管理

版本：1.2.0；更新：2026年10月12日；范围：模块设计，未实现。

维护孩子档案、全学科能力状态、长期与短期计划，为下一堂课提出有依据的学习需求。英语优先是当前家庭目标与时间分配，不限制状态框架的学科范围。家庭进度可以提前、拓展或进阶，年级和学校单元只作参考。

| 文件 | 负责说明 |
| --- | --- |
| [profile.md](profile.md) | 基础参考、推算背景、家庭条件、外部测评和兴趣信息的组织与来源 |
| [state.md](state.md) | 全学科知识与能力、跨学科学习能力、综合应用表现、材料位置和证据条件 |
| [capability-catalog.md](capability-catalog.md) | 统一学科/能力/概念身份、定义、别名/合并/细分与历史映射 |
| [plans.md](plans.md) | 长期路线、年度、阶段、周计划及下一课需求，目标与调整条件 |
| [updates.md](updates.md) | 课后更新、去重与更正、冲突和未知处理、调整权限及变化说明 |
| [handoffs.md](handoffs.md) | 与备课、评价、课程和课堂的交接，版本一致性与未来验收场景 |

这些文件是逻辑设计，不规定数据库、API、最终代码路径或多Agent实现。示例均为假设，不是孩子的实际表现。

跨模块采用[共同合同](../shared/business-contracts.md)和[执行/失败接续](../shared/execution-recovery.md)，由learning维护目录/有效状态/计划/需求；事实/评价先保存，状态/计划及需求实际生效后再采用，候选与旧基线继续条件明示。

## 信息归属

| 信息 | 维护责任 | 本模块如何使用 |
| --- | --- | --- |
| 孩子档案、全学科状态、计划及其修订 | learning | 维护当前有效内容及修订依据 |
| 课堂原答、实际帮助与完成报告 | classroom；结束后由evaluation整理 | 引用实际记录，不从教案生成表现 |
| 最终实施记录、证据和评价 | evaluation | 使用任务判断与修订依据，不另存一份相互竞争的事实或逐题评分 |
| Jane唯一角色、全局方法与改进版本 | teacher | 提供相关状态与计划依据，不另建学生记忆 |
| 课程、素材、评价依据及绑定的Jane版本/本课简报 | curriculum | 引用实际课程与教师绑定，不将备课内容当学习进度 |
| 备课过程与课程就绪 | preparation | 提交需求、处理可行性缺口，不宣布课程已就绪 |
| 实际存储、来源与版本传递能力 | platform | 业务归属不等于存储实现，具体技术后续决定 |

输入是家庭目标与条件、基础参考、已整理的真实反馈及评价依据；输出是相关状态摘要、下一课需求、计划调整和可追溯的修订说明。状态面向全部学科与跨学科能力，但不要求同时测试全部维度；尚未观察的部分保持未知。

## 维护与使用边界

- 基础参考提供一次，按日期推算背景；不要求家长定期填年龄、年级或能力等级。日期增长、计划到期和教材位置不能生成掌握结论。
- 学科知识与能力、跨学科学习能力、综合应用表现分别维护。每条判断保留任务范围、材料、日期、帮助、证据与不确定项；不同学科可处于不同位置。
- 学习需求连接当前状态与目标；先备知识、学校进度、家庭材料位置和实际能力可区分。融合课分别判断各学科及工具条件，通常只增加一种主要难度。
- 课中仅有本堂必要内存与判断，不维护正式长期状态；结束且收到家长一次实际反馈后统一整理。成人、技术模拟不构成儿童证据；教师示范本身不能证明孩子掌握，实际接触与帮助后尝试分别保留。
- evaluation提供状态更新依据，本模块负责将依据落实为跨课状态与计划；preparation接收下一课需求。常规有依据的小调整由AI落实并解释，重要方向、优先级、固定预算与主要评价方式由家长决定。
- Jane是唯一教师，[teacher](../teacher/README.md)依据评价维护教学方法与改进版本，学生状态与计划仍归本模块。备课选择Jane方法，课堂读本课简报，不另存教师专属学生画像。
- 只细化近期计划，不预排十年每日课程。不复制全部历史给每次备课，也不把未知项全部变成家长问卷。

LearningWithAI目前仍是家庭档案与历史证据的权威来源。J的学习管理尚未实现；本轮只完善设计，不导入真实档案、生成儿童状态或回写旧项目。未来迁移必须明确唯一维护入口、来源和版本，见[旧项目关系](../../docs/legacy-import.md)。总入口见[模块设计](../README.md)。

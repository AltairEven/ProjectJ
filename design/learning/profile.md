# 孩子档案与基础参考

版本：1.0.0；更新：2026年10月11日；范围：逻辑设计，未实现。

档案保存判断学习条件所需的事实与参考，不承担课堂记录、能力评价或设备故障日志的职责。设计入口见[学习管理](README.md)。本文件描述结构，不复制当前家庭的真实信息。

## 档案的组成

| 信息组 | 内容 | 更新依据 |
| --- | --- | --- |
| 基础参考 | 学习者标识、出生年月、某日期的实际学段与年级、必要的学制参考；性别可选 | 家长提供一次；错误更正或实际路径变化时更新并留来源 |
| 家庭条件 | 学科优先级、固定时间预算、陪伴方式、可用材料与环境、学校要求等必要条件 | 家长提供；重大变化按决策权限处理 |
| 外部测评与学习经历 | 测评名称、日期、结果、报告是否读取、帮助条件；阅读平台或教材的已报告位置 | 保存每次来源与条件，不覆盖历史或换算为所有能力的等级 |
| 兴趣与活动偏好 | 孩子选择、家长观察、发生日期和场景 | 根据实际反馈积累，区分近期偏好与多次观察，不固化为性格 |
| 当前状态与计划入口 | 指向相关状态、计划及最新修订 | 只作入口；内容分别按[state.md](state.md)与[plans.md](plans.md)维护 |

不强制记录真实姓名、学校班级、联系方式或与教学无关的信息。缺少性别等可选信息不阻塞规划。设备、账号、模型设置、语音检查和成人故障历史归运行与验收模块；家庭的陪伴约定和实际可用学习条件仍属于档案。

## 固定参考与按日期推算的背景

- 出生年月用于计算读取当日的年龄范围，不另维护容易过期的“当前年龄”。只有年月时，不补造具体生日。
- 学段与年级保留实际报告日期。可按明确的学年和学制假设推算预计阶段，标注计算日期与假设，不称已核实学籍。
- 实际跳级、留级、转学制等变化由家长补充后更新参考；保留原报告和更正原因。预计升学不推定实际大学入学、专业或课程。
- 背景可以随日期重算，学习状态与材料位置仍必须依据新反馈。年龄增长不表示已经学会相应年级内容。

这些推算只提供规划背景，不是难度上限或进阶条件。不同学科、阅读与表达可具有不同的实际起点。

## 来源与历史

每项事实保留内容、来源、报告日期、实际发生日期（已知时）、核实范围和不确定项。家长陈述、已读取报告、学校反馈和AI推算可区分；不知道测评条件时保持未知，不默认独立作答。

外部测评分数与实际任务表现分别保存。不同平台等级不自动换算；历史估计与后来的测评结果不直接计算增长。阅读指标用于选材，不能推定听力、口语、写作或其他学科能力。

学校教材进度保留为带日期的报告；家庭实际材料位置由实施记录维护。教材页码、完成练习数量和平台读到的位置都不单独证明掌握。未读过的教材内容不能凭单元编号补造。

更正事实采用新说明与新修订，保留原来源。家长可以更正事实、指出AI解释不合适；AI根据更正重新审视相关判断，不要求家长填写替代能力等级。

## 家长输入负担

日常只需提交一段真实活动反馈，必要时附原作品或学校材料；不要求定期重填基本信息、全部教材进度或逐科评分。只有影响当前备课或状态判断的关键缺失才询问，例如：实际说话者、是否提供内容提示、学校参考发生了真实变化。

没有完整档案时也可先进行合适的观察活动；与当前任务无关的未知不阻塞。阶段变化时重新评估陪伴和自主使用方式，年龄只是背景，还需实际表现与家长决定。

当前数据仍由LearningWithAI维护。未来迁移时需保留来源日期、更正历史及状态证据链接，不在J和旧项目中同时维护两个权威档案，见[交接与一致性](handoffs.md)。

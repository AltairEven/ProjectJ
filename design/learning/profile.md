# 学习资料与建档

版本：2.3.1；更新：2026年10月28日；范围：逻辑设计；按[ADR-0018](../../decisions/ADR-0018.md)实施中。

学习资料保存判断学习条件所需的事实与参考，不承担课堂记录、能力评价或设备故障日志的职责。设计入口见[学习管理](README.md)。本文件描述结构，不复制任何真实信息。不预设学生是孩子还是成人；课程难度与内容按学习资料和学习状态决定。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 学习者归属与扩展边界

每个数据空间只有一名学习者，有稳定内部标识；一名学习者一套学习资料、全学科状态、计划及证据关系。标识不依赖姓名、账号或当前页面。

| 范围 | 归属与复用 |
| --- | --- |
| 个人学习对象 | 学习资料、状态、计划、需求、备课采用关系、活动/封存事实、补记/评价、复盘、待办和待决定方案均明确所属学习者；引用链核对同一归属 |
| 通用内容与Jane | 能力目录、资源/模板、可复用课程内容及Jane通用策略可以共享；个人适配与采用关系按学习者保存，Jane仍只有一个身份 |
| 验收与使用资格 | 通用技术检查报告可声明共享范围；内容适配、需求与本次开课资格核对学习者归属 |

操作者不等于学习者身份：学生请人类教师协助时，程序不区分操作者，所有补记与决定都记在这名学习者名下。个人对象缺少归属或引用冲突时先核对，不推补。多学习者以后需要时按上述边界扩展。

## 学习资料的组成

| 信息 | 内容 | 更新依据 |
| --- | --- | --- |
| 英语蓝思阅读值 | 规范写法“数字+L”或“BR+数字+L” | 建档时必填；学生可在学习状态页修改，留修订 |
| 文章难度档位 | 持平（+0L）、稍难（+50L）、挑战（+100L）、更难（+150L）；没有时按挑战（[ADR-0023](../../decisions/ADR-0023.md)） | 学生在学习状态页或选题材时修改；每课认可评价时评“太难/正好/太简单”自动降一档、不变或升一档，到头不动；留修订 |
| 聊天原文 | 建档时Jane固定问题与学生的原话 | 建档时保存，之后不改 |
| 背景、兴趣、每周可用时间、想加强的方面 | AI根据聊天与小测整理的文字 | 学生确认或修改；之后可随时修改 |
| 可用实物与条件 | 课程可以使用的实物与环境，可不填 | 学生填写；不填时课程不安排离屏实物任务 |
| 当前状态与计划入口 | 指向相关状态、计划及最新修订 | 只作入口；内容按[state.md](state.md)与[plans.md](plans.md)维护 |

不强制记录真实姓名、年龄、学校班级、联系方式或与教学无关的信息。模型请求只带学习资料、状态与任务数据，不带学习者标识。

蓝思值、外部测评与教材位置只用于选材参考，不换算为任何能力维度的判断，也不推定听力、口语、写作或其他学科能力。备课按蓝思值加档位定故事的目标蓝思值与词数（建档小测不加档位）；目标值是选材目标，不是测量。档位与难易评分不进课后评价、学习状态与规划。学习资料修改后，下一次规划与备课读取最新版本；修改不追溯已上的课。

## 建档

首次使用、或清空学习记录后，学生打开主页面即进入建档，完成前其他栏目不可用：

1. 填英语蓝思阅读值（必填）。
2. Jane用四五个固定问题聊几句（学习目的、兴趣爱好、每周可用时间、最想加强的方面），按[ADR-0021](../../decisions/ADR-0021.md)只用初学者能读懂的英文短句给出、合成播放（问题固定：服务启动时建档还没聊完就在后台预先合成，学生点“Hear Jane ask”时整句播放，不等现场合成；预合成未完成或失败时现场合成）；学生用文字回答，任一语言均可。聊天是自述，不作为能力证据评分；AI据此整理的学习资料用英文写，不超过学生的蓝思值。
3. 小测：需求由规则生成（主目标阅读事实与顺序、辅助目标英语朗读发音，注明“建档小测：按蓝思值取样，结果只作起点”），备课按蓝思值与聊天内容编写一节短课，学生点“开始小测”后照常生成资源、上课、封存与自动评价。
4. 小测评价完成后，学习规划用途读聊天原文、蓝思值与小测评价，整理背景、兴趣、可用时间与想加强的方面。
5. 学生确认或修改学习资料（可补填可用实物与条件），即视为认可小测评价；学习状态按规则采用小测评价，学习规划随后提出第一个目标与计划，学生确认后开始备第一课（见[课后更新](updates.md)）。

任一步中断后再次打开，从已保存的位置继续。判断不了的维度保持未知，不硬给分数。

## 生词记录

学生读故事时标记的词（[ADR-0024](../../decisions/ADR-0024.md)）归学习者，是一份独立文档（kind `vocabulary`），每次更新一个新修订，不进学习状态、评价与计划：

| 内容 | 说明 |
| --- | --- |
| 每个词 | 原形（小写，模型给出；查词失败时用学生标记的词形）、已标过的词形、词性、英文释义、音频文件、状态（生词/已掌握）、累计标记次数、退出计数、首次与上次标记日期、上次见到日期、掌握时的活动编号（掌握日期即上次见到日期，掌握课程即最后一次未标记出现的课程）、每次标记所在课程与句子、每次出现而未标记的课程 |
| 更新时机 | 课堂封存后立即由程序按规则更新，不等评价、不等认可；课中只在内存 |
| 标记 | 本课标记的词：计数加一、退出计数清零、状态回到生词、补齐释义与音频（已有的不覆盖） |
| 退出 | 本课读完（按过“I've finished reading”）的故事文本里出现（原形或已标词形）而没有再标的词：退出计数加一、上次见到更新；达到5转为已掌握并记活动编号。没读完的课不计 |
| 权重 | 累计标记次数 + 距上次见到的整周数；只用于排序，不设阈值 |
| 给备课 | 全部状态为生词的词按权重降序，最多100个，带原形、词性、权重、标记次数、距上次见到天数；复习课与建档小测不给 |
| 重新生成 | 课中按盒子里的词、课外按记录里的词重新查释义并合成，新结果覆盖旧值 |

释义由模型用途`vocabulary`给出：全英文、不超过20个英文词、不含原词、按所在句子的意思；规则不通过的按词记失败。词形匹配只认原形和学生标过的词形，没标过的变形不算出现（明确近似）。生词、释义与句子不进诊断日志。

## 来源与历史

每项事实保留内容、来源、报告日期与修订；学生陈述、AI整理和测评结果可区分。外部测评分数与实际任务表现分别保存，不同平台等级不自动换算。更正事实采用新修订并保留原来源。

## 输入负担

日常只需上课、认可评价，必要时补记或修改学习资料；不要求定期重填基本信息或逐科评分。只有影响当前备课或状态判断的关键缺失才询问。

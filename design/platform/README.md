# 基础服务

版本：1.3.0；更新：2026年10月12日；范围：模块设计，未实现。

为业务模块提供可替换的模型、语音、多模态、数据和通用运行能力，不决定教学目标、难度或学习进度。

- 输入：业务模块限定范围的模型请求、已允许回应、实际音频输入、需要保存的最终数据。
- 输出：经格式核对的模型结果、语音与素材、取消或故障状态、存储与导入导出结果。
- 包含：模型接入、语音识别合成与流式交互能力、多模态素材接入、配置、存储、版本绑定、通用验证与故障处理。
- 边界：密钥由服务端管理；模型和语音方案可替换；提示词不能冒称实际参数设置。课堂职责与备课/评价的模型配置分别核对。

停止优先，迟到结果不能推进课堂或继续播放。课中必要状态保留内存，结束且有家长实际反馈后统一归档；默认不保存原始音频、不监控屏幕。重启或故障不能用预期内容补造事实。

对[备课生产](../preparation/versions-handoffs.md)提供实际模型/素材/声音能力与结果、资源可获取性和存储状态；请求/脚本或接口成功不等于实际素材已生成且内容合格。内容用途、核验与呈现权限由preparation/classroom限定，媒介支持按实际实现验收。

联合classroom/interface执行[本次开课检查](../preparation/readiness.md)，提供当前输入/声音、材料访问、取消与备用等实际技术依据；不自行判教学就绪。必需数字内容和依赖保存不完整时明确缺口，同一修订恢复，不冒称交付成功。

课堂生成仅按允许范围使用必要内存，按阶段和停止取消/丢弃迟到结果，结束反馈后统一保存必要实际内容或引用；生成的教学音频与儿童原始录音区分。具体流式、缓存、版本一致性与保存技术后续决定，本轮不实现接口或生成媒体。

按[课程交接](../curriculum/handoffs.md)提供固定内容/依赖的保存和获取、实际可访问性、缺失与完整性结果。对象身份、版本语义、生命周期和使用限制归curriculum，平台不自行判教学就绪或替换“最新”内容。

[历史保存](../curriculum/history-corrections.md)所需原内容与依赖不因归档自动删除；近似恢复不冒称原件。原答和判断仍以evaluation为准，具体存储、备份及清理方案后续决定，本轮不执行迁移、删除或实现新系统。

按[课堂统一交接](../classroom/boundaries-events.md)为interface提供录音/识别/合成/视觉/取消能力，为核心提供有范围的模型调用和实际计时等技术结果；交付反馈带动作、版本、实际范围与失败/取消，不自行解释教学意图、评分或转场。录音结束、识别、判断、呈现开始等耗时分开，技术完成不补成学生收到。

支持对应层的即时暂停/停止，取消可控录音、播放和等待并使旧结果无效；已在远端运行的结果迟到也不得推进或交付。实际能力/缺口用于[开课与入口变化](../classroom/session-start.md)，新媒介不自动等价。[异常与内存取舍](../classroom/time-exceptions.md)明确进程重启缺口，后续持久化另设计，本轮不实现新协议或适配。

内容正确性归preparation，课堂行为正确性归classroom，评价依据归evaluation；本模块负责接入、数据和故障等通用正确性。技术栈、具体存储和语音协议后续决定；LearningWithAI对接需要独立来源与兼容设计。总入口见[模块设计](../README.md)。

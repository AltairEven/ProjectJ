## 输入输出与组织

- 输入：业务限定的模型/素材需求、实际输入、已允许教学内容、控制请求及需要保存的业务数据。
- 输出：实际能力与配置、有范围的模型结果、素材/声音、交付/取消/故障和保存状态；未知保留未知。
- 组织：七项能力共用请求身份、适用版本、权限、期限、取消和结果约定，通过可替换接入连接服务商或本地能力。
- 边界：统一接口保留各方案的能力差异，不假定所有模型支持相同媒介、参数、保留或取消；模块不要求独立服务或额外Agent。

## 共同规则

课堂核心决定教学含义与允许动作，interface执行具体输入/呈现，platform提供技术能力。首版作答为文字/点选提交，只有英语朗读评分任务录音交发音评分，模型接收文字或评分结果，核心允许后合成并播放（[ADR-0014](../../decisions/ADR-0014.md)）；不设语音识别，输入不要求家长逐句委派，不另设绕过Harness的语音教师。

第五个模型用途“生词释义”（`vocabulary`，[ADR-0024](../../decisions/ADR-0024.md)）：一次请求整盒生词，结构化输出每词原形、词性、释义，期限60秒；未单独配置时跟随课堂判断的绑定而不是全局默认档位，准入复用同一模型的探针结果（auth、model、structured_output）；新增用途改变配置摘要，现有安装须重新probe。合成器另按词合成短音频（WAV），课中只在内存，封存时写入学习者数据区的assets并随导出导入迁移。

课程、素材、Jane、简报与本堂运行配置绑定实际版本，不在课堂追随“最新”。模型结构正确、素材生成成功、声音播放完成、学生实际收到及理解分别判断，平台不自行标教学就绪或掌握。

暂停/停止本端即时取消，核心同步范围如实报告；迟到结果不得推进或交付。课中只保留必要内存，默认不存原始音频、磁盘草稿或快照、不采集屏幕。结束时按[共同封存规则](../shared/execution-recovery.md)保存，进程丢失明确缺口，不能依据教案补造事实。

本地保存、Git同步与服务商数据保留分别核对。儿童真实数据接入前检查适用政策、账户和接口能力；不以家长陪伴、本机不录音或单个参数代替服务商条件。当前仍仅成人开发范围，具体边界见[配置与权限](configuration-permissions.md)。

首版技术基线采用[选型文档](../../docs/technology.md)，实际依赖与接入按阶段0验证；性能目标以[验收口径](../../docs/acceptance.md#最小版本质量门槛)为准，多端列后续扩展。[ADR-0011](../../decisions/ADR-0011.md)细化[ADR-0008](../../decisions/ADR-0008.md)的待定选型，总入口见[模块设计](../README.md)。

项目阶段、真实数据权威与新旧设计关系统一见[共同入口](../shared/README.md)。

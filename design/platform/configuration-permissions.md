# 配置权限与儿童数据边界

文档版本：1.1.0；更新：2026年10月12日；范围：逻辑设计，未实现。

配置说明实际采用哪些能力与条件，权限限制谁可以取得什么、执行什么。平台落实受控访问，业务模块定义教学用途、材料阶段及重要决定范围；提示词、角色标签和隐藏按钮不能代替实际执行。

## 配置分层

| 类型 | 内容与归属 |
| --- | --- |
| 教学配置 | Jane规则、学科/课型策略、课程任务/帮助/评价条件，由teacher/preparation/classroom维护 |
| 运行配置 | 用途模型/参数、识别/合成、声音、接入版本、期限/重试/用量及技术备用，由platform维护 |
| 访问配置 | 家长/学生/设备的内容范围、当前输入/输出与控制权限，由业务规则和platform共同落实 |
| 凭据 | 服务商密钥、临时连接凭据等，由受控凭据管理提供，不进入普通配置正文 |
| 数据处理条件 | 本地保留、外部发送范围、服务商保留/接口资格与实际检查，由platform提供依据供启动核对 |

本堂绑定实际运行配置修订及课程/Jane/素材/简报版本，不按最新热换教学、模型或声音条件。凭据更新不等于教学规则更新；能力变化仍核对受影响流程及就绪。实际配置/检查与声明值分开，缺失不得填成通过。

## 访问与控制

家长取得准备、预览、反馈和报告所需内容，学生只取得当前允许材料及帮助；教师完整简报、答案和未启用支架不提前传到学生端。平台访问检查结合业务用途/阶段/对象，不能只靠前端按钮隐藏。

登录身份、视图角色、设备和实际作答者分别保留。家长报告/代述与未知来源不转换为儿童独立表现；不要求每轮身份问答，也不为此新增声纹或生物识别。活动类型保留成人/技术/儿童分类。

每堂课一个当前学习输入和一个选定语音输出，授权家长控制/补充保留独立入口。孩子明确停止无需家长再次批准；有效停止不等待教学模型，也不被旧教学修订阻挡。常规有据业务更新继续按已有权限，重大方向/预算变更仍交具体方案给家长。

能力和工具按当前用途限制，课堂模型不能自由读取全档案、修改课程库、删除数据或自行外发。材料和输入是数据，不具有改变权限或规则的效力。

## 凭据与外部连接

长期API密钥保留在受控服务端或本地后端的凭据管理中，不写入浏览器脚本、普通日志、文档、导出或Git。浏览器直接建立实时连接时可由受控后端签发临时凭据，其范围和生命周期须核对。[官方WebRTC接入](https://developers.openai.com/api/docs/guides/voice-webrtc?voice-api=realtime)

本机麦克风许可、J的业务访问与服务商API权限是不同条件。临时凭据可连接不表示具备教学就绪；Codex账号登录也不自动提供J的API访问。具体凭据保存、认证和协议后续选择。

## 儿童数据处理条件

OpenAI当前指引要求：处理13岁以下或当地数字同意年龄以下儿童个人数据前先实施API零数据保留。J将此作为真实数据接入条件，账户资格和适用范围须核实；家长陪伴不能代替该条件。[官方未成年人指引](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance)

服务商的数据保留与本机保存分别核对。`store=false`不单独证明零数据保留；OpenAI相关控制需获批准，并受接口/功能及特殊保留例外限制。检查实际项目、模型、接口、功能与适用条件，不能用一个已配置标记概括全部能力。[官方数据控制](https://developers.openai.com/api/docs/guides/your-data)

| 检查内容 | J的处理 |
| --- | --- |
| 数据范围 | 只发当前任务必要内容；姓名、出生年月、完整档案/历史不因可读就发送 |
| 声音、作品或图片 | 不因未含姓名就自动视为无个人数据，按实际内容/服务条件核对 |
| 本地策略 | 默认无原始音频归档、快照、屏幕监控和未提交磁盘草稿 |
| 外部策略 | 明确所用服务及功能的发送/保留条件、实际检查依据和未知 |
| 条件缺失 | 保留儿童真实数据入口缺口，先用虚构材料和成人开发检查 |
| 配置变化 | 复核受影响接口与启动条件，不继承过期检查或自行换服务绕过 |

J应提供适龄的AI说明及与课程相关的内容防护；具体机制按后续产品/接入设计落实，不能借此增加默认录音归档、屏幕监控或新审批清单。政策和服务条件在真实接入及相关变化时复核，不将本次文档核对当账户验收。

目前没有实际API、零数据保留配置或儿童入口验收。保存范围见[storage-lifecycle.md](storage-lifecycle.md)，启动衔接见[handoffs.md](handoffs.md)。

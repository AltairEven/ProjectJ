# 配置权限与儿童数据边界

文档版本：1.4.0；更新：2026年10月18日；范围：逻辑设计，实际接入未验证。

配置说明实际采用哪些能力与条件，权限限制谁可以取得什么、执行什么。平台落实受控访问，业务模块定义教学用途、材料阶段及重要决定范围；提示词、角色标签和隐藏按钮不能代替实际执行。

## 配置分层

| 类型 | 内容与归属 |
| --- | --- |
| 教学配置 | Jane规则、学科/课型策略、课程任务/帮助/评价条件，由teacher/preparation/classroom维护 |
| 运行配置 | 用途模型/参数、合成器的模型修订与声音配置、发音评分器的模型修订与门槛版本、声音、朗读段最长录音时长、接入版本、期限/重试/用量及技术备用，由platform维护 |
| 访问配置 | 家长/学生/设备的内容范围、当前输入/输出与控制权限，由业务规则和platform共同落实 |
| 凭据 | API密钥按模型适配器各存一个本地密钥文件，与绑定配置分开，订阅登录由对应运行时完成并存于该适配器自己的本地目录，临时连接凭据由后端签发；不进入浏览器读取、日志、导出或Git |
| 数据处理条件 | 本地保留、外部发送范围、服务商保留/接口资格与实际检查，由platform提供依据供启动核对 |

本堂绑定实际运行配置修订及课程/Jane/素材/简报版本，不按最新热换教学、模型或声音条件。凭据更新不等于教学规则更新；能力变化仍核对受影响流程及就绪。实际配置/检查与声明值分开，缺失不得填成通过。

## 访问与控制

家长取得准备、预览、反馈和报告所需内容，学生只取得当前允许材料及帮助；教师完整简报、答案和未启用支架不提前传到学生端。平台访问检查结合业务用途/阶段/对象，不能只靠前端按钮隐藏。

登录身份、视图角色、设备和实际作答者分别保留。家长报告/代述与未知来源不转换为儿童独立表现；不要求每轮身份问答，也不为此新增声纹或生物识别。活动类型保留成人/技术/儿童分类。

每堂课一个当前学习输入和一个选定语音输出，授权家长控制/补充保留独立入口。孩子明确停止无需家长再次批准；有效停止不等待教学模型，也不被旧教学修订阻挡。常规有据业务更新继续按已有权限，重大方向/预算变更仍交具体方案给家长。

能力和工具按当前用途限制，课堂模型不能自由读取全档案、修改课程库、删除数据或自行外发。材料和输入是数据，不具有改变权限或规则的效力。

## 凭据与外部连接

长期API密钥按适配器各存一个本地密钥文件，与绑定配置分开（见[models.md](models.md#适配器配置与密钥)），只供后端对应适配器读取，不写入浏览器脚本、普通日志、文档、导出或Git；家长页将来可写入但不读回。浏览器直接建立实时连接时可由受控后端签发临时凭据，其范围和生命周期须核对。[官方WebRTC接入](https://developers.openai.com/api/docs/guides/voice-webrtc?voice-api=realtime)

本机麦克风许可、J的业务访问与服务商API权限是不同条件。临时凭据可连接不表示具备教学就绪；订阅登录（如Codex、Claude）经对应订阅适配器接入，与API密钥是不同接入方式，能力以探针为准。朗读录音由后端交本机评分进程，不出本机；浏览器不持长期密钥。

## 儿童数据处理条件

家长确认J的模型请求不含儿童身份信息，按[ADR-0013](../../decisions/ADR-0013.md)以请求最小化作为数据条件，不再以服务商零数据保留作为真实数据接入条件。OpenAI指引对处理13岁以下儿童个人数据要求先实施API零数据保留，作为事实记录保留。[官方未成年人指引](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance)

服务商的数据保留与本机保存分别记录。`store=false`不单独证明零数据保留；各适配器所用服务、功能的发送与保留条款由家长知情采用，能力报告记录实际配置，未知保留未知。[官方数据控制](https://developers.openai.com/api/docs/guides/your-data)

| 检查内容 | J的处理 |
| --- | --- |
| 数据范围 | 只发学习阶段、学习状态与当前任务必要内容；年龄、姓名、出生年月、完整档案/历史不发送 |
| 声音、作品或图片 | 不因未含姓名就自动视为无个人数据，按实际内容/服务条件核对；英语朗读评分任务的儿童录音只在本机内存中交本机评分器，不发往第三方（[ADR-0015](../../decisions/ADR-0015.md)）；Jane的合成文字也只在本机处理（[ADR-0016](../../decisions/ADR-0016.md)）；评分与合成子工程只在各自初始化时外联下载模型，不含儿童数据 |
| 本地策略 | 默认无原始音频归档、快照、屏幕监控和未提交磁盘草稿；朗读录音只在内存交给评分后即弃 |
| 外部策略 | 记录所用适配器、服务及功能的发送范围与条款、实际检查依据和未知 |
| 配置变化 | 复核受影响接口与启动条件，不继承过期检查或自行换服务绕过 |

J应提供适龄的AI说明及与课程相关的内容防护；具体机制按后续产品/接入设计落实，不能借此增加默认录音归档、屏幕监控或新审批清单。政策和服务条件在真实接入及相关变化时复核，不将本次文档核对当账户验收。

实际API、合成与发音评分接入仍未验证，清单见[接入缺口](../../docs/technology.md#p0官方事实复核与接入缺口)。儿童入口仍按[验收标准](../../docs/acceptance.md)关闭。保存范围见[storage-lifecycle.md](storage-lifecycle.md)，启动衔接见[handoffs.md](handoffs.md)。

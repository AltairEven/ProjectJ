# 模型服务与用途配置

文档版本：2.3.0；更新：2026年10月16日；范围：逻辑设计；适配层第一期已实现（模拟、OpenAI与Codex SDK适配器），合成与发音评分未实现，实际接入未验证。

模型服务统一接入与调用，不复制业务判断规则。preparation、classroom、evaluation按用途提出必要内容和结果要求，平台经模型适配层取得结果并核对结构，接收模块核对事实、教学动作或评价依据。采用依据见[ADR-0013](../../decisions/ADR-0013.md)，语音部分见[ADR-0014](../../decisions/ADR-0014.md)。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 按用途组织

| 用途 | 默认目标绑定 | 调用条件 |
| --- | --- | --- |
| 备课与内容整理 | gpt-6.1-sol／medium | 相关资料、目标、状态与Jane方法，允许较长处理 |
| 课堂判断与指导 | gpt-6.1-sol／low | 本题、必要上下文、允许帮助与动作，优先及时响应；朗读任务接收发音评分结果，不接收录音 |
| 学习规划与复盘 | gpt-6.1-sol／medium | 相关已保存依据与家庭条件，提出有据方案，由learning核对采用 |
| 课后最终评价 | gpt-6.1-sol／medium | 实际来源、当时版本、家长反馈及必要历史 |
| 语音合成 | 独立合成适配器 | 中英文、Jane声音、流式、取消与首段延迟按实际核对；不设语音识别 |
| 英语发音评分 | 独立发音评分适配器 | 只用于朗读/跟读任务；参考文本与录音长度上限、逐词/音素结果按实际核对 |
| 多模态生产、分析 | 按用途配置 | 生成与分析分开，确认所需媒介及内容检查能力 |

前四项是文字模型用途，配置标识依次为planning、preparation、classroom_judgment、evaluation，每项可绑定不同适配器；第一期学习规划与备课尚无模型调用，只参与绑定、探测与准入。这些是项目默认目标，实际绑定由初始化配置决定，不表示账号已经接入。接入时核对实际模型ID、支持参数和生效配置，返回实际调用信息；提示词中的“Low”不能代替参数。API密钥与订阅登录是不同接入方式，各由对应适配器接入并经探针实测。模型、媒介、接入方式或服务商变化不创建另一位教师，Jane仍是唯一教师。

## 模型适配层

上层只按用途发出通用请求、取得通用结果，不感知服务商或接入方式；每种接入一个适配器，自行处理鉴权、结构化输出、参数、错误、限流与额度差异。

| 部分 | 内容 |
| --- | --- |
| 请求 | 用途、业务模块编写且与模型无关的指令、结构化上下文、结果结构、推理档位目标及期限；不设会话或线程编号 |
| 结果 | 校验后的输出，或失败类型（鉴权、额度、超时、拒绝、不完整、输出不合规、配置明确不符、不可用）；实际配置逐项列请求值、实际值及已核实/未核实/不支持；用量、耗时、请求编号、适配器名称与版本 |
| 适配器 | 调用、取消（外层取消时关闭底层请求）与探针；只取得自身配置节及密钥 |
| 统一入口 | 保存用途绑定，统一校验输出结构、判定明确不符并记录每次调用；不含业务判断 |

接入分API类（如OpenAI Responses）与订阅SDK类（如Codex SDK、Claude Agent SDK）。能严格约束结构的接入直接使用；只保证合法JSON的由适配器把结构写入指令，统一入口仍按结构校验，不合规即失败，不当作学生答错。

每次请求自带完整必要上下文，不依赖服务端或SDK会话记忆：核心掌握已作废的判断、被覆盖的输入和更正，会话记忆不能区分；请求内容即模型所见，供核对与归因。订阅类每次开新会话、只运行一轮、关闭工具，在空临时目录运行且不加载项目或个人配置；无法隔离的部分（如代理自带提示词）由探针如实报告。

实际配置不能核实的项允许启用并逐次记录为未核实，供评价与教学归因作替代解释；明确不符（如返回模型与请求不同）判失败。每个用途只绑定一个适配器，课中失败按[故障处理](failures-performance.md)，不自动切换其他适配器。

## 探针与能力报告

每个适配器实现同一探针协议，用最小虚构样本逐项实测，结果分已核实、未核实、不支持和失败：

| 探测项 | 方法 |
| --- | --- |
| 鉴权与连通 | 最小请求 |
| 模型 | 返回的实际模型是否与请求一致 |
| 推理档位 | 配置用到的每个档位各测一次，看返回是否标明 |
| 结构化输出 | 固定样本与结构能否通过校验，区分严格结构与仅JSON |
| 取消 | 发出后立即取消，测客户端收回时间；服务端停止与计费记未核实 |
| 图片输入 | 程序生成的64×64纯红图，问颜色 |
| 工具关闭 | 订阅类代理每轮返回条目中有无工具调用；出现即明确不符 |
| 耗时与用量 | 记录，不作准入条件 |

按[实时语音](realtime-voice.md)，模型不听录音、也不直接出声，文字模型不探测音频输入/输出；声音由合成适配器提供，发音由发音评分适配器评分。（2026年10月16日按底层协议实测Codex订阅，模型声明的输入只有文字和图片，发送wav时回答未收到音频，仅作记录。）能力报告绑定适配器名称/版本、模型、档位与UTC时间，初始化记录再把它与配置摘要绑定。用途声明所需能力：课堂判断需鉴权、模型、结构化输出与取消，学习规划、备课与课后评价需鉴权、模型与结构化输出；推理档位按该用途实际绑定的档位探测，可未核实；多模态用途启用时声明所需媒介，按报告准入。模拟适配器的报告标明模拟，不能当作真实能力。

## 合成与发音评分适配器

语音合成与英语发音评分是两类独立能力，不是文字模型用途，各有自己的合同与适配器，复用本层的初始化、探针、准入、凭据隔离与“未核实如实记录”规则；可与文字模型同一服务商、同一密钥，各适配器仍只读自己的密钥文件。

| 能力 | 请求 → 结果 | 探针 |
| --- | --- | --- |
| 语音合成 | 核心已批准的文本、声音配置、语速 → 流式音频；可取消 | 固定中英文短句的首段延迟、取消收回、实际声音标识；音色由成人试听，不由程序判定 |
| 发音评分 | 录音、参考文本、评测模式（单词/句子/段落） → 逐词/音素准确度、流利度、完整度、服务给出的等级（如有），服务与版本 | 固定标准朗读录音与故意读错录音，核对错误词得分更低、方向正确；记录该服务的文本词数与录音时长上限 |

准入按课程实际需要：使用语音交付的课堂要求合成通过，含朗读/跟读评分段的课程另要求发音评分通过且评分段不超过记录的上限；只用文字的课堂不要求这两项。合成与评分失败按[故障处理](failures-performance.md)：合成失败改文字呈现或暂停，评分失败该段记未知，不当作学生读错。预合成的教师语句属于课程素材，随课程包核验与保存。

## 初始化与准入

使用模型前须初始化：配置默认绑定（适配器、模型、档位）及按用途覆盖，未配置默认绑定时先配置；对配置中的每个适配器与模型运行探针；逐用途比对所需能力，不支持、失败或明确不符即不通过，全部通过才记初始化完成。初始化记录保存配置摘要（含绑定、适配器版本及密钥的单向摘要，不可还原密钥）、能力报告与时间，不含密钥；配置、密钥或适配器版本变化即失效，需重新探测。启动沿用仍有效的记录，不每次启动付费探测；家长可随时重新探测。

未初始化或记录失效时，备课、开课、规划复盘与课后评价拒绝并给出原因及处理方式；查看、导出、备份恢复与家长补记不受影响。课后评价遇准入失效只记评价失败，课堂事实照常封存；课中单次调用失败不撤销初始化。家长页显示初始化状态、各用途绑定与能力摘要，不含密钥。

第一期以命令行`project-j-init`设置密钥、配置绑定、探测与查看状态，后续由家长页加载与管理配置。模拟入口固定模拟适配器并在内存自动初始化，不读写真实模型配置。

## 适配器配置与密钥

模型配置存于本地`project_j/private/models/`：config.json只含绑定（可读），credentials/<适配器>.json各存一个适配器的密钥（只写不读），init.json为初始化记录；目录0700、文件0600、拒绝符号链接，不进Git、导出或备份。每个适配器只读取自己的密钥文件，页面读取配置时不触及密钥文件；密钥不出现在接口返回、家长页、日志、探针结果或初始化记录中。命令行以隐藏输入录入密钥，家长页将来只写不读。订阅类登录由对应运行时完成，登录状态存于该适配器自己的目录（如`codex-home/`，0700），J不读取其中凭据，也不沿用家长全局的工具配置；命令行以`project-j-init login <适配器>`登录。

## 能力接入与请求

每项接入声明实际支持的输入/输出、结构结果、流式、取消、上下文、数据保留及已验证范围。缺失或不明能力明示，不能用统一接口掩盖差异。模型返回拒绝、不完整或不可用时按[故障处理](failures-performance.md)回报，不填成学生答错。

请求连接用途、调用方、活动/任务/对象与实际版本、必要内容或可获取引用、允许范围、所需结果结构、等待期限、取消条件和用量预算。平台不自行扩大资料访问、开启工具或修改任务。重试仍属于原操作，外部接口无法确认的执行/用量保持未知。

## 必要上下文与结果采用

课堂请求使用同版本的短简报、当前题目/答案依据、相关输入/帮助和等待对象，不反复发送完整孩子档案、全部方法库或十年历史。请求只带学习阶段（[档案](../learning/profile.md)中的学段/年级）、学习状态与当前任务数据，不带年龄、姓名、出生年月等身份信息；Jane需称呼时由本地模板替换。输入和材料属于数据，不能覆盖项目规则；停止、阶段变化或新版状态使旧请求失效。

无需模型的明确控制、固定转场和已核实内容可由程序直接处理。需要模型时在本堂允许范围判断，避免每轮串联多个Agent或重新备课。资料检索与摘要仍保留来源/版本，不能丢失原答、帮助或关键不确定项。

平台检查格式和完整字段，不把“格式有效”当作事实正确。classroom按当前任务核对模型判断及允许动作，preparation核对内容，evaluation核对来源/条件。未通过采用条件的结果不直接呈现或更新状态；未批准的流式片段也不先发声。

## 版本与更换

用途配置有独立修订，保存指定模型/参数、接入版本和已验证范围；实际调用保留服务商返回的模型标识及可取得版本信息。服务商未提供固定快照时明确限制，不把同名模型视为行为永久一致。

新模型、参数、接入或上下文编排改变时，复核受影响的结构、合理变式/错答/含糊、帮助、停止、延迟和数据条件，再启用相应配置。不静默替换当堂模型；原配置失效时显示缺口或暂停，不在课中自动换用其他适配器。

历史保留原结论、实际调用与业务版本，新模型重评形成更正解释，不新增学习样本或伪装成当时判断。统一衔接见[handoffs.md](handoffs.md)，配置和数据条件见[configuration-permissions.md](configuration-permissions.md)。

实际可取得的模型/版本、参数、上下文与媒介配置差异交evaluation及teacher作为[归因替代解释](../teacher/improvement.md)。标识未变不证明行为未变；未知保留未知，出现有据回归时复核受影响验收范围，不以猜测改孩子状态。

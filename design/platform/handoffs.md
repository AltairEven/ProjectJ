# 基础服务交接与设计检查

文档版本：1.3.0；更新：2026年10月16日；范围：逻辑设计，未实现。

基础服务统一技术交接，各业务模块保持目标、内容、事实及判断权威。七项能力共享身份、版本、权限、期限、取消和实际结果，不要求新增微服务、调度Agent或选择具体API/数据库。

统一请求/结果与[共同合同](../shared/business-contracts.md)相连，platform提供实际能力、保存/未知/取消回执，业务生效由原维护者裁定。[应用层执行](../shared/execution-recovery.md)负责顺序和接续，平台不接管目标、评价或跨课计划，也不以协调进度绕过课中内存边界。

跨模块步骤由[应用协调层](../application/README.md)组织；本模块返回自己维护对象的实际结果、影响范围及下一步，操作进度不成为另一份业务对象。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 共同请求与结果

| 请求联系 | 必须说明 |
| --- | --- |
| 身份和来源 | 用途、调用方、活动类型、对象/任务/动作及原操作身份 |
| 内容和版本 | 实际内容或可获取引用、课程/素材/Jane/简报与相关状态修订、运行配置 |
| 允许范围 | 所需能力、结果形式、对象/阶段、材料许可和采用条件 |
| 运行边界 | 等待期限、取消、有限重试/预算与核实备用 |
| 数据条件 | 最小必要外发、本地/服务商处理条件及实际检查范围 |

结果返回原联系、实际模型/参数/接入或素材版本、处理范围、开始/部分/完成/失败/取消、可取得时间/用量、缺口/未知及可接续信息。字段和协议以后确定，接口成功只代表明确的技术范围，不意味着内容正确或业务完成。

课堂输入、教学动作和交付反馈仍按[统一课堂约定](../classroom/boundaries-events.md)，平台技术结果不另建第四套教学判断。普通结果采用前核对当前任务/状态；明确停止优先，不被旧教学版本挡住。

## 模块衔接

| 模块 | 向平台提供什么 | 平台返回什么及边界 |
| --- | --- | --- |
| preparation | 目标限定的模型/素材需求、检查方法、所需能力与版本 | 实际产物/配置/访问/失败；内容核验与备课完成仍由备课汇总 |
| classroom | 当前任务判断、允许回应/素材、计时/取消与采用范围 | 模型及时间/运行结果；核心管理帮助、转场、预算和收尾 |
| interface | 实际输入、允许呈现、设备/连接和控制操作 | 识别/合成/访问/取消/同步；界面回报实际呈现，不能自己评分 |
| evaluation | 结束封存、后来反馈、分析与修订保存需求 | 模型、技术事实和保存/版本状态；解释/归因和任务判断归评价 |
| curriculum | 固定内容/依赖的保存、取得和完整性需求 | 实际资源/缺失/访问；内容身份、生命周期与更正语义归课程 |
| learning | 有权限的数据读取/保存与来源修订 | 技术状态；全学科能力与计划的更新依据及落实归学习管理 |
| teacher | Jane配置/方法版本的保存与获取 | 技术结果；全局角色与改进由teacher管理，模型更换不换教师 |

本次启动联合classroom/interface核对课程绑定、[模型初始化与准入](models.md#初始化与准入)、当前能力、材料访问、停止/同步/备用及[儿童数据条件](configuration-permissions.md)。已配置、界面有入口、旧检查或家长预览不自动标就绪；保留实际检查范围和关键未知。

## 版本与归档联系

业务内容、运行配置、接入与实际模型信息分别关联。本堂固定课程/素材/Jane/简报及生效运行修订，重连沿用原活动，变化复查受影响能力，不以最新配置改历史或当堂条件。

课中只必要内存，不保存快照/原始音频；结束时按[共同封存规则](../shared/execution-recovery.md)保存实际采用内容、交付/帮助和必要技术结果。evaluation保存原事实，其他模块引用来源，存储不复制新的事实权威。进程丢失不补造，近似素材不当原件。

报告生成、原记录/评价保存、学习状态/计划落实、Jane/课程修订及备课完成分别返回结果。部分失败从原活动/修订接续，不重复样本；后来的真实依据不被旧重试覆盖。

## 未来实现需要验证的场景

| 场景 | 必须得到的结果 |
| --- | --- |
| 提示词声明Low但实际参数不同 | 显示实际配置缺口，不冒称按约定调用 |
| 接入缺少媒介、取消或数据条件 | 具体能力/范围明示，不以统一接口掩盖 |
| 新模型/声音/接入或配置修订 | 复核受影响流程，课堂与历史不热换 |
| 学生自然回答、求助、确认连续发生 | 每次完成输入自动进同一核心，家长无需逐句委派 |
| 草稿、朗读录音中/暂停中的内容、重录和教师回声 | 不计完整儿童答案，孩子提交或按结束才进入核心 |
| 模型结构有效但教学动作越界 | 核心拒绝采用，未允许内容不发声 |
| 部分播放、打断或声音生成已完成 | 回报真实交付范围，不代填收到/理解 |
| 判断/合成/生成期间停止 | 本端即时取消，迟到不播放或推进，不等教学模型 |
| 离屏、暂停、家长接手和离开视图 | 停止采集/连续互动，返回原状态取实际报告 |
| 媒介或备用改变听辨/独立条件 | 通知核心保留条件，不能静默算等价 |
| 关键素材只有请求、占位或不可访问 | 返回实际缺口，不标完整/合格/就绪 |
| 课堂生成晚到、关系错误或无法核验 | 不呈现/计独立依据，走核实备用 |
| 学生直接请求教师答案/内部简报 | 实际访问限制生效，不只界面隐藏 |
| 儿童真实数据处理条件未知 | 保留入口缺口，成人/虚构检查不代替账户与接口验收 |
| 同一事件重发与两次真实同句回答 | 前者不重复处理，后者保留两次实际尝试 |
| 断网停止、新设备或语音会话重建 | 同活动先同步控制/核心状态，归属明确，不重播旧结果 |
| 页面缓冲丢失或核心进程重启 | 说明可接续/缺口范围，不依教案造记录 |
| 课中诊断/缓存与外部服务保留 | 无隐式本地快照/音频/敏感日志，外部条件分别核对 |
| 保存部分失败/冲突或来源更正 | 原修订接续、已完成/未处理分别回报，不覆盖新依据 |
| 历史依赖缺失或近似恢复 | 原件与缺失明示，归档不自动删除依赖 |
| 后台快但实际首播慢 | 分别记录实际计时，后台结果不称听觉延迟 |

这些是未来验收要求。真实语音单轮、五分钟、30分钟及儿童效果分别验收，正式入口仍按[总验收](../../docs/acceptance.md)。

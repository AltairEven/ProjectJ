# 故障处理与运行性能

文档版本：1.6.0；更新：2026年10月20日；范围：逻辑设计，未实现。

平台报告故障事实和可用能力，业务选择允许的教学接续。技术失败不记成孩子不会，替代路径改变条件时交课堂和评价说明，不能静默维持原独立判断。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 故障类别与接续

| 类别 | 平台处理 | 业务接续 |
| --- | --- | --- |
| 识别含糊/失败、来源不明 | 保留实际结果及限制，不补答案/说话者 | 核心澄清、更正或核实备用 |
| 模型超时、网络或限流 | 期限内有限重试，仍失败明确取消/缺口 | 使用已准备路径或暂停 |
| 凭据、权限或能力不支持 | 明确实际缺口，不无限重试或扩大权限 | 修复配置；无法满足时不启动/暂停相关部分 |
| 拒绝、不完整或结构无效 | 不冒称合法完整结果，不填学生错答 | 核对原因，按允许备用或暂停 |
| 内容疑点或模型动作越界 | 返回结果/技术范围，未允许不交付 | preparation/classroom核对，不热改答案依据 |
| 素材缺失/生成失败 | 返回实际生成/访问与缺失范围，取消失效结果 | 核验备用、跳过或暂停 |
| 声音失败/打断 | 返回实际交付范围，取消待播 | 核心决定补交，不推定已收到 |
| 发音评分失败（本机评分进程未就绪、崩溃或超时） | 返回失败类别与耗时，课中不换评分器 | 该段记未知，不当读错；按允许动作请孩子重读、继续下一段或暂停 |
| 本机合成失败或慢于实时（进程未就绪、崩溃、GPU争用） | 返回实际已交付范围与原因，取消待播，课中不换合成器 | 按声音失败接续：改文字呈现或暂停，不推定已收到 |
| 连接中断/进程丢失 | 本端取消，区分可接续与内存缺口 | 原状态核对或明确中断，不造事实 |
| 保存失败/版本冲突 | 分开已保存与未处理范围，原修订接续 | 保留未完成，不重复样本或覆盖新依据 |

## 期限重试与取消

运行配置声明普通教学、素材、备课和评价的等待期限、有限重试及用量范围；首版短答与超时目标按[统一验收口径](../../docs/acceptance.md#最小版本质量门槛)实测，其他用途按实际任务配置。重试只针对允许且有意义的故障，仍核对权限、版本和取消；凭据缺失、内容越界或停止后不自动循环。

重复提交先核对原操作状态，外部接口是否支持确认/去重按实际能力处理。请求结果不明时不承诺从未执行/收费；恢复核对已知结果，必要有限重试保留不确定性，不把技术重试变成学生再答。

暂停/停止优先，立即取消本端采集、播放、等待和待交付，同时同步核心。远端任务无法取消时标明，并使返回失效；普通超时重试不能撤销停止。控制同步与普通判断/素材队列分开，不等待长任务。

界面给学生短且适龄的等待/失败说明和可用暂停方式，详细技术诊断按需给家长。没有输入、离屏或暂停不连续催促；失败不要求家长每轮重新委派。

## 时间与响应

实际计时区分总经过、教学、暂停、离屏和技术等待；平台报告时间，课堂核心按预算取舍，不由模型猜时长或用轮数代替。

| 时间依据 | 用途 |
| --- | --- |
| 提交（朗读按结束）、发音评分与判断结束 | 区分输入结束与评分/判断处理 |
| 判断开始/结束与状态核对 | 解释后台等待，不冒称已发声 |
| 合成开始/可交付及界面实际首播 | 解释声音等待及实际播放 |
| 生成、取消、中断与保存结果 | 定位运行和归档缺口 |

只有相应实际时间可取得时才计算，未知不补值。孩子说完到首播的等待与后台调用耗时分开；实际阈值需真实语音核对，模拟计时不能证明听觉体验。

## 上下文资源与最少诊断

课堂使用必要上下文与已备素材，明确控制可直接执行，避免逐轮多个Agent、重新备课或生成关键媒体。课堂请求优先于后台大量素材任务；用量预算和限制不能自动改变教学目标、评分或静默换模型。

缓存只在许可的数据范围、版本和实际能力内使用。课中缓存保留内存，服务商缓存/保留另按[数据条件](configuration-permissions.md)检查，不用“缓存优化”绕过约定。结束后技术数据保留策略按必要范围明确。

诊断默认只取请求用途/身份、实际配置、时间、结果、错误类别与用量，避免提示词、儿童原话、录音、图片、凭据进入常规日志或外部追踪。课中必要计时不是跨任务监控；不轮询课堂快照、采集屏幕或运行项目检查。

服务进程在每条链路写诊断日志到标准错误（2026年10月19日家长决定），便于出问题后排查：每个接口请求的方法、路径、状态与耗时及拒绝原因，课堂核心每个事件的种类、身份与结果字段，每次模型调用的用途、绑定、失败类别、耗时与用量，每次评分与合成的状态与耗时，学生页每句播放的方式（采样率、读取次数、迟到段数，以及浏览器给出的输出断档次数、时长与延迟），开课判定、封存与课后评价结果，以及评分、合成和模型运行时的启动与错误输出。日志只含这些元数据，不含作答、反馈、教学文字、参考文本、录音、令牌或密钥；应用自身不写日志文件、不进数据库，日志不作为课堂记录、恢复或评价依据。朗读评分耗时另随尝试封存，因为它计入十秒期限。

结束后由evaluation结合技术事实解释影响，问题交platform/classroom或内容模块处理。运行修复不自动修改能力或Jane方法，也不宣称教学效果改善。未来验收见[handoffs.md](handoffs.md)。

# 课程与教学内容

版本：1.5.0；更新：2026年10月27日；范围：模块设计，未实现；课文插图与带图题（[ADR-0026](../../decisions/ADR-0026.md)）。

管理版本化课程包、教学资源及实际绑定的Jane版本与本课教师简报，保证备课、课堂与评价引用同一份内容及依据。全局教师角色和方法由teacher维护。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

这些文件定义逻辑组织和责任，不选择技术栈、数据格式或存储方案。

- 输入：preparation产出的内容、核验与就绪依据、可追溯材料。
- 输出：带版本与来源的课程包、素材及Jane配置/策略绑定和本课教师简报，供课堂及评价引用。
- 包含：目标、材料、任务、答案依据、帮助策略、允许的现场调整、挑战与降阶、评价取样、时间与结束条件。
- 边界：课程表达计划，不记成实际表现；发布过的版本与历史保留，课堂中不悄悄改题或评分依据。

## 内容库与状态

原始资料提供核验依据，教学资源服务具体任务，模板提供可复用框架，具体课程包绑定当前需求、内容与Jane版本；历史及更正保留来源关系。原材料、答案和方法各有权威来源，不复制出互相竞争的副本。

稳定标识表示同一对象，版本表示实际内容修订。固定版本可引用、核验和派生，未完成检查或资源缺口仍明确保留；固定/本地发布不自动表示备课完成或当前可以开课，也不涉及远程同步。

课程生命周期、备课完成情况、本次启动条件和实际使用关系分别维护。同一版本可由多堂真实活动引用，课程不能仅因用过一次就永久标成完成；活动事实与结束状态由evaluation维护，本模块只引用。

复用依据目标、条件、材料熟悉度与检查范围，已经接触过的材料不能冒充首次新材料。全学科索引引用统一能力/概念标识，学校年级与教材位置不是能力或复用许可。

已使用版本保留原内容及依赖，更正以附加说明和新修订处理。已知错误限制受影响的未来使用，并追踪历史评价与状态；停用或归档不能随意删除必要材料。

备课负责怎样生产和核对，课程模块负责保存什么、怎样标识及引用。[teacher](../teacher/README.md)负责Jane唯一角色、通用规则、学科/课型方法及其改进版本；本模块保存preparation编制的本课简报和版本引用，不维护第二份全局教师规则。

课程绑定实际Jane、启用策略与简报版本，不能仅引用会变化的“最新Jane”。准备期间版本变化只核对受影响部分，已实施课程保留当时内容与条件，课堂不热更新。具体交接见[teacher/handoffs.md](../teacher/handoffs.md)。

按[课程包设计](../preparation/course-package.md)保存目标/任务/答案、教学分支、实际素材、简报、核验与预览及依赖。素材带用途、来源、关联任务、可见阶段、检查和备用；内容相互引用，不维护多份不同答案。逻辑组成不预定物理文件或数据格式。

preparation提供[备课完成依据](../preparation/readiness.md)，本模块保存并保证可获取；本次开课条件由classroom/platform/interface核对。保存不完整、依赖变化或关键内容更正时，按[版本交接](../preparation/versions-handoffs.md)重审相关就绪依据，不能只保留旧绿色标记。

课程与素材目前保留在项目courses/。未来生成素材应与课程版本、来源及可用范围绑定，未审核素材不能成为独立评价依据。总入口见[模块设计](../README.md)。

课程组织、固定版本与历史更正的设计决定见[ADR-0004](../../decisions/ADR-0004.md)。

项目阶段、真实数据权威与新旧设计关系统一见[共同入口](../shared/README.md)。

# 版本、生命周期与使用关系

文档版本：1.1.0；更新：2026年10月12日；范围：逻辑设计，未实现。

标识表示对象身份，版本表示内容修订。课程、资源、模板与任务依赖有可回查的实际版本，不在课堂中读取会变化的“最新内容”。本文件中的发布仅指本地形成可引用固定版本，不表示对外公开、远程同步或允许开课。

## 身份与修订

- 同一课程修订保留课程标识并产生新版本；学习目的或课程用途形成新课程时建立新标识，连接来源/派生关系。
- 资料、资源与模板独立记录版本；相同资源被复用时保持引用，不为每门课复制一个无来源副本。
- 任务保留所属课程/模板与标识，实际题意、材料、答案、帮助或取样条件变化要能定位对应版本；不能只凭同名合并样本。
- 具体课程绑定需求/状态依据、任务、素材、Jane配置/策略、简报、核验和预览；文档版本与这些业务版本分别标识。

## 相互独立的状态

| 信息 | 含义与维护来源 |
| --- | --- |
| 草案 | preparation正在编制，可修订；缺口明确，不用于绕过开课条件 |
| 固定版本 | 实际内容与依赖声明已确定，可核验、引用、派生；未知/缺失仍注明，不自动代表合格 |
| 被替代 | 有后续版本或方案；原版仍可回查，后续是否可选按适用范围判断 |
| 停用 | 已知问题或不适用限制了未来选择/执行，保留原因和范围，原历史仍可访问 |
| 备课完成情况 | preparation按实际内容、素材、教学和检查范围判断，curriculum保存依据 |
| 本次开课情况 | classroom/platform/interface按当前版本、设备与家庭条件检查，本次有效 |
| 使用关系 | 指向实际活动/修订及使用的版本、任务和资源；事实由evaluation维护 |

这些是逻辑状态，具体字段与存储后续决定。固定版本不自动通过核验，有已知关键缺口不能备课完成；生命周期不被“ready”单个布尔值代替。

一份课程使用过、活动结束或某堂课提前停止都不能把课程永久标成完成。多次使用引用各自真实活动，活动日期和样本次数来自实际记录，不能因多个资源/学科引用重复计算。

## 固定版本的形成

1. preparation提交当前实际内容、对象/依赖、核验状态、缺口和来源。
2. 核对目标/任务/答案/素材/简报引用一致，实际已取得内容与未取得依赖分别记，不能把缺失素材声明成已生成。
3. 固定本次内容与依赖声明，记录版本、范围和来源；未验证候选可用于核验，仍显示待检查，不能进入正式课堂。
4. 后续完成核验时添加与该固定内容对应的检查记录；若修复改变内容或依赖，则形成新版本并复核影响。
5. 实际采用前读取停用/更正和有效检查范围，再做本次启动检查；不以固定、发布或用户预览代替。

检查、生命周期说明和更正可以追加有来源的修订，不覆盖固定的教学内容。备课完整交付仍按[两层就绪](../preparation/readiness.md)，当前原型儿童入口不可用，本轮没有建立版本发布系统。

[共同执行](../shared/execution-recovery.md)明确变更源、复核主责、限制范围和解除依据。curriculum保留固定内容，对适用性/停用/检查追加有来源修订，原课程存在不代表仍适用；无影响的范围可明确沿用，关键疑点未处理不能从旧绿色状态启动。

## 依赖变化与课堂绑定

素材事件/数值/关系、答案、提示、Jane方法或运行条件变化时，检查受影响任务与就绪依据；没有影响的检查可明确复用，不能整体继承旧版通过结论。范围见[备课版本约定](../preparation/versions-handoffs.md)。

classroom在进入本堂时绑定实际版本及允许材料/分支，本堂不热换全局内容。已实施课堂保留当时依赖；现场允许变式以实际使用内容与条件在结束反馈后记录，不悄悄改课程版本。

已知错误或资源失效需要限制后续使用并追查相关依赖。若课堂发现关键问题，按已有暂停/跳过/停止路径处理，不能悄悄换答案后把原答重新判为正确或错误。历史和更正见[history-corrections.md](history-corrections.md)。

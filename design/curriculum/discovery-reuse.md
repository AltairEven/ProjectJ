# 课程检索、复用与派生

文档版本：1.0.0；更新：2026年10月12日；范围：逻辑设计，未实现。

内容库返回候选及条件，learning/preparation结合当前需求选择和适配。候选匹配不表示材料已核验、孩子掌握前提或当前可以开课。索引支持全学科，不局限于当前优先英语。

## 索引信息

| 维度 | 保存的描述 |
| --- | --- |
| 学科与目标 | 主要/辅助学科、能力和概念引用、课型、任务用途与实际应用场景 |
| 前提与任务要求 | 概念、语言、表达、工具、材料条件及预计支持，未知明确 |
| 难度依据 | 实际文本/题目/概念关系与任务要求、正式指标及其来源（存在时），不是全科等级 |
| 时间与家庭投入 | 预计时间、离屏、实物/工具、家长准备与陪伴、忙碌/降阶选项 |
| 资源与运行需求 | 文字/声音/图像/交互、必需与可选、可获取性、备用和适用检查范围 |
| 生命周期与来源 | 草案/固定/替代/停用、版本、核验缺口、来源与更正、派生关系 |

预计时间不冒称实际课堂耗时。年级/教材位置是衔接标签，不替代能力；自编材料不标为官方分级或实测Lexile。能力/概念标识引用统一目录，不另建学习状态体系。

原资料、模板与资源可分别检索。原始来源可核实不表示相关题卡已适配，模板完整不表示全部学科策略已验证。每个候选显示选择理由、适用条件、尚缺什么，不只按名称或主题排序。

## 复用层次

- 原资料复用：核对实际读取内容、版本及来源，不能只沿用可能变化或已失效的链接。
- 资源复用：核对用途、可见阶段、帮助与答案关系、当前可获取性；同一图/音频在不同任务中的帮助作用可能不同。
- 模板复用：保留阶段与必要分支，结合Jane策略及实际任务生成课程；不复制孩子历史或预填成绩。
- 课程包复用：重新核对当前需求、相关状态、熟悉程度、时间/材料/输入条件及检查范围，必要时由备课产生修订或派生课程。

复用不默认继承全部核验。原内容和使用条件未受影响的检查可以有范围地引用，改变数值/语义/图示/反馈/取样条件时重审相关部分，不每次重复全部演练。

## 材料熟悉度与取样

孩子是否已接触材料由learning/evaluation的真实记录或家长报告提供；成人演练、课程已保存和备课次数不表示孩子读过。条件不清时保留未知或轻量核对。

假设未来一篇故事已用于阅读教学，它可供复习；不能再次称为未见材料的首次独立阅读。若要观察新材料理解，可复用结构换核实文本，形成对应课程/资源版本。这个例子不构成当前孩子的实际记录。

复习、帮助后练习、独立验证、保持和迁移分别核对条件。语言输出困难不自动更换更低阅读/科学内容，学科融合要检查所有相关先备与工具条件，通常只增加一种主要难度。

## 派生与选择权限

同一课程内容改进用新版本；新目的/用途形成新课程时保留派生关系、复用对象、改动与检查范围。模板和共享资源剥离不必要的个性化背景，只引用当前课需要的状态依据。

常规有据的小调整在已有授权内由AI完成，重大目标/预算/主要教学或评价方式变化交家长决定。内容库提供候选，不自动替换周计划、不生成儿童进度或启动课堂。

家长界面可显示近期候选、待准备、已备好和历史使用；“已备好”与“本次可开课”分别展示。不预先生成十年全部资源或课程，逐步维护实际出现的教学需求。

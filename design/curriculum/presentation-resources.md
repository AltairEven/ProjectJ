# 素材来源、呈现与使用边界

文档版本：1.2.0；更新：2026年10月12日；范围：逻辑设计，未实现。

资源具有实际内容、来源、用途和呈现条件。curriculum保存这些声明与版本，preparation负责生产/核验，classroom与interface按阶段呈现，platform提供获取与播放。资源存在不自动表示已核验或适合当前任务。

## 来源与资源信息

| 信息 | 要求 |
| --- | --- |
| 身份与实际内容 | 资源标识/版本、类型、原件或可获取引用、取得范围、缺失项 |
| 来源 | 已读资料版本/片段与日期、作者或出处、改写/生成关系；自编与原文可区分 |
| 教学用途 | 关联任务、知识/语义/数量关系、材料要求，是否承载答案或提供内容帮助 |
| 呈现条件 | 学生/家长/教师对象、出现阶段、需要的展示/输入能力、反馈时机 |
| 检查与可获取性 | 实际内容/显示/试听结果、适用范围、版本与取得方式，失效/停用和更正 |
| 备用与变化 | 必需/可选、核实备用、允许变换范围、检查及条件变化影响 |

引用链接要注明实际读取范围，链接存在不证明已经读过或可稳定回查。原件、摘录、改写与生成内容分别识别；不能仅凭文件名、平台等级或教材单元补造内容。

未知来源、未取得媒体或只有生成脚本时，保留未知/待生成，不显示实际产物已就绪。实际任务的事实、图文关系、声音清晰度等按[素材生产约定](../preparation/multimodal-materials.md)和[核验](../preparation/verification.md)检查。

## 对象与阶段呈现

- 学生任务材料：当前阶段可取得的文本/图片/音频/操作要求，不能提前泄露独立观察答案。
- 教师内部内容：答案、错误依据、帮助分支、完整简报；学生视图只取得当前允许内容，不能先交完整答案再仅隐藏显示。
- 家长准备与控制：材料、陪伴和备用说明，可按需查看教案；若在任务中提供内容帮助，evaluation按实际条件记录。
- 反馈或帮助后材料：支架、示范和纠错例子，仅在允许阶段出现，并保留其帮助作用。

同一图、音频或题卡可在不同任务承担不同用途；是否影响独立性由实际内容与评价条件判断，不以媒体类型自动分类。目标、答案、资源和简报引用一致，改变事件/数量/关系等要重审关联内容。

classroom决定当前允许动作和材料，interface执行呈现，platform按绑定版本获取/播放并处理取消。停止或阶段变化后的迟到素材不能继续显示或发声；生成和播放完成不等于学生实际看到/听到。

课堂按[统一教学动作](../classroom/boundaries-events.md)声明任务/对象/阶段与素材版本，interface适配具体呈现，platform提供媒介能力，交付反馈回到核心。媒介失败或切换不自行替换题意/答案，技术成功、学生收到与理解分开；指认/离屏按[实际报告条件](../classroom/materials-offscreen.md)处理。

界面按[学生视图](../interface/student-classroom.md)和[角色许可](../interface/roles-devices.md)取得当前材料，家长详情不传学生后隐藏，进入帮助阶段才取对应支架。字幕/朗读/重播/语速等[适配](../interface/input-output-adapters.md)服从实际任务，变化保留支持/条件和交付范围；界面切换不改变固定版本或历史依据。

## 课堂生成与入库

课前课程保存允许生成的用途、变换范围、核验方式、等待/退出与备用。课堂在必要内存中使用实际变式，按用途检查后呈现；未核验的新内容不作为独立能力依据，也不直接替换固定课程。

结束且家长一次反馈后统一整理实际采用内容或可获取引用、版本/变式、检查、任务/阶段及帮助条件。原素材缺失时保留缺失，不能重生成冒称当时版本。由evaluation维护实际使用事实，curriculum只连接资源与课程引用。

若课后内容经核实且适合复用，可由preparation提取教学部分并形成新资源，保留来源与检查范围，去除不必要的个性化背景。课堂原答、学生作品与真实状态仍由对应模块维护，不自动转成公共教材或共享学习记录。

默认不保存儿童原始音频；生成的教学音频与儿童录音区分。共享表示内容库内多课程复用，不代表公开发布或远程上传，本轮不生成实际媒体。

## 可获取性与历史

必需资源访问失败时，核对是否有维持用途/条件的已核实备用，否则保留缺口，不让草案或历史旧标记直接变成可开课。采用改变帮助/评价条件的替代要按允许路径记录，不能仍称原独立条件。

历史课堂必需资源和内容关系要可回查；链接失效、文件缺失或后续外部内容变化需明确报告。保留与恢复、更正处理见[history-corrections.md](history-corrections.md)，具体缓存、文件和存储实现后续决定。

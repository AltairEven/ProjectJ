# 课程模块交接与设计检查

文档版本：1.3.0；更新：2026年10月12日；范围：逻辑设计，未实现。

课程库是内容及实际依赖版本的维护入口。交接按用途取得必要摘要或固定内容，不复制整个资料库、学生档案或完整历史到每个请求。具体接口和存储后续决定。

## 输入与输出

| 模块 | 交接内容 | 责任边界 |
| --- | --- | --- |
| learning | 提供目标/能力/条件作为候选选择依据；取得课程、资源或模板摘要及缺口 | 维护计划/状态和熟悉材料信息，内容库不自动生成进度或替换目标 |
| preparation | 取得资料、资源、模板与历史版本；提交课程包、实际素材、简报、核验、预览和依赖/修订 | 生产与核验归备课，固定版本及历史归curriculum，不另建不同答案副本 |
| teacher | 提供唯一Jane的配置/策略版本及范围 | 全局角色和方法归teacher，课程只保存实际绑定和本课展开 |
| classroom | 取得实际课程/任务/素材/简报、允许呈现/分支/生成/备用、检查与更正限制；结束反馈后回连实际使用引用 | 课堂保持本堂状态与停止，内容库不逐轮决定教学或播放 |
| evaluation | 取得当时内容、评价依据与更正；提供实际活动引用和问题/影响证据 | 真实事实、原答和判断归evaluation，curriculum不重新逐题评分或增加样本 |
| platform | 取得保存/获取/完整性/可访问性需求及实际版本 | 技术结果归平台，内容含义/生命周期与教学核验归业务模块 |
| interface | 取得候选、版本、缺口、历史与允许材料 | 按职责呈现，不自建评分或把固定版本显示成当前可开课 |

交接至少包含对象与版本、来源/依赖、用途与条件、检查范围/结果、缺口/限制及下一步。候选可供备课不代表完整可执行，备课完成及本次启动依[两层就绪](../preparation/readiness.md)分别处理。

## 交给备课与课堂

备课检索按[复用约定](discovery-reuse.md)核对来源、目标、熟悉程度、材料/输入和旧检查适用范围。课程包形成按[生产合同](../preparation/course-package.md)，模板不预填儿童表现，也不复制全局Jane规则。

启动时定位固定课程及其实际依赖，核对停用/更正、资源可获取与有效备课依据，再检查当前条件。不能在课堂中自动替换“最新”素材或策略，也不能先将答案/支架传给学生视图后只隐藏显示。

运行中使用的允许变式在必要内存记录实际内容、来源、检查与帮助；结束且家长一次反馈后由evaluation统一整理，curriculum只连接必要资源/课程引用。素材缺失不能事后重生成原件；复用新资源需经备课核验。

课堂核心通过[事件/教学动作/交付反馈](../classroom/boundaries-events.md)交接，具体输入和呈现由interface/platform适配；内容库只提供固定内容、用途/能力/权限，不逐轮控制设备。结束反馈后按[课堂交接](../classroom/closing-handoffs.md)连接实际使用，不以动作生成或播放完成推定收到/理解或活动完成。

## 交给评价与回查

评价取得实际使用的课程版本、任务、答案/素材/策略及条件，不能用后来的新版本覆盖当时判断依据。使用关系提供活动引用和修订，原答/帮助/结束状态以evaluation的事实记录为准。

内容问题按[历史更正](history-corrections.md)追踪涉及资源、课程、活动和判断：preparation修订内容，evaluation更正解释，learning重审状态/未来计划，teacher仅处理有据的方法问题。更正不增加新样本，不回放已结束输入给课堂控制器。

评价按[事实与证据](../evaluation/facts-evidence.md)及[课堂对照](../evaluation/lesson-alignment.md)取得当时固定基线/依赖和实际使用差异，内容库不以新版改写历史或另建课堂事实。[评价修订](../evaluation/reports-revisions.md)关联原活动/问题及更正影响，交相关模块回查，修订不重复计样本。

## 版本一致性与旧项目

物理保存失败、对象缺失或依赖不一致时明确未完成部分，不能冒称固定内容完整、备课合格或历史证据可回查。恢复保留来源与实际版本，不能以近似重建替代原件。

J目前只保留原型已导入的指定素材，LearningWithAI仍是家庭档案与历史权威。本轮不重命名、移动或迁移这些内容；未来对接需明确唯一维护入口、标识映射、证据可访问和修订兼容，见[旧项目关系](../../docs/legacy-import.md)。

## 未来实现需要验证的场景

| 场景 | 必须得到的结果 |
| --- | --- |
| 同一课程版本使用两次 | 引用两次真实活动，课程不永久完成，实际样本次数由记录条件决定 |
| 不同课程有同名任务 | 通过所属对象与实际版本区分，不误合并任务/证据 |
| 固定候选尚未核验或依赖缺失 | 可回查声明内容，缺口明确，不能成为备课完成/当前可开课 |
| 素材或Jane出现新版本 | 新版通过备课修订使用，课堂和历史仍保留当时绑定 |
| 外部链接内容变化或失效 | 不默认沿用核验，显示缺口/已取得内容范围，不能冒称历史完整 |
| 已读故事再用于观察 | 明确熟悉条件，用于复习或另选新材料，不冒称未见首读 |
| 学生材料与教师答案共处资源库 | 按对象/阶段只交允许内容，不靠界面隐藏已传出的答案 |
| 课堂生成内容丢失 | 保留缺失，重生成另建来源/版本，不补造原材料或表现 |
| 已知错误被停用 | 限制受影响未来使用，原历史可查并显示更正，回查评价与状态 |
| 只修未来答案但旧状态仍依赖旧依据 | 追踪并交evaluation/learning重审，保留原答和更正说明 |
| 归档历史或恢复近似资源 | 必需依赖不自动删除，近似版本不当原件，记录访问缺口 |
| 成人/模拟资料与儿童引用混合 | 分类保留，课程库不将成人使用转换为儿童样本 |
| 新增数学或人文模板 | 复用全学科索引与依赖框架，核实学科内容，不创建新教师或学生等级 |

本轮仅设计，这些程序场景未实现或执行。文档与既有原型检查通过不表示内容库/生命周期功能、实际声音或教学效果已验收。总入口见[acceptance.md](../../docs/acceptance.md)。

固定资源保存/取得按[平台存储](../platform/storage-lifecycle.md)回报实际对象/版本、依赖/完整性和缺失，不找不到旧版就换最新。课前产物与课中必要内存素材遵循[平台素材边界](../platform/multimodal-materials.md)，内容身份/历史更正仍归curriculum；物理保存不自动标备课/本次就绪。

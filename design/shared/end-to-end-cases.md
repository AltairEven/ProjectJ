# 端到端验收案例

文档版本：1.0.0；更新：2026年10月12日；范围：验收设计，全部案例未执行。

案例从已保存需求、实际课程与运行条件出发，检查课堂、课后保存、状态/计划和下一课的完整结果。它们补充各模块场景，不用文档齐备、格式或既有原型回归冒称新闭环通过。

## 来源环境与共同核对

所有下述人物、版本和表现是明确虚构条件。自动化验证使用隔离测试空间、模拟能力和来源，不能访问或写真实儿童档案；表中的学习变化是符合真实条件时的预期，测试产物不是学习证据。真实成人演练保持成人分类，只保存成人检查，不因扮演学生运行儿童状态更新。

未来每次执行记录案例身份、实际版本/配置、输入来源、检查方式与环境、结果/缺口、下一课判断及依据。模拟、内容审阅、实际API/声音、成人流程、30分钟与儿童效果分开验收。真实接口须满足[数据条件](../platform/configuration-permissions.md)，不是这些案例的默认执行步骤。

共同核对：原答/帮助/交付/日期与来源保留，活动/尝试不重复，正式修订有保存及处理依据，历史固定，待处理与下一步明确，下一课消费的需求/状态/计划版本实际一致。验收必须同时核对发生了什么和哪些结论不得出现。

## E2E01 正常完成与下一课准备

- 前提：虚构学习者的状态S1、计划P1、需求D1已有效；课程C1、Jane J1、素材和核验固定，本次条件具备。
- 路径：备课/预览与启动 → 首次阅读任务及合理正确回答 → 必要指认/离屏实际报告 → 正常小结及确认 → 家长提交无额外补充 → 课后整理/保存 → 下一课备课。
- 预期：原活动A1连接当时版本；事实和评价先保存，learning仅在实际范围形成单次工作判断，保存状态S2；计划修订或明确沿用P1，需求D2连接有效结果，下一包引用D2。
- 继续条件：D2及课程核验/依赖有效，再检查本次条件。不得因单次顺畅称稳定掌握，报告或需求不自动变开课许可。

## E2E02 帮助后答对与离屏未报告

- 前提：D1要求先取未提示样本；课程有不同求助指导、再试和离屏报告路径。
- 路径：首答不符合 → 求助 → 换指导/实际句框 → 再试答对 → 离屏返回但没报结果 → 按预算收尾 → 家长确认没观察到离屏表现 → 保存与下节调整。
- 预期：初答和帮助后表现分开，英语句框标对应维度帮助，离屏未知；科学理解只按已取得样本判断。状态/需求建议巩固或新任务减少支持，不能整课标独立。
- 继续条件：允许不补测离屏就形成有据需求；下一包安排轻量观察或核实备用，不把未知算失败/欠账。

## E2E03 明确停止与迟到结果

- 前提：课堂正在等待模型或合成，已有部分真实输入，剩余核心活动未做。
- 路径：发出明确停止 → 本端取消及核心停止 → 旧模型/声音晚到 → 家长反馈 → 整理已发生范围 → 下节需求。
- 预期：迟到不播/推进，停止不等模型或小结确认；保存停止原因、实际样本及未完成，不假装正常结束或补造离屏。
- 继续条件：有据范围足以形成下一需求即可，未完成不强制补课；停课本身不降低能力或自动判Jane失职。

## E2E04 事实或评价保存失败

- 前提：反馈已提交，事实F1与评价E1已生成，尚未取得全部保存结果。
- 路径：注入F1保存失败；另一分支让F1成功而E1失败/未知 → 显示分项状态 → 核对原操作并接续 → 完成下游。
- 预期：F1未保存时不从其派生正式新状态；E1失败时保留已存F1，不重新创建活动。恢复原修订，不能重复计样本；来源修订未变不重做已成功步骤。
- 继续条件：依赖失败结果的新需求只作草案；旧有效需求需另有适用复核才继续，不能自动绕过缺口。

## E2E05 状态已保存但计划或需求失败

- 前提：F1/E1/S2保存成功，计划更新P2或需求D2待保存。
- 路径：P2保存失败 → 家长查看报告 → 重试时已有新的相关依据 → learning核对当前版本 → 保存合适计划/需求；另测仅D2失败或汇总报告失败。
- 预期：S2仍有效，P2未生效不称已改计划；重试不覆盖后来依据，沿用旧计划须明示适用范围。D2失败不假装备课已正式采用；汇总失败只恢复报告，不撤销已存状态。
- 继续条件：依赖新计划/需求的包待处理；不相关且复核仍适用的旧需求可继续。家长不逐项批准常规重试。

## E2E06 反馈更正与后来的活动并存

- 前提：A1已整理为单次独立判断，后来A2有新的真实条件样本；某下一课已引用A1依据。
- 路径：家长更正A1存在内容帮助 → evaluation保存来源更正/新解释 → learning重审A1相关状态并综合A2 → 复核依赖的计划/需求/课程与Jane建议。
- 预期：A1原答/日期/旧解释保留，更正不新增活动或回放控制器；不能继续将A1当独立，也不能回滚/抹去A2。关联包标受影响待复核，问题共用身份。
- 继续条件：当前需求和课程复核完成后继续，无关部分不全部失效；历史基线不换成新答案。

## E2E07 新状态改变已备课程的适用性

- 前提：C1为尚未见故事的观察任务，依赖D1/S1，已经备好；课外实际报告表明该故事已读过。
- 路径：来源核对与材料经历更新 → learning说明相关变化 → preparation复核 → 保持原观察目标换核实新材料，或经需求修订改作合适复习 → 固定相应包/检查 → 启动。
- 预期：原C1内容保留，不能冒称首次未见阅读；新材料/目的检查相应影响，预览同步。只更新无关能力则有理由沿用原包。
- 继续条件：受影响取样条件未解决不开相关任务；不为每次新状态重新验证全部课程。

## E2E08 Jane候选改进与关键缺陷

- 前提：J1方法已检查适用，评价提出J2候选；另有分支确认J1某求助路径有关键缺陷。
- 路径：问题分派 → teacher准备候选与复查方法 → 下一课备课选择方法 → 核验/后续使用反馈。
- 预期：无关键缺陷时不因J2未完成阻塞全部课，仍可选适用J1；已知缺陷则限制对应路径，用核实替代或待修复。启用J2不称儿童效果改善，不改学生状态。
- 继续条件：相关方法与本课分支有适用依据，无关改进可待复查；不热换正在课堂的Jane版本。

## E2E09 延后反馈与内存丢失

- 前提：活动已结束但尚无家长反馈，记录只在必要内存；下节已有旧有效需求。
- 路径：家长选择稍后反馈 → 显示未归档 → 分别测试同进程接续、刷新本端及核心进程丢失 → 家长后来提供有限报告 → 有据补记/需求复核。
- 预期：未反馈不自动归档，不增加磁盘草稿；丢失后不还原预期对话。有限报告按家长来源和实际日期，身份/同次关系未知时待核对，不重复计样本。
- 继续条件：可先用保存基线做暂定草案；正式采用旧需求须有仍适用的业务结果及关键缺口处理，不能假定上一课已完成或完全恢复。

## E2E10 数据权威切换与成人隔离

- 前提：当前旧项目仍是权威，仅有成人/模拟数据；未来拟接入一份最小档案/当前状态/计划和必要证据映射。
- 路径：核对来源/分类/身份修订及未完成事项 → 尚未满足接入条件时请求闭环 → 在隔离方案推演满足条件后的唯一写入入口与后续更正。
- 预期：前者不迁移或写儿童状态；后者按已明确切换边界只写J的新正式数据、旧历史只读。旧成人检查不变为儿童样本，无自动双写。
- 继续条件：实际切换范围、来源可用、数据与正式验收/采用条件具备才接真实路径；方案存在不称迁移成功。

## E2E11 语义判断不可靠而格式有效

- 前提：核实题意/答案或开放任务依据已提供，测试含合理变式、真正错误和语义不清输入。
- 路径：输入进核心 → 模型提案格式有效但与核实条件不符/无充分依据 → 核心核对与澄清/限制 → 实际反馈和再试 → 课后复核 → 交内容/方法/运行主责。
- 预期：结构通过不直接认定正确、错误或就绪。合理变式应接受，已知错误给具体纠错和再试，不清不强判；不能只再问同模型就声称独立核验，转写不评价发音。
- 继续条件：关键内容判断仍有疑点时限制相关使用；有据部分可保存并为下节提出核实需求。实际语义质量需相应内容基准与审阅，程序边界测试不能代替。

## E2E12 目录别名细分与融合评价

- 前提：任务分别涉及故事排序、数学大小排序、英语表达与科学解释；既有目录存在相关条目和旧宽泛判断。
- 路径：备课提出新名称/范围 → learning核对定义/别名 → 课程引用合适条目 → 课堂在不同帮助条件取得样本 → 评价分维度 → 状态/需求采用；再推演目录细分更正。
- 预期：同义名称复用身份，两个“排序”不误合并；旧宽泛判断不复制给全部细分项，同一融合证据不增加日期。英语句框不自动降科学或升所有语言维度。
- 继续条件：映射不清可保留原任务范围及待核对，不伪造永久能力；关键目标映射影响时复核相应需求/课程。

## 用例结果与验收结论

每个案例报告已执行/未执行、实际结果、依据、缺口和消费版本。失败回到对应合同或模块，复查受影响案例；不能把案例删去或改预期来适应错误结果。

正常、停止、未确认和部分失败均可得到符合规则的终态；完整闭环要求实际下游保存/采用可查，并能说明下一课为何可继续或应等待。用户声音延迟、30分钟节奏与真实学习效果仍按[总验收](../../docs/acceptance.md)取得各自证据，本文件没有执行任何实际课堂或测试。

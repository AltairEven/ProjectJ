# 端到端验收案例

文档版本：1.1.0；更新：2026年10月12日；范围：验收设计，全部案例未执行。

案例从已保存需求、实际课程与运行条件出发，检查课堂、课后保存、状态/计划和下一课的完整结果。它们补充各模块场景，不用文档齐备、格式或既有原型回归冒称新闭环通过。

## 来源环境与共同核对

所有下述人物、版本和表现是明确虚构条件。自动化验证使用隔离测试空间、模拟能力和来源，不能访问或写真实儿童档案；表中的学习变化是符合真实条件时的预期，测试产物不是学习证据。真实成人演练保持成人分类，只保存成人检查，不因扮演学生运行儿童状态更新。

未来每次执行记录案例身份、实际版本/配置、输入来源、检查方式与环境、结果/缺口、下一课判断及依据。模拟、内容审阅、实际API/声音、成人流程、30分钟与儿童效果分开验收。真实接口须满足[数据条件](../platform/configuration-permissions.md)，不是这些案例的默认执行步骤。

共同核对：原答/帮助/交付/日期与来源保留，活动/尝试不重复，正式修订有保存及处理依据，历史固定，待处理与下一步明确，下一课消费的需求/状态/计划版本实际一致。验收必须同时核对发生了什么和哪些结论不得出现。

## E2E01 正常完成与下一课准备

- 前提：隔离虚构学习者，状态S1、计划PL1、需求D1有效；已验证运行配置CFG1、输入策略IS1及匹配使用范围的验收报告VR1。实际执行前这些前提也要取得测试证据，不能由本例文字宣称通过。
- 路径：按下表执行。OP为操作、C为课程、B为简报、J为Jane配置、M为素材、A为活动、I为输入、T为尝试、O为动作、F为封存事实、FB为家长反馈、E为评价、N为候选建议。编号只为本案例说明，不是数据schema。

| 顺序与触发 | 调用者 → 维护者 | 命名结果及保存边界 | 继续或失败接续 |
| --- | --- | --- | --- |
| 1. 家长请求准备下一课 | interface → 应用层OP-prep1 → learning | 复核已保存D1对S1/PL1仍适用 | 来源不足按范围澄清/草案，不虚构状态 |
| 2. 编制核验 | 应用层 → preparation/teacher/curriculum | C1、B1、J1、M1及核验V1，固定依赖保存 | 必需内容未核实/未保存则停在备课缺口 |
| 3. 家长预览 | 应用层 → interface及业务维护者 | 预览PV1连接C1；家庭条件HC1和必要方案决定实际提交保存 | 实质变化回到需求/备课，浏览不当决定 |
| 4. 请求开始 | interface → 应用层OP-start1 → classroom | 汇总D1/C1/V1/VR1/CFG1/IS1/HC1形成启动结论R1 | 依开课判定处理通过/未知/冲突/失败；不手改就绪 |
| 5. 建立课堂 | classroom | 活动A1绑定上述实际版本；教学事件只在内存 | 同一开始重发不新建活动；停止优先 |
| 6. 开场与目标 | classroom → platform/interface | 动作O1、交付DL1，实际目标确认输入I1；核心接受后给下一任务 | 未交付/确认保留缺口，确认不算学会 |
| 7. 自然回答 | platform识别 → interface按IS1提交 → classroom | 语段最终化且提交条件具备形成I2，关联任务实例Q1和尝试T1 | 片段不评分、重发同ID不重复；合理变式按核实依据判断 |
| 8. 反馈和下一问 | classroom模型提案经Harness → interface | 允许动作O2及实际交付DL2，正确/帮助/未知按实际保留 | 未允许不播放，迟到不切题，单次正确不称稳定掌握 |
| 9. 指认与离屏 | 核心安排 → 实际报告I3/I4 | 记录提供者、帮助和结果；离屏停采集，返回后取实际报告 | 返回页面不算完成；报告缺失保留未知 |
| 10. 正常收尾 | classroom → 实际交付及确认I5 | O-close、实际小结/建议、结束边界END1；立即结束采集和教学 | 小结只表达已发生范围；确认失败走未确认结束分支 |
| 11. 结束封存 | 核心END1 → 应用层OP-seal1 → evaluation/platform | 将当时内存事实与依赖封存为F1，取得保存回执SR1 | 不等模型或FB1；未知先查OP-seal1，成功后可关闭应用 |
| 12. 家长反馈 | interface → 应用层OP-feedback1 → evaluation | 稍后读取F1，家长“无额外补充”形成FB1并保存 | FB1缺少帮助声明仍不填独立；重发不新建活动 |
| 13. 评价 | evaluation读取F1/FB1/C1 → 保存E1与N1 | E1含任务判断/对照/限制，N1为候选建议 | 模型或保存失败不损坏F1；待反馈时另有阶段性分支 |
| 14. 状态计划需求 | 应用层 → learning | S2或无变化回执；PL1明确沿用或PL2保存；N1采纳理由及D2保存 | 三步独立回执；冲突重核当前基线，需求不引用未生效草案 |
| 15. 下节与家长报告 | 应用层 → preparation/evaluation/interface | 下一包C2引用D2；报告REP1显示各实际结果和待处理 | 报告失败不撤销S2，C2需自身核验和下一次启动检查 |

- 预期：上述来源/对象/修订链可回查；仅有据维度产生相应工作判断，实际帮助未知时不写独立，模拟不写真实儿童库。运行事实在END1前不落盘，F1保存不依赖FB1；原答与后续解释分开。
- 继续条件：D2采用有效S2/计划及家庭条件，C2必需内容和资格有效；下一次实际条件另核对。未完成可选任务、待处理非阻断改进和REP1失败不自动阻塞下一课。

## E2E02 帮助后答对与离屏未报告

- 前提：D1要求先取未提示样本；课程有不同求助指导、再试和离屏报告路径。
- 路径：首答不符合 → 求助 → 换指导/实际句框 → 再试答对 → 离屏返回但没报结果 → 按预算收尾 → 家长确认没观察到离屏表现 → 保存与下节调整。
- 预期：初答和帮助后表现分开，英语句框标对应维度帮助，离屏未知；科学理解只按已取得样本判断。状态/需求建议巩固或新任务减少支持，不能整课标独立。
- 继续条件：允许不补测离屏就形成有据需求；下一包安排轻量观察或核实备用，不把未知算失败/欠账。

## E2E03 明确停止与迟到结果

- 前提：课堂正在等待模型或合成，已有部分真实输入，剩余核心活动未做。
- 路径：发出明确停止 → 本端取消及核心停止 → 旧模型/声音晚到 → 封存已发生范围 → 家长稍后反馈/有据评价 → 下节需求。
- 预期：迟到不播/推进，停止不等模型或小结确认；保存停止原因、实际样本及未完成，不假装正常结束或补造离屏。
- 继续条件：有据范围足以形成下一需求即可，未完成不强制补课；停课本身不降低能力或自动判Jane失职。

## E2E04 事实或评价保存失败

- 前提：活动已结束、家长尚未反馈；结束事实F1待保存，或F1已存而评价E1待保存。
- 路径：注入F1保存失败；另测F1已保存但回执/协调台账失败；再测E1生成或保存失败 → 查询原操作 → 只接续缺失步骤。
- 预期：停止不等保存，F1封存不调用评价模型；未知时查询原操作，不创建F2冒充另一活动。F1成功后可重启读取；若未成功且进程丢失，如实保留缺口。E1失败不损坏F1。
- 继续条件：依赖失败依据的需求待补，其他有据路径经适用核对可继续；无保存回执不承诺可关闭后恢复。

## E2E05 状态已保存但计划或需求失败

- 前提：F1/E1/S2保存成功，计划更新P2或需求D2待保存。
- 路径：P2保存失败 → 家长查看报告 → 重试时已有新的相关依据 → learning核对当前版本 → 保存合适计划/需求；另测仅D2失败或汇总报告失败。
- 预期：S2仍有效，P2未生效不称已改计划；重试不覆盖后来依据，沿用旧计划须明示适用范围。D2失败不假装备课已正式采用；汇总失败只恢复报告，不撤销已存状态。
- 继续条件：依赖新计划/需求的包待处理；不相关且复核仍适用的旧需求可继续。家长不逐项批准常规重试。

## E2E06 反馈更正与后来的活动并存

- 前提：A1已整理为单次独立判断，后来A2有新的真实条件样本；某下一课已引用A1依据。
- 路径：家长更正A1存在内容帮助 → evaluation保存来源更正/新解释 → learning重审A1相关状态并综合A2 → 复核依赖的计划/需求/课程与Jane建议。
- 预期：A1原答/日期/旧解释保留，更正不新增活动或回放控制器；不能继续将A1当独立，也不能回滚/抹去A2。关联包标受影响待复核，问题共用身份。
- 继续条件：当前需求和课程复核完成后继续，无关部分不全部失效；历史基线不换成新答案。

## E2E07 新状态改变已备课程的适用性

- 前提：C1为尚未见故事的观察任务，依赖D1/S1，已经备好；课外实际报告表明该故事已读过。
- 路径：来源核对与材料经历更新 → learning说明相关变化 → preparation复核 → 保持原观察目标换核实新材料，或经需求修订改作合适复习 → 固定相应包/检查 → 启动。
- 预期：原C1内容保留，不能冒称首次未见阅读；新材料/目的检查相应影响，预览同步。只更新无关能力则有理由沿用原包。
- 继续条件：受影响取样条件未解决不开相关任务；不为每次新状态重新验证全部课程。

## E2E08 Jane候选改进与关键缺陷

- 前提：J1方法已检查适用，评价提出J2候选；另有分支确认J1某求助路径有关键缺陷。
- 路径：问题分派 → teacher准备候选与复查方法 → 下一课备课选择方法 → 核验/后续使用反馈。
- 预期：无关键缺陷时不因J2未完成阻塞全部课，仍可选适用J1；已知缺陷则限制对应路径，用核实替代或待修复。启用J2不称儿童效果改善，不改学生状态。
- 继续条件：相关方法与本课分支有适用依据，无关改进可待复查；不热换正在课堂的Jane版本。

## E2E09 延后反馈与丢失边界

- 前提：活动已结束、反馈未提交，分别设置封存成功、封存失败/未知和课中崩溃三个分支。
- 路径：成功分支关闭/重启后读取原F1并追加反馈；失败/未知分支先查询原操作再接续；崩溃分支仅取得家长有限报告。
- 预期：成功分支原答/帮助/离屏与版本可读，无需家长重述整堂。反馈草稿未提交可丢失但不损坏F1；未保存内容丢失不补造完整课堂。父母有限报告保留报告来源/日期，活动关系不明先核对。
- 继续条件：有据阶段性评价支持的范围可继续；必要家庭事实不明则补一项或换有据路径，家长选择不自动使未知通过。

## E2E10 数据权威切换与成人隔离

- 前提：当前旧项目仍是权威，仅有成人/模拟数据；未来拟接入一份最小档案/当前状态/计划和必要证据映射。
- 路径：核对来源/分类/身份修订及未完成事项 → 尚未满足接入条件时请求闭环 → 在隔离方案推演满足条件后的唯一写入入口与后续更正。
- 预期：前者不迁移或写儿童状态；后者按已明确切换边界只写J的新正式数据、旧历史只读。旧成人检查不变为儿童样本，无自动双写。
- 继续条件：实际切换范围、来源可用、数据与正式验收/采用条件具备才接真实路径；方案存在不称迁移成功。

## E2E11 语义判断不可靠而格式有效

- 前提：核实题意/答案或开放任务依据已提供，测试含合理变式、真正错误和语义不清输入。
- 路径：输入进核心 → 模型提案格式有效但与核实条件不符/无充分依据 → 核心核对与澄清/限制 → 实际反馈和再试 → 课后复核 → 交内容/方法/运行主责。
- 预期：结构通过不直接认定正确、错误或就绪。合理变式应接受，已知错误给具体纠错和再试，不清不强判；不能只再问同模型就声称独立核验，转写不评价发音。
- 继续条件：关键内容判断仍有疑点时限制相关使用；有据部分可保存并为下节提出核实需求。实际语义质量需相应内容基准与审阅，程序边界测试不能代替。

## E2E12 目录别名细分与融合评价

- 前提：任务分别涉及故事排序、数学大小排序、英语表达与科学解释；既有目录存在相关条目和旧宽泛判断。
- 路径：备课提出新名称/范围 → learning核对定义/别名 → 课程引用合适条目 → 课堂在不同帮助条件取得样本 → 评价分维度 → 状态/需求采用；再推演目录细分更正。
- 预期：同义名称复用身份，两个“排序”不误合并；旧宽泛判断不复制给全部细分项，同一融合证据不增加日期。英语句框不自动降科学或升所有语言维度。
- 继续条件：映射不清可保留原任务范围及待核对，不伪造永久能力；关键目标映射影响时复核相应需求/课程。


## E2E13 语音停顿、改口和旧输入

- 前提：自动策略IS1已配置到任务Q1，提供可控片段/最终识别和实际声音两类检查。
- 路径：句中停顿后续说 → 最终识别迟到 → 一次自动提交I1 → 网络重发 → “还没说完”补充；另测切到Q2后的旧转写、教师回声和播放中停止。
- 预期：候选期间合并，识别片段不评分；同I1重发不新增尝试。补充回连原答，已交付帮助保留；旧题输入不评分到Q2。停止绕过普通提交等待，不依赖教学模型；不确定来源先澄清。
- 继续条件：程序与真实声音分别通过适用范围才启用IS1；失败可用已验证的提交/文字备用，并核对任务条件，不能默许自动模式通过。

## E2E14 开课依据冲突与替代

- 前提：课程备课完成，但旧声音检查通过、当前设备不可用；另一分支家长报告材料未备，业务检查仍写可用。
- 路径：应用层收集结果 → classroom核对版本/时间/来源 → 返回冲突或失败 → 相应维护者补查或给核实替代 → 重新判定。
- 预期：旧通过和家长开始不覆盖当前必需失败；仅装饰图缺失不阻断主任务。替代若改变独立条件则明确限制/修订，停止或数据条件不足仍阻断对应入口。
- 继续条件：受影响项具备实际依据，替代适用与必要决定完成后才开始；其他无关检查不全重跑。

## E2E15 周阶段年度复盘与部分失败

- 前提：阶段第四周事项到期，若干评价已保存；年度方向仍有效，某学科/保持样本不足。
- 路径：工作台生成一次待复盘事项 → 家长发起OP-review1 → 汇总证据 → 常规周调整、阶段结论及年度候选方案 → 注入需求保存失败 → 后来有新反馈时接续；另测周期末及年度主动回看。
- 预期：到期不自动完成，缺样本不填掌握，复盘不计新学习日期。已成功计划保留，重试不覆盖新依据；重大方向方案待决定，常规调整可独立完成。
- 继续条件：下一需求依据实际有效计划且不依赖未决定方案即可备课，复盘报告失败不回滚已落实结果。

## E2E16 方案过期、建议选择与简报一致

- 前提：evaluation有N1/N2候选，learning选择不同于单课建议的安排；预算变更方案DEC1待家长，期间家庭条件改变。
- 路径：记录采纳/修改/暂缓理由 → DEC1过期复核 → 家长接受实际新版DEC2 → 保存计划/需求 → preparation按唯一合同编制B2并固定课程。
- 预期：候选不直接发布需求；旧接受不套新版实质方案，接受与保存生效分开。teacher只供策略，B2内容合同唯一，简报与素材/答案/预算一致。
- 继续条件：有效需求与必要决定已落实、简报核验通过；不依赖预算变更的旧有效路径可经适用复核继续。

## E2E17 模型行为变化与验收范围

- 前提：Jane J1不变，模型配置/输入策略改变，或同名模型出现有据判断回归但服务端版本不可取得。
- 路径：platform提供实际差异/未知 → evaluation核对替代解释 → teacher提出相关复查 → 使用固定虚构案例与成人检查 → 应用层修订VR1适用范围。
- 预期：不直接归咎孩子或方法；模型名相同不排除漂移，也不冒称已查明静默更新。必要受影响资格待复核，无关范围不全部失效；报告保存与实际检查证据可查。
- 继续条件：相应能力修复/核实备用并取得匹配验收依据后使用；不能用文档或家长接受覆盖失败。

## E2E18 待反馈先行评价与后续更正

- 前提：F1已存，可确认接触材料及句框后完成，但家长是否额外帮助未知；下一课目标可巩固，不要求认定独立。

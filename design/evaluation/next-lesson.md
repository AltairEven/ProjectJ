# 下节建议与改进依据

文档版本：1.0.0；更新：2026年10月12日；范围：逻辑设计，未实现。

evaluation根据实际任务评价、相关历史与[课堂对照](lesson-alignment.md)提出下一步，learning综合全学科状态/计划形成需求，preparation再生产课程。建议、计划已调整、课程已备好和本次可开课分别维护。

## 下节建议的内容

| 信息 | 要求 |
| --- | --- |
| 来源与理由 | 实际活动/评价修订、相关任务/证据、能力范围和仍未知部分 |
| 目标与方向 | 巩固、复查、拓展或小步进阶，一个主要和一个辅助目标，与已有计划关联 |
| 基本预期 | 下节准备观察/练习什么，依据与条件，不能将预期冒称已具备能力 |
| 预计帮助 | 相关困难、已有支持和准备的替代表征/方法；预测保留待验证范围 |
| 活动与条件 | 需要的材料/媒介、时间/陪伴或离屏，是否熟悉，核心与可选取舍 |
| 挑战与退出 | 在原预算内替换活动、降阶/跳过/暂停/停止及核实备用需求 |
| 复查方式 | 什么实际表现能支持维持/修改建议，保持/迁移需要何种新样本 |

建议应具体到可编制需求，但不抢先生成完整课程或自行更改评价依据。通常只选一个主要调整/主要新增难度，预算来自当前家庭条件，不将可用时间排满；多个必要修正须保留范围，不能因此宣称识别出某一因果效果。

## 选择下一步

| 已有依据 | 可建议方向及限制 |
| --- | --- |
| 样本不足、识别/帮助不明 | 下次短观察或澄清，先用有依据部分继续，不要求重做整课 |
| 本题需帮助但再试有进展 | 巩固并准备实际不同支持，适合时在新任务减少帮助，原题不重标独立 |
| 单次独立完成 | 相近新材料/情境验证范围或轻量拓展，不直接宣布稳定掌握 |
| 不同日期相近条件表现 | 结合目标安排保持、迁移或小步进阶，不自动扩大到全学科/所有难度 |
| 实际难度/预算与预期不符 | 将有据状态和对照问题交learning/preparation重新适配，区别技术等待与学习困难 |
| 体验或家庭投入不合适 | 在原权限内改活动/支持，重大方式或固定预算变化形成具体方案交家长 |

旧证据久未复查可安排轻量复查，不按日期自动降级。较难新任务的困难不撤销较简单范围的有效表现。教案覆盖不足、停课、声音故障不直接变成学习欠账或强制补课。

## 分别反馈学习与教学

向learning交付有据的任务判断/状态修订依据与下节建议，由其核对旧状态、证据适用性与计划后落实，不能再建立一套逐题评分。全学科相关前提与融合维度需要时一起读取，英语优先不限制其他维度。

向teacher交付具体Jane行为、所用方法/版本、帮助/纠错与再试、实际结果、体验和待验证假设，提出小步方法修改及如何复查。一次换法后更顺不证明长期效果；已知规则违背可以及时修正，不需等待更多失败。teacher维护唯一Jane，评价不直接改全局策略。

向preparation交付任务/难度/素材/分支/时间不适配的实际依据及影响，修课以learning最新需求和适用Jane版本为基础。运行、识别、展示与停止问题交对应模块，原答和事实仍以evaluation为准。问题主责与关联按[课堂对照](lesson-alignment.md)，不为每个模块复制另一份事实。

## 决策与复盘

常规有据状态维护、巩固/复查与近期小调整由相关模块在已授权范围落实并解释。长期方向、学科优先级、固定预算、主要教学或评价方式变化，提供具体方案、证据、影响与复查条件交家长决定；已授权决定不重复询问。

周/阶段复盘可汇总已有评价、状态与改进处理结果，使用真实日期、条件和来源，不将复盘算新活动。反复相关差异支持扩大修订范围时仍需核对替代解释和权限，不因一次波动重排十年或无反馈宣称改善，也不自动创建定时任务。

家长看到建议理由、预计帮助、可选挑战与退出及实际变化；落实状态与版本按[reports-revisions.md](reports-revisions.md)和[handoffs.md](handoffs.md)返回。本轮不更新真实学习状态、计划、Jane配置或课程。

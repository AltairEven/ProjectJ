# 报告、修订与处理状态

文档版本：1.4.0；更新：2026年10月12日；范围：逻辑设计，未实现。

evaluation输出有来源的报告内容和交接结果，interface决定文字/语音等呈现，platform提供模型/存储。事实、解释、建议及后续实际落实分开；不在评价核心录音、播放或排版。

[共同合同](../shared/business-contracts.md)把可保存的评价依据与家长汇总报告分开；[执行顺序](../shared/execution-recovery.md)先存事实/评价，再落实状态/计划/需求，最后取得实际结果汇总。汇总或非关键改进失败不撤销已生效内容，也不重新造活动；关键更正限制相关下一课。

## 家长报告

默认展示：本次实际完成与结束情况、最有依据的表现/帮助、未确定项、备课与课堂关键差异、状态/计划实际变化和下节预期。详细原答、依据、对照和更正按需展开，不要求家长逐题审批或给孩子/教师总评级。

| 报告部分 | 应能解释 |
| --- | --- |
| 实施与本课评价 | 原表现、实际条件、判断依据与限制，正常/未确认/停止/中断不混为完成 |
| 课堂对照 | 计划 → 实际 → 原因/未知 → 是否允许 → 影响 → 修订建议与处理状态 |
| 状态与计划 | 原判断/安排 → 新判断/安排 → 依据与未确定项；未落实只呈现建议/待处理 |
| 下节预期 | 主辅目标、基本预期/帮助、可选挑战、退出与复查，课程仍需备课与启动检查 |
| 改进处理 | 问题主责/关联、建议、适用范围、版本与已知检查/复查结果 |

给孩子的课中简短收尾按课堂规则；家长可先看事实与阶段性评价，反馈后查看最终整理，新解释不冒称课上已发声。展示或朗读报告不自动表示家长了解/接受重要方案，必要决定取实际授权，其余常规更新不增加审批。

按[界面报告流程](../interface/feedback-reports.md)呈现统一结果、实际处理范围与按需证据，原答/判断含义和限制不被朗读/布局改写。家长更正或必要决定关联原活动/方案版本，由业务处理后回报；显示/朗读不代替接受，重试保存/反馈不新建样本，默认不隐式保存未提交磁盘草稿。

## 质量核对与状态

实质判断应能定位原表现、当时任务/依据、帮助与条件，分事实/解释/假设，限制未知；对照保留课前基线，不以新版本改写当时预期。模型审阅、结构或格式通过不能证明教学有效，也不为报告完整度补造证据。

按[封存与反馈流程](../shared/execution-recovery.md)分别显示事实保存、反馈待补、阶段性/最终评价、必要澄清和下游更新；部分有据结论可以保留，不以“最终报告”暗示所有目标观察或全流程成功。

报告生成、原记录保存、状态修订、计划调整、Jane改进、课程修订/备课完成分别报告实际结果。没有接收模块的处理依据不能声称已更新/修复；保存失败、版本冲突或未验证也不能变绿色完成。具体状态字段/一致性技术后续确定。

## 稳定标识与修订

活动、事实记录、评价和问题有稳定标识/来源关系，版本说明当次解释与修改依据；上传/报告/修订日期不替换实际发生日期。原答/原话、原结论、后续补充/更正及原因保留，不能只保存最新摘要。

重发同一整理或处理请求连接同一来源修订，不重复创建活动/样本；新的实际反馈/作品更正形成原活动的补充。不同模型审阅同一来源不增加观察，实际两次相同回答也不按文本误去重。

## 更正与影响回查

1. 记录实际补充/问题来源、原内容、涉及活动/评价修订与范围。
2. 核对原答、帮助、日期、识别或内容依据的影响；未知保持未知，疑点不直接改为事实。
3. 保存更正解释及理由，必要限制原结论的使用，保留原始记录。
4. 交learning重审依赖状态/未来计划，teacher重审相关改进，preparation/curriculum处理内容与版本。
5. 接收实际处理结果，向家长说明改变与剩余缺口；新记录已出现时综合当前依据，不能盲目回滚全部状态。

内容错误按[课程历史更正](../curriculum/history-corrections.md)联动，不能只修未来答案而保留错误状态。已结束输入不回放控制器，近似重生成素材不充当当时原件；更正不制造新日期、独立样本或虚构学习进步。

## 保存与历史权威

事实封存、反馈追加与修订保存按[共同执行](../shared/execution-recovery.md)由platform承载，其他模块引用evaluation的原来源。部分失败明确完成/未完成项，从原活动/修订接续，版本冲突只处理受影响部分，不覆盖后来的真实依据。

历史归档不自动丢弃必要原内容/依赖，更正保留可回查关系。交接与未来检查见[handoffs.md](handoffs.md)。

物理保存与接续见[平台存储](../platform/storage-lifecycle.md)，模型/运行版本和实际故障范围见[统一交接](../platform/handoffs.md)。报告、原记录/评价保存、各下游更新分别有据；平台不能把重试当新样本、近似内容当原件或旧修订覆盖后来的依据。儿童来源外发先满足[数据条件](../platform/configuration-permissions.md)。

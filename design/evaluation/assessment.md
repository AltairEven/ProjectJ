# 本课评价与学习状态依据

文档版本：1.0.1；更新：2026年10月12日；范围：逻辑设计，未实现。

本课评价解释实际任务表现、帮助和限制，向learning提供可追溯依据；不在evaluation另建持续学生画像、全科等级或第二份计划。基于当时实际材料与评价依据，而非后来的“最新答案”重写历史。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 判断过程

1. 确认实际任务/材料、主辅目标、评价条件及原回答来源。
2. 核对题意、答案/合理变式或开放任务维度，先排除识别、内容与运行问题。
3. 分别解释首次与帮助后表现、纠错再试、独立应用及实际未观察项。
4. 将结论连接到证据、条件和学科/能力范围，注明替代解释与待复查项。
5. 形成状态修订依据与下节建议，交learning核对适用范围并落实，而不是逐题再评分。

课中判断是当时解释，课后检查关键冲突可以更正并保留理由。不默认重新调用模型评价每一道题，模型重复判断或自称高置信度不产生独立证据。程序可检查来源/引用与边界，不能仅凭格式证明内容或教学效果正确。

## 本课需要分别评价什么

| 方面 | 依据与限制 |
| --- | --- |
| 主辅目标表现 | 实际取到的任务样本，是否符合/部分符合/不符合要求或无法判断，保留依据 |
| 帮助后学习 | 实际支持、指导变化与再试结果，帮助后答对不覆盖初答或自动变为独立 |
| 独立应用 | 相应新任务与允许条件，熟悉原题/跟读/示范后的重复不冒称独立应用 |
| 保持与迁移 | 真实间隔或合适新情境及材料条件；没有样本保留未观察 |
| 体验与投入 | 原话、参与报告、准备/陪伴负担；顺畅、喜好和完成量不证明学会 |
| 课堂与备课对照 | 计划与实际的差异及原因，按[契合度规则](lesson-alignment.md)，与学生能力分别解释 |

封闭题接受有依据的合理变式，开放任务按指定维度和范围解释，不强制唯一措辞。不默认生成总分、进步幅度或无依据百分比；课程若有核实的评分规则，只在其指定范围使用，并保留条件。

## 全学科与融合

听、说、读、写，学科理解、表达、工具与综合应用按实际取样分别解释。英语输出有支架，不自动使科学概念或数学表现降级；作品完成也不自动使每个相关维度独立达标。

学科、能力与概念引用统一目录及learning的[状态范围](../learning/state.md)，不因措辞变化新建等级。不对没有样本的计划目标补评价；外部阅读指标/材料等级仅作有来源参考，不直接填全维能力。

## 学习状态更新依据

交接包括活动/任务/记录修订、实际日期与来源、能力范围、原表现与帮助、材料熟悉度/媒介条件、判断及限制、相关历史和建议复查。可以支持尚未观察/无法判断、需要帮助、单次独立完成、不同日期相近条件多次独立完成或表现不一致等工作描述；这些不是统一升级阶梯。

一次新困难不撤销旧简单范围的有效证据，旧样本久未复查不自动退步。跨课描述需要实际相应历史，保持与迁移另判；同一活动多维引用不重复计日期。learning复用任务判断，核对来源、旧状态与适用条件，不另建逐题评分。

常规有据修订按既定权限落实并解释，重大方向/预算/主要教学或评价变化交家长决定。评价提出依据不表示状态已经更新，取得实际处理结果后才显示落实；具体交接见[handoffs.md](handoffs.md)。

## 教学行为与归因

实际教师行为、内容/rubric、识别、运行与学习困难分别定位。一次困难不证明方法无效，换法后表现改善也不自动证明因果；需要保留任务、帮助、熟悉度和实际条件等替代解释。

已确认的规则违背或内容错误可立即修正，范围不明时保留待定位。向Jane的是有据行为改进建议，向备课的是具体内容/分支问题；不能以“更有耐心”替代可执行修改，也不把教师讲得顺当孩子掌握。下一步见[next-lesson.md](next-lesson.md)。

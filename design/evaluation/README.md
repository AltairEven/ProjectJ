# 课后反馈与评价

版本：1.9.0；更新：2026年10月20日；范围：模块设计；首版实现见[技术选型](../../docs/technology.md#课后评价)。

维护结束封存事实，并结合当时内容依据和已提交家长反馈，形成任务评价、状态修订依据、候选建议与教学改进。备课与实际课堂对照解释超出/不足、原因及影响，分别反馈主责与关联模块。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 输入与输出

- 输入：classroom结束后的实际事件/条件与结束原因，实际课程/任务/素材/Jane/简报/评价依据，家长原话/必要作品及相关历史。
- 输出：封存事实与来源修订、阶段性/最终评价及课堂对照、学习状态依据、候选建议和教学/内容/运行问题与处理范围。
- 边界：evaluation维护原事实与本次解释；learning维护跨课状态/计划，teacher维护唯一Jane，preparation生产课程，curriculum保存内容历史。输入/报告内容统一，interface采集/呈现，platform提供模型/存储等能力。

## 共同原则

首版实现（2026年10月19日）：课后评价模型只提议逐题工作判断（未知、需要帮助、单次独立）、家外帮助与给家长的解读，并写本课概括、最有依据的表现、未确定项及课程与课堂差异；规则逐题核对——单次独立须初答正确、课中无帮助且家长明确说没有额外帮助，需要帮助须有课中帮助、家长报告的帮助或答错，家外帮助须逐字引用家长反馈，受更正影响的一律未知；不合规的判断退回未知并记原因，草稿漏掉或多出尝试时整份不保存、可重试。请求只带任务数据，不含学习者身份。保持、迁移与跨日期判断不由评价提议。学生为本课勾选了加强项目时（2026年10月20日），请求附上课程对这些项目的要求，评价在概括里写学生在这些项目上的实际表现与依据，没有观察写未知，不另立评分维度。

结束时按[共同封存规则](../shared/execution-recovery.md)保存，暂停不当结束；明确停止、未确认或中断可整理已发生部分，不补造离屏、小结或完整逐字稿。家长不用逐题打分、填能力等级或重填基本信息，仅关键冲突短澄清，其他未知保留。

按当时任务/依据解释原答，课堂判断可核对修订，生成/交付/收到/理解与能力分开。观察、帮助后表现、独立应用、保持/迁移分别保留，帮助按任务/学科记录，换法不抹去最强程度。转写不评发音，技术故障/未做不判学生错误；成人/技术不产生儿童证据。

全学科与融合任务按[learning范围](../learning/state.md)取实际维度，不用总分或材料进度代替能力，不把同次多维引用当新样本。顺畅、喜好、覆盖率和模型自信不证明教学效果，实际困难不直接归因孩子或Jane方法。

备课对照固定课前基线，按目标/范围、任务/材料、难度/帮助、流程、时间/投入解释差异。区分合理适配、设计不适配、执行偏离/故障和未知，保留许可/原因/影响、主责与关联；明确停止造成覆盖不足不直接判失职，课后不能改教案伪装完全契合。

learning依据任务判断落实有据状态/计划，按[更新规则](../learning/updates.md)形成下一课需求；teacher按[迭代规则](../teacher/improvement.md)小步改方法，preparation按[版本交接](../preparation/versions-handoffs.md)修课。常规调整按权限解释，重大方向/优先级/固定预算/主要方式变化交家长具体方案。下节建议不代表已调整/备好/可开课。

原答、原话和原解释保留，更正连接原活动，按[内容更正](../curriculum/history-corrections.md)回查状态/计划与方法，不重放控制器、重复计日期或重生成原素材。报告生成、保存、下游修订与备课完成各有实际状态，部分失败/版本冲突不冒称全流程成功。

课中只必要内存，无快照、文件归档、监控、检查或原始音频保存；进程丢失明确缺口。[ADR-0006](../../decisions/ADR-0006.md)记录决定，设计文档不代表评价功能或儿童效果已验收，见[总标准](../../docs/acceptance.md)。

项目阶段、真实数据权威与新旧设计关系统一见[共同入口](../shared/README.md)。

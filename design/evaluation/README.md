# 课后反馈与评价

版本：1.1.0；更新：2026年10月11日；范围：模块设计，未实现。

结合课堂实际事件和家长一次反馈，形成可解释的课堂评价、下节预期及学习状态更新依据。

- 输入：classroom的本堂事件、课程版本与评价依据、家长原话及必要历史证据。
- 输出：最终实施记录、课堂评价、下节建议、供learning使用的状态更新依据。
- 包含：事实整理、帮助条件、独立尝试与帮助后表现区分、离屏与保持/迁移证据、体验与家庭负担。
- 边界：保留原答与原话，AI解释另列；家长报告、实际观察、推断与待验证假设可区分。一次表现不足以判定稳定掌握，成人数据不更新儿童状态。

按实际任务评价各学科知识与能力、跨学科学习能力和综合应用表现，不只评价英语。语言与融合学科、工具条件分别记录；综合任务完成不证明所有维度独立掌握。关键冲突保留来源，必要时澄清；其余未知不强迫家长填满。报告给出基本目标、预计帮助、可选挑战、退出与复查，下节建议不等于备课完成。

## 与学习管理的交接

按[交接约定](../learning/handoffs.md)输出活动与修订、实际日期和来源类型、结束原因、实际课程/材料版本、各任务的原表现与帮助、完成/未观察项、判断与状态修订依据。首次尝试、帮助后完成、离屏、保持与迁移分别保留；转写不能判断发音，未报告的帮助不能默认独立。

本模块维护最终事实记录、证据与本次评价；learning复用这些判断更新[全学科状态](../learning/state.md)和计划，不另建逐题评分。周与阶段复盘可以综合相关证据提供依据，复盘本身不成为新学习样本。

同一活动的家长补充和作品合并到原来源。更正原答、帮助或日期时保留更正说明与修订，并通知learning重审依赖结论；同一融合活动引用多个维度不增加样本次数，成人与技术数据不进入儿童状态。

常规修订由learning落实并解释；本模块不直接改变全局优先级、长期方向或固定预算。更新规则见[课后更新](../learning/updates.md)。课外实际作品和学校反馈可按真实来源评价，不虚构AI课堂。

课后统一保存由platform承载，本目录不存真实学习记录。总入口见[模块设计](../README.md)。

# 课后反馈与评价

版本：1.4.0；更新：2026年10月12日；范围：模块设计，未实现。

结合课堂实际事件和家长一次反馈，形成可解释的课堂评价、下节预期及学习状态更新依据。

- 输入：classroom的本堂事件、实际课程/Jane/策略版本与评价依据、家长原话及必要历史证据。
- 输出：最终实施记录、课堂评价、下节建议、供learning使用的状态更新依据及供teacher使用的教学行为改进依据。
- 包含：事实整理、帮助条件、独立尝试与帮助后表现区分、离屏与保持/迁移证据、体验与家庭负担。
- 边界：保留原答与原话，AI解释另列；家长报告、实际观察、推断与待验证假设可区分。一次表现不足以判定稳定掌握，成人数据不更新儿童状态。

按实际任务评价各学科知识与能力、跨学科学习能力和综合应用表现，不只评价英语。语言与融合学科、工具条件分别记录；综合任务完成不证明所有维度独立掌握。关键冲突保留来源，必要时澄清；其余未知不强迫家长填满。报告给出基本目标、预计帮助、可选挑战、退出与复查，下节建议不等于备课完成。

## 与学习管理的交接

按[交接约定](../learning/handoffs.md)输出活动与修订、实际日期和来源类型、结束原因、实际课程/材料版本、各任务的原表现与帮助、完成/未观察项、判断与状态修订依据。首次尝试、帮助后完成、离屏、保持与迁移分别保留；转写不能判断发音，未报告的帮助不能默认独立。

本模块维护最终事实记录、证据与本次评价；learning复用这些判断更新[全学科状态](../learning/state.md)和计划，不另建逐题评分。周与阶段复盘可以综合相关证据提供依据，复盘本身不成为新学习样本。

同一活动的家长补充和作品合并到原来源。更正原答、帮助或日期时保留更正说明与修订，并通知learning重审依赖结论；同一融合活动引用多个维度不增加样本次数，成人与技术数据不进入儿童状态。

常规修订由learning落实并解释；本模块不直接改变全局优先级、长期方向或固定预算。更新规则见[课后更新](../learning/updates.md)。课外实际作品和学校反馈可按真实来源评价，不虚构AI课堂。

## 与Jane持续改进的交接

按[teacher交接](../teacher/handoffs.md)分别分析学生表现和教学行为，提供实际事件引用、所用版本/方法、提问和指导变化、帮助/纠错/再试、体验投入、未知项、问题假设与小步建议。不因一次困难直接判学生能力不足或全局方法无效；先区分内容/rubric、识别、运行与教学不适配。

teacher按[反馈与版本规则](../teacher/improvement.md)修订Jane的方法；learning依据本模块维护学生状态，两者不互相代替。成人演练只支持相应流程及成人体验，不证明儿童能力或方法效果。同一来源给两个模块使用不增加活动或独立样本。

顺畅、喜好和完成量不足以证明教学效果；有实际样本才看独立理解/应用、保持/迁移，结合参与体验与家庭投入。日常仍只收家长一次实际反馈，不另设逐题或每日教师评分表。

## 反馈到备课与素材

按[备课版本交接](../preparation/versions-handoffs.md)回连实际课程/任务/素材/变式、Jane策略和帮助，提供内容准确性、难度、教学分支、素材呈现或备用不适配的实际依据。learning修订需求，teacher改进方法，preparation修订内容/素材/简报，运行问题交对应模块。

课堂未核验的新素材不能作为独立能力依据；若当时内容缺失，保留未知，不重生成后冒称原件。事后发现题目/答案问题时保存更正并重审相关评价与状态，而不是只修改未来课程。备课模拟、核验次数和生成成功不产生儿童样本或证明教学效果。

按[课程交接](../curriculum/handoffs.md)读取当时固定版本及实际使用素材/条件，不以新版覆盖历史评价依据。向curriculum提供实际活动/修订引用和内容问题证据，原答、帮助和结束事实仍由本模块维护，使用关系不是第二份记录。

[历史更正](../curriculum/history-corrections.md)追踪受影响活动：基于原答、实际帮助与新核实依据更正解释，交learning重审相关状态/计划，保留原结论和更正原因。缺失条件保留未知，不改写学生回答、不回放已结束输入或增加样本日期；成人/技术资料不转成儿童证据。

课后统一保存由platform承载，本目录不存真实学习记录。总入口见[模块设计](../README.md)。

# 课后反馈与评价

版本：1.0.0；更新：2026年10月11日；范围：模块设计，未实现。

结合课堂实际事件和家长一次反馈，形成可解释的课堂评价、下节预期及学习状态更新依据。

- 输入：classroom的本堂事件、课程版本与评价依据、家长原话及必要历史证据。
- 输出：最终实施记录、课堂评价、下节建议、供learning使用的状态更新依据。
- 包含：事实整理、帮助条件、独立尝试与帮助后表现区分、离屏与保持/迁移证据、体验与家庭负担。
- 边界：保留原答与原话，AI解释另列；家长报告、实际观察、推断与待验证假设可区分。一次表现不足以判定稳定掌握，成人数据不更新儿童状态。

语言与融合学科分别评价。关键冲突保留来源，必要时澄清；其余未知不强迫家长填满。报告给出基本目标、预计帮助、可选挑战、退出与复查，下节建议不等于备课完成。

learning维护正式学习状态与计划，本模块提供更新依据。课后统一保存由platform承载，本目录不存真实学习记录。总入口见[模块设计](../README.md)。

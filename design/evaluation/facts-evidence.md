# 实施事实、证据与条件

文档版本：1.1.2；更新：2026年10月16日；范围：逻辑设计，未实现。

evaluation维护结束封存事实、后来追加的来源与评价解释，其他模块引用同一来源。封存依照[共同执行](../shared/execution-recovery.md)，结构核对和保存不依赖模型总结。原答、原话、实际报告与AI判断分别保存；记录的修订不改变真实发生日期或制造新学习样本。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 事实整理

| 层次 | 保存与关联 |
| --- | --- |
| 活动 | 稳定标识、来源类型、实际日期、结束原因、相关家庭条件和记录修订 |
| 当时依据 | 课程/任务/素材、Jane/策略与简报、评价条件、课前需求/准备范围及实际版本 |
| 实际输入 | 原回答、作品/操作报告或可获取引用、提供者、识别限制/更正和任务顺序 |
| 教学与帮助 | 实际采用指导、帮助来源/程度、纠错、再试、备用和条件变化 |
| 交付与操作 | 动作生成/允许、实际呈现范围、收到确认、指认/离屏报告与未观察 |
| 时间与体验 | 实际计时/等待/暂停、孩子原话、家长投入和报告范围；不猜时长或性格 |

课程中的计划、模型提案和实际采用动作分开；未交付内容不称教过。播放/展示成功不自动表示学生收到，收到不证明理解，某次正确回答也不证明保持或迁移。

缺失实际素材标明范围及其对判断的影响，不能重生成原件或按教案填补表现。默认不保存儿童原始音频，不要求监控/截图；必要内容按实际取得范围保留，不宣称拥有完整逐字稿。

## 证据的可用范围

每条用于判断的证据连接活动/任务、原答/作品或报告、材料与实际条件、帮助、日期、来源/修订，以及所支持的学科/能力范围。家长自述与直接取得作品可以支持各自范围的解释，不能冒称另一种来源。

关键身份、题意、材料、帮助或识别情况未知时限制结论，并给出缺口和下一步；不默认0分、不会或完全独立。不把所有任务统一标记可靠/不可靠，保留可以解释的部分与受影响部分。

课堂未核验新材料不能作独立能力依据；内容/答案有疑点时保留原答并暂停相关解释，按[课程更正](../curriculum/history-corrections.md)核对。内容核实后可修订解释，但当时已泄露答案或接受示范的条件不能事后抹去。

## 原答、帮助与再试

首次未提示尝试、轻提示/支架/完整示范后的表现、新任务减少支持后的尝试分别连接。按任务/维度保留Jane、家长、材料和工具的实际帮助，换方法不抹去最强帮助；不知道是否发生帮助时保持未知。

计划或生成过的支架与实际交付/使用分开，帮助影响按实际范围判断。合理变式、部分满足、错误和无法判断的解释见[assessment.md](assessment.md)，识别更正不是一次新发言；回应实际交付后的改答按[输入分界](../interface/input-submission.md#补充再试与评分异议的分界)保留为当前等待对象下的新尝试，评价不能把纠错后的正确再答并回未提示初答。

## 去重与真实日期

- 同一活动的事件、家长反馈、作品和后续补充连接原活动，不计为多个日期。
- 一个融合任务引用多个维度不增加样本；周/阶段复盘、摘要重写和不同模型评价不产生新观察。
- 同一事件重发只处理一次，两次真实相同回答保留不同尝试，不能按文本去重。
- 上传/反馈/修订日期与实际学习日期分开；重新上传旧作品不形成保持样本。
- 实际更正保留原来源/原顺序和更正依据，不把已结束转写重送控制器生成新事件。

记录不等于最终能力结论。条件相近但不同日期的表现可以支持相应跨课描述，保持/迁移仍需自己的实际样本。整理、更正和保存失败见[reports-revisions.md](reports-revisions.md)，不改写旧项目历史。

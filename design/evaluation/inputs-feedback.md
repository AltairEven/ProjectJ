# 评价输入与学生补记

文档版本：2.0.0；更新：2026年10月20日；范围：逻辑设计；按[ADR-0018](../../decisions/ADR-0018.md)改为下课自动评价（实施中）。

evaluation接收结束封存事实，并结合当时内容、学生已经提交的补记与异议及必要历史形成有范围的解释。它处理统一业务输入/输出，interface负责收集与呈现，platform提供模型和存储等能力。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 输入来源

| 来源 | 内容与限制 |
| --- | --- |
| classroom | 活动用途/实际日期/结束、输入与原答、判断/帮助/再试、动作/交付/确认、指认离屏、时间与实际素材；缺失保持缺失 |
| curriculum/preparation | 当时固定课程/任务/素材、评价依据、Jane简报、目标/预算、核心/可选及允许分支、核验范围；计划不证明实施 |
| 学生 | 通过interface提交的补记（实际原话、体验、额外帮助、作品/离屏结果和条件）与异议；发生日期与报告日期分别保留 |
| learning/历史评价 | 相关能力范围、帮助/材料经历、原状态及必要保持/迁移证据；不加载全份档案与全部历史 |
| teacher/平台信息 | 当时方法版本、技术反馈和实际能力限制，用于行为/问题定位，不自动当学习证据 |

输入关联活动/修订、来源、当时对象/版本和取得范围。学生自述与补记、直接取得作品、模型解释及运行结果分别识别；未知不补成独立表现。只有教案或模型生成内容不能补成实际事件。

## 结束封存与自动评价

按[共同执行](../shared/execution-recovery.md)，classroom确定活动结束后，evaluation接收已有事件、绑定和结束范围，先作结构/来源边界核对并保存封存事实；不等待学生补记或模型总结。正常结束、收尾未确认、明确停止和可控中断保留各自原因，暂停不当结束。

ADR-0018起，封存成功后应用协调层自动请求一次评价（没有补记时按暂定解释），不再等待反馈或“稍后反馈”的选择；evaluation本身不监听封存就调用模型。只有学生认可的评价交learning采用；帮助/材料条件缺失不默认为独立。

技术模拟维持来源分类；课外作品、学校反馈等按真实来源直接接收，不虚构AI课堂。丢失事实按实际可提供的来源补记，不从教案或后来的模型输出还原原答。

## 补记与异议

认可前，学生可补记课堂无法取得的信息：实际体验、额外帮助、查了什么、离屏或作品结果、熟悉材料，以及下次条件变化；也可以对某题判断提出异议并写明理由。不要求逐题打分、完整逐字稿或手工能力等级。

补记与异议都追加为同一活动的来源，来源版本加一后重新评价；异议原文同时作为更正说明，受影响的任务判断在新评价里先按待复核处理。来源相同不增加独立样本。“没有额外补充”不代表所有任务独立、声音顺畅或全部完成。

认可绑定确切的评价版本；评价已因补记或异议更新时，认可旧版本被拒绝。认可后要改走[更正](reports-revisions.md)。界面收取与状态显示见[课后评价页](../interface/feedback-reports.md)；重试关联原提交/活动，未提交草稿不当补记。

## 关键澄清与冲突

只补会改变当前判断或下节安排的缺口，例如内容帮助是否发生、材料是否熟悉、离屏结果/日期冲突。先处理有依据部分，其他未知不要求填满；追问不变成第二次课堂或课后补测。

冲突保留双方来源，核对是否对应同一任务/时间/条件，再必要澄清。原事件和学生补记都不自动成为唯一正确答案，不能用模型多数意见裁定事实。确认前限制相关判断，不为凑完整报告编造原因。

输入核对及记录见[facts-evidence.md](facts-evidence.md)，本课评价与备课对照见[assessment.md](assessment.md)、[lesson-alignment.md](lesson-alignment.md)。

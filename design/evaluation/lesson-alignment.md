# 备课与实际课堂对照

文档版本：1.0.0；更新：2026年10月12日；范围：逻辑设计，未实现。

契合度说明本课准备安排与实际实施的关系，并产生面向责任模块的修订依据。它属于本课评价及教学改进，与孩子能力判断分别呈现；不只计算教案完成率，不默认生成总契合度百分比。

## 对照依据与维度

基线是开课时绑定的课程/简报/需求和预算、核心/可选任务、适用规则及允许分支，实际来自课堂事件与家长报告。现场允许变化另记原因与条件，不在课后改基线让实际过程看起来完全一致。

| 维度 | 计划与实际对照 |
| --- | --- |
| 目标与范围 | 主辅目标、核心内容与知识范围，实际活动是否服务目标，额外/遗漏内容及影响 |
| 任务与材料 | 核心/可选任务，实际交付、尝试、跳过、替换/生成及材料版本/用途 |
| 难度与帮助 | 预期条件/帮助与实际困难、支持、再试及分支是否可用，未知不凭年级推定 |
| 教学流程 | 观察、新授、练习、纠错再试、指认/离屏、目标/收尾确认是否符合本课适用路径 |
| 时间与投入 | 原预算/家庭条件与实际教学、等待、暂停、离屏和陪伴投入；计时/报告不明保留未知 |

计划有安排、模型提出/核心允许动作、实际交付、学生收到、实际尝试和学习结果分开。任务未呈现不能记成教过，任务做过不自动证明学会；核心/可选与分支不混成同一个完成比例。

## 每项差异的解释

| 类型 | 条件与反馈 |
| --- | --- |
| 合理适配 | 在允许分支/预算内增加支持、缩减可选活动、挑战替换、核实备用或响应明确停止；记录理由和结果，可修订备课预期 |
| 设计不适配 | 任务/预算过多、前提/难度估计或帮助/材料不足，结合真实条件定位准备问题和需求影响 |
| 执行偏离或故障 | 必要说明/步骤遗漏、越出许可、无依据改判断条件、缺再试或交付失败；依实际证据定位课堂/方法/交互/平台 |
| 无法判断 | 记录、基线、来源或交付范围不清，保留未知/待核实，不补成通过或失败 |

一种实际差异可能涉及多个方面，保留事实、许可判断和原因假设，不能为填表强行单一归因。明确停止导致核心活动未完成要如实记录，同时说明停止处理是否符合规则，不直接判老师失职或孩子不会。

必须保持的目标/评价依据、真实证据、独立条件和停止边界，与可调整的支架、表征、允许活动/备用分别核对。备课允许变化不自动证明变化有效，也不允许以“个性化”掩盖越界。难度与帮助差异不单凭一课上升为学生永久等级或全局方法问题。

## 主责与关联反馈

| 发现及实际依据 | 主责/关联模块 |
| --- | --- |
| 内容、预算、难度或帮助分支不适配 | preparation修课，涉及目标/时间/前提时learning调整需求；curriculum保存版本 |
| Jane提问/解释/指导/纠错偏离绑定方法 | teacher改进方法，preparation核对简报与分支；若是状态/转场问题交classroom |
| 任务遗漏、错误接续、停止未生效 | classroom处理运行规则，interface/platform核对实际控制与交付 |
| 识别、材料展示或播放故障 | interface/platform按实际原因修复，不归为学生能力不足 |
| 实际样本支持不同于原预期的能力范围 | learning按评价依据修订状态/需求，preparation重新适配，不直接全科升降级 |
| 实际内容与固定版本不一致或材料有误 | curriculum连接使用/更正，preparation修内容，evaluation/learning回查相关结论 |

问题保留标识、事实引用、基线/实际版本、范围、原因/未知、主责与关联、建议和复查方式。未定位时明确待定位，其他模块引用同一问题，避免每个模块各自改出互相竞争的结论；不要求额外Agent或自动给所有模块发消息。

## 家长可见结果与检查

默认展示关键差异：计划 → 实际 → 原因及依据 → 是否在允许范围 → 影响 → 建议/落实状态，详细任务对照按需展开。只有任务单位、分母和实际范围清楚时才报告相应计数，不能把覆盖率当学习效果或全部教学质量。

假设三项核心任务只尝试两项：如果第三项因网络未交付，应记录运行问题与后续观察缺口；如果前两项需更多有效帮助而用掉预算，则记录支持条件并重审任务安排。两种情况都不能直接判孩子能力不足。此为设计示例，不是孩子记录。

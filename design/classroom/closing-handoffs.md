# 收尾、必要记录与模块衔接

文档版本：1.1.0；更新：2026年10月12日；范围：逻辑设计，未实现。

课堂核心输出当堂教学反馈、实际事件与结束原因，最终事实整理/评价归evaluation，状态与计划归learning。收尾表达、交付和学生实际确认通过[统一交接](boundaries-events.md)分开，界面和基础能力不自行决定课堂完成。

## 正常收尾与其他结束

正常收尾总结真实做过的活动、一个有用方法、仍需练习或未完成处，并给出课程范围内有条件的下节预期。无实际依据不说独立掌握；下节预期不代表计划已改、课程已备好或开课就绪。给孩子的简短小结与课后家长最终报告分别形成。

按动作反馈核对小结与建议的实际交付范围，接受与当前内容有关的自然确认，不要求固定口令。只听到前半段、被打断或未听到时按预算补交或保留缺口；收到一句泛泛附和不能补成全部听到，实际确认也不证明理解/掌握。

| 结束路径 | 留下什么 |
| --- | --- |
| 正常收尾已确认 | 实际小结/预期、交付与确认、完成/未完成项和结束原因 |
| 收尾未确认或交付失败 | 已发生范围、未确认/缺失内容及后续方式，不伪装闭环完成 |
| 明确停止 | 立即停题与取消，简短结束和实际原因，不强迫总结、确认或补测 |
| 技术/条件中断 | 原会话/任务、实际已知事件与缺口，不用教案补造结果 |

确认等待有预算和退出，不无限追问；到时仍未取得则保留未确认/中断状态。暂停不是结束，活动结束也不把课程永久标成完成。

## 本堂必要内存与最终事实

| 内容 | 要求 |
| --- | --- |
| 活动与绑定 | 活动用途/来源类型、实际日期、课程/任务/素材、Jane/策略与简报版本、启动条件 |
| 原始表现 | 实际回答/作品或报告、提供者/来源、识别更正及限制、先后与任务联系 |
| 判断与教学 | 当堂判断依据、未知、所用指导/纠错、再试、实际帮助来源/程度与条件 |
| 呈现与操作 | 允许动作、实际交付范围、目标/小结确认、指认和离屏报告，未做/未观察 |
| 运行与结束 | 实际时间/等待/控制、条件变化、采用备用、结束原因及缺口 |

模型提案、实际采用动作、交付反馈、学生确认和能力解释分别保留。默认不保存儿童原始音频；所需素材/原答按实际取得范围记录，不编造逐字稿。课中只必要内存，不写快照、文件、阶段归档、运行检查或Git。

结束且家长一次实际反馈后交evaluation统一整理保存；关键矛盾可短澄清，不要求家长逐题打分或重填基础档案。缺失、来源未知、家长代述和推断明确区分，同一次更正不新增学习日期/样本。归档失败恢复原活动修订，不能声称完成或重复创建记录。

## 模块交接

| 模块 | 输入/输出与责任 |
| --- | --- |
| preparation | 提供核实任务/素材、简报、允许分支/生成/备用、预算和检查；取得实际不适配问题及证据 |
| curriculum | 提供固定版本与实际依赖、呈现条件/更正限制；连接结束反馈后的实际使用引用，不复制课堂事实 |
| teacher | 提供唯一Jane方法与版本，evaluation反馈实际教学行为；课堂不热改全局策略 |
| interface | 送统一输入/交付反馈、当前能力与家庭报告，执行允许教学动作及即时控制；不另建评分/转场 |
| platform | 提供模型与媒介能力、实际技术结果、计时/取消/访问和课后存储；不判内容或教学就绪 |
| evaluation | 取得上述实际事件/条件、当堂判断和家长原话，维护最终事实/评价与学生/教学问题依据 |
| learning | 提供需求与相关背景；通过evaluation取得有据状态更新与下节计划建议，课堂不直接改长期状态/预算 |

交接只带本课必要信息与实际版本/引用，不加载全部历史到每轮。课后分别定位内容、识别、运行、方法和学习困难：preparation修课，teacher改方法，platform/interface/classroom修运行，learning按有据评价调整状态/需求，不能只因顺畅就判教学有效。

内容错误按[历史更正](../curriculum/history-corrections.md)回查相关评价与状态，原答和当时依据保留，不重放已结束输入。LearningWithAI仍是家庭档案与历史权威，本轮不迁移、回写或生成儿童证据；成人演练/模拟仅支持相应检查范围。

交给[评价输入/事实](../evaluation/inputs-feedback.md)时保留当时内容/计划依据、实际动作与交付/尝试、帮助、时间及结束，不新增课中采集或归档。按[备课课堂对照](../evaluation/lesson-alignment.md)提供核心/可选及允许变化关联、实际采用和原因/未知，事件不足不补造契合；最终评价和[修订回查](../evaluation/reports-revisions.md)不回放为课堂输入。

## 未来实现需要验证的场景

| 场景 | 必须得到的结果 |
| --- | --- |
| 网页/手机/纯语音更换入口 | 统一事件/动作/反馈复用核心，核对实际能力与评价条件，不重新定义评分 |
| 自然答案、求助和确认连续出现 | 自动接续后台，家长不逐句委派，转场后有实际下一任务 |
| 生成/播放成功但被打断或未确认 | 保留实际交付范围，不假定孩子收到，更不计学会 |
| 同一事件重发与两次相同回答 | 前者只处理一次，后者保留两次真实尝试，不按文本去重 |
| 识别更正到达后已经换题 | 连接原事件核对影响，不静默评分下一题或制造新发言 |
| 合理变式、开放回答或未知 | 用任务依据接受/分维度判断/澄清，不只靠关键词，不默认错 |
| 故意错答与纠错后再试 | 指出具体问题，实际支持和再试闭环，原答/帮助后表现分开 |
| 两次求助无效 | 换实际方法、升级或退出，帮助最高程度不因换法抹去 |
| 英语表达难但概念有依据 | 分语言/学科/工具观察，不统一降级，转写不能评发音 |
| 跟读、指认、自述和视觉报告 | 按实际任务与来源区分，无视觉不冒称看见 |
| 离屏返回但未做/没报结果 | 不代填答案，保留未观察；离屏不持续录音/提问 |
| 模型越界、素材未核实或媒介失败 | 不推进/乱呈现，按范围采用核实备用或暂停，记录条件变化 |
| 预算不足、长等待或无人回答 | 用实际计时缩减/收尾或有限澄清，不自动加时、无限调用或判失败 |
| 判断/播放期间停止或暂停 | 即时取消并同步状态，迟到结果不播、不推进，不依赖模型批准 |
| 正常收尾、停止和未确认 | 各自保存实际范围，正常确认可自然表达，停止不强迫闭环 |
| 中断、进程重启或课后保存失败 | 缺口明确，无伪造恢复/重复样本，原活动修订可辨 |
| 成人模拟与正式儿童活动 | 分类隔离，不混学生状态；五分钟和30分钟/实际效果分别验收 |

这些场景尚未实现或执行。本轮只可核对设计职责、格式与引用，原型回归不证明新版课堂、实际声音、30分钟或教学效果。总体范围见[验收标准](../../docs/acceptance.md)。

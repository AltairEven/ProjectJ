# 回答判断、分级帮助与纠错

文档版本：1.1.2；更新：2026年10月16日；范围：逻辑设计，未实现。

判断依据来自本课核实任务与材料，指导方法来自绑定Jane策略。当前反馈支持学习，最终跨课能力判断由evaluation/learning处理；一次答对、顺畅或完成不代表稳定掌握。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 判断与证据条件

封闭题核对实际结果、课程允许表达和合理变式，不用关键词相同替代题意判断。开放题按指定维度、依据与条件评价，允许部分满足、待澄清与未知，不强制唯一措辞。适合程序核对的计算/数量等按实际核验能力辅助，不能将检查存在当答案可靠。

先区分识别问题、题意误解、知识/关系困难、表达或工具条件。语音转写不能评价发音，重复题干不等于理解，技术故障不判学生错误。融合任务分别看语言、学科理解、操作与综合应用，英文表达难不能自动降低数学/科学状态。

起点观察和独立验证先保留未提示尝试，反馈时机服从取样安排；新授允许示范，其后表现注明条件。原答、当堂判断、实际帮助和再试分别记录；原答被识别更正时保留来源及原顺序，不虚构一次新发言。

## 依据困难换指导

| 困难方向 | 可选指导，须在本题允许范围内 |
| --- | --- |
| 题意或输入 | 核对问题，短句重述/允许语言澄清；不要提前给所需答案 |
| 信息定位 | 指向段落、图中位置或相关线索，减少搜索范围 |
| 知识前提/关系 | 回到一个必要概念，换图示、对比或具体例子 |
| 步骤负担 | 拆成小步，先完成一个可操作部分，再连接起来 |
| 表达 | 允许动作/短语、句框或口头组织，概念与语言分别看 |
| 操作或工具 | 示范操作步骤或使用已核实替代，不把工具失败算能力失败 |

困难方向可以是待验证假设，必要时用一个短问题澄清。指导记录实际内容、方式及再试结果，不能只记录“已帮助”；不把一次偏好固定成永久学习类型。

## 帮助强度与升级

沿用learning/evaluation的无内容帮助、轻提示、支架、完整示范、未知分类，按受影响任务和学科记录。来源包括Jane、材料、家长和工具；是否帮助由实际内容与评价条件判断，媒体类型不自动决定独立性。

模型选择的帮助和实际交付/使用分别记录，未交付的示范不当成已经接受。按实际呈现、报告及接收情况判断影响范围；关键情况未知不能默认完全独立，也不能仅凭生成过示范就断言孩子得到完整帮助。

第一次求助使用与困难有关的支持；重复无效时换实际表征/步骤或升级。仍困难可降阶、换已准备任务、跳过、暂停或结束，不强迫连续失败后继续。具体上限和退出由课程预算与分支给出，不固定所有孩子同样次数。

换方法不能抹去本任务最强帮助，完整示范后答对仍是示范后的表现。减少支持后的新任务可以另取样，注明新条件与材料熟悉程度；不能将已经泄露答案的同一题重新标成独立验证。重复题干、中文解释或家长代述影响哪些维度须如实保留。

## 纠错闭环

1. 核对收到的回答、实际材料、题意和评价依据；不确定先澄清。
2. 指出有依据的具体问题，并给孩子可理解的说明；观察阶段按规定时机反馈。
3. 选择必要支持，使用允许支架、示范或其他方法，说明当前要尝试什么。
4. 留一次适合的再试，按实际帮助判断结果；没有再试保留未观察。纠错已实际交付后收到的改答是同任务的新尝试，按[补充与再试分界](../interface/input-submission.md#补充再试与评分异议的分界)处理，不能合并回初答。
5. 根据结果继续、撤去适当支持、换指导或退出，不泛泛表扬错答或只宣布“错了”。

合理变式与错误分别处理；未解决的内容/答案问题采用暂停、跳过或停止路径，结束后走[内容更正](../curriculum/history-corrections.md)。不能热换答案依据后重放历史输入，也不能为了纠错改写孩子原回答。

## 教学调整权限

课堂可选择已准备的方法、支持、降阶、挑战与备用，在任务和预算范围内调整措辞。改变主要目标、评价依据、独立条件或全局Jane配置不属于当堂自由调整；条件变化采用允许路径并记录，后续正式修订交对应模块。

交互与材料规则见[interaction-harness.md](interaction-harness.md)、[materials-offscreen.md](materials-offscreen.md)，统一交接见[closing-handoffs.md](closing-handoffs.md)。

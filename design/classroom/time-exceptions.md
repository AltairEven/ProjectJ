# 时间预算、控制与异常

文档版本：1.4.1；更新：2026年10月25日；范围：逻辑设计；不按30分钟截断与题型预计用时已实现（[ADR-0020](../../decisions/ADR-0020.md)）。

classroom依据课程预算与实际计时管理取舍，interface/platform提供技术计时、交付与取消。时间和等待必须有实际运行事件依据，不由模型猜测，不用轮数推算，也不监控其他任务。

## 预算与节奏

本课预算包含开场、读故事、各题、朗读、离屏和收尾。各段分钟数由备课规则按题型的预计用时算出（[课程包](../preparation/course-package.md#题型与预计用时)）：30分钟是估算题量的目标，整节课预计超过40分钟退回删题，练习课少于20分钟退回加题（[ADR-0020](../../decisions/ADR-0020.md)）。

读故事由学生自己计时（[ADR-0022](../../decisions/ADR-0022.md)）：从按“Start reading”到按“I've finished reading”，按核心时钟、暂停期间不计；不设阅读时限，也不因读得快慢提醒或打断。预算仍按“1+词数÷60”分钟估算读故事。

记录实际起止、阶段/交付/等待、暂停和离屏时间，区分整体经过时间与教学运行时间；暂停不是教学失败，也不自动延长家庭约定的结束时间。已有预算/结束窗口内缩减可选活动或提前收尾，家长主动调整可用时间时保留变化；不为补齐教案自动加时。

困难增加时换支持并压缩后续可选项；挑战替换活动。课堂不按时间截断：超过30分钟也继续把题做完，做完最后一题再收尾（2026年10月21日用户决定，替代原“到预算边界优先安全结束当前活动、转入简短收尾”）；学生随时可以暂停、停止或用进度条后的收尾按钮提前收尾，未完成任务如实保留。孩子明确停止不等待时间条件或完整总结。

## 等待与响应

平台/交互层报告实际输入完成、识别、判断、材料生成、呈现开始等时间，分别衡量后台耗时与用户实际等待。后台结果时间不冒称语音首播或听觉延迟，未知值保持未知。

课程与运行配置声明允许等待、有限重试/取消和核实备用，具体阈值在后续接入与实际验证中确定。超出范围时说明正在处理或失败原因，采用备用、跳过或暂停，不无限调用模型、重复请求或空等家长催促。

没有输入时只能根据实际等待事件作一次适合的短澄清或提供暂停方式，不猜孩子在做什么、是否不会或等了多久。离屏/暂停期间不连续提醒和追问。课中计时和取消是必要运行行为，不是项目检查、截图或快照。

## 控制路径

| 情况 | 立即动作与记录 |
| --- | --- |
| 暂停 | 核心保留原会话/任务并使待交付教学动作失效；interface/platform取消录音、播放和等待 |
| 恢复 | 核对当前状态和受影响条件，简短交代当前任务并直接接续；不重放旧输入 |
| 跳过 | 标记实际未完成/未观察与原因，转入允许后续，不按错误或掌握填结果 |
| 明确停止 | 针对当前会话立即停止，取消交付，简短结束；无需目标/小结确认、补测或模型批准 |
| 正常预算结束 | 使用剩余预算收尾，取得实际确认或保留未确认/中断，不强迫做完所有题 |

按钮/明确操作直接触发优先控制；自然语言在取得明确意图后同样执行。语音无法识别时仍有可立即操作的停止入口。核心与交互层同步控制状态，迟到模型、素材、识别和声音结果不得恢复已停课堂。

## 故障与退化

| 问题 | 处理与证据边界 |
| --- | --- |
| 识别含糊/失败 | 澄清、允许更正或换核实方式，不直接评分；保留来源与变化 |
| 模型越界/失败 | 不推进，有限重试或已准备澄清/备用，仍失败暂停；不将故障当学生错误 |
| 材料/声音不可用 | 保留已交付范围，按用途使用核实替代；改变条件记实际支持，无适合备用暂停 |
| 内容或答案有疑点 | 限制相关教学/评价，跳过/暂停/停止；课后走内容更正，不热改依据 |
| 连接中断但会话仍在内存 | 取消旧交付并重新连接同一会话，核对状态/能力后接续 |
| 进程重启或内存丢失 | 明确中断和缺口，不承诺完整恢复，不凭教案或近似生成补造事实 |
| 结束后保存失败 | 保留未完成状态，按原活动/修订重试，不能重复计活动或声称归档成功 |

课中只保留必要内存；进程丢失可能损失尚未封存的实际内容。已经成功封存的事实可以重新读取，封存失败/未知和可控中断按[共同接续](../shared/execution-recovery.md)处理；本设计不承诺课中崩溃完整恢复。

异常不自动改变学科能力或Jane全局策略。事实封存后，evaluation依据可用来源区分技术、材料、教学与实际学生表现，按[交接](closing-handoffs.md)转对应模块修订。

[平台故障/性能](../platform/failures-performance.md)定义故障类别、有限期限/重试、取消与最少计时，平台不把失败当学生错误或静默改模型/条件。恢复按[会话同步](../platform/sessions-sync.md)先同步控制再核对核心，普通积压输入不自动套下一题；[内存与课后保存](../platform/storage-lifecycle.md)继续无课中持久化，部分失败原修订接续。

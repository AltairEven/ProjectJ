# 课堂执行

版本：1.1.0；更新：2026年10月12日；范围：模块设计，未实现。

执行本堂课程，管理教学会话、实际输入、指导与接续。每堂课独立会话，暂停后沿用本堂；只加载本课相关背景，不混入其他课堂上下文。

- 输入：绑定版本的课程包与Jane本课教师简报、必要学习背景、孩子实际输入和家长报告。
- 输出：当前允许的教学回应、材料呈现要求、本堂事件与帮助条件、结束原因。
- 包含：回顾或摸底、目标说明、教学练习、判断澄清、纠错、分级帮助、挑战或降阶、离屏、正常收尾及明确停止。
- 边界：Harness管理允许动作和转场，模型在课程范围内调整指导，不自行扩大目标或更改评分依据。未知不判错误，转写不评发音。

孩子自然回答后由应用接续，家长不逐句转发或逐题批准。帮助需对应实际困难；重复无效换方法或升级，仍困难时允许跳过或结束。目标与收尾需要实际读到或听到的确认，不以附和、生成或播放完成代替。

## Jane策略的执行

按[teacher交接](../teacher/handoffs.md)使用本课绑定的Jane配置、策略与简报。学科与课型变化仍由同一个Jane教学；课堂只读取相关内容，不每轮加载整个方法库或调用额外教师Agent。

Harness保持状态、允许动作、帮助/确认与停止，模型在当前允许范围内按实际困难选指导。课中可使用已准备的替代、降阶或挑战，不更改目标、评价依据、独立条件和全局Jane配置。观察先保留未提示样本，新授/帮助后练习注明条件；纠错后留再试机会。

本堂必要事件包含实际使用的方法、指导变化、各任务/学科的帮助来源和程度、原答、纠错/再试、动作与离屏报告、目标/收尾确认及结束原因。结束且收到家长反馈后交evaluation，供学生评价和Jane改进分别使用；方法返回、文字生成或播放完成不证明学生实际听到或做过。

离屏时停止录音与连续提问，返回后收实际报告。课中只维护必要内存，不做监控、截图、快照或阶段归档；结束后与家长反馈一起交evaluation整理。正常收尾与明确停止分别保留，不补造未完成流程。总入口见[模块设计](../README.md)。

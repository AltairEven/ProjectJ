# 课堂执行

版本：1.13.0；更新：2026年11月1日；范围：模块设计；题型登记驱动的课堂引擎已实现（[ADR-0020](../../decisions/ADR-0020.md)）；课堂全英文（[ADR-0021](../../decisions/ADR-0021.md)）；先自读、后答题（[ADR-0022](../../decisions/ADR-0022.md)）；读故事时标记生词（[ADR-0024](../../decisions/ADR-0024.md)）；课堂判断的等待期限在每次提交时读配置，课中改了下一次判断就按新值，失败事件记实际期限（[ADR-0025](../../decisions/ADR-0025.md)）；课文插图与带图题（[ADR-0026](../../decisions/ADR-0026.md)）；朗读按比例判定、选词标记生词（[ADR-0028](../../decisions/ADR-0028.md)）；读完后可从生词盒移除（[ADR-0029](../../decisions/ADR-0029.md)）。

管理本堂教学含义与会话状态，把绑定版本的课程和Jane简报转成允许教学动作，接住实际回应并交给课后评价。classroom不处理设备/界面的最终输入输出：interface适配输入与呈现，platform提供模型、录音/识别/合成、计时与取消等能力。

## 输入、输出与边界

- 输入：实际课程/素材/Jane/策略与简报、必要需求和背景、统一输入事件、能力/交付/计时等实际反馈。
- 输出：允许教学动作、当前状态/等待条件、实际事件与帮助、使用引用和结束原因；具体显示/声音由对应层实现。
- 包含：回顾或首课/摸底、目标介绍、教学练习、澄清判断、纠错再试、分级帮助、挑战/降阶、指认离屏、预算与收尾。
- 边界：Harness保持状态、允许动作和转场，模型在课程内理解/指导；不扩大目标或更改评分依据，未知不判错误，转写不评发音。

## 共同运行规则

孩子自然回答、求助、确认经应用持续接续，家长不逐句委派或逐题批准。阶段满足条件后直接给下一项实际任务，不只宣布开始而等待催促。一轮一个清楚回应目的，不自行补输入或无限模型调用。

Jane唯一身份与绑定方法按[教师交接](../teacher/handoffs.md)应用，只加载相关简报。观察先留未提示样本；帮助依据实际困难换法/升级或退出，保留最强帮助和初答；有依据纠错后留再试。语言、学科与工具条件分别记录。

动作生成、Harness允许、实际交付、学生收到与理解分别维护，收尾取得自然且有对象的实际确认，开场改为学生按“Start reading”自读（[ADR-0022](../../decisions/ADR-0022.md)）；界面不自建评分或转场，播放完不能直接进下一题。当前会话的明确停止优先，交互/基础层即时取消，核心同步状态，迟到结果不播或推进。

按[两层就绪](../preparation/readiness.md)核对固定内容与当前能力/家庭条件，按[课程生命周期](../curriculum/versions-lifecycle.md)保留实际版本和更正限制。更换入口核对受影响条件，不热换最新内容，媒体替代不自动保留独立性。必需内容/能力不足按核实备用、跳过、暂停或停止处理。

离屏由核心发任务、对应层停止录音和连续互动，返回后收实际结果/帮助，不声称看见未观察动作。正常收尾、未确认、明确停止与中断分别记录，未完成不补造。实际计时管理预算，挑战替换活动，困难缩减可选项，不自动加时；课堂不按30分钟截断，做完最后一题再收尾（[时间预算](time-exceptions.md#预算与节奏)）。

每道题按题型登记走同一流程（[ADR-0020](../../decisions/ADR-0020.md)）：出题时快照带该题型的显示内容（不含答案）；选择、排序、配对、填空收按钮作答、由程序判定且课中不调用模型（[规则路径](interaction-harness.md#点选类题的规则路径)）；精确问答与开放问答收文字、由课堂判断模型判定。开放问答依据要点与“怎样算够”的说明：与故事相符、覆盖要点或说得通、用自己的英文说清楚为正确；与故事矛盾、离题、只有一两个词或缺少要求的部分为不正确，并提示还缺什么。朗读走发音评分，判断由核心按评分定：标出的词不超过本段词数的十分之一为通过（[ADR-0028](../../decisions/ADR-0028.md)），课堂判断模型只写措辞，改判即拒收并按评分的固定规则回应。开放问答的判定说明与要点只随开放问答发送；真实课堂判断重跑参考题集1.1.0通过（50/50）后，正式学习也使用开放问答。

全英文（[ADR-0021](../../decisions/ADR-0021.md)）：Jane的固定台词、帮助与回应都是英文；作答一律英文。学生作答含汉字时判为含糊，Jane提醒“Please answer in English.”，不算答错、不扣分、不用掉帮助；自由填空含汉字拒收、不记作答；全角标点不算中文。课堂判断回应含中文按超出依据拒绝。求助认“Help me”“I need help”“I don't understand the question”等，“I don't know”按含糊；确认收到认“yes”“OK”“got it”“I heard you”等；停止与暂停仍认中文与英文。参考题集2.0.0（54题）用真实模型跑通过前不用于正式学习。

先自读、后答题（[ADR-0022](../../decisions/ADR-0022.md)）：开场只说备课写好的阅读提醒（1到2句、不超过30个英文单词，读的时候留意哪些信息，不说答案）。学生按“Start reading”后文章才出现，按核心时钟计时，暂停不计、暂停时不显示文章；按“I've finished reading”后才出第一题。阅读阶段打字、求助与跳过被拒收并提示该按哪个按钮。读完、停课、收尾或中断时课堂记录追加阅读事件（用时、词数、是否第一次读、暂停次数），只在课后评价页显示，不进AI评价、评分与计划。

生词盒（[ADR-0024](../../decisions/ADR-0024.md)）：阅读阶段（未暂停）学生选中故事里的一个词后按“Add to vocabulary”标记、选中已标记的词按“Remove from vocabulary”取消（[ADR-0028](../../decisions/ADR-0028.md)，原为点词），核心只记事件`word_marked`/`word_unmarked`（词、所在句子），不弹释义、不放发音；标题、题干、选项与帮助文字不能标记。按“I've finished reading”后不能再标记，但课堂未暂停、未结束时可从盒子里移除标错的词（[ADR-0029](../../decisions/ADR-0029.md)，事件照旧`word_unmarked`，正在查的词结果回来时丢弃），第一题立刻出，应用协调层同时在后台把盒子里的词交给模型用途`vocabulary`取释义（学习记录里已有的直接复用）并逐词本机合成发音，结果按词写回盒子（准备中/失败/就绪，事件`word_lookup`只记状态），课中释义与音频只在内存。答题阶段盒子收起在Jane那一栏下方，展开可看释义、听发音、重新生成、移除。盒子不进评分、评价请求与结束记录；封存后由学习模块按规则更新生词记录。

课中只必要内存，不监控、截图、写文件/快照、运行检查或Git。结束时交evaluation按[共同规则](../shared/execution-recovery.md)封存事实，随后按可用评价/反馈，learning更新有据状态/计划，teacher改进方法；本模块不直接改长期状态或全局策略。进程丢失不承诺完整恢复，丢失素材不重生成原件，默认不存儿童原始音频。

成人与技术活动不进入儿童证据。[ADR-0005](../../decisions/ADR-0005.md)记录职责决定；设计文档不代表新版课堂、真实声音、30分钟或教学效果验收，见[总标准](../../docs/acceptance.md)。

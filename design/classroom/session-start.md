# 本堂会话、开课与接续

文档版本：1.4.0；更新：2026年10月22日；范围：逻辑设计，未实现。

一堂实际活动有一个独立会话，绑定课程、任务、素材、Jane/策略与本课教师简报的实际版本。相同课程可使用多次，各自连接实际活动；暂停或更换入口后接续原会话，不因设备变化重复计学习样本。

## 会话信息与状态

必要信息包括活动用途/来源类型、相关学习需求、实际版本、本次能力/家庭条件、当前阶段与任务、允许动作、等待对象、帮助与尝试、预算和结束原因。儿童、成人演练、技术模拟在入口和交接中分别标识，成人扮演学生不改变活动类型。

逻辑上区分待启动、教学运行、离屏、暂停、收尾、正常结束、明确停止和中断。当前正在交付/等待输入/等待判断属于本堂运行情况，不能把“输出生成完成”直接当任务或活动结束。具体状态字段和存储后续设计。

只读取相关状态/真实历史和本课简报，不混入其他课堂、成人故障历史或完整学生档案。课程/Jane不热更新；实际使用内容和许可范围见[课程版本](../curriculum/versions-lifecycle.md)。

## 开课过程和判定权

应用协调层收集检查依据；classroom维护本次启动结论并按下面规则决定是否进入。各业务模块维护自己出具的依据，interface接收家长声明，platform提供实际技术结果。最终结论是规则汇总，不由某个模型自由裁决。

| 检查项 | 依据维护与方式 | 本次判定要求 |
| --- | --- | --- |
| 需求仍适用 | learning业务复核：有效状态/计划/材料经历与缺口 | 能说明当前目标和取样条件有据；未知按继续条件限定范围 |
| 课程与必要内容 | preparation业务核验，curriculum提供版本/依赖与限制，程序核对引用 | 当前包备课完成，主要目标所需材料/任务有效可获取 |
| 运行验收范围 | 应用层[验收报告](../application/acceptance.md)，程序检查绑定与失效 | 覆盖当前路径、配置、时长及使用类型，无受影响阻断 |
| 输入、声音与取消 | platform技术检查；interface实际入口结果及必要试听报告 | 所用输入提交策略已验证（朗读为按键录音），当前能力/退出可用；按钮存在不算通过 |
| 模型接入 | platform[初始化记录与能力报告](../platform/models.md#初始化与准入)，程序核对配置摘要仍有效 | 本堂用途绑定已通过准入；使用语音交付另要求合成通过，含朗读评分段的课程另要求发音评分通过；未核实项如实记录，不支持、失败或明确不符阻断 |
| 数据与访问条件 | platform提供实际条件，程序检查当前范围与权限 | 满足当前来源和处理用途的必需条件，家长同意不能替代技术资格 |
| 实物、时间、陪伴与熟悉度 | interface接收家长实际声明；learning/preparation核对影响 | 只询问影响当前任务的未知，不猜已备材料或重复填档案 |
| 采用安排并开始 | interface接收家长对当前版本/条件的明确开始 | 可合并确认已了解安排；重大方案仍按绑定决定处理 |

每项依据带对象/版本、来源、范围、发生/检查时间和结果。家长报告用于家庭事实，程序结果用于技术条件，业务结论用于教学适用；三者不互相覆盖。有效期由条件变化/检查范围决定，不任意设置统一天数。

## 结果与冲突处理

| 情况 | classroom结果与下一步 |
| --- | --- |
| 所有必需项具备、家长明确开始 | 允许进入，生成本次绑定结论，建立/接续同一活动 |
| 必需项未知、缺失或来源冲突 | 待补充/待复核，列最少问题和主责；不得静默当通过 |
| 已知必需项失败 | 阻断原路径，说明范围和解除依据 |
| 已核实替代能保持目标与允许条件 | 返回替代方案，核对其独立条件/预览/资格后采用；重大变化待具体决定 |
| 可选装饰/挑战不可用 | 移除可选项并更新实际采用范围；必要时同步预览，不阻断无关核心任务 |

“关键”按[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。结论不一致时先核对是否同一版本、设备、任务和日期；旧结论不覆盖当前失效信息，较新结果也不能越权替代不同来源。仍冲突则由相应维护者复核，核心保留待补，不多数投票或家长勾选放行。

进入前再次核对引用版本和当前能力，防止检查后材料/配置已变。变化只使相关结论待复核；无关更新可明确沿用。开始双击/重发采用原操作，不建立两堂课。暂停恢复沿用原活动，并核对变化范围。

通过后进入开场：Jane只说阅读提醒，学生按“Start reading”自读，按“I've finished reading”后在同一接续给出第一项实际任务（[ADR-0022](../../decisions/ADR-0022.md)）。实际开始并不证明学生已经收到内容或学会。总执行见[共同顺序](../shared/execution-recovery.md)。

## 共同骨架与课型

| 阶段 | 教学用途与转场依据 |
| --- | --- |
| 回顾/摸底 | 引用真实相关旧知，无记录用首课分支；观察保留未提示尝试，不以成人活动或计划冒称学过 |
| 目标与安排 | 说明主要/辅助目标、用途及活动方式，不提前泄露观察答案；需要实际收到说明的确认 |
| 教学/练习/应用 | 依据当前任务接住回答、反馈、帮助和再试，按课程条件继续、挑战、降阶或退出 |
| 指认/离屏 | 按任务处理动作与实际报告，未做/未报告保留未观察，不能用跟读代替 |
| 正常收尾 | 总结实际活动和方法、未完成项及下节预期，确认收到后结束 |

骨架支持课型差异，不固定逐字台词或全部阶段顺序。起点观察先取得未提示样本再教学；探究可从问题/预测开始。目标和收尾确认接受与当前内容有关的自然表达，“收到”与知识理解分开，含糊时短澄清，不反复索取固定口令。

视图导航与[角色/设备接续](../interface/roles-devices.md)不新建学习活动，家长接手/查看内部教案先暂停并明确来源，核心与平台核对权限和当前入口。恢复前处理未同步暂停/停止并复查受影响能力，取消旧待交付，不根据刷新页面或角色按钮自动恢复教学。

## 能力与入口变化

语音、文字、图片或实物报告按实际用途核对。文字入口不能承接未改条件的听辨/发音观察，发音评分不可用时朗读评分段记未知、不改由模型评发音，无视觉输入不能声称看见指认；有核实备用时按允许路径使用，注明实际支持与变化，否则暂停相关任务。

会话仍在内存时，恢复或换入口先核对身份/当前状态及受影响能力，取消旧入口待呈现动作，简短回顾当前任务并等待合适输入。新入口不取得完整教师答案，也不自行从头开一堂新课。暂停期间的普通答案不自动推进，必要时恢复后核对意图。

进程重启、记录丢失或无法定位原会话时明确中断和缺口，不能凭教案恢复实际表现。默认不做课中持久化；重新开展活动须明确来源和与原中断的关系，不能重放旧输入制造新样本。时间与故障见[time-exceptions.md](time-exceptions.md)。

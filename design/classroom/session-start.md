# 本堂会话、开课与接续

文档版本：1.1.0；更新：2026年10月12日；范围：逻辑设计，未实现。

一堂实际活动有一个独立会话，绑定课程、任务、素材、Jane/策略与本课教师简报的实际版本。相同课程可使用多次，各自连接实际活动；暂停或更换入口后接续原会话，不因设备变化重复计学习样本。

## 会话信息与状态

必要信息包括活动用途/来源类型、相关学习需求、实际版本、本次能力/家庭条件、当前阶段与任务、允许动作、等待对象、帮助与尝试、预算和结束原因。儿童、成人演练、技术模拟在入口和交接中分别标识，成人扮演学生不改变活动类型。

逻辑上区分待启动、教学运行、离屏、暂停、收尾、正常结束、明确停止和中断。当前正在交付/等待输入/等待判断属于本堂运行情况，不能把“输出生成完成”直接当任务或活动结束。具体状态字段和存储后续设计。

只读取相关状态/真实历史和本课简报，不混入其他课堂、成人故障历史或完整学生档案。课程/Jane不热更新；实际使用内容和许可范围见[课程版本](../curriculum/versions-lifecycle.md)。

## 开课过程

1. 定位固定课程与备课依据，核对任务、素材、简报、检查范围和停用/更正限制。
2. 通过interface/platform取得本次实际能力、数字材料访问和必要家庭报告，核对输入、呈现、取消、实物、陪伴、时间与备用。
3. 区分关键缺口与可选项，只补必要未知；已有明确授权与条件不重复询问。备课完成和本次可开课仍按[两层就绪](../preparation/readiness.md)分别判断。
4. 家长明确开始，建立或接续绑定会话，按本课课型进入开场；实际课堂只在相应验收及入口可用后开始。
5. 执行回顾/首课分支、目标介绍与后续任务。必要确认收到后，在同一接续中给出下一项实际任务，不只说“现在开始”后等待额外催促。

本轮不开放儿童入口或启动任何活动。0.1成人原型与已有检查不能直接代替新版课堂、真实声音或30分钟条件。

## 共同骨架与课型

| 阶段 | 教学用途与转场依据 |
| --- | --- |
| 回顾/摸底 | 引用真实相关旧知，无记录用首课分支；观察保留未提示尝试，不以成人活动或计划冒称学过 |
| 目标与安排 | 说明主要/辅助目标、用途及活动方式，不提前泄露观察答案；需要实际收到说明的确认 |
| 教学/练习/应用 | 依据当前任务接住回答、反馈、帮助和再试，按课程条件继续、挑战、降阶或退出 |
| 指认/离屏 | 按任务处理动作与实际报告，未做/未报告保留未观察，不能用跟读代替 |
| 正常收尾 | 总结实际活动和方法、未完成项及下节预期，确认收到后结束 |

骨架支持课型差异，不固定逐字台词或全部阶段顺序。起点观察先取得未提示样本再教学；探究可从问题/预测开始。目标和收尾确认接受与当前内容有关的自然表达，“收到”与知识理解分开，含糊时短澄清，不反复索取固定口令。

视图导航与[角色/设备接续](../interface/roles-devices.md)不新建学习活动，家长接手/查看内部教案先暂停并明确来源，核心与平台核对权限和当前入口。恢复前处理未同步暂停/停止并复查受影响能力，取消旧待交付，不根据刷新页面或角色按钮自动恢复教学。

## 能力与入口变化

语音、文字、图片或实物报告按实际用途核对。文字入口不能承接未改条件的听辨/发音观察，无视觉输入不能声称看见指认；有核实备用时按允许路径使用，注明实际支持与变化，否则暂停相关任务。

会话仍在内存时，恢复或换入口先核对身份/当前状态及受影响能力，取消旧入口待呈现动作，简短回顾当前任务并等待合适输入。新入口不取得完整教师答案，也不自行从头开一堂新课。暂停期间的普通答案不自动推进，必要时恢复后核对意图。

进程重启、记录丢失或无法定位原会话时明确中断和缺口，不能凭教案恢复实际表现。默认不做课中持久化；重新开展活动须明确来源和与原中断的关系，不能重放旧输入制造新样本。时间与故障见[time-exceptions.md](time-exceptions.md)。

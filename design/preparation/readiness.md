# 备课完成与本次开课就绪

文档版本：2.0.1；更新：2026年10月21日；范围：逻辑设计；按[ADR-0018](../../decisions/ADR-0018.md)改为确认后自动生成并采用资源、开课不再询问陪伴（实施中）。

两层状态回答不同问题：课程包是否已经准备好；这一次是否具备实际开课条件。preparation汇总备课依据，curriculum保存版本，classroom联合platform/interface在启动时核对本次条件。任何单个“ready”标记、学生确认或格式通过都不能替代关键证据。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 第一层：备课完成

| 条件 | 所需依据 |
| --- | --- |
| 需求与任务匹配 | 主辅目标、相关状态、先备/未知、课型、预算和取样条件清楚 |
| 内容核验完成 | 核实事实、题意、答案/合理变式及相应来源，未解决关键问题不标通过 |
| 必需素材与备用可用 | 实际生成/取得且按用途检查，版本/任务/出现阶段一致，必要依赖可访问；预合成教师语句与示范音已核验，朗读任务已切成不超过评分服务上限的评分段并带参考文本 |
| 教学与简报完整 | Jane/策略绑定、主/替代路径、实际帮助纠错、再试、离屏、停止与正常收尾明确 |
| 执行验证范围适用 | 所需功能和流程有匹配的实际检查依据，已执行/未执行分开；新变更复核影响 |
| 交付一致 | 核验记录、课程、素材、简报和预览版本一致，保存完整且可获取 |
| 关键决定已处理 | 影响目标/固定预算/主要教学或评价方式的学生决定完成，核心缺口已修复或有核实替代 |

课程详情已生成且可阅读属于交付完成；学生是否实际看过单列，不能从页面出现自动推定。课程未确认时显示“课程包备好，等你确认”，不能因此声称当下可开课。影响课程的必要学生决定未完成时保留待决定。

首版备课由备课模型编写文字课程并经规则核对（见[P1工程映射](README.md#p1工程映射)），目录内任何主辅目标组合都可备课；模型失败或两稿都未通过规则时，不保存课程对象，下一课报告记为未就绪并给出原因，可以重试。课程须经学生确认确切版本后才能开课。学生点“确认课程”后，AI在后台逐项生成并采用（不开课，等学生按“开始上课”；开始时缺的再补）每项最新一次成功的版本（[ADR-0017](../../decisions/ADR-0017.md)经ADR-0018修订）：朗读示范与模型标为必需的图片、动画生成失败时不开课，返回“资源未就绪”并列出缺项、可以重试；采用后文件不符、或语音的声音配置与采样率已变的版本当作未采用。可选资源缺失时，题目语音改现场合成，图片、动画不显示。程序只核对文件摘要、格式与SVG白名单，不判断画面或声音质量；学生可在课程详情试听或查看、重新生成或选回旧版本。

实物准备要求和可行替代在备课中明确，今天是否实际摆好在第二层核对。必需生成素材未完成则第一层不通过；可选素材失败但已核实备用能维持用途和条件时，可按修订后的包完成，并解释采用方式。

## 第二层：本次开课前检查

本次判定的唯一规则在[课堂启动](../classroom/session-start.md)。preparation提供备课完成结果、当前课程版本、任务必需能力/实物、允许替代和已知限制；应用协调层汇集其余依据，classroom返回本次允许、待补、阻断或可用替代。

数字材料可获取由platform检查，实物由学生在课程用到时勾选报告，时间按课程预算核对，不再询问陪伴；内容适用由业务核验；结果冲突按启动规则处理。备课完成不自动表示当前可开课，预览或开始请求不能覆盖必需项失败。已有明确事实不重复问，日常开课不重跑无关检查。

需求、媒介、材料或相关配置变化时，preparation只重核受影响任务和取样条件。替代改变独立条件时注明实际支持，重大目标/预算/主要方式变化形成[待决定方案](../shared/business-contracts.md)。下一课范围由[共同继续条件](../shared/execution-recovery.md)约束。

## 状态与检查记录

可以呈现待准备、草案、素材待完成、核验待完成、待必要决定、备课完成、待本次启动检查、当前可开课等信息；预览已生成/已实际阅读另列。它们是概念状态，字段与存储命名后续确定。

每个判断显示对象及实际版本、条件/运行配置、检查方法和日期、执行与结果、证据、未验证范围、缺口和备用。失败、未执行、未知、不适用与通过分别标注，不适用有理由，不能用于删除必要检查。

报告要能说明“内容与素材合格，当前声音仍未核实”等部分结论；不能只显示绿色。结构、模型审阅、实际API/声音、完整流程和教学效果分别报告。

## 未来实现需要验证的场景

| 场景 | 必须得到的结果 |
| --- | --- |
| 生成脚本存在但必需图/音频未生成 | 显示素材缺口，不标备课完成 |
| 图中数量/关系与题目不一致 | 修复素材及关联题目/答案，未经核实不呈现或评价 |
| 题卡有帮助字段但重复求助只换措辞 | 教学核验发现分支缺口，不能以结构通过代替 |
| 起点观察前音频/配图泄露答案 | 调整呈现时机或材料，重新检查相关取样条件 |
| 课程包合格但麦克风/声音不明 | 备课与本次状态分开，做必要实际检查，不直接开始 |
| 朗读评分段超出评分服务上限或缺参考文本 | 重新切分或补参考文本，不标备课完成；换评分服务后按新上限复核 |
| 预合成示范音缺失或与课程文本不一致 | 显示素材缺口，重新合成并核验，不用现场合成冒充已核验示范 |
| 可选生成失败但核实备用可用 | 使用修订后明确的备用，保持用途/条件并解释，不阻塞无关部分 |
| 核心运行检查未执行 | 保留未验证和具体范围，预览或人工勾选不能覆盖 |
| 新Jane/素材/运行版本改变关键路径 | 复核相关就绪依据，历史课程和记录保留当时绑定 |
| 学生仅表示开始但关键实物未报告 | 只补必要实际确认，不猜准备好，也不重复索取已授权许可 |
| 课堂新生成素材未核验或停止后返回 | 不呈现/计独立证据，采用备用；迟到结果不能继续课堂 |
| 检查报告或课程保存不完整 | 明确未完成部分，恢复同一修订，不冒称备课已完成 |
| 模拟流程通过 | 只记录实际范围，不填学习状态或直接证明30分钟/教学效果 |

总验收见[acceptance.md](../../docs/acceptance.md)。

本次技术依据按[平台交接](../platform/handoffs.md)连接实际能力、用途参数、运行修订、版本、取消/同步及核实备用。[外发范围](../platform/configuration-permissions.md)：只带学习资料、学习状态与当前任务数据，不含姓名等身份信息与学习者标识。

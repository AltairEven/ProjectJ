# 课程包与本课教师简报

文档版本：1.10.0；更新：2026年10月28日；范围：逻辑设计；预合成语音、资源出现阶段与题型登记已有P1实现。

备课生产一套相互引用的课程内容，curriculum保存实际版本与历史。课程表达准备安排，不表示实施发生或能力掌握；具体数据格式、物理存储和运行代码后续决定。

## 课程包组成

| 部分 | 必须明确 |
| --- | --- |
| 课程标识与依据 | 课程版本、需求/状态/计划引用、Jane与启用策略版本、材料来源与检查范围 |
| 课程设计 | 主辅目标、选择依据、先备条件、课型与阶段、预算和基本预期 |
| 任务与评价依据 | 任务用途、提示、材料、可接受回答或表现、依据、允许帮助和反馈时机 |
| 教学分支 | 正常、合理变式、错误、求助、输入不清、再试、降阶/挑战、跳过/停止与返回路径 |
| 素材集合 | 实际可用的学生/家长/教师材料、离屏内容、阶段可见性和核实备用版本 |
| 本课教师简报 | 当前目标、相关历史/状态、所选方法、困难分支和允许调整的紧凑说明 |
| 核验与就绪依据 | 逐项结果、实际方法与证据、缺口、适用版本/条件及检查复用范围 |
| 家长预览 | 为什么上、预期/帮助、材料与职责、时间、挑战/退出、当前缺口 |

这些是逻辑组成，不要求每部分成为一份独立文件。答案、原材料和核验依据使用稳定引用；简报、预览与学生材料由同一内容生成，不能各自维护不同答案或时间。

保存与来源关系按[课程分层](../curriculum/organization.md)组织，实际版本按[生命周期](../curriculum/versions-lifecycle.md)固定。模板是可复用结构，具体包需本课适配；同一包可以多次使用，实际记录分别引用，不能将课程永久标成已完成。

执行需求按[课堂统一交接](../classroom/boundaries-events.md)说明输入/呈现能力、允许教学动作、必要交付/确认与失败/备用；不绑定某个按钮或语音口令。任务/材料用途与条件明确，具体媒介交互由interface/platform适配，课堂核心不处理最终设备输入输出。

为[备课课堂对照](../evaluation/lesson-alignment.md)保留本课主辅目标、核心/可选、适用流程、预期难度/帮助、预算和允许变化/备用的固定基线；现场采用与原因另记，课后不覆盖原安排。评价使用实际交付/尝试与条件，计划不能充当学习事实。

## 题型与预计用时

每题的题型（`purpose`）按[ADR-0020](../../decisions/ADR-0020.md)由登记驱动，题型内容写在课程里与题型同名的字段中，并记结构版本（旧课程缺省为1）：

| 题型 | 内容 | 核对 |
| --- | --- | --- |
| 选择`choice` | 变种判断（选项固定“对、错”）、对错没提（固定“对、错、文中没提”）、单选（2–5项）；唯一正确项；答对时Jane说的一句 | 依据逐字出自故事；正确项为“文中没提”时在课程限制里注明无法逐字核对 |
| 排序`order` | 变种故事事件或连词成句；3–6张卡按正确顺序 | 连词成句连起来须是故事原句 |
| 配对`match` | 左右各3–6项一一对应，0–2个右列干扰项 | 互不相同 |
| 填空`fill` | 用`___`标空的一句；每空1–3种写法；选词变种另给1–3个干扰词 | 每空第一种写法填回后须是故事原句 |
| 精确问答`answer` | 依据、可接受回答、常见错答 | 依据逐字出自故事 |
| 开放问答`open` | 变种复述、谈看法、如果换成你；1–5条要点；怎样算够 | 依据逐字出自故事；要点由出题说明要求，规则不逐字核对 |
| 朗读、指认、离屏 | 照旧；离屏题自带预计分钟数（2–10） | 照旧 |

题型分布由备课模型按本课目标决定，规则只守底线：主要目标至少一道非程序判定的题（防蒙对）；练习课至少3种题型（朗读算一种）、同一题型不超过题数一半；选择、排序、配对、填空显示的文字不含排在其后的精确问答的第一条可接受回答（只有一个词的答案不比对）；建档小测不用新题型。朗读段由规则插在第一道开放问答之前，没有开放问答时在最后。

课程各段分钟数（开场、读故事、各题、朗读、离屏、收尾）由规则按题型的预计用时算出并保存，备课模型不再填：开场、收尾各2；读故事1+词数÷60；判断0.5，单选与对错没提1；排序0.5+每张0.25；配对0.5+每对0.25；填空0.5+每空0.5；精确问答2；开放问答4；指认2；朗读每段1+段词数÷60；离屏取题上的分钟数；各段向上取整。30分钟是估算题量的目标，整节课超过40分钟退回删题，练习课少于20分钟退回加题。积累至少5个实际样本后，按最近20个样本“实际÷预计”的平均（单个比值先限制在0.3–3）校准该题型，离屏题不校准。

## 任务先于素材

一个任务说明：关联目标/学科、阶段目的、实际材料、任务要求、允许条件、判断依据、反馈时机、后续动作、帮助和退出。任务标识用于连接素材、教学行为与课后证据，不因措辞变化重复建同一任务。

封闭题核对正确结果与合理变式；开放任务明确可接受范围、依据和无法判断条件，不强制唯一措辞。回答正确性、帮助后完成和独立能力不是同一结论。

起点观察/独立验证保留未提示尝试；新授可示范，帮助后表现注明条件。需要避免前题反馈、配图或音频泄露后续样本答案。复习引用真实旧知，保持和迁移具有相应历史/材料条件，不凭计划自动生成。

## 朗读评分段与预合成语音

英语朗读或跟读任务在备课时标明需要发音评分，并切成评分段（故事超过150词时只朗读备课选出的一段连续整句，见[ADR-0023](../../decisions/ADR-0023.md)）：按段落或句群切分，每段文本词数与预计朗读时长不超过运行配置的产品上限（首版每段不超过100词、录音不超过300秒，见[ADR-0015](../../decisions/ADR-0015.md)），切在句末，不拆开一个句子；每段带参考文本、在原文中的位置和所属任务。课堂逐段显示、逐段录音与评分，课后按段汇总到该任务。阅读理解、问答等非朗读任务不切段、不评分。

固定的教师语句与示范音（题目、指令、跟读示范）在备课时经合成适配器用课堂同一本机合成器与声音配置预合成（[ADR-0016](../../decisions/ADR-0016.md)），作为课程素材核验与保存：内容与课程文本一致、英文发音可懂（[ADR-0021](../../decisions/ADR-0021.md)）、声音配置与Jane一致；示范音由成人试听，不能只凭合成成功标为可用。现场回应仍由课堂批准后合成，不在此预合成。依据见[ADR-0014](../../decisions/ADR-0014.md)。

课程包的文件（[ADR-0027](../../decisions/ADR-0027.md)）：确认资源前放在课程草稿目录，确认资源后整体放进`lessons/<类型>-<序号>-<日期>/`，含故事、课程与简报、清单及采用的音频与图片，定稿记录列出每个文件的摘要，课堂只读这份记录。P1实现（[ADR-0017](../../decisions/ADR-0017.md)）：规则从课程生成开场说明、每题题目与每个朗读段示范三类语音资源，文字与课堂所说逐字相同；朗读题提问时只说题目、不念原文，示范在完整示范一级的帮助里播放。模型列的图片、动画、视频带出现阶段（提问时、求助后、随故事某一段或作为某个选项）与对象；给家长或教师的不进入学生视图。

课文插图与带图题（[ADR-0026](../../decisions/ADR-0026.md)）：课程包保存本课画面风格`picture_style`（一句话；有任何图片或动画时必填，之前的课程为空）。资源说明可带`paragraph`（插图配给第几段，从1起不含标题，按页面同一切段规则计数）、`option`（选项图对应的选项下标）与`picture_question`（看图题的题图）。规则核对：插图至多2张、每段至多1张、段落不越界，且无题号、给学生、可选；带图题至多2道，图片选项题是3到4个选项的single choice、每个选项恰好一张静态图，看图题是choice或fill、一张静态图，带图题的图可选、只挂一题；一题只用一种带图形式；有图却没写风格即退回修正。

开场说明（[ADR-0022](../../decisions/ADR-0022.md)）：课程包保存备课模型写的阅读提醒（1到2句、每句以.!?结尾、合计不超过30个英文单词；读的时候留意哪些信息，与本课题目对应，不说出答案，观察课不说出要观察的结果）。规则核对长度与句数，提醒含任一题两个词以上的可接受答案或单选正确选项原文即退回修正。开场语音为“I'm Jane. {提醒} Press Start reading when you are ready.”，复习课在提醒前加“You have read this story before.”；之前保存、没有提醒的课程用“Read the story on your own.”代替提醒。

文章难度（[ADR-0023](../../decisions/ADR-0023.md)）：课程包记下本课故事的目标蓝思值`story_level`（学生当时的蓝思值、档位、目标值与词数区间；建档小测档位为空，没有蓝思值时整项为空）。它是选材目标，不是测量；课程页显示“Aimed at about …; not measured”。

## 教学分支需要具体可用

- 主路径：怎样进入任务、接收原答、给反馈、让学生继续或再试。
- 困难区分：题意/识别、知识前提、定位与关系、表达、操作等，仅使用有依据的判断或短澄清。
- 替代帮助：准备实际不同的表征、提示、步骤、句框或示范及对应材料，重复无效不能只换措辞。
- 纠错：具体不对应之处、课程依据、支持方式和再试任务；合理变式和识别不清分别处理。
- 帮助记录：按任务/学科记录来源和程度，换方法不抹去最强帮助；整课不能默认独立。
- 退出与收尾：降阶、跳过、预算不足、材料失败、暂停、明确停止与正常收尾分别有路径；不强迫补齐未完成任务。

分支定义用途、依据和边界，不写死每一句对话。Jane在允许范围内理解实际困难并调整措辞/指导，不能改变目标、答案依据或独立条件。

## 本课教师简报合同

本节是简报内容的唯一规范来源，由preparation维护；teacher提供策略配置，curriculum保存实际包与简报版本。

| 内容 | 要求 |
| --- | --- |
| 来源与版本 | 课程、需求、相关状态引用；实际Jane配置、通用规则和启用策略版本 |
| 目标与课型 | 主要/辅助目标，各阶段用途和观察/教学边界，基本预期 |
| 历史与背景 | 真实练过的相关内容、帮助和证据；不足时首课或无历史分支 |
| 实际教学路径 | 开场/目标、所选方法、困难区分、主路径和替代、实际材料引用 |
| 帮助与纠错 | 本题允许帮助、具体支持、错误依据、再试和撤去支持条件；记录影响维度 |
| 现场调整 | 可选挑战、降阶、跳过、离屏、预算及退出；生成材料的已核实范围与备用 |
| 收尾 | 正常小结的内容范围、下次预期及实际确认；明确停止另有简短结束路径 |

## 本课教师简报怎样生成

从已核实课程与输入提取满足上述合同的必要信息：

1. 固定需求、相关状态、Jane配置与策略、实际课程/素材版本。
2. 提取主辅目标、课型、阶段、时间和基本预期，未知明确标注为观察目标。
3. 选取真实相关历史与帮助；无儿童记录时编制无历史分支，成人演练不进入回顾。
4. 将所选方法落实为本题主路径、困难信号、实际替代、纠错/再试和退出，引用课程内容。
5. 展开材料呈现、独立取样、离屏、现场生成允许范围与备用，以及正常/停止收尾条件。
6. 核对简报与任务、答案、预算、素材和核验记录一致，删除不相关档案与全局方法库内容。

全局Jane规则由teacher维护，简报是本课实例。简报可以包含必要展开内容与引用，但不成为第二份全局教师配置；也不能让课堂依靠规划聊天记忆取得背景。

## 呈现与归档边界

每项材料标记对象和出现阶段：学生任务、家长准备、教师答案/支架、反馈后示范等。学生视图按阶段取得允许内容，不能提前看教师简报的答案或支架。

课程包和预览由curriculum保存，真实实施记录由evaluation维护。版本与保存一致性见[versions-handoffs.md](versions-handoffs.md)。

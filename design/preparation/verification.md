# 内容与教学核验

文档版本：1.2.2；更新：2026年10月12日；范围：逻辑设计，未实现。

核验分别检查内容、适配、教学、素材、执行和依赖。检查方法与结果要有实际依据；格式通过、生成成功、模型自审或家长预览不能单独证明内容正确或课程可开课。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 分层核验

| 层次 | 核对内容 | 可用依据 |
| --- | --- | --- |
| 内容准确性 | 事实、概念、题意、答案/合理变式、引用与自编标识 | 已读取原材料、适合问题的可靠来源、实际计算或必要操作检查；只提供链接不等于已核实 |
| 难度与适配 | 语言、概念、任务要求、材料熟悉度、工具和预计帮助分别看 | 相关状态与条件、实际文本/任务、先备观察和明确未知；外部指标只作参考 |
| 教学设计 | 目标对应任务、策略适用、实际帮助变换、纠错后再试、支持撤去、离屏与退出 | Jane/课型规则、核实分支、样本条件和时间预算；不只检查是否出现“帮助”字段 |
| 素材 | 实际内容、清晰度、可见对象/阶段、音文图一致和备用 | 查看、试听或操作实际产物，检查数量/标签/关系、获取与呈现能力 |
| 执行路径 | 正常、变式、错误、重复求助、输入不清、跳过、暂停、离屏、停止和正常收尾 | 明确模拟、适用程序/接口检查及必要成人实际演练；后台结果不冒称实际听到 |
| 版本一致性 | 需求/状态/Jane/策略/课程/素材/简报/报告匹配 | 实际版本与内容依赖、可访问引用、变更影响核对 |

科学预测不能写成实验结果；历史或人文事实需保留材料与不确定项。数学可计算结果实际核算，开放任务明确依据与可接受范围。模型审阅用于找疑点，仍需回到原材料、推导、计算或相应实际检查。

自编材料不称教材原文、官方分级或实测Lexile。难度是有依据的候选选择，需在实际反馈中复查；阅读指标不推定听说/写作或融合学科水平，英语表达难也不自动降低阅读与学科理解任务。

## 教学与取样重点

- 主要/辅助目标与实际练习、验证任务相符，其他维度不都变成本课必达目标。
- 观察、新授、帮助后尝试、独立验证、保持和迁移条件明确；音频、配图、前题反馈不提前泄露观察答案。
- 同一融合任务各维度的帮助和判断可区分；任务图片是否属于支持按用途与内容判断。
- 指导替代确实改变方法，纠错说明具体问题并留再试；不强迫所有学生走满固定帮助级数。
- 预算涵盖回顾、教学、练习、离屏与收尾，各关键分支有退出/备用，挑战不加时。
- 无历史分支、实际动作报告、正常确认与明确停止都可接续，未知不代填为完成或失败。

[共同检查能力](../shared/business-contracts.md)分别说明程序强制、内容核验和模型判断，语义质量不能由格式或重复询问同模型证明。[端到端案例](../shared/end-to-end-cases.md)检查备课到下一课实际消费版本、保存/更正与禁止结论；这些案例仅设计，后续按实际影响范围执行与审阅。

## 核验记录

每项记录检查对象/版本、用途与适用条件、实际方法、证据/来源、执行日期、结果、缺口、修复与复查。区分已通过、失败、未执行、无法核实、不适用；不适用要有理由，不能用于掩盖核心缺口。具体存储状态名称后续决定。

模型意见、开发模拟、实际API/声音、成人流程和儿童学习效果分别记范围。成人顺畅或五分钟通过不能直接证明30分钟可靠。已有程序检查也不能继承为新课程或新策略的实际验收。

## 复用与问题修复

既有检查可在对象、相关版本、运行条件与用途仍适用时复用，并明确覆盖范围；不要求每次同模板新材料重复全部演练。新内容核实内容，改变帮助或流程则验证受影响分支，重大流程变化需要完整演练。

失败返回受影响的课程、素材、分支或需求，修复后只复查相关层和依赖；发现新的问题再扩大范围。不能改名称、关闭必要分支或手改就绪标记以绕过验收。

有依据的常规修订由AI完成，向家长展示结果与必要缺口；主要目标、固定预算、主要教学或评价方式变化交家长决定。没有完成关键核验时，仍可提供草案与预览，但不能标记备课完成或本次可开课。

核验结果汇入[两层就绪](readiness.md)，修改影响与责任见[versions-handoffs.md](versions-handoffs.md)。

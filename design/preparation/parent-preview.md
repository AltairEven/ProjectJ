# 课程详情

文档版本：2.1.0；更新：2026年10月28日；范围：逻辑设计；按[ADR-0018](../../decisions/ADR-0018.md)由“家长一页预览”改为学生的课程详情（文件名沿用）。

课程详情帮助学生理解下一课、准备实物，并在开始前提出修改意见。AI承担课程生产与内容核验，学生不需要逐词逐题审批答案或给能力评级。详情从实际课程版本和核验记录生成。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 详情回答的问题

| 内容 | 学生需要知道 |
| --- | --- |
| 为什么上这课 | 主辅目标、当前需求与相关证据；未知时说明是观察任务 |
| 本课故事与题目 | 故事、题目与预计帮助；不提前显示参考答案 |
| 怎样进行 | 简短阶段与时间概览、Jane所用方法、离屏安排 |
| 准备什么 | 课程用到的实物（只来自学习资料里的可用实物与条件） |
| 有余力或困难时 | 挑战增加哪种难度、退回/跳过/暂停/停止方式，预算不增加 |
| 教学资源 | 语音、图片、动画清单；确认后的生成进度、采用的版本 |
| 当前能否开始 | 备课完成范围、关键缺口、下一步 |

参考答案、教师简报和内部评价依据不在课程详情里显示；课堂中的帮助/反馈材料按当前许可呈现。

## 修改意见

学生（或协助的人类教师）写修改意见后，AI改稿并经规则核对成为课程新版本，旧版本记录保留（确认后只留最终版本的文件），意见原文只存在讨论记录里、不进日志。常规小调整直接落实并解释；改变目标、预算、主要教学或评价方式的意见，在说明里写明需要回到学习规划或由学生决定。只询问影响当前课的关键缺口，显示详情不自动等于已阅读或同意。

## 确认与资源

学生点“确认课程”时确认的是确切课程版本；讨论产生新版本后要重新确认。确认只保存、不开课，学生准备好后另按“开始上课”。确认后AI逐项生成清单里的语音、图片与动画（视频显示“未接入”），每项采用最新一次成功的版本，页面写明进行到第几项；学生可试听或查看、重新生成、选回任一旧版本（[ADR-0017](../../decisions/ADR-0017.md)经ADR-0018修订）。挑好后点“确认资源”：在用的版本放进课程文件夹（`lessons/<类型>-<序号>-<日期>/`），其他版本删除，之后不能再改；还没确认资源就点“开始上课”时，按当前在用的版本代为确认。确认后某项文件失效，可用“重做失效资源”只重做失效项（[ADR-0027](../../decisions/ADR-0027.md)）。语音项显示Jane要说的原话。具体交互见[课程详情与开始](../interface/preview-start.md)。

## 与就绪的关系

课程内容核验、学生确认和本次设备/实物检查分别维护。学生确认不能替代事实准确性或实际声音/流程证据；课程包备好也不能推定当下评分、合成与实物已就绪。变更后更新受影响详情并标明差异。备课层关键核验未做时，可先给草案与缺口，不冒称备课完成。正式开课仍由绑定版本的课堂流程处理，见[就绪](readiness.md)。

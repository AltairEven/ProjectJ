# 家长一页预览

文档版本：1.5.0；更新：2026年10月20日；范围：逻辑设计，讨论、确认与资源采用已有P1实现。

预览帮助家长理解下一课、准备材料和调整实际条件。AI承担课程生产与内容核验，家长不需要逐词逐题审批答案或给能力评级。预览从实际课程版本和核验记录生成。

涉及继续条件的“关键”与阻断判定，统一采用[共同阻断标准](../shared/business-contracts.md#关键阻断的共同标准)。

## 一页回答的问题

| 内容 | 家长需要知道 |
| --- | --- |
| 为什么上这课 | 主辅目标、当前需求与相关证据；未知时说明是观察任务 |
| 基本预期 | 希望取得的最小实际表现、可能需要的帮助，不预填成绩或保证掌握 |
| 怎样进行 | 简短阶段与时间概览、Jane所用方法、离屏安排和关键观察条件 |
| 准备什么 | 必需/可选实物与数字材料、取得方式、家长准备负担与备用 |
| 家长做什么 | 陪伴、必要操作或动作报告；独立取样时哪些帮助会影响条件 |
| 有余力或困难时 | 挑战增加哪种难度、退回/跳过/暂停/停止方式，预算不增加 |
| 当前能否使用 | 备课完成范围、关键缺口、下一步；本次开课检查是否仍待做 |

课前学生预览不提前展示教师答案、支架和内部评价依据，家长可按需展开详细材料与检查；实际课堂的帮助/反馈材料按当前许可呈现。预览要简短，完整课程包和证据另行可查，不能把整本教案作为必读清单。

## 反馈与调整

家长可补充材料不可得、实际时间变化、孩子近期状态或活动偏好，备课提出对应替代并检查受影响部分。常规材料/教学小调整直接落实并解释；改变优先级、固定预算、主要教学或评价方式时形成具体方案交家长决定。

只询问影响当前课的关键缺口，不要求重填基本信息、所有学科状态或完整历史。预览记录针对哪一版本已向家长呈现、必要家庭条件如何确认、有哪些反馈与变更；显示预览不自动等于已阅读或同意。

家长开始请求可以同时表达对安排的采用；已明确的信息不再重复索取许可。仍未知的关键材料或运行条件按[本次检查](readiness.md)核对，可合并成一次简短操作，不增加逐项内容审批。

具体交互按[界面预览/启动](../interface/preview-start.md)提供一页内容、条件反馈和受影响版本变化。家长查看详细材料按[角色许可](../interface/roles-devices.md)，学生端不提前取得；显示/实际阅读/必要决定分别处理，界面不自判内容合格或复用对新内容的接受。

P1实现（2026年10月19日）：预览显示一页五项、模型给家长的说明、教学资源清单与历次讨论；家长写修改意见后，模型改稿并经规则核对成为课程新版本，旧版本保留，意见原文只存在预览的讨论记录里、不进日志。家长确认的是确切课程版本，讨论产生新版本后需重新确认；未确认的版本不能开课。确认后清单里的语音、图片与动画可以逐项生成（视频显示“未接入”），家长试听或查看后采用，不满意可重新生成，旧版本保留，有多个版本时可选回任一版试听、查看和采用；语音项显示Jane要说的原话，开始按钮旁列出仍未采用的必需资源（[ADR-0017](../../decisions/ADR-0017.md)）。备课、修订、生成资源与准备下一课进行时，工作台写明正在做什么，生成全部资源时写明进行到第几项。

## 与就绪的关系

课程内容核验、家长预览和本次设备/材料检查分别维护。家长预览不能替代事实准确性或实际声音/流程证据；课程包备好也不能推定当下麦克风、物品和学习时间已就绪。

变更后更新受影响预览并标明差异，原始家庭反馈保留来源。备课层关键核验未做时，可先给草案预览与缺口，不冒称备课完成；仅本次启动检查待做时，显示“课程包备好，本次就绪待核对”。正式开课仍由绑定版本的课堂流程处理。

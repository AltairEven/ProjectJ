# 备课

版本：1.0.0；更新：2026年10月11日；范围：模块设计，未实现。

将下一课需求转为可预览、可执行的教学设计，承担材料整理、内容核验、编排和就绪检查，降低家长备课负担。

- 输入：learning的下一课需求、curriculum中的课程与素材、家长提供的必要材料。
- 输出：课程草案、核验结果、家长一页预览、材料清单与就绪缺口。
- 包含：主要与辅助目标、难度依据、先备知识、教学与取样任务、纠错与分级帮助、挑战与降阶、离屏、时间预算和备用流程。
- 边界：关键材料提前核对；自编材料不冒称教材原文或已测阅读等级；结构检查和模型自审不单独证明课程就绪。

AI承担常规备课，只对影响本课的关键缺失请家长补充。技术或教学流程变更时验证受影响部分，未执行检查保留未验证。核对后的课程版本交curriculum管理，课堂按绑定版本执行。

本目录存备课方法、流程与质量要求，课程正文和素材归curriculum及课程库。总入口见[模块设计](../README.md)。

## 核心组织

先明确孩子需要完成的实际任务及其验证条件，再选择Jane的方法、编排教学与帮助分支，最后制作素材和教师简报。课程、素材、题目、答案与简报通过实际标识/版本引用保持一致，不在多个文件中各自维护不同答案。

交付是一套课程包，加核验记录、家长一页预览和具体缺口。课程包由curriculum管理；teacher维护全局Jane规则，备课只编制本课简报；learning维护学生状态和计划，不以备课结果生成实际进度。

资料、资源和模板按[课程库复用规则](../curriculum/discovery-reuse.md)选择，固定内容与依赖按[生命周期](../curriculum/versions-lifecycle.md)提交；候选或固定版本不自动备课完成。内容错误按[历史更正](../curriculum/history-corrections.md)回查原使用和判断，不能只改下一课答案。

必需材料提前生成并核验，课堂补充生成限定用途与范围，未核验素材不直接呈现或用作独立评价依据。每个关键生成需求有备用路径，生成脚本/请求不等于素材已经完成。

“课程包备课完成”与“当前设备、本次家庭条件可以开课”分别显示。preparation汇总前者所需证据，classroom联合platform与interface执行本次开课检查；家长预览或人工标记不能绕过缺失的核心验收。具体条件见[readiness.md](readiness.md)。

AI承担常规备课，只对影响本课的关键缺失请家长补充。技术或教学流程变更时验证受影响部分，未执行检查保留未验证。核对后的课程版本交curriculum管理，课堂按绑定版本执行。

## 与学习管理的交接

按[交接约定](../learning/handoffs.md)接收[下一课需求](../learning/plans.md)：主要与辅助目标、相关全学科状态和证据、学科/工具先备条件、实际时间与材料、预计帮助、独立验证与复查、离屏、挑战与退出。英语优先不限制读取其他学科；只取本课相关摘要和必要原证据，不加载全部档案与故障历史。

融合课分别选择语言、学科概念与工具难度，通常只增加一种主要难度；其他涉及能力可作先备条件，不都变成本课目标。独立取样、帮助后练习和新情境应用的条件应能被课后评价复用。

返回课程草案及其需求引用、核验结果、家长预览和就绪缺口。材料、先备知识或时间不适合时提供替代方案，由learning处理需求修订；不静默扩大目标或改变主要评价方式。核心缺口保留未就绪，不能以学习管理提出了需求为由宣布可开课。

备课期间有新状态，核对受影响部分并保留需求/状态/课程版本关联；已实施课程保留当时版本。未知前提可设计轻量观察，不要求家长先为所有学科评级。

## 与Jane的交接

Jane是唯一教师。按[teacher交接](../teacher/handoffs.md)结合需求、相关状态、课型、材料和实际输入能力，选择[学科策略](../teacher/subject-strategies.md)与[课型策略](../teacher/lesson-types.md)；不创建其他教师或每轮重新规划。

本模块将方法落实为核实的具体任务、示例、错误依据、主路径、替代指导、再试与退出。不能只写“必要时帮助”；需要说明怎样区分困难、重复求助如何换实际指导、何时撤去支持以及各维度怎样记录帮助。

编制[本课教师简报](course-package.md)，按[teacher交接要求](../teacher/handoffs.md)连接Jane/策略版本、需求与状态依据、真实历史或无历史分支、目标/阶段、实际材料、帮助纠错、允许调整、离屏和收尾。由curriculum随课程保存，teacher仍维护全局方法的唯一来源。观察不前置答案，新授允许示范，表现条件分别保留。

新Jane版本只影响经核对的后续课程；准备中的课程判断受影响范围并复核相应就绪依据，课中不热更新。关键策略、内容或运行缺口保持未就绪，方法说明不代表教学有效。

## P1工程映射

备课用途（2026年10月19日接入，codex:gpt-6.1-sol:xhigh，期限600秒；真实草稿约4.5分钟）按已保存的下节需求编写文字课程：复用课程库故事或自编英语短故事（30–250词、每句以.!?结尾），题目、可接受回答与常见错答、两级以上换方法的帮助、离屏任务、30分钟预算各段、需求逐条对应、家长预览五项、Jane简报（历史、允许调整、收尾）、给家长的说明与教学资源清单。drafting.py的规则核对通过才保存：答题依据逐字出自故事，题型限于参考题集已覆盖的故事问答、指认/离屏实际报告与朗读评分，主要目标有题、辅助目标有题或帮助覆盖，帮助只影响本题维度或主辅目标，预算合计30且有开场与收尾、离屏题与离屏段同在，需求每条恰好对应一次，已读故事只能作复习；不通过时带问题清单让模型修正一次，仍不通过或模型失败则不保存任何课程对象并返回可重试的中文原因。课程、简报、素材、内容核对与预览同一步保存。固定纸桥课程退为课程库模板交给模型复用，模拟适配器原样返回它。

家长对某一课程版本提修改意见，模型改稿、核对后课程与简报升修订号，旧版本保留；改目标、预算或主要教学/评价方式的意见由模型在说明里转回学习规划或家长决定。家长确认绑定确切的课程版本，只有当前且已确认的版本能开课，讨论后需重新确认。教学资源（图片、音频、动画、视频）此批只列清单，确认后待生成；生成器未接入，资源只能是可选的，课程须在没有资源时也能上（家长同日决定资源生成另批，图片、动画、视频暂不接生成器）。

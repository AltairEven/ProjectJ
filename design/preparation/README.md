## 核心组织

先明确学生需要完成的实际任务及其验证条件，再选择Jane的方法、编排教学与帮助分支，最后制作素材和教师简报。课程、素材、题目、答案与简报通过实际标识/版本引用保持一致，不在多个文件中各自维护不同答案。

交付是一套课程包，加核验记录、课程详情和具体缺口。课程包由curriculum管理；teacher维护全局Jane规则，备课只编制本课简报；learning维护学生状态和计划，不以备课结果生成实际进度。

资料、资源和模板按[课程库复用规则](../curriculum/discovery-reuse.md)选择，固定内容与依赖按[生命周期](../curriculum/versions-lifecycle.md)提交；候选或固定版本不自动备课完成。内容错误按[历史更正](../curriculum/history-corrections.md)回查原使用和判断，不能只改下一课答案。

必需材料提前生成并核验，课堂补充生成限定用途与范围，未核验素材不直接呈现或用作独立评价依据。每个关键生成需求有备用路径，生成脚本/请求不等于素材已经完成。

“课程包备课完成”与“当前设备、本次条件可以开课”分别显示。preparation汇总前者所需证据，classroom联合platform与interface执行本次开课检查；学生确认或人工标记不能绕过缺失的核心验收。具体条件见[readiness.md](readiness.md)。

AI承担常规备课，只对影响本课的关键缺失请学生补充。技术或教学流程变更时验证受影响部分，未执行检查保留未验证。核对后的课程版本交curriculum管理，课堂按绑定版本执行。

## 与学习管理的交接

按[交接约定](../learning/handoffs.md)接收[下一课需求](../learning/plans.md)：主要与辅助目标、相关全学科状态和证据、学科/工具先备条件、实际时间与材料、预计帮助、独立验证与复查、离屏、挑战与退出。英语优先不限制读取其他学科；只取本课相关摘要和必要原证据，不加载全部档案与故障历史。

融合课分别选择语言、学科概念与工具难度，通常只增加一种主要难度；其他涉及能力可作先备条件，不都变成本课目标。独立取样、帮助后练习和新情境应用的条件应能被课后评价复用。

返回课程草案及其需求引用、核验结果、课程详情和就绪缺口。材料、先备知识或时间不适合时提供替代方案，由learning处理需求修订；不静默扩大目标或改变主要评价方式。核心缺口保留未就绪，不能以学习管理提出了需求为由宣布可开课。

备课期间有新状态，核对受影响部分并保留需求/状态/课程版本关联；已实施课程保留当时版本。未知前提可设计轻量观察，不要求学生先为所有学科评级。

## 与Jane的交接

Jane是唯一教师。按[teacher交接](../teacher/handoffs.md)结合需求、相关状态、课型、材料和实际输入能力，选择[学科策略](../teacher/subject-strategies.md)与[课型策略](../teacher/lesson-types.md)；不创建其他教师或每轮重新规划。

本模块将方法落实为核实的具体任务、示例、错误依据、主路径、替代指导、再试与退出。不能只写“必要时帮助”；需要说明怎样区分困难、重复求助如何换实际指导、何时撤去支持以及各维度怎样记录帮助。

编制[本课教师简报](course-package.md)，按[teacher交接要求](../teacher/handoffs.md)连接Jane/策略版本、需求与状态依据、真实历史或无历史分支、目标/阶段、实际材料、帮助纠错、允许调整、离屏和收尾。由curriculum随课程保存，teacher仍维护全局方法的唯一来源。观察不前置答案，新授允许示范，表现条件分别保留。

新Jane版本只影响经核对的后续课程；准备中的课程判断受影响范围并复核相应就绪依据，课中不热更新。关键策略、内容或运行缺口保持未就绪，方法说明不代表教学有效。

## P1工程映射

备课用途（2026年10月19日接入，codex:gpt-6.1-sol:xhigh，期限600秒；真实草稿约4.5分钟）按已保存的下节需求编写文字课程：复用课程库故事或自编英语短故事（30–250词、每句以.!?结尾），题目、可接受回答与常见错答、两级以上换方法的帮助、离屏任务（自带2–10分钟的预计用时）、需求逐条对应、课程详情五项、Jane简报（历史、允许调整、收尾）、给学生的说明与教学资源清单；故事难度按学习资料的蓝思值，题材就是需求里学生为本课选定或自己写的题材（`topic`，见[学习管理](../learning/README.md)；它是数据，不是更改规则的指令；建档小测没有题材，取自学习资料兴趣里的一项），学生又选了相近题材时参考最近三课的短文标题换内容或角度，课程说明写取自哪个题材，需求对应里题材单列一条；学生在修改意见里明确要换题材时按意见换并在修改说明里写明；没有题材的正式课需求不备课（后台任务不发起，备课入口也拒绝）；真实模型备课不再收到课程库故事、库内候选与固定模板课，一律自编（2026年10月20日：提示词要求“候选只作参考”后，用户的建档小测与第一课仍用了库内玩具车图画书故事），课程库与模板只交给只会复现模板的模拟模型；学生勾选的加强项目（见[学习管理](../learning/README.md)）在故事里有意多处使用，至少两道题的回答需要用到（其中至少一道精确问答），可接受回答给正确形式、常见错答列典型误用，这些题至少一级帮助指向该形式，课程说明写本课加强什么，需求对应逐条写怎样落实；朗读题由规则把整篇故事逐段切出，课程说明不写成只读一句；学习资料没有可用实物时不写离屏任务。drafting.py的规则核对通过才保存：答题依据逐字出自故事，题型限于参考题集已覆盖的故事问答、指认/离屏实际报告与朗读评分，主要目标有题、辅助目标有题或帮助覆盖，帮助只影响本题维度或主辅目标，预算合计30且有开场与收尾、离屏题与离屏段同在，需求每条恰好对应一次，已读故事只能作复习；不通过时带问题清单让模型修正一次，仍不通过或模型失败则不保存任何课程对象并返回可重试的中文原因。课程、简报、素材、内容核对与预览同一步保存。固定纸桥课程退为课程库模板交给模型复用，模拟适配器原样返回它。

题型由登记驱动（[ADR-0020](../../decisions/ADR-0020.md)）：选择、排序、配对、填空、精确问答、开放问答、朗读、指认、离屏各按代号在备课（`preparation/task_types.py`：内容结构、核对、预计用时、出题说明、难度梯子）、课堂（`classroom/responses.py`：显示内容与判定）、课后评价（`evaluation/scoring.py`：计分方式）与页面（`web/src/tasks.ts`）各登记一项，一项测试核对各处都已登记。备课模型在与题型同名的内容字段里填题目内容，题型分布由它决定；规则核对内容结构与原文依据、防蒙对、练习课题型多样、不泄露答案，并按题型的预计用时算出课程各段分钟数（超过40分钟退回删题，练习课少于20分钟退回加题；内容与规则见[课程包](course-package.md#题型与预计用时)）。点选类题答对、答错与求助时Jane说的话按课程文字预合成。请求附最近5节课按题型与能力的平均分（10分制，未知不计）与题数，各题型的预计用时按已封存课堂的实际用时校准。开放问答由开关`OPEN_IN_STUDY`控制正式学习是否使用：真实课堂判断重跑参考题集1.1.0通过（50/50，2026年10月21日）后已打开，课堂判断再变化时须先重跑；模拟空间始终可用。

学生对某一课程版本提修改意见，模型改稿、核对后课程与简报升修订号，旧版本保留；改目标、预算或主要教学/评价方式的意见由模型在说明里转回学习规划或学生决定。学生确认绑定确切的课程版本，只有当前且已确认的版本能开课，讨论后需重新确认。教学资源在确认后才生成（[ADR-0017](../../decisions/ADR-0017.md)）。语音由规则从课程生成，模型不列：开场说明、每题题目（可选，未采用时课堂现场合成同一句）与每个朗读段的示范（必需），文字与课堂所说逐字相同，经本机合成。模型只列图片、动画、视频，写明出现阶段（提问时或求助后）与对象；图片经Codex出图、动画由备课模型写成SVG并按白名单核对后生成，可以设为必需；视频未接入，只能可选。学生点“确认并开始上课”后，AI逐项生成并采用每项最新一次成功的版本，页面显示进度；学生仍可在课程详情试听或查看、重新生成、选回旧版本，每次一个新版本、旧版本保留；生成与采用都记在预览的新修订里，文件按内容摘要保存并进入备份。必需资源生成失败时不开课，给出原因与重试；可选资源失败不阻止开课；采用后声音配置或采样率变了、文件不符的版本视为未采用。课堂进行中不生成。

## 核心组织

先明确学生需要完成的实际任务及其验证条件，再选择Jane的方法、编排教学与帮助分支，最后制作素材和教师简报。课程、素材、题目、答案与简报通过实际标识/版本引用保持一致，不在多个文件中各自维护不同答案。

交付是一套课程包，加核验记录、课程详情和具体缺口。课程包由curriculum管理；teacher维护全局Jane规则，备课只编制本课简报；learning维护学生状态和计划，不以备课结果生成实际进度。

资料、资源和模板按[课程库复用规则](../curriculum/discovery-reuse.md)选择，固定内容与依赖按[生命周期](../curriculum/versions-lifecycle.md)提交；候选或固定版本不自动备课完成。内容错误按[历史更正](../curriculum/history-corrections.md)回查原使用和判断，不能只改下一课答案。

必需材料提前生成并核验，课堂补充生成限定用途与范围，未核验素材不直接呈现或用作独立评价依据。每个关键生成需求有备用路径，生成脚本/请求不等于素材已经完成。

“课程包备课完成”与“当前设备、本次条件可以开课”分别显示。preparation汇总前者所需证据，classroom联合platform与interface执行本次开课检查；学生确认或人工标记不能绕过缺失的核心验收。具体条件见[readiness.md](readiness.md)。

AI承担常规备课，只对影响本课的关键缺失请学生补充。技术或教学流程变更时验证受影响部分，未执行检查保留未验证。核对后的课程版本交curriculum管理，课堂按绑定版本执行。

## 与学习管理的交接

按[交接约定](../learning/handoffs.md)接收[下一课需求](../learning/plans.md)：主要与辅助目标、相关全学科状态和证据、学科/工具先备条件、实际时间与材料、预计帮助、独立验证与复查、离屏、挑战与退出。英语优先不限制读取其他学科；只取本课相关摘要和必要原证据，不加载全部档案与故障历史。

融合课分别选择语言、学科概念与工具难度，通常只增加一种主要难度；其他涉及能力可作先备条件，不都变成本课目标。独立取样、帮助后练习和新情境应用的条件应能被课后评价复用。

返回课程草案及其需求引用、核验结果、课程详情和就绪缺口。材料、先备知识或时间不适合时提供替代方案，由learning处理需求修订；不静默扩大目标或改变主要评价方式。需求是本课要达到的目的：其中点名的具体题目、题型或题数只作参考，题型、题数与问法由备课按目标、分数与需求方向决定；方向为进阶或拓展时落实需求写明的那一步难度，写明退回时照着退回（[ADR-0030](../../decisions/ADR-0030.md)）。核心缺口保留未就绪，不能以学习管理提出了需求为由宣布可开课。

备课期间有新状态，核对受影响部分并保留需求/状态/课程版本关联；已实施课程保留当时版本。未知前提可设计轻量观察，不要求学生先为所有学科评级。

## 与Jane的交接

Jane是唯一教师。按[teacher交接](../teacher/handoffs.md)结合需求、相关状态、课型、材料和实际输入能力，选择[学科策略](../teacher/subject-strategies.md)与[课型策略](../teacher/lesson-types.md)；不创建其他教师或每轮重新规划。

本模块将方法落实为核实的具体任务、示例、错误依据、主路径、替代指导、再试与退出。不能只写“必要时帮助”；需要说明怎样区分困难、重复求助如何换实际指导、何时撤去支持以及各维度怎样记录帮助。

编制[本课教师简报](course-package.md)，按[teacher交接要求](../teacher/handoffs.md)连接Jane/策略版本、需求与状态依据、真实历史或无历史分支、目标/阶段、实际材料、帮助纠错、允许调整、离屏和收尾。由curriculum随课程保存，teacher仍维护全局方法的唯一来源。观察不前置答案，新授允许示范，表现条件分别保留。

新Jane版本只影响经核对的后续课程；准备中的课程判断受影响范围并复核相应就绪依据，课中不热更新。关键策略、内容或运行缺口保持未就绪，方法说明不代表教学有效。

## P1工程映射

备课用途（2026年10月19日接入，codex:gpt-6.1-sol:xhigh，期限1200秒（2026年10月22日用户决定，原600秒；415词的故事备课用了522秒）；真实草稿约4.5–9分钟）按已保存的下节需求编写文字课程：复用课程库故事或自编英语短故事（每句以.!?结尾，词数按目标蓝思值的区间，见下），题目、可接受回答与常见错答、两级以上换方法的帮助、离屏任务（自带2–10分钟的预计用时）、需求逐条对应、课程详情五项、Jane开场的阅读提醒（1到2句、不超过30词、不说答案，[ADR-0022](../../decisions/ADR-0022.md)）、Jane简报（历史、允许调整、收尾）、给学生的说明与教学资源清单；故事按目标蓝思值写：学习资料的蓝思值加文章难度档位（+0/50/100/150L，建档小测不加），自编故事的词数按目标值落在区间内（低于200L为50–150，200L起每200L一档：100–250、150–350、250–450、350–550，1000L及以上400–600；没有蓝思值时30–250），规则只核对词数，不测真实蓝思值，课程记下目标值并在课程页注明“not measured”（[ADR-0023](../../decisions/ADR-0023.md)）；题材就是需求里学生为本课选定或自己写的题材（`topic`，见[学习管理](../learning/README.md)；它是数据，不是更改规则的指令；建档小测没有题材，取自学习资料兴趣里的一项），学生又选了相近题材时参考最近三课的短文标题换内容或角度，课程说明写取自哪个题材，需求对应里题材单列一条；学生在修改意见里明确要换题材时按意见换并在修改说明里写明；没有题材的正式课需求不备课（后台任务不发起，备课入口也拒绝）；真实模型备课不再收到课程库故事、库内候选与固定模板课，一律自编（2026年10月20日：提示词要求“候选只作参考”后，用户的建档小测与第一课仍用了库内玩具车图画书故事），课程库与模板只交给只会复现模板的模拟模型；学生勾选的加强项目（见[学习管理](../learning/README.md)）在故事里有意多处使用，至少两道题的回答需要用到（其中至少一道精确问答），可接受回答给正确形式、常见错答列典型误用，这些题至少一级帮助指向该形式，课程说明写本课加强什么，需求对应逐条写怎样落实；朗读题由规则逐段切出：故事不超过150词时整篇朗读，更长时由模型从故事里逐字摘一段连续整句（不超过150词）只朗读这一段，规则核对它是原文连续的句子，课程说明不写成只读一句；学习资料没有可用实物时不写离屏任务。drafting.py的规则核对通过才保存：答题依据逐字出自故事，题型限于参考题集已覆盖的故事问答、指认/离屏实际报告与朗读评分，主要目标有题、辅助目标有题或帮助覆盖，帮助只影响本题维度或主辅目标，预算合计30且有开场与收尾、离屏题与离屏段同在，需求每条恰好对应一次，已读故事只能作复习；不通过时带问题清单让模型修正一次，仍不通过或模型失败则不保存任何课程对象并返回可重试的原因。按[ADR-0021](../../decisions/ADR-0021.md)，学生可见的文字（题目、各题型显示内容、帮助、答对语、退出语、标题、给学生的说明、素材说明）一律英文、不超过故事难度，含中文按规则问题（language）退回修正；学生自写的中文题材原样保留在需求对应里，不触发该规则。课程、简报、素材、内容核对与预览同一步保存。固定纸桥课程退为课程库模板交给模型复用，模拟适配器原样返回它。

课文形式与先文后题（[ADR-0031](../../decisions/ADR-0031.md)）：备课请求附形式清单、最近三课的标题、形式与正文（正文读自已确认的课程文件夹，读不到时为空）和最近两课用过的形式。需求的`form`不为空时是学生选的形式，草稿的`story_form`必须是它；为空时由备课模型选，不能是最近两课用过的；自编课文没填`story_form`、与学生所选不符或与最近两课相同时规则退回修正。学生在修改意见里要求换形式时不受这两条限制。复用课程库故事时课程的`story_form`为空。指令要求：本课换掉最近三课共有的写法；先把课文写成一篇值得读的东西，再从课文里实际有的内容出题；顺序可以由任何先后关系取证，不必用顺序词或安排结尾三步；课文难度与长度只按`story_level`，写到目标这一档、词数取区间中段，需求里与之冲突的说法不作数。规则不核对课文写得是否多样。

生词回流（[ADR-0024](../../decisions/ADR-0024.md)）：备课请求附学习者生词记录里状态为生词的词（原形、词性、权重、标记次数、距上次见到天数，按权重降序，最多100个；复习课与建档小测不附），指令要求把合适的词自然地写进故事，每课最多用5个，最近几课刚见过的往后放，不要为了用词让故事不自然（[ADR-0031](../../decisions/ADR-0031.md)，原为“用多少个自己决定”）；草稿多一个字段`vocabulary_used`（本课故事实际用到的生词原形），规则只去掉不在故事里的词（原形或以它开头、最多多三个字母的词形）并把去掉的数量记进课程限制，不核对数量、不退回；课程包保存`vocabulary_used`，课程详情显示“Review words”。

题型由登记驱动（[ADR-0020](../../decisions/ADR-0020.md)）：选择、排序、配对、填空、精确问答、开放问答、朗读、指认、离屏各按代号在备课（`preparation/task_types.py`：内容结构、核对、预计用时、出题说明、难度梯子）、课堂（`classroom/responses.py`：显示内容与判定）、课后评价（`evaluation/scoring.py`：计分方式）与页面（`web/src/tasks.ts`）各登记一项，一项测试核对各处都已登记。备课模型在与题型同名的内容字段里填题目内容，题型分布由它决定；规则核对内容结构与原文依据、防蒙对、练习课题型多样、不泄露答案，并按题型的预计用时算出课程各段分钟数（超过40分钟退回删题，练习课少于20分钟退回加题；内容与规则见[课程包](course-package.md#题型与预计用时)）。点选类题答对、答错与求助时Jane说的话按课程文字预合成。请求附最近5节课按题型与能力的平均分（10分制，未知不计）与题数，各题型的预计用时按已封存课堂的实际用时校准。开放问答在正式学习与模拟空间都使用：真实课堂判断重跑参考题集1.1.0通过（50/50，2026年10月21日）后启用。课堂判断再变化时须先重跑参考题集；重跑未通过时，再加回关闭正式学习开放问答的开关。

学生对某一课程版本提修改意见，模型改稿、核对后课程与简报升修订号，旧版本记录保留（文件只留最终版本，见下）；改目标、预算或主要教学/评价方式的意见由模型在说明里转回学习规划或学生决定。学生确认绑定确切的课程版本，只有当前且已确认的版本能开课，讨论后需重新确认。教学资源在确认后才生成（[ADR-0017](../../decisions/ADR-0017.md)）。语音由规则从课程生成，模型不列：开场说明、每题题目（可选，未采用时课堂现场合成同一句）与每个朗读段的示范（必需），文字与课堂所说逐字相同，经本机合成。模型只列图片、动画、视频，写明出现阶段（提问时或求助后）与对象；图片经Codex出图、动画由备课模型写成SVG并按白名单核对后生成，可以设为必需；视频未接入，只能可选。学生点“确认并开始上课”后，AI逐项生成并采用每项最新一次成功的版本，页面显示进度；学生仍可在课程详情试听或查看、重新生成、选回旧版本，每次一个新版本；确认内容时每项资源各建一条记录，生成、采用、核对都只改这一条，版本文件写在课程草稿目录。学生点“确认资源”（或直接开始上课，由Start代为确认）后，采用版本复制进`lessons/`下的课程文件夹，保存定稿记录，未采用的版本与草稿目录删除；之后锁定，开课只读定稿记录，必需项失效时用“重做失效资源”只重做失效项（[ADR-0027](../../decisions/ADR-0027.md)）。必需资源生成失败时不开课，给出原因与重试；可选资源失败不阻止开课；采用后声音配置或采样率变了、文件不符的版本视为未采用。课堂进行中不生成。

扩展阅读（[ADR-0033](../../decisions/ADR-0033.md)）：学生在已上过的课里把课文扩写成一本分章英文小说，在网页的书架上读或下载到手机读（[ADR-0035](../../decisions/ADR-0035.md)）。扩写归备课模块（文字与插图的请求和核对在`preparation/expansion.py`，EPUB打包在`preparation/epub.py`），流程与书的文件由应用协调层`application/books.py`组织；书不是课程：不进课程包、课程库、评价、学习状态与生词掌握，写在学习者目录的`books/<课程文件夹名>-<UTC时间>/`：正式版本是`book.json`、`pictures/`与`book.epub`，编辑中的草稿在`draft/`（`book.json`、`pictures/`）；提纲讨论、写作、改写、续写与补画都只写草稿，保存时才由草稿打包EPUB并覆盖正式版本（[ADR-0035](../../decisions/ADR-0035.md)；旧的`readings/`升级时改名并整理），原课程文件夹不改。用`reading`用途先出提纲（[ADR-0034](../../decisions/ADR-0034.md)：书名、故事大致内容、人物的名字与外貌、2–12章各自的章名情节与生词，生词盒全部生词各分到一章，原插图各指派一章，外貌不写任何人物名字），学生可写意见多轮修改，每轮只留最新一版；确认后逐章严格按提纲情节写（每章400–800词、本章生词都用上、插图段落不越界且每段至多一张、全英文），提纲每轮与每章各最多修正一次，修正后只缺生词不算失败；每章另画一张新插图，画图请求只用人物外貌、插图描述里的名字换成外貌，不做看图核对，失败该章不配新图，完成后可只补画失败的插图。完成的书可续写：在已确认提纲末尾讨论新章（书名、已写章、人物、画风与原插图指派由程序按已确认的提纲保留，只取模型新加的章与人物），确认后只写新章。难度按主页四档算目标蓝思值，只用于这本书，不写回学习资料。完成后可对某一章写修改意见只改写这一章（只能在这一章的提纲情节之内改），改写全部在内存里完成后才依次写入草稿的新插图与记录。

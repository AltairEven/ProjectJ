# Project J 产品范围

版本：2.0.2；更新：2026年10月21日。

J是AI自学助理（[ADR-0018](../decisions/ADR-0018.md)）。学生在一个主页面上使用唯一的AI教师Jane：建档、确认学什么、上课、认可课后评价，AI承担规划、备课、教学资源、指导、评价与复盘。程序只有“学生”一个身份，不预设学生是孩子还是成人；课程难度与内容只按学习资料和学习状态（蓝思值、背景、等级、兴趣等）决定。

学习管理覆盖全部学科，英语优先只决定近期投入。蓝思值、年级和外部测评只作参考，不替代分维度能力证据；课程保持一个主要目标和一个辅助目标，通常只增加语言、概念或工具中的一种主要难度。时间包含回顾、练习、离屏和收尾，可选挑战替换原活动，不自动加时。

## 谁做决定

| 学生确认 | AI决定 |
| --- | --- |
| 学习资料（建档时与之后的修改） | 备课细节与改稿 |
| 学习目标与计划，含规划提出的新能力条目 | 教学资源的生成与采用 |
| 开始一节课 | 计划的小幅调整、复盘到期后的发起 |
| 课后认可评价，或补记、提出异议、更正 | 课堂中的提问、判断、帮助与纠错 |

学生可以请一位人类教师在同一台电脑、同一个画面上协助判断备课质量与课后评价；这只是使用方式，程序不区分操作者。

## 使用流程

首次使用先建档：填英语蓝思阅读值 → Jane用固定问题聊几句 → 小测（一节按蓝思值准备的短课，含阅读与朗读评分）→ AI整理学习资料，学生确认 → AI提出第一个目标与计划，学生确认。

之后循环：AI备课 → 学生在课程详情查看，可写修改意见让AI改稿 → 学生确认课程，AI生成并采用教学资源 → 学生准备好后开始上课，进入全屏课堂 → 下课封存事实并自动评价 → 学生认可，或补记、提出异议后看新评价 → 学习状态采用、规划下一课；换目标或需要新能力条目时先请学生确认 → 学生在主页勾选下一课要加强的语言项目（可不选） → 下一课按学生兴趣自编短文备课。

学生输入经适配器自动提交到同一课堂核心；核心在允许范围提问、判断、澄清、帮助与纠错，批准后交付声音和素材。学生可以随时暂停或停止。指认和离屏按实际报告记录，不以返回页面或跟读替代。事实保存、评价与状态/计划处理分别显示，未知不默认为独立。具体保存/丢失范围和继续条件以[共同执行](../design/shared/execution-recovery.md)为准。

周、阶段与年度复盘到期后由AI自动发起，学生也可以主动发起。重要方向、预算或主要教学/评价方式变化形成具体方案，由学生决定；常规有据调整直接落实并解释。

首版范围统一见[最小可用版本](mvp.md)，技术基线见[选型](technology.md)，阶段交付见[开发路线](roadmap.md)；更多学科与入口按实际使用扩展。

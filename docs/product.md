# Project J 产品范围

版本：1.9.0；更新：2026年10月12日。

当前暂停新功能开发，先讨论家长主导的家庭AI学习工作台设计。已按学习管理、备课、Jane教师与教学策略、课程内容、课堂执行、课后评价、界面和基础服务建立[八个模块的设计目录](../design/README.md)。现有0.1原型只提供实验参考，不预先限定最终交互、模型能力或技术栈。

目标是让家庭长期复用可靠的备课和教学执行方式，让孩子尝试、理解、应用并逐渐自主。现阶段英语优先、适度融合科学等学科，家长陪伴。应用名字取灵感于Jane，不把教师塑造成真人、依赖对象或全知伙伴。

Jane始终是唯一教师，通过反馈持续调整方法以适应学生与学习计划，见[教师模块](../design/teacher/README.md)及[决定](../decisions/ADR-0002.md)。学科与课型是Jane的方法库，备课选择方法；全局角色/策略由teacher维护，本课简报与版本绑定由preparation编制、curriculum保存，classroom在允许范围内使用，evaluation分别提供学生状态与教学改进依据。改进兼顾独立理解/应用、保持/迁移、体验与家庭投入，并保留实际版本。该设计尚未实现。

长期规划与家庭学习状态继续以LearningWithAI为依据。教学进度可以早于学校或加深应用，但调整须有实际能力与体验依据。课程保持一个主要目标、一个辅助目标，新增语言、概念、工具只选一种主要难度。

学习管理按[模块设计](../design/learning/README.md)组织档案、全学科状态、长期与短期计划及课后更新。状态覆盖各学科、跨学科学习能力和综合应用，不局限于英语；当前优先级只影响近期投入。评价提供任务级表现与修订依据，学习管理维护跨课状态并提出下一课需求，备课将需求转成课程包；交接内容与版本要求见[对应设计](../design/learning/handoffs.md)。当前没有实现这些状态与计划维护功能，也不自动迁移或回写家庭数据。

产品流程是“家长提出目标与材料 → Agent备课 → 内容及运行检查 → 家长预览 → 本堂独立会话 → 互动及离屏 → 结束反馈 → 评价与下节预期”。每堂课一个应用会话，暂停沿用同一会话；未来不再依靠每轮Codex语音自行委派来控制教学。

按[备课设计](../design/preparation/README.md)，先结合学习需求、状态与Jane策略设计目标及验证，再生产相互引用的课程包、素材和本课简报，完成分层核验与家长一页预览。[备课完成](../design/preparation/readiness.md)表示核实交付可用，本次开课还须由classroom/platform/interface核对实际设备、材料和家庭条件；预览已生成、实际阅读与关键决定分别记录。版本与交接见[对应设计](../design/preparation/versions-handoffs.md)，模块未实现。

按[课程模块设计](../design/curriculum/README.md)保存原始资料、教学资源、模板、具体课程包与历史/更正，实际依赖固定，生命周期与两层就绪/使用引用分别维护。本地固定版本可供核验或引用，不能自动开课；复用核对熟悉程度与条件，素材按对象/阶段呈现，已知错误限制受影响使用并回查历史判断。该模块未实现，不迁移或改写现有课程、素材和家庭档案。

按[课堂设计](../design/classroom/README.md)，classroom只管本堂教学含义、状态与允许动作，interface适配具体输入/呈现，platform提供模型/媒介/计时/取消。[统一交接](../design/classroom/boundaries-events.md)分输入事件、教学动作和交付反馈，不因播放成功推定收到或理解。自然回应自动接续，帮助/纠错有再试，离屏有实际报告，预算与收尾/停止分开；不同入口核对实际能力和评价条件。该设计未接入原型，首版受控语音交互路径见[基础服务](../design/platform/realtime-voice.md)，具体协议仍待选择，不开放儿童入口。

按[评价设计](../design/evaluation/README.md)，结束且家长一次实际反馈后整理事实与任务评价，形成状态修订依据、下节建议和方法/内容/运行问题。[课堂对照](../design/evaluation/lesson-alignment.md)按五维保存课前基线、实际差异、许可/原因/影响及主责关联，不机械扣完成率或归咎孩子。learning落实状态/需求，teacher改Jane，preparation修课；生成、保存与下游处理分别报告，更正回查原活动及依赖。模块未实现，不评价真实孩子或回写历史。

按[界面设计](../design/interface/README.md)，家长工作台以当前重点/下一步为主，学生课堂专注当前任务，预览/反馈/报告按权限提供。[媒介适配](../design/interface/input-output-adapters.md)统一接核心，字幕/重播/语速等保持任务条件；[角色/设备切换](../design/interface/roles-devices.md)不重开课堂，来源与角色分开，当前学习输入/语音输出明确，停止本端即时取消并如实报告同步。仅设计，不选最终技术形态或实现新界面/多端。

按[基础服务设计](../design/platform/README.md)，七项技术能力按用途组织，共享身份、实际版本、权限、期限、取消和结果。首版语音自动提交完成输入、核心批准后合成，设备交付和学生收到分开；活动与连接分离，部分失败在原修订接续。[儿童数据条件](../design/platform/configuration-permissions.md)区分本机保存和服务商保留，缺失不开放真实数据入口；运行数据、内容依赖与凭据分开。仅设计，未选择技术栈或实现新服务、改变现有数据策略。

整体闭环按[共同约定](../design/shared/README.md)：各对象唯一维护，应用层协调准备/启动/课后/更正，先保存事实/评价依据再更新有效状态、计划与需求，家长汇总采用实际处理结果。待反馈、失败或变更时[下一课条件](../design/shared/execution-recovery.md)区分草案/备课完成/本次开课，相关关键缺口限制使用，无关候选不阻断全部活动。[12个端到端案例](../design/shared/end-to-end-cases.md)仅为明确虚构验收设计，未执行；shared不增加模块、服务或Agent。

0.1已经实现成人纸桥课程的执行、内容检查入口与课后保存；AI备课部分仅支持审阅已导入课程，不含自动生成并发布新课。正式儿童课堂、学习档案、计划自动维护、新素材生成、完整备课编辑器和连续实时语音属于后续里程碑。

课堂中的生成必须服从课程包。关键题目、答案和教材事实提前核验。实时图片或例子只能在已允许范围内生成，未审核的素材不能用于独立评价；素材未完成时采用预备材料，不让孩子等待。

家长看到当天目标、材料、可选挑战和退出条件，能重复、求助、跳过、暂停、停止。首次观察、帮助后练习、新情境应用、延迟保持分别记录。未知保留未知，语言与融合学科分开；单次顺畅不能支持稳定掌握。

默认不保存课中快照或原始音频，只维护必要内存。课堂结束且家长提交实际反馈后一次归档。应用进程重启造成中断时明确说明，不能用教案补造实际事件。

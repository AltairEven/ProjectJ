# Project J 产品范围

版本：1.11.0；更新：2026年10月12日。

J为家庭提供唯一教师Jane和家长工作台，帮助长期规划、准备课程、互动学习、评价与调整。孩子通过尝试、求助、练习、应用和离屏活动学习，家长提供实际条件、陪伴并决定重要方向；AI承担常规规划、备课、指导和有据更新。

学习管理覆盖全部学科，英语优先只决定近期投入。年级、教材位置和外部测评用于参考，不替代分维度能力证据；课程保持一个主要目标和一个辅助目标，通常只增加语言、概念或工具中的一种主要难度。时间包含回顾、练习、离屏和收尾，可选挑战替换原活动，不自动加时。

## 家庭使用

家长请求准备下一课，应用采用有效状态/计划形成需求，结合Jane策略制作核实课程、素材和紧凑简报。家长预览理由、材料、预计帮助、挑战与退出，补必要家庭事实；本次开课按实际能力、条件和验收范围判断。

学生输入经适配器自动提交到同一课堂核心；核心在允许范围提问、判断、澄清、帮助与纠错，批准后交付声音和素材。家长无需逐句转交，学生可暂停或停止。指认和离屏按实际报告记录，不以返回页面或跟读替代。

结束后先封存已取得事实，家长可稍后反馈。家长看到事实保存、反馈、评价和状态/计划处理的不同结果；家长明确稍后反馈且下一课准备或工作台当前用途确需评价时，按需形成或复用限定范围的阶段性评价，未知不默认为独立。后续反馈追加来源与必要更正，不丢原答，不重复计活动。具体保存/丢失范围和继续条件以[共同执行](../design/shared/execution-recovery.md)为准。

learning综合候选建议和跨课证据选择下一需求；Jane改进、内容修正和运行问题交对应主责。周、阶段与年度复盘有独立用例，工作台显示到期事项，家长可以主动发起。重要方向、预算或主要教学/评价方式变化形成具体方案，常规有据调整直接落实并解释。

首版范围统一见[最小可用版本](mvp.md)，从本机、单学习者、30分钟阅读融合探究课程完成到下一课程包的闭环。技术基线见[选型](technology.md)，阶段交付见[开发路线](roadmap.md)；更多学科与入口按实际反馈扩展。

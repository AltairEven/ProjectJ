# Project J 0.1 实验原型架构

文档版本：1.1.0；对应原型：0.1.0；更新：2026年10月11日。

本文件描述已经建立的实验原型，不作为最终应用架构。家长已要求暂停功能开发，先梳理产品形态、使用流程与大模块。目标设计及文件路径以[模块设计入口](../design/README.md)为准；浏览器、后端和模型职责已提出，技术栈与最终代码布局仍待决定。

采用本机Python服务与浏览器界面，将内容、流程、判断和播放分别控制。0.1无第三方运行依赖，优先验证教学闭环；后续可替换HTTP框架、模型提供者或界面，不改课程与证据含义。

## 内容合同

courses/paper-bridge/lesson.json 是0.1执行内容的唯一入口，包含目标、预算、材料、任务、rubric、可接受变式、错误、依据、纠错和帮助策略。原Markdown材料保留原字节与来源摘要；不能把新执行包的版本混称原课程版本。

每个任务有稳定ID、类型、phase、prompt、next；答案节点具有rubric与三级help，按实际困难可选择help_by_difficulty。任务类型为ack、answer、action、practice、offscreen、experience、summary。正式JSON Schema与更丰富内容合同在M1完善；当前自带校验器已检查主要路径、预算、依据、帮助和素材关系。

流程可按课程配置，状态机不写死物品词表。教师人格是表达约定；任务合同是执行边界。不同课程可选择观察、新授、复习或项目模板，不要求所有课程都按相同仪式推进。

## 状态与输入

每个会话具有session_id、revision、course_hash、当前任务、帮助、初答与事件，独立于Codex聊天。事件只取当次真实输入，不重放历史。revision拒绝过期答案；明确停止可立即打断等待。模型请求在锁外运行，结果回来后再次核对状态，过期结果丢弃。

确认与附和分开；动作必须有done和实际报告。离屏两题都收到才反馈，未做可跳过，不把“做完了”代填答案。帮助未知先澄清，重复无效换方法，最强帮助条件不因换方向降级；达到边界允许跳过。归档保留实际原答，不用修正后答案覆盖。

模型只接收当前题卡、对应阅读材料与答案依据，输出correct、incorrect或unknown及依据。当前给出的是受限语义判断，仍可能出错；有效依据标识不证明判断正确。教师话术使用课程内已准备内容与事实小结，模型返回不能直接变成可播放新题。

## 语音与家长界面

浏览器负责录音、文本核对、播放和取消，服务端保管密钥。语音合成只接受session_id与revision，从控制器取文本，拒绝客户端任意教学文本。生成完成后再次检查版本；前端也以播放epoch拒绝迟到音频。播放完成不等于家长听清，确认仍来自实际操作。

第一版为逐轮录音转写，暂不实现连续全双工；暂停、离屏和停止可以取消音频。当前是家长控制台，听力动作时转开文字，不宣称本界面已独立隔离学生屏幕。0.1只供成人验证。

## 备课与评价

备课先检查结构、材料来源、预算、题卡与分支，再请模型按目标、歧义、帮助、难度、独立性和家庭负担审阅。模型审阅不能自动写就绪。后续就绪依据绑定课程内容摘要、检查方法、运行版本、真实验收范围与报告。

课后保留家长原话和实际事件，再由Medium整理建议，事实与推断分开。成人结果只写.data/adult，不是儿童session；正式学习记录格式与LearningWithAI兼容由后续导出器实现。

## 扩展边界

后续增加备课生成器、学生材料视图、多模态素材、不同课程模板与学习档案适配器。领域合同不嵌入某个模型接口字段，既有ID、帮助条件和证据含义保持。应用生成、自评和程序通过不能替代孩子的保持、迁移和体验。

官方技术依据于2026年10月11日核对：

- [结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)：约束格式，内容仍可能有错误。
- [语音架构](https://developers.openai.com/api/docs/guides/voice-agents)：串联路径可检查中间文本。
- [语音识别](https://developers.openai.com/api/docs/guides/speech-to-text)、[语音合成](https://developers.openai.com/api/docs/guides/text-to-speech)：与判断模型分别配置。
- [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)：实际账号访问与时延另行测试。

# 0.1.0 开发验证

版本：1.0.0；日期：2026年10月11日；范围：开发模拟与本地浏览器，孩子未参与。

本报告只确认应用程序闭环。没有调用真实模型、请求麦克风、试听声音、开展实际离屏活动或验证30分钟教学。成人开发结果不进入儿童档案。

| 检查 | 结果与依据 |
| --- | --- |
| 课程检查 | 主要转场、预算总和30分钟、题卡依据与原材料SHA256通过 |
| Python程序与HTTP | 31项通过，包含初答、合理未知、帮助升级、两题收集、收尾确认、停止优先及模型迟到结果 |
| 浏览器取消逻辑 | 3项Node模拟通过：迟到麦克风许可释放资源、取消录音不转写、停止后迟到语音不播放 |
| JavaScript语法 | node --check通过 |
| 实际浏览器界面 | 本地规则模式跑完P0→READ→R1→R2→R3→L1→O1→T→U→FEEL→END；模拟收到8个样本，正常确认结束 |
| 帮助与纠错界面 | “英语表达”归为困难而非答案，两次帮助由关键词变为句框；初答car保留，练习回到R1核对 |
| 离屏报告校验 | 只填一题被拒绝且未推进，填齐两题后统一反馈。勾选和报告都是测试输入，不证明实际离屏完成 |
| 课后保存与导出 | 明确标注全部为模拟的反馈保存成功，实际下载JSON为completed、adult_only=true、child_learning_evidence=false，8个样本 |
| 浏览器错误 | 本次完整界面检查未取得控制台error记录 |

检查中修复：完整困难名称被误作答题、含糊困难误推进、保存失败后不能重试、麦克风许可或语音合成迟到后的取消竞态。也核对并修正新文B的帮助内容，模型判断现在附带当前对应阅读材料，避免只凭答案例句核对合理变式。

# Project J 开发路线

版本：1.8.0；更新：2026年10月12日。按验证结果推进，不预设上线日期。

当前优先完成[八个大模块的设计](../design/README.md)，依次梳理使用流程、职责、输入输出和质量标准，再确定技术方案并实现。暂停功能开发；以下里程碑保留为原型后续能力的参考，顺序和内容需随目标设计复核，不自动继续开发。

已细化[学习管理](../design/learning/README.md)的档案、全学科状态、计划层次、课后更新与交接设计；这是文档成果，尚未实现。后续状态框架应从基础上支持全部学科，具体学科内容和课程模板可分期扩展，不能把M5理解为此前只保存英语状态。旧项目数据迁移需单独明确维护入口与来源。

已新增[唯一教师Jane的模块设计](../design/teacher/README.md)，明确角色、通用规则、学科/课型策略、反馈迭代和版本衔接；不恢复功能开发，不建设教师阵容或因新增模块增加每轮Agent调用。下面的里程碑仅保留参考，其实现顺序仍需整体设计复核。

已细化[备课生产设计](../design/preparation/README.md)，覆盖输入、课程包/简报、多模态素材、核验/预览、两层就绪和版本交接。后续实现需将这些条件接入课程与启动流程，现有原型没有实现自动生产或新就绪系统；素材能力按实际需求逐步接入，不以生成脚本或检查通过冒称媒体与教学可用。

已细化[课程与教学内容](../design/curriculum/README.md)的分层、版本/生命周期、检索复用、呈现、历史更正与交接设计。后续实现需让固定依赖、使用关系和更正影响可追溯；这不是已经建立内容库，也不恢复功能开发或提前生成十年课程。

已细化[课堂核心与交互分离](../design/classroom/README.md)及统一事件/动作/交付反馈、开课、指导纠错、离屏、预算与收尾。[未来场景](../design/classroom/closing-handoffs.md)覆盖不同入口、持续自然接续、帮助/再试、迟到与停止、未确认和中断。仅设计，未更改0.1原型，实际单轮、五分钟、30分钟及效果仍分别验收。

已细化[课后评价与对照设计](../design/evaluation/README.md)，覆盖低负担反馈、事实/证据、任务判断、备课课堂契合度、下节建议、报告修订及主责关联交接。未来[场景](../design/evaluation/handoffs.md)需验证来源/帮助/未知、合理适配/超出不足、去重/更正、保存和下游处理范围；仅设计，不恢复开发或写入真实孩子状态。

已细化[家长学生界面](../design/interface/README.md)的工作台、课堂、预览/反馈、媒介适配和角色/设备接续。[场景](../design/interface/handoffs.md)需验证材料许可、真实来源/状态、重复/迟到、字幕等条件变化、停止同步和反馈失败。先按当前电脑同设备验证，再按实际需求扩展其他入口；只设计，未实现新页面或多端。

已细化[基础服务](../design/platform/README.md)的七项能力、统一交接、实际运行版本及[儿童数据边界](../design/platform/configuration-permissions.md)。后续按[场景](../design/platform/handoffs.md)验证实际参数、核心批准后交付、取消/迟到、权限、同步/内存缺口和部分保存；具体协议、存储及等待阈值以后选择。本轮仅文档，未接入服务商或开放儿童入口。

| 里程碑 | 交付 | 完成条件 |
| --- | --- | --- |
| M0 应用骨架 | 独立项目、纸桥结构化课、内存Harness、家长界面、模型语音适配器、成人课后保存 | 本地程序及接口检查通过；真实API和声音未验收 |
| M1 课程合同与备课质量 | 资料/资源/模板/课程包组织、固定依赖和生命周期、Jane简报、核验/预览及备课依据 | 至少两种课程共享执行器，内容/素材/简报一致，固定不冒称就绪，实际指导可用，检查范围和缺口可追溯 |
| M2 模型与交互接入 | 用途模型/实际参数、核心批准后语音交付、统一交接/媒介、权限/儿童数据条件、同步与取消/备用 | 实际API/账户/数据条件及单轮/持续接续、错答/求助、指认/离屏、收尾/停止分别有据；输入/媒介条件可辨，迟到不交付，同设备先验证，其他入口按需验收 |
| M3 首课陪伴试教 | 正式记录导出、备课与本次启动检查、30分钟预算与退出 | 关键内容/运行条件有相应依据，家长明确开始，真实反馈不混成人测试，能给有据下节预期 |
| M4 持续备课与反馈 | 新课审阅与复用、课后事实/评价和备课课堂对照、全学科状态/计划、Jane改进与更正回查 | 差异按依据/许可/原因反馈主责关联，学习/教学分别调整，保存与下游落实可辨，历史可追溯，不重复计样本或按日期增长能力，投入可接受 |
| M5 多模态与学科内容扩展 | 审核素材生成、题型模块、更多语言与学科课程模板 | 复用全学科状态与证据框架，保持来源、独立条件和停止边界 |

第一版课程导入不意味着材料难度已再次验收。关键生成素材先备好，可选生成失败不会中断课堂。先跑通从备课到课后的一条路径，再增加界面和自动化；不提前开发十年完整课程或多Agent调度系统。

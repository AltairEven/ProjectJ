# Project J 开发路线

版本：1.1.0；更新：2026年10月11日。按验证结果推进，不预设上线日期。

当前优先完成[七个大模块的设计](../design/README.md)，依次梳理使用流程、职责、输入输出和质量标准，再确定技术方案并实现。暂停功能开发；以下里程碑保留为原型后续能力的参考，顺序和内容需随目标设计复核，不自动继续开发。

| 里程碑 | 交付 | 完成条件 |
| --- | --- | --- |
| M0 应用骨架 | 独立项目、纸桥结构化课、内存Harness、家长界面、模型语音适配器、成人课后保存 | 本地程序及接口检查通过；真实API和声音未验收 |
| M1 课程合同与备课质量 | 完整Schema、内容来源与版本绑定、可生成家长预览、质量案例集、备课编辑及降阶模板 | 至少两种课程共享执行器，合理变式/错误/帮助与泄露检查可复用 |
| M2 模型与语音接入 | 实际API配置、逐轮语音、取消与故障备用、学生材料独立视图 | 单轮、故意错答、连续求助、动作、离屏和收尾成人实测 |
| M3 首课陪伴试教 | 正式记录导出、真实课程就绪、30分钟预算与退出 | 家长明确开课，真实反馈不混成人测试，能给有依据的下节预期 |
| M4 持续备课与反馈 | 新课生成审阅、周计划读取、复习取样、状态建议与反馈编辑 | 小步迭代有证据、家庭负担可接受，不按日期增长能力 |
| M5 多模态与更多学科 | 审核素材生成、题型模块、其他语言与学科模板 | 模块可替换，保持独立证据、来源和停止边界 |

第一版课程导入不意味着材料难度已再次验收。关键生成素材先备好，可选生成失败不会中断课堂。先跑通从备课到课后的一条路径，再增加界面和自动化；不提前开发十年完整课程或多Agent调度系统。

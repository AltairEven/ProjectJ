# Project J 开发路线

版本：1.2.0；更新：2026年10月12日。按验证结果推进，不预设上线日期。

当前优先完成[八个大模块的设计](../design/README.md)，依次梳理使用流程、职责、输入输出和质量标准，再确定技术方案并实现。暂停功能开发；以下里程碑保留为原型后续能力的参考，顺序和内容需随目标设计复核，不自动继续开发。

已细化[学习管理](../design/learning/README.md)的档案、全学科状态、计划层次、课后更新与交接设计；这是文档成果，尚未实现。后续状态框架应从基础上支持全部学科，具体学科内容和课程模板可分期扩展，不能把M5理解为此前只保存英语状态。旧项目数据迁移需单独明确维护入口与来源。

已新增[唯一教师Jane的模块设计](../design/teacher/README.md)，明确角色、通用规则、学科/课型策略、反馈迭代和版本衔接。后续备课设计需要落实策略选择、具体指导分支与本课简报；不恢复功能开发，不建设教师阵容或因新增模块增加每轮Agent调用。下面的里程碑仅保留参考，其实现顺序仍需整体设计复核。

| 里程碑 | 交付 | 完成条件 |
| --- | --- | --- |
| M0 应用骨架 | 独立项目、纸桥结构化课、内存Harness、家长界面、模型语音适配器、成人课后保存 | 本地程序及接口检查通过；真实API和声音未验收 |
| M1 课程合同与备课质量 | 完整Schema、内容来源与版本绑定、Jane策略选择和本课简报、家长预览、质量案例集与降阶模板 | 至少两种课程共享执行器，Jane/策略/课程引用一致，合理变式/错误/帮助与泄露检查可复用 |
| M2 模型与语音接入 | 实际API配置、逐轮语音、取消与故障备用、学生材料独立视图 | 单轮、故意错答、连续求助、动作、离屏和收尾成人实测 |
| M3 首课陪伴试教 | 正式记录导出、真实课程就绪、30分钟预算与退出 | 家长明确开课，真实反馈不混成人测试，能给有依据的下节预期 |
| M4 持续备课与反馈 | 新课生成审阅、长期至周计划衔接、全学科状态框架、Jane教学行为改进、复习取样与反馈修订 | 学生状态与教学改进分开、小步迭代有证据、任务帮助可区分、不重复计样本，家庭负担可接受，不按日期增长能力 |
| M5 多模态与学科内容扩展 | 审核素材生成、题型模块、更多语言与学科课程模板 | 复用全学科状态与证据框架，保持来源、独立条件和停止边界 |

第一版课程导入不意味着材料难度已再次验收。关键生成素材先备好，可选生成失败不会中断课堂。先跑通从备课到课后的一条路径，再增加界面和自动化；不提前开发十年完整课程或多Agent调度系统。

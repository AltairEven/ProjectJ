# Project J 分阶段实现计划

版本：1.14.0；更新：2026年10月20日；状态：阶段0至3的能力已实现并有隔离检查与真实调试记录；2026年10月20日定位改为AI自学助理（[ADR-0018](../decisions/ADR-0018.md)），阶段4、5由“自学助理改版与自用”取代。按验收推进，不预设上线日期。

以[E2E01](../design/shared/end-to-end-cases.md#e2e01-正常完成与下一课准备)实现从本课需求到下一课程包的完整路径。[最小版本](mvp.md)定义范围，[技术选型](technology.md)定义基线，质量门槛统一见[验收标准](acceptance.md)。0.1原型已按[ADR-0012](../decisions/ADR-0012.md)删除，新实现不以其为迁移基础。

## 开发顺序和阶段关卡

| 阶段 | 主要交付与顺序 | 本阶段通过条件 |
| --- | --- | --- |
| 0 确认边界与接入 | 固定首课、设备/浏览器和对象合同草案；锁定依赖基线；成人短测模型、合成、英语朗读录音与发音评分、打断和端到端延迟；核对账户与儿童数据条件 | 得到实际能力/未知与适用范围清单；选定语音路径或具体待验证替代，并写明其儿童数据条件覆盖为已核实或待核实；阶段1所需对象、来源与保存边界明确，外部阻断按用途列出 |
| 1 完整模拟闭环 | 用虚构学习者、模拟模型和最薄可操作界面走通D1到C2；建立数据库、用例进度、版本、失败接续及简版复盘/方案 | E2E01隔离运行可回查；封存成功后重启可读；重复不重复建活动；部分失败可接续；导出/备份恢复与归属隔离有检查结果 |
| 2 真实AI备课判断和评价 | 先接平台SDK，再生成/核验课程包与素材，接课堂语义/指导、证据化评价及有据学习更新 | 实际配置可查；参考题集通过内容与语义检查；C2体现D2及具体取舍；模型拒绝/不完整不推进；正常反馈不先做两次评价 |
| 3 自然语音课堂 | 将合成交付与英语朗读录音评分接到同一核心；实现朗读暂停续读/重读、逐段评分、纠错再试、交付、打断、离屏和备用 | 文字作答、求助、目标/小结确认持续提交，英语朗读逐段录音评分；E2E13实际语音分支通过；停止/迟到可靠；达到所选配置的响应门槛 |
| 4 成人完整验收（已由ADR-0018取代） | 五分钟检查分支后，做30分钟完整流程；封存后关闭再开、稍后反馈、准备C2；复查适用异常 | 目标、纠错/升级帮助、指认、离屏、正常收尾与停止各有证据；19个案例的适用检查已处理，匹配报告保存，无未解阻断 |
| 5 家长陪伴试教（已由ADR-0018取代） | 满足试教前提后接入最小真实资料和唯一写入入口；实际授课、反馈、更正、状态/需求与下一包 | 一次真实闭环完成且评价忠于原答和帮助；家长理解调整；未观察项保留，实际教学效果继续观察 |
| 自学助理改版与自用 | 按[实施计划](superpowers/plans/2026-10-20-self-study-assistant.md)完成SELF-1至SELF-4：文档、单一操作者与正式学习空间、建档与自动接续的课程链路、主页面重写、参考题集重跑与真实核对 | 用户在正式学习空间完成建档，并至少完成一次“上课 → 评价认可 → 下一课备好”；之后的顺序由用户以后定 |
| 6 持续使用和扩展 | 根据实际反馈完善Jane与复盘，再增加课型、学科、素材和入口 | 每项扩展有具体需求、证据、适用范围、受影响验证和退出方式；保留历史与唯一教师 |

阶段0是先消除接入假设的短验证，不先建设完整应用。其外部接口未就绪时，隔离模拟的阶段1仍可推进；阶段2、3所依赖的实际能力未通过则保持待处理。

阶段0至3仅使用隔离虚构数据或明确成人来源。ADR-0018之后，正式学习空间的记录即学生的学习记录；开发期间的真实核对使用单独运行编号并在结束后清空。

## 阶段0的具体产物

1. 明确一条首课及下一课的范围，选定一个浏览器/设备配置，列出文字和声音备用条件。
2. 定义E2E01所需对象与事件的最小字段、维护者和版本关系；明确学习者、成人/模拟类型、任务实例、尝试、交付与结束边界。
3. 定义请求身份、重复处理、失败/未知回执和发布前版本核对；细化数据库/私有文件路径，选定受维护的Python运行时并锁定依赖版本。
4. 成人短验证取得模型配置、识别完成、实际首播、打断结果、请求用量和数据发送范围；未能验证的部分列明继续范围，不填“已接入”。
5. 固定独立参考题集和E2E01模拟输入/预期结果，为阶段1与2分别提供基准。模板与输入是数据，不能改变Harness权限。

## 交付证据与推进

每阶段交付可操作结果、对应代码/合同/课程/配置版本、检查方式和实际结果、已知限制、可继续范围。报告维护职责在[应用验收管理](../design/application/acceptance.md)；本路线只维护阶段顺序，不另维护一套使用资格。

检查失败回到对应步骤，修复后复查受影响范围；技术失败不扩大成家长逐项审批。改变主目标、固定预算或主要方式时才按业务规则形成具体方案。未完成的非阻断扩展不拖住已满足条件的主线。

P0已细化阶段1所需字段、接口、保存边界及模拟输入/预期，并建立项目级锁定环境和独立验证工具；实际模型/麦克风和真实资料迁移均未执行；P1已执行隔离闭环，具体层次见交接。交付及外部阻断见[交接](handoff.md)，阶段1已明确确认；后续真实接入仍需对应实际依据。

P0已明确对象/来源/保存边界、首课/C2方向、依赖与检查入口；独立验证通过，故具备**隔离模拟阶段1的技术与合同入口**。已取得Opus对第三方库/工程工具的无阻断审查，六项工具建议由GPT核实落实；该范围不证明完整业务或实际API/语音通过。P1授权及当前交付已另登记；本次不自动启动真实阶段。

| 缺口 | 影响用途/阶段 | 不依赖该项的继续范围 |

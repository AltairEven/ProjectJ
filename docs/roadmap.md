# Project J 开发路线

版本：1.10.0；更新：2026年10月12日。按验证结果推进，不预设上线日期。

当前阶段与实施授权统一见[共同入口](../design/shared/README.md)。后续实现以[E2E01完整时序](../design/shared/end-to-end-cases.md)为第一条可运行路径，包含应用协调、输入提交、开课判定、结束封存、反馈、状态/计划/需求及下一课；不把闭环所需保存与学习更新推到首次试教之后。

| 里程碑 | 交付 | 完成依据 |
| --- | --- | --- |
| M0 成人实验参考 | 既有0.1原型 | 原有程序检查；实际能力与新设计差距见README/验收，不能直接开放儿童入口 |
| M1 隔离完整闭环 | 命名对象、权威合同、协调操作、版本/保存/重试、课程与简报、复盘/方案 | E2E01和适用异常案例的程序/内容检查，模拟数据与真实学习隔离 |
| M2 实际模型与输入交付 | 用途配置、提交策略、语音与素材、权限/数据条件、取消和备用 | 实际接口/单轮/错误/求助/停顿改口/持续转交证据，运行版本绑定 |
| M3 成人完整验收 | 目标、练习、指导纠错、指认、离屏、收尾、封存及反馈/下节 | 五分钟后按受影响范围验证30分钟；结束关闭后可追加反馈，报告资格可追溯 |
| M4 家长陪伴试教 | 最小真实数据接入、就绪与备用、有据评价及下节调整 | 具体采用范围、来源切换和必要验收满足；未知保留，真实效果后续观察 |
| M5 持续优化与扩展 | 周阶段年度复盘、Jane迭代、更多题型/素材/学科及入口 | 根据真实独立表现、保持迁移、体验和负担扩展；新增入口复用同一合同 |

全学科状态和证据框架从M1建立，具体学科内容按需要扩展。关键素材课前备好，现场生成使用核实范围与备用。技术选择服务完整路径，不预先构建十年课程、多个教师或多Agent调度系统。

# Project J 最小可用版本

版本：1.0.0；更新：2026年10月12日；状态：范围已采用，实现待启动。

首个可用版本在当前电脑上，由家长陪伴完成一堂30分钟课程，并依据实际表现和反馈准备下一课。以[E2E01](../design/shared/end-to-end-cases.md#e2e01-正常完成与下一课准备)贯穿八模块和应用协调层，每个模块先提供支撑这条闭环的最小能力。

范围由本文件维护，[技术选型](technology.md)说明实现基线，[开发路线](roadmap.md)维护顺序与阶段交付，[验收标准](acceptance.md)维护质量口径和儿童试教前提。业务含义继续服从[共同规范](../design/shared/README.md)，阻断采用[共同标准](../design/shared/business-contracts.md#关键阻断的共同标准)。

## 使用形态与完成标准

家长通过一个本机启动入口打开网页，在家长工作台准备与预览课程；孩子在学生课堂自然回应，家长陪伴并可接手或停止。首版固定一款桌面浏览器和一套实际验证过的设备配置；本地保存不表示模型离线运行，模型与声音能力仍取决于实际服务连接。

完整交付包括：需求D1 → 已核验课程C1与简报/素材 → 预览与本次启动 → 活动A1 → 结束事实F1 → 家长反馈FB1 → 评价E1 → 状态/计划处理与需求D2 → 下一课程包C2。每个结果关联真实来源、版本与保存状态，沿用计划或状态无变化也返回有依据的结果。

仅展示下节建议不算闭环完成。C2必须实际采用D2，并能解释哪些任务、帮助或观察条件依据第一课结果作了调整，或为什么沿用；C2仍有自己的内容核验与下一次启动检查。

## 首版能力

| 部分 | 首版交付 | 验收可见结果 |
| --- | --- | --- |
| 家长与学生入口 | 一个孩子，两种视图；准备、预览、开始、课堂、反馈与报告 | 日常无需通过Codex转交每句输入，也不用家长填写能力等级 |
| 学习管理 | 全学科状态结构、稳定学习者标识；长期方向、阶段计划、周安排与下一课需求 | 本课只更新有据维度，其他学科保留未知；个人对象归属可核对 |
| Jane | 唯一身份、版本化通用规则、首批英语阅读与科学探究策略 | 本课绑定的方法与实际帮助、纠错可以对照 |
| 备课与内容 | 从需求生成任务、材料、题卡、帮助分支、教师简报和预览，保存核验与固定依赖 | 备课完成与本次可开课分别给依据；修改能定位实际版本 |
| 课堂 | 30分钟预算，回顾与目标、自然回答、澄清、帮助、纠错再试、指认、离屏及收尾 | 回应按当前等待对象接续；原答、帮助和新尝试分别保留；暂停/停止可用 |
| 课后 | 结束封存、反馈追加、更正、任务评价、课堂与备课对照、下节候选建议 | 关闭再打开后能读已封存事实；评价失败不损坏事实 |
| 协调与维护 | 操作身份、分步保存、有限接续、版本冲突、验收报告、导出及备份恢复 | 重发不重复计活动，失败后知道继续哪一步，恢复有实际依据 |
| 计划复盘 | 周、阶段、年度共用简版复盘流程，重大变化形成具体方案 | 到期只产生待办，家长发起；有据常规调整与待决定内容分开 |

全学科数据结构从首轮实现建立，具体目录先细化首课需要的英语与科学维度。复盘机制在成人验收前用虚构历史验证，不等待真实使用满一年。学习者隔离从数据与接口建立，多孩子界面后续扩展。

## 首个课程范围

首批采用英语阅读结合纸桥科学探究的课程模板，主辅目标明确，起点观察和帮助后表现分别取样。现有纸桥材料可作为编制来源，正式采用前核对需求、难度、事实、题意、合理变式和分级帮助；外部阅读测评只作选材参考，不给自编故事冒标官方蓝思等级。

课前准备文字、题卡、简单图示与示范音频，并核验出现阶段、答案泄露风险和备用。课堂可在已核验范围内调整措辞与支持；复杂图片、视频及课堂即时生成列入扩展。示范音频的存在不表示应在独立观察前播放。

观察、新授和复习可先共用受限模板与不同分支。实现首个模板时仍按任务与事件合同组织，避免将纸桥题目或固定答案写进通用控制器。

## 使用资格与后续扩展

阶段4完成后形成绑定范围的成人可用版；进入家长陪伴的儿童试教需满足[试教前提](acceptance.md#进入儿童试教的前提)。第一次试教完成后仍需观察真实难度、独立表现、家庭投入与后续保持，不能将技术闭环称为长期教学有效。

后续按反馈增加其他学科、课型和素材，再考虑多学习者界面、多设备、手机/桌面安装包、远程同步、大规模资料检索和复杂排程。首版不建设这些能力，也不接入多Agent调度；必要扩展通过现有合同接入。

当前实现状态、真实资料权威和迁入边界统一见[共同入口](../design/shared/README.md)。本范围不授权迁移真实资料或直接开课。

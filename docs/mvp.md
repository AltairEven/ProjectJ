# Project J 最小可用版本

版本：2.0.0；更新：2026年10月20日；状态：范围按[ADR-0018](../decisions/ADR-0018.md)改为AI自学助理，按[实施计划](superpowers/plans/2026-10-20-self-study-assistant.md)实现中。

首个可用版本在当前电脑上，由学生本人完成建档，并循环完成“备课 → 上课 → 评价认可 → 下一课”。以[E2E01](../design/shared/end-to-end-cases.md#e2e01-正常完成与下一课准备)贯穿八模块和应用协调层（阅读时按[术语规则](../design/shared/README.md#术语规则)），每个模块先提供支撑这条闭环的最小能力。

范围由本文件维护，[技术选型](technology.md)说明实现基线，[开发路线](roadmap.md)维护顺序与阶段交付，[验收标准](acceptance.md)维护质量口径。业务含义继续服从[共同规范](../design/shared/README.md)，阻断采用[共同标准](../design/shared/business-contracts.md#关键阻断的共同标准)。

## 使用形态与完成标准

学生通过一个本机启动入口打开一个浏览器页面：左侧导航（主页、学习状态、学习计划、课程、课后评价、设置），主页只放一件“下一步”；课堂从课程进入并全屏显示。本地保存不表示模型离线运行，模型能力仍取决于实际服务连接；发音评分与语音合成在本机运行。

完整交付包括：建档（学习资料、小测、首个目标）→ 需求D1 → 已核验课程C1与简报/素材 → 学生确认并开始 → 活动A1 → 结束事实F1 → 评价E1（可有补记或异议）→ 学生认可 → 状态/计划处理与需求D2（换目标经学生确认）→ 下一课程包C2。每个结果关联来源、版本与保存状态，沿用计划或状态无变化也返回有依据的结果。

仅展示下节建议不算闭环完成。C2必须实际采用D2，并能解释哪些任务、帮助或观察条件依据上一课结果作了调整，或为什么沿用。

## 首版能力

| 部分 | 首版交付 | 验收可见结果 |
| --- | --- | --- |
| 主页面 | 一个学生，一个页面；建档、下一步、各栏目与全屏课堂 | 任何时候主页只给一件该做的事；后台进行中的事与失败原因可见、可重试 |
| 学习管理 | 学习资料、全学科状态结构；长期方向、阶段计划、周安排与下一课需求 | 本课只更新有据维度，其他保留未知；换目标与新能力条目经学生确认 |
| Jane | 唯一身份、版本化通用规则与策略 | 本课绑定的方法与实际帮助、纠错可以对照 |
| 备课与内容 | 从需求生成任务、材料、帮助分支、教师简报与课程详情，修改意见改稿，确认后自动生成并采用资源 | 备课完成与本次可开课分别给依据 |
| 课堂 | 30分钟预算，回顾与目标、文字/点选作答、英语朗读录音评分、澄清、帮助、纠错再试、指认、离屏及收尾 | 原答、帮助和新尝试分别保留；暂停/停止可用 |
| 课后 | 结束封存、自动评价、补记与异议、认可、更正、下节候选建议 | 关闭再打开后能读已封存事实；评价失败不损坏事实 |
| 协调与维护 | 操作身份、分步保存、后台任务接续、版本冲突、导出、备份恢复与清空 | 重发不重复计活动，失败后知道继续哪一步 |
| 计划复盘 | 周、阶段、年度共用简版复盘，到期自动发起，重大变化形成具体方案 | 有据常规调整与待决定内容分开 |

## 首个课程范围

第一位使用者是用户本人，学英语。课程题型限于参考题集已覆盖的故事问答、指认/离屏实际报告与朗读评分段；故事按学习资料的蓝思值与兴趣选择或由备课模型新写，现有纸桥材料可复用。外部阅读测评只作选材参考，不给自编故事冒标官方蓝思等级。扩展题型需另批扩充参考题集。

## 后续扩展

后续按实际使用增加其他学科、课型和素材，再考虑多学习者、多设备、手机/桌面安装包与远程同步。首版不建设这些能力，也不接入多Agent调度；必要扩展通过现有合同接入。

当前实现状态与数据权威统一见[共同入口](../design/shared/README.md)。

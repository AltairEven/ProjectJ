## 最小版本质量门槛

以下门槛用于[分阶段实现](roadmap.md)，是待实际验证的目标，不是现有性能结果。检查环境、课程/配置、来源、样本数量、失败/未知及实际结果随报告保存。

| 维度 | 验收方法与通过条件 |
| --- | --- |
| 教学判断 | 使用事先核实的参考题集，覆盖正答、错答、合理变式、含糊、中文或中英混合作答（应提醒用英文）、两次求助和帮助后再试；逐项比对预期，必要样例未通过先修复/限制用途，不让同一模型的自评代替参考答案 |
| C2与计划采用 | 从E1追到S2或无变化、计划修订/沿用、D2及C2；能说明任务、帮助、观察条件的变化或沿用理由，不只返回一句建议 |
| 调用和用量 | 记录用途、触发、来源修订、实际配置、次数和可取得用量；正常反馈只走最终评价，封存/刷新不调评价模型，适用结果复用；必要重试和新依据另列 |
| 声音延迟 | 固定成人短答任务与实际设备/网络，测“说完至第一段有效教学回应实际首播”。起点是提交时刻（朗读为学生按结束或最长录音时长到期），见[输入提交规则](../design/interface/input-submission.md)与[ADR-0014](../decisions/ADR-0014.md)；终点是已批准回应的第一段声音实际开始播放。初始目标中位数不超过2.5秒、95%的轮次不超过5秒；提交送达、发音评分（朗读任务）、课堂判断、合成首段和播放分别计时保存，空泛等待语不算有效回应 |
| 超时与控制 | 普通短答自上述起点达到10秒仍无有效回应时进入明确失败或已核实备用，不继续无声等待；学生思考/离屏不套用这个响应超时。停止不等待该期限或模型返回，迟到结果不播放、不推进 |
| 保存与恢复 | 注入封存失败、保存成功但回执丢失、评价失败、状态成功但需求失败；原操作能核对/接续；已封存后重启可读，数据库及素材备份可恢复到一致范围 |
| 学生负担 | 学生可完成建档、确认、开始、认可评价和查看调整，无需抄日志、填写能力等级或逐句推动；页面能区分保存、评价、实际更新和待处理 |

教学判断的参考题集固定在courses/paper-bridge/judgment-reference.json（成人编写的虚构作答，预期逐句核对原文），用project-j-judge-reference运行，检查的是课堂判断这套配置而不是某一课。1.1.0（2026年10月21日）在原37题上补开放问答13题（复述与谈看法：正答、换说法、中文、中英混合、与故事矛盾、太短、含糊、求助、帮助后再答、离题），原题与预期未改。2.0.0（2026年10月22日，[ADR-0021](../decisions/ADR-0021.md)）随全英文改版：原中文与中英混合作答的预期改为“含糊并提醒用英文”，补英文小错、英文“不懂题”的求助与中文报告等题，共54题。2.1.0（2026年10月28日，[ADR-0028](../decisions/ADR-0028.md)）随朗读改为核心按评分比例判定：只标一个词的两道朗读题预期改为通过（仍须点出该词），新增标出6个词的不通过题，共55题。2.2.0（2026年11月16日）随“精确问答的回答带多余内容判不正确”：新增4题（答案句之外多抄一句、抄整段，预期不正确）与2题对照（先答再引原文、复述题目里已有的事加全部依据，预期正确），共61题，原题与预期未改。2.3.0（2026年11月19日）随“题目要求用某词或某种形式而回答没用到、或那个词形式用错判不正确”：新增courses/judgment-forms下知识页与对话两篇固定材料（只供题集使用，不进课程库）与7道题，补练习要求9题、知识页事实与三要点解释、对话“谁说的／答了什么”，共31题、全套92题；作答与预期由开发代理起草并逐条复核，用户委托开发代理确认，原题与预期未改。2.3.1（同日首轮真实运行后）改正两处出题缺陷：K2-wrong-content的禁止词原是题目原文（复述题目不算泄露），talk-who的依据补上旁白一句（否则模型无法核对用角色称呼的回答）；作答与预期未改。题集自检新增一条：禁止词不得出现在题目里。按ADR-0020，选择、排序、配对、填空由程序判定，不经课堂判断模型，不需要参考题集。何时运用：

- 必须重跑（不改题）：课堂判断的模型、档位或服务层级变化；课堂判断指令或请求上下文字段变化；模型适配器或SDK升级。重跑通过前，变化后的配置不用于正式学习。整套重跑中个别题因超时等调用失败不通过时，可用`--case`只补跑这些题，每题补跑一次通过即算该题通过（2026年11月19日用户决定，原为不少于5次且全部通过；仍超时可再补跑）；判错（标签或回应不合预期）不靠补跑抵消，先查原因。整套报告与补跑报告一起作为依据。也可在设置页由用户确认后运行整套与补跑（[ADR-0032](../decisions/ADR-0032.md)），规则相同；页面与开课处显示当前配置的题集状态，未通过只提示、不拦开课。
- 必须补题：课程出现新题型或新学科（如开放式解释、数学计算、中文阅读、科学实验报告），先补该类题并重跑，通过后才在课堂使用该类题；实际上课发现的判错补成新题。补题只增不改，已有题的预期只在原文依据被证明理解错时修订并记录理由。
- 不需要：每次备课、每节新课。新课的参考答案、已知错答和帮助由备课核验逐课负责；备课模型生成的检查样例只能作补充，不能代替题集。

阶段0确定代表性短答样本清单、数量和测量办法，阶段3在相同口径下复测；包含失败和超时的比例，不能删掉慢轮次后宣称达标。服务商性能会变，固定版本和实际结果决定采用范围。阈值如需调整，记录理由并复核体验，不能事后改门槛掩盖失败。

学生思考、打字与朗读暂停的时间不计入延迟，起点固定为提交或按结束时刻；不能改以提交送达、判断开始或评分完成为起点来达标。所用服务层级作为测量变量记录；更高价格的层级是否采用由用户按实际成本决定，不为达标静默切换。

课中只保留自身互动所需计时与事件于内存，结束后整理；验收不增加监控、截屏或原始录音归档。普通短答指标不代表30分钟整体节奏，后者由完整流程与实际使用另评。

## 进入儿童试教的前提

本节已由[ADR-0018](../decisions/ADR-0018.md)取消：程序不再区分孩子与成人，也没有家长陪伴试教阶段；标题保留供历史文档引用。

## 正式学习空间

正式学习用`project_j/scripts/start.sh --study --run-id <id>`启动（真实模型、本机评分与本机合成，数据写`project_j/private/study/<run_id>`）。开发期间清空某个运行编号的全部学习记录用`project-j-reset --run-id <id>`（需输入运行编号确认，服务运行时不要执行）。开发中的真实核对使用单独的运行编号，结束后清空，不写入用户的正式学习记录。程序检查只在模拟空间进行，不能当作正式学习的验收。

## 实际声音与正式使用

声音先单轮，再错误/求助/确认，最后完整流程；输入自动提交还需慢答、句中停顿和自己改口。响应时间分判断、合成首播和实际总等待，后台耗时不能替代听觉延迟。资格和相关变化统一按[验收管理](../design/application/acceptance.md)复核。

## P0固定短测样本与测量记录

此节细化上述质量门槛，不改变起点/终点/阈值。P0已经实现离线记录校验和统计，实际模型/声音样本均为0，不能称延迟通过；程序检查结果见[交接](handoff.md#进展)。

成人普通短答固定10种情形，每种4轮，预先登记40个身份S01—S10/trial1—4，不把多轮当儿童独立样本。使用同一课程、CFG/IS、网络、设备/声音和default服务层级；配置改变另立测量运行，不混入一组求分位数。

| 样本 | 固定输入/条件 |
| --- | --- |
| S01/S02/S03 | R1英文正答“a bridge”、中文“给车搭桥”（2.0.0起应提醒用英文）、合理变式“She wants to build a bridge for her toy car.” |
| S04/S05 | R1错答“a car”、含糊“that thing”，预期分别有据纠错/澄清 |
| S06/S07 | R2顺序正答“She folded it.”、错答“added books” |
| S08/S09 | 第一次/第二次求助“Help me”/“I still don't understand”（原“帮我一下”/“还是不懂”），预期不同已核验指导 |
| S10 | 实际句框交付后再答“a bridge”，保留初答/帮助和新尝试，回应不能冒称独立 |

参考任务/内容和预期唯一见[E2E01固定输入](../design/shared/end-to-end-cases.md#p0固定输入与阶段1预期)。慢答、自我改口/补充、朗读暂停后续读、忘按结束到最长时长、重录、评分异议与评分失败、播放中按麦克风、模型/评分/合成等待及播放中停止、离屏返回无报告作为单列控制/输入检查；每种至少2次（模拟与成人实际分别登记），不得用这些分支替代40轮普通短答或从普通样本里删慢轮。五分钟与30分钟保持独立关卡，短测不冒称已通过整课。

开始前固定CFG/IS/构建/参考题集摘要、账号项目的非秘密标签、模型/effort/实际服务层级、合成器的模型修订与声音配置、发音评分器的模型修订与门槛版本、录音格式、OS/浏览器/麦克风/扬声器、网络说明、UTC时间及成人来源；缺失项写未验证。朗读段最长录音时长在成人短测中核对，未验证的不启用正式课堂。

每轮记录同一客户端单调时钟上的提交（朗读为按结束）、正式送达、发音评分完成（朗读任务）、核心判断完成、合成首段抵达、批准有效回应实际首播，以及必要失败/备用事件时间。跨服务请求只把客户端发送/接收投影到该时钟，不能直接减不同服务器时钟。Web Audio的getOutputTimestamp提供输出帧时间映射，performanceTime仍是渲染时刻估计；记录映射方法、outputLatency及不确定范围，并由成人试听核对首段确实可听，不能只拿调度预测当实际首播。无法取得实际播放依据或不确定范围影响阈值判断时终点未知，不用下载首块/调用play()成功代替。口头“等等”不算有效回应。[输出时间戳](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp)、[输出延迟](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/outputLatency)

总延迟=实际首播−提交时刻（朗读为按结束时刻）。记录阶段耗时与重叠，不能简单相加重复计时；预合成语句直接播放时合成首段不另计。中位数取全体轮次；P95使用nearest-rank的第ceil(0.95×N)轮，并另报五秒内比例。失败、超时、未知和只有等待语的轮次按无有效回应保留在分母及最慢端，分位数落入这些轮次就记未取得，不填零。达到十秒的轮次必须有十秒内明确失败或核实备用的实际事件；停止另查优先控制与迟到丢弃，不等待期限。

课中计时只在互动所需内存。成人短测结束并固定边界后才能整理到private/adult_checks；不存原始录音或截屏。示例JSON明确标simulated，分析输出永不自动授予使用资格。当前没有实际语音连接/浏览器测量实现，首播与打断采证仍待接入条件具备后的独立短验证。

## P1统一工程检查

主实现者完成隔离工程后统一运行锁定同步、依赖审计、Ruff、Python导出的接口类型生成、前端类型/构建、本地文档及临时库pytest。检查产物绑定源码、测试/固定输入、课程和工程配置摘要，标记simulation_only/not_granted；更改工程使旧依据失效。它只允许虚构模拟入口，不能转作真实API、声音、成人时长或儿童用途报告。

模拟时钟推进检查27分钟收尾边界与30分钟未确认结束（2026年10月21日起按ADR-0020改为检查超过30分钟仍继续下一题、可手动收尾），仅证明程序分支，不是实际30分钟体验；模拟识别信号和文字DOM交付也不证明任何声音延迟门槛。P1-R2修复与自测覆盖控制回执乱序、沿用S后D失败及较新证据、复核步骤完成回执丢失、受限依赖备课/开课与合法解除；P1-R3补测两套模板的完整句框答复及错阶段确认拒绝，确认不产生作答或取消在途判断。固定模拟答案集仍不是自然语义模型，未列表达可保持未知；真实模型语义另行验证。研发协作按[共建规则](../AGENTS.md#共建协作)执行，不要求模型互审，不降低上述测试和真实用途验收条件。历史审查、检查结果、调试入口与未验证项见[交接](handoff.md)。

# Project J 验收标准

版本：1.1.0；更新：2026年10月11日。

应用可靠性与教学效果分别验收。开发测试、真实API、真实声音、成人完整课堂和儿童真实学习是不同层次；未做保持未验收。

| 层次 | 必须确认的行为 | 0.1范围 |
| --- | --- | --- |
| 内容结构 | 目标、任务、依据、预算、帮助、转场、素材存在且一致 | 自动检查 |
| 教学内容 | 阅读难度、题意、可接受表达、纠错与独立条件适合当前课程 | 待内容审阅，模型意见只是辅助 |
| 课堂程序 | 目标确认进入固定R1，按题推进，初答保留，帮助改变，离屏及正常收尾确认 | 开发模拟 |
| 故障 | 模型失败不推进、过期事件拒绝、停止不等待判断、迟到音频不播、进程中断不造记录 | 程序测试与浏览器检查；声音效果另测 |
| 模型接口 | 实际Low判断、Medium审阅与评价，正确/错误/合理变式/含糊样本 | 未实际接入 |
| 真实语音 | 中英文清晰、转写可核对、逐轮等待、取消有效、响应时间可接受 | 未实际接入 |
| 成人完整流程 | 正答、故意错答、两次求助、动作、离屏报告、目标和小结确认均闭环 | 待实际演练；五分钟不证明30分钟 |
| 儿童试教 | 家长陪伴、明确就绪及备用，原答/帮助/体验完整，课后调整可解释 | 当前入口不提供 |
| 教学效果 | 独立尝试、延迟保持、新情境应用及家庭负担 | 只能依据后续实际反馈 |

建议真实语音先单轮，再验证故意错误和求助，最后完整成人课程；每个关卡保持原范围，不重复无关测速。响应时间分转写、判断、语音首播与总等待，不能把后台耗时称实际听觉延迟。

正式入口开放前，需要可信的验收报告与运行配置绑定；不能只手改readiness布尔值。当前代码即使改课程就绪字段也不提供儿童模式，后续发布须连同验收实现与检查一起修改。

## 学习管理设计与未来验收

[学习管理设计](../design/learning/README.md)规定孩子档案、全学科能力状态、长期与短期计划、课后更新和备课/评价交接。其[场景清单](../design/learning/handoffs.md)是未来实现的验收要求，包括全学科扩展、帮助分维度、同次反馈更正不重复计样本、未知与旧证据、版本变化、决策权限和来源切换。

本轮只可检查设计职责、规则与引用是否一致；该模块尚未实现，不能把文档齐备或原型回归检查通过称为学习管理功能通过。后续实现需使用明确模拟来源验证这些场景，真实儿童学习效果仍需另行观察。

| 层次 | 必须确认的行为 |
| --- | --- |

| 模型接口 | 实际Low判断、Medium审阅与评价，正确/错误/合理变式/含糊样本 |
| 真实语音 | 中英文清晰、转写可核对、逐轮等待、取消有效、响应时间可接受 |
| 成人完整流程 | 正答、故意错答、两次求助、动作、离屏报告、目标和小结确认均闭环 |
| 儿童试教 | 家长陪伴、明确就绪及备用，原答/帮助/体验完整，课后调整可解释 |
| 教学效果 | 独立尝试、延迟保持、新情境应用及家庭负担 |

## 最小版本质量门槛

以下门槛用于[分阶段实现](roadmap.md)，是待实际验证的目标，不是现有性能结果。检查环境、课程/配置、来源、样本数量、失败/未知及实际结果随报告保存。

| 维度 | 验收方法与通过条件 |
| --- | --- |
| 教学判断 | 使用事先核实的参考题集，覆盖正答、错答、合理变式、含糊、中英表达、两次求助和帮助后再试；逐项比对预期，必要样例未通过先修复/限制用途，不让同一模型的自评代替参考答案 |
| C2与计划采用 | 从E1追到S2或无变化、计划修订/沿用、D2及C2；能说明任务、帮助、观察条件的变化或沿用理由，不只返回一句建议 |
| 调用和用量 | 记录用途、触发、来源修订、实际配置、次数和可取得用量；正常反馈只走最终评价，封存/刷新不调评价模型，适用结果复用；必要重试和新依据另列 |
| 声音延迟 | 固定成人短答任务与实际设备/网络，测“说完至第一段有效教学回应实际首播”。起点是客户端VAD判定语音结束，即[输入提交规则](../design/interface/input-submission.md)中的候选结束时刻；终点是已批准回应的第一段声音实际开始播放。初始目标中位数不超过2.5秒、95%的轮次不超过5秒；停顿窗口、最终转写、核心判断、合成首段和播放分别计时保存，停顿窗口计入总时长不扣除，空泛等待语不算有效回应 |
| 超时与控制 | 普通短答自上述起点达到10秒仍无有效回应时进入明确失败或已核实备用，不继续无声等待；孩子思考/离屏不套用这个响应超时。停止不等待该期限或模型返回，迟到结果不播放、不推进 |
| 保存与恢复 | 注入封存失败、保存成功但回执丢失、评价失败、状态成功但需求失败；原操作能核对/接续；已封存后重启可读，数据库及素材备份可恢复到一致范围 |
| 家长负担 | 家长可完成预览、开始、一次反馈和查看调整，无需抄日志、填写能力等级或逐句推动；报告能区分保存、评价、实际更新和待处理 |

阶段0确定代表性短答样本清单、数量和测量办法，阶段3在相同口径下复测；包含失败和超时的比例，不能删掉慢轮次后宣称达标。服务商性能会变，固定版本和实际结果决定采用范围。阈值如需调整，记录理由并复核体验，不能事后改门槛掩盖失败。

停顿窗口与延迟目标相互约束：为照顾慢答加长窗口时，在同一起点口径下复测并说明体验取舍，不能改以提交时刻为起点来达标。所用服务层级作为测量变量记录；更高价格的层级是否采用由家长按实际成本决定，不为达标静默切换。

课中只保留自身互动所需计时与事件于内存，结束后整理；验收不增加儿童监控、截屏或原始录音归档。普通短答指标不代表30分钟整体节奏，后者由成人完整流程及实际试教另评。

## 进入儿童试教的前提

进入[路线阶段5](roadmap.md)前，下列依据须对同一采用范围成立；应用协调层汇总报告，classroom仍执行本次启动判定。停止、数据和版本等阻断按[共同标准](../design/shared/business-contracts.md#关键阻断的共同标准)处理，家长开始不能覆盖失败。

| 前提 | 必须取得的依据 |
| --- | --- |
| 成人完整验收 | 阶段1至4适用检查通过，五分钟分支和30分钟完整体验各有证据；报告绑定构建、课程、Jane、模型、输入策略、设备及有效范围 |
| 内容和课堂适配 | 本课需求、材料难度、事实/题意/评价、分级帮助/再试、离屏、预算及备用已核验；备课完成与当前实物/时间/陪伴条件分别成立 |
| 实际接口与数据条件 | 对实际账户、项目、模型、接口及发送范围核对[儿童数据条件](../design/platform/configuration-permissions.md#儿童数据处理条件)，包含适用零数据保留资格；store=false、匿名标签、家长陪伴不代替服务条件 |
| 最小真实资料接入 | [数据切换](../design/shared/execution-recovery.md#家庭数据权威的阶段切换)已明确具体采用范围、来源/日期/修订映射、待处理冲突与唯一写入入口；家长采用该具体范围，旧历史保持可回查 |
| 本地维护与权限 | 封存/反馈/更正及失败接续、导出和备份恢复有验证；私有数据与成人测试/Git分离，学生只能取得当前允许材料，凭据不进入浏览器普通配置或导出 |
| 本次明确开始 | 家长了解当前范围与备用、全程陪伴并明确开始；孩子能暂停/停止，界面提供适龄AI说明与课程内容防护 |

数据条件在阶段0先核对，未具备时保持儿童真实数据入口关闭，可继续成人/虚构来源开发。具体要求的权威说明在平台配置文档，相关服务变化时复核，不以早期一次查询永久放行。

首次试教前不要求已经证明长期教学效果。首次真实闭环后检查难度、独立与帮助后表现、评价忠实性和家庭负担；后续保持/迁移需新证据。试教发现有据缺陷时收缩相关用途，保留已发生事实，再按对应模块修复。

## 实际声音与试教

声音先单轮，再错误/求助/确认，最后完整成人流程；输入自动提交还需慢答、句中停顿和自己改口。响应时间分识别、判断、合成首播和实际总等待，后台耗时不能替代听觉延迟。

试教采用上节前提；正式入口消费已保存且范围匹配的报告，不直接信任手改ready标记。五分钟、30分钟、不同设备/入口及来源分别报告，资格和相关变化统一按[验收管理](../design/application/acceptance.md)复核。

## P0固定短测样本与测量记录

此节细化上述质量门槛，不改变起点/终点/阈值。P0已经实现离线记录校验和统计，实际模型/声音样本均为0，不能称延迟通过；程序检查结果见[交接](handoff.md#进展)。

成人普通短答固定10种情形，每种4轮，预先登记40个身份S01—S10/trial1—4，不把多轮当儿童独立样本。使用同一课程、CFG/IS、网络、设备/声音和default服务层级；配置改变另立测量运行，不混入一组求分位数。

| 样本 | 固定输入/条件 |
| --- | --- |
| S01/S02/S03 | R1英文正答“a bridge”、中文“给车搭桥”、合理变式“She wants to build a bridge for her toy car.” |
| S04/S05 | R1错答“a car”、含糊“that thing”，预期分别有据纠错/澄清 |
| S06/S07 | R2顺序正答“She folded it.”、错答“added books” |
| S08/S09 | 第一次/第二次求助“帮我一下”/“还是不懂”，预期不同已核验指导 |
| S10 | 实际句框交付后再答“a bridge”，保留初答/帮助和新尝试，回应不能冒称独立 |

参考任务/内容和预期唯一见[E2E01固定输入](../design/shared/end-to-end-cases.md#p0固定输入与阶段1预期)。慢答、句中停顿续说、自我改口/补充、最终识别迟到/修订、教师回声、模型/合成等待及播放中停止、离屏返回无报告作为单列控制/输入检查；每种至少2次（模拟与成人实际分别登记），不得用这些分支替代40轮普通短答或从普通样本里删慢轮。五分钟与30分钟保持独立关卡，短测不冒称已通过整课。

开始前固定CFG/IS/构建/参考题集摘要、账号项目的非秘密标签、模型/effort/实际服务层级、转写/合成端点/声音、OS/浏览器/麦克风/扬声器、网络说明、UTC时间及成人来源；缺失项写未验证。普通语音自动策略的停顿窗口先在成人短测中比较，例如短答600ms/1000ms、解释1200ms/1800ms，都是待验证变量；慢答/暂停窗口与延迟一起验，未验自动策略不启用正式课堂。识别delay与教学reasoning.effort是不同参数，分别核对。

每轮记录同一客户端单调时钟上的候选结束、窗口到期、最终转写取得、正式提交、核心判断完成、合成首段抵达、批准有效回应实际首播，以及必要失败/备用事件时间。跨服务请求只把客户端发送/接收投影到该时钟，不能直接减不同服务器时钟；ASR最终可能先于窗口到期，两条件齐后才提交。Web Audio的getOutputTimestamp提供输出帧时间映射，performanceTime仍是渲染时刻估计；记录映射方法、outputLatency及不确定范围，并由成人试听核对首段确实可听，不能只拿调度预测当实际首播。无法取得实际播放依据或不确定范围影响阈值判断时终点未知，不用下载首块/调用play()成功代替。口头“等等”不算有效回应。[输出时间戳](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp)、[输出延迟](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/outputLatency)

总延迟=实际首播−候选结束，停顿窗口不扣除。记录阶段耗时与重叠（识别和窗口可并行），不能简单相加重复计时。中位数取全体轮次；P95使用nearest-rank的第ceil(0.95×N)轮，并另报五秒内比例。失败、超时、未知和只有等待语的轮次按无有效回应保留在分母及最慢端，分位数落入这些轮次就记未取得，不填零。达到十秒的轮次必须有十秒内明确失败或核实备用的实际事件；停止另查优先控制与迟到丢弃，不等待期限。

课中计时只在互动所需内存。成人短测结束并固定边界后才能整理到private/adult_checks；不存原始录音或截屏。示例JSON明确标simulated，分析输出永不自动授予使用资格。当前没有实际语音连接/浏览器测量实现，首播与打断采证仍待接入条件具备后的独立短验证。

## P1统一工程检查

主实现者完成隔离工程后统一运行锁定同步、依赖审计、Ruff、Python导出的接口类型生成、前端类型/构建、本地文档及临时库pytest。检查产物绑定源码、测试/固定输入、课程和工程配置摘要，标记simulation_only/not_granted；更改工程使旧依据失效。它只允许虚构模拟入口，不能转作真实API、声音、成人时长或儿童用途报告。

模拟时钟推进检查27分钟收尾边界与30分钟未确认结束，仅证明程序分支，不是实际30分钟体验；模拟识别信号和文字DOM交付也不证明任何声音延迟门槛。P1-R2修复与自测覆盖控制回执乱序、沿用S后D失败及较新证据、复核步骤完成回执丢失、受限依赖备课/开课与合法解除；研发协作按[共建规则](../AGENTS.md#共建协作)执行，不要求模型互审，不降低上述测试和真实用途验收条件。历史审查、检查结果、调试入口与未验证项见[交接](handoff.md)。

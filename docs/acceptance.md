# Project J 验收标准

版本：1.5.0；更新：2026年10月12日。

应用可靠性与教学效果分别验收。开发测试、真实API、真实声音、成人完整课堂和儿童真实学习是不同层次；未做保持未验收。

| 层次 | 必须确认的行为 | 0.1范围 |
| --- | --- | --- |
| 内容结构 | 目标、任务、依据、预算、帮助、转场、素材存在且一致 | 自动检查 |
| 教学内容 | 阅读难度、题意、可接受表达、纠错与独立条件适合当前课程 | 待内容审阅，模型意见只是辅助 |
| 课堂程序 | 目标确认进入固定R1，按题推进，初答保留，帮助改变，离屏及正常收尾确认 | 开发模拟 |
| 故障 | 模型失败不推进、过期事件拒绝、停止不等待判断、迟到音频不播、进程中断不造记录 | 程序测试与浏览器检查；声音效果另测 |
| 模型接口 | 实际Low判断、Medium审阅与评价，正确/错误/合理变式/含糊样本 | 未实际接入 |
| 真实语音 | 中英文清晰、转写可核对、逐轮等待、取消有效、响应时间可接受 | 未实际接入 |
| 成人完整流程 | 正答、故意错答、两次求助、动作、离屏报告、目标和小结确认均闭环 | 待实际演练；五分钟不证明30分钟 |
| 儿童试教 | 家长陪伴、明确就绪及备用，原答/帮助/体验完整，课后调整可解释 | 当前入口不提供 |
| 教学效果 | 独立尝试、延迟保持、新情境应用及家庭负担 | 只能依据后续实际反馈 |

建议真实语音先单轮，再验证故意错误和求助，最后完整成人课程；每个关卡保持原范围，不重复无关测速。响应时间分转写、判断、语音首播与总等待，不能把后台耗时称实际听觉延迟。

正式入口开放前，需要可信的验收报告与运行配置绑定；不能只手改readiness布尔值。当前代码即使改课程就绪字段也不提供儿童模式，后续发布须连同验收实现与检查一起修改。

## 学习管理设计与未来验收

[学习管理设计](../design/learning/README.md)规定孩子档案、全学科能力状态、长期与短期计划、课后更新和备课/评价交接。其[场景清单](../design/learning/handoffs.md)是未来实现的验收要求，包括全学科扩展、帮助分维度、同次反馈更正不重复计样本、未知与旧证据、版本变化、决策权限和来源切换。

本轮只可检查设计职责、规则与引用是否一致；该模块尚未实现，不能把文档齐备或原型回归检查通过称为学习管理功能通过。后续实现需使用明确模拟来源验证这些场景，真实儿童学习效果仍需另行观察。

## Jane教师设计与未来验收

[teacher设计](../design/teacher/README.md)规定Jane唯一身份、通用规则、学科/课型策略、反馈迭代和版本管理。[交接与场景](../design/teacher/handoffs.md)要求检查身份连续、观察/教学边界、重复求助换实际指导、纠错与再试、未知和停止、版本绑定，以及学生状态与教学改进责任分离。

本轮只有文档检查，没有接入或执行该模块。以后按内容、程序、实际声音、成人流程和真实儿童学习分层验证；检查或启用某方法只能说明其指定使用范围，不能证明长期效果。Jane的改进同时观察独立理解/应用、保持与迁移、参与体验和家庭投入，不只追求顺畅或完成量。

## 备课生产与两层就绪的未来验收

[备课设计](../design/preparation/README.md)规定需求/状态/Jane策略到课程、素材、简报、核验与预览的流程；[核验分层](../design/preparation/verification.md)与[就绪场景](../design/preparation/readiness.md)要求检查实际产物、题目/答案/媒体一致性、帮助换法、观察不泄露、声音未核实、备用、版本变更和保存缺口。

备课完成与当前可以开课分别验收，家长预览不替代内容或运行证据。生成请求/脚本不表示素材存在，后台文本不表示声音可用；课堂补充生成按用途检查后呈现，未核验内容不能计独立依据。变更检查复用须覆盖实际版本和条件，成人五分钟通过不自动证明30分钟或儿童效果。

本轮仅检查设计职责、格式和引用，未实现生成/生产/就绪系统，不通过修改现有原型标记开放儿童入口。未来实际验收需对应这些场景及相关层次，不能用本轮回归测试冒称功能已通过。

## 课程内容库与历史更正的未来验收

[课程模块](../design/curriculum/README.md)定义分层组织、固定版本与依赖、独立生命周期/就绪/使用关系、条件复用与阶段呈现。[交接场景](../design/curriculum/handoffs.md)需验证同版本多次使用、同名任务区分、固定候选未核验、熟悉材料、外部资源失效、学生答案隔离、现场素材缺失及已知错误回查。

固定或本地发布不自动表示备课完成/当前可开课，使用过不将课程永久完成；归档保留历史必需依赖，更正不覆盖原答、不重复计样本或回放旧事件。评价和learning按实际来源重审受影响结论，不只修改未来答案。

本轮仅文档，没有实现检索、发布、呈现、保存或更正系统，也没有执行上述场景。现有原型回归通过仅说明原有代码检查，不证明内容库功能、声音或教学效果已验收。

## 课堂核心与交互分离的未来验收

[课堂设计](../design/classroom/README.md)及[交接场景](../design/classroom/closing-handoffs.md)要求验证统一输入/动作/交付反馈、不同入口能力匹配、自然回答持续接续、原答/识别更正、帮助换法/纠错再试、指认与离屏、预算、正常收尾/未确认/停止及中断。

interface不自建评分或转场，platform技术成功不代表学生收到/理解。事件重发和真实相同回答区分，迟到结果不推进/呈现，停止不依赖教学模型；替代媒介保留实际评价条件，转写不评发音，未做不补造。必要内存结束且家长反馈后一次整理，进程丢失不声称完整恢复。

本轮只文档，未实现统一交接、入口适配或新版执行，未做实际声音/演练。现有原型回归不能替代新场景；单轮、五分钟、30分钟、儿童课堂与效果分层报告，儿童入口仍未开放。

| 真实语音 | 中英文清晰、转写可核对、逐轮等待、取消有效、响应时间可接受 | 未实际接入 |
| 成人完整流程 | 正答、故意错答、两次求助、动作、离屏报告、目标和小结确认均闭环 | 待实际演练；五分钟不证明30分钟 |
| 儿童试教 | 家长陪伴、明确就绪及备用，原答/帮助/体验完整，课后调整可解释 | 当前入口不提供 |

## 最小版本质量门槛

以下门槛用于[分阶段实现](roadmap.md)，是待实际验证的目标，不是现有性能结果。检查环境、课程/配置、来源、样本数量、失败/未知及实际结果随报告保存。

| 维度 | 验收方法与通过条件 |
| --- | --- |
| 教学判断 | 使用事先核实的参考题集，覆盖正答、错答、合理变式、含糊、中英表达、两次求助和帮助后再试；逐项比对预期，必要样例未通过先修复/限制用途，不让同一模型的自评代替参考答案 |
| C2与计划采用 | 从E1追到S2或无变化、计划修订/沿用、D2及C2；能说明任务、帮助、观察条件的变化或沿用理由，不只返回一句建议 |
| 调用和用量 | 记录用途、触发、来源修订、实际配置、次数和可取得用量；正常反馈只走最终评价，封存/刷新不调评价模型，适用结果复用；必要重试和新依据另列 |
| 声音延迟 | 固定成人短答任务与实际设备/网络，测“说完至第一段有效教学回应实际首播”：初始目标中位数不超过2.5秒、95%的轮次不超过5秒；识别/判断/合成后台耗时分别保留，空泛等待语不算有效回应 |
| 超时与控制 | 普通短答达到10秒进入明确失败或已核实备用，不继续无声等待；孩子思考/离屏不套用这个响应超时。停止不等待该期限或模型返回，迟到结果不播放、不推进 |
| 保存与恢复 | 注入封存失败、保存成功但回执丢失、评价失败、状态成功但需求失败；原操作能核对/接续；已封存后重启可读，数据库及素材备份可恢复到一致范围 |
| 家长负担 | 家长可完成预览、开始、一次反馈和查看调整，无需抄日志、填写能力等级或逐句推动；报告能区分保存、评价、实际更新和待处理 |

阶段0确定代表性短答样本清单、数量和测量办法，阶段3在相同口径下复测；包含失败和超时的比例，不能删掉慢轮次后宣称达标。服务商性能会变，固定版本和实际结果决定采用范围。阈值如需调整，记录理由并复核体验，不能事后改门槛掩盖失败。

课中只保留自身互动所需计时与事件于内存，结束后整理；验收不增加儿童监控、截屏或原始录音归档。普通短答指标不代表30分钟整体节奏，后者由成人完整流程及实际试教另评。

## 进入儿童试教的前提

进入[路线阶段5](roadmap.md)前，下列依据须对同一采用范围成立；应用协调层汇总报告，classroom仍执行本次启动判定。停止、数据和版本等阻断按[共同标准](../design/shared/business-contracts.md#关键阻断的共同标准)处理，家长开始不能覆盖失败。

| 前提 | 必须取得的依据 |
| --- | --- |
| 成人完整验收 | 阶段1至4适用检查通过，五分钟分支和30分钟完整体验各有证据；报告绑定构建、课程、Jane、模型、输入策略、设备及有效范围 |
| 内容和课堂适配 | 本课需求、材料难度、事实/题意/评价、分级帮助/再试、离屏、预算及备用已核验；备课完成与当前实物/时间/陪伴条件分别成立 |
| 实际接口与数据条件 | 对实际账户、项目、模型、接口及发送范围核对[儿童数据条件](../design/platform/configuration-permissions.md#儿童数据处理条件)，包含适用零数据保留资格；store=false、匿名标签、家长陪伴不代替服务条件 |
| 最小真实资料接入 | [数据切换](../design/shared/execution-recovery.md#家庭数据权威的阶段切换)已明确具体采用范围、来源/日期/修订映射、待处理冲突与唯一写入入口；家长采用该具体范围，旧历史保持可回查 |
| 本地维护与权限 | 封存/反馈/更正及失败接续、导出和备份恢复有验证；私有数据与成人测试/Git分离，学生只能取得当前允许材料，凭据不进入浏览器普通配置或导出 |
| 本次明确开始 | 家长了解当前范围与备用、全程陪伴并明确开始；孩子能暂停/停止，界面提供适龄AI说明与课程内容防护 |

数据条件在阶段0先核对，未具备时保持儿童真实数据入口关闭，可继续成人/虚构来源开发。具体要求的权威说明在平台配置文档，相关服务变化时复核，不以早期一次查询永久放行。

首次试教前不要求已经证明长期教学效果。首次真实闭环后检查难度、独立与帮助后表现、评价忠实性和家庭负担；后续保持/迁移需新证据。试教发现有据缺陷时收缩相关用途，保留已发生事实，再按对应模块修复。

## 实际声音与试教

声音先单轮，再错误/求助/确认，最后完整成人流程；输入自动提交还需慢答、句中停顿和自己改口。响应时间分识别、判断、合成首播和实际总等待，后台耗时不能替代听觉延迟。

试教采用上节前提；正式入口消费已保存且范围匹配的报告，不直接信任手改ready标记。五分钟、30分钟、不同设备/入口及来源分别报告，资格和相关变化统一按[验收管理](../design/application/acceptance.md)复核。

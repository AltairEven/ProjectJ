# 与 LearningWithAI 的关系

版本：1.1.0；更新：2026年10月12日。

家长决定在同级目录J建立独立教学应用。当前设计与成人实验阶段的家庭规划、档案、课程历史和检查仍在LearningWithAI；本阶段如产生真实反馈也在原权威入口接续。正式接入后的权威按下方切换条件确定。既有记录不删除、不改写，也不全部复制到应用源码。

0.1只导入首课L-C2026-01-001／1.9.0的三篇自编原材料，保留原字节、旧版本和SHA256，重新编成J-PAPER-BRIDGE-001／0.1.0。任务、帮助、顺序与归档改成应用合同，因此不是原教案的无变化复制。旧成人检查通过或失败的结论不能替代新应用验收。

本应用的lesson.json管理执行内容；原项目课程是历史及家庭规划参照。后续编辑应明确选择新应用课程版本，不同时改两个权威副本。应用导出与旧项目记录导入需要独立适配，当前不自动回写。

未导入出生年月、性别、学籍、学习状态或成人完整转写。阅读参考219L和RAZ H的条件在原档案维护，不把自编故事标为219L或H。

迁移后保留：一个主要目标与辅助目标、分维度难度、先尝试、真实帮助、未知、离屏、停止、课后一次反馈及成人/儿童分离。每堂课一个新应用会话承担上下文隔离；Codex仍用于开发、备课与整理，不再作为必须的课堂语音转交层。

## 正式接入目标与切换条件

按[共同执行设计](../design/shared/execution-recovery.md)，正式接入目标为J管理接入后的新状态/计划和真实记录，LearningWithAI作为只读历史来源。切换前明确最小档案/状态/计划及必要证据、来源身份/日期/修订映射和可获取性，处理未完成事项/冲突，确认唯一写入入口与切换边界，并取得实际数据条件、功能验收和具体范围采用。

这是设计目标，不表示当前切换或迁移已发生。当前旧项目仍维护家庭真实档案与历史，J不自动导入/双写或把成人检查转儿童证据；原历史及更正保留，具体适配/迁移操作另行授权与验证。对应[端到端案例](../design/shared/end-to-end-cases.md)仅模拟方案，未执行。
